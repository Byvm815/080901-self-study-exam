# 第一章 绪论 · 考前简记（关键词版）


**数据结构 = 逻辑结构 + 存储结构 + 运算（三要素）**
**4 类逻辑结构**：集合（无关系）· 线性（1:1）· 树（1:n）· 图（m:n）
**4 种存储方法**：顺序（连续、随机存取）· 链式（指针、顺序存取）· 索引（索引表）· 散列（哈希函数算地址）
**关系**：逻辑=抽象（面向问题）；存储=实现（面向机器）；一种逻辑→多种存储；存储不同→操作实现与效率不同
**ADT** = 数学模型 + 其上的一组操作（只讲逻辑，与实现无关）
**术语**：数据 > 数据元素 > 数据项（数据项最小）；基本操作＝定义在逻辑结构上的运算

**算法 5 特性**：有穷 · 确定 · 可行 · 输入 · 输出
**问题规模 n**：输入量的度量
**时间复杂度**：基本操作执行次数 f(n) → T(n)=O(f(n))（只留最高阶、去系数）
**增长阶**：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
**空间复杂度**：辅助空间 S(n)=O(f(n))；原地算法 O(1)
**分析三步**：找基本操作 → 数频度 → 取最高阶去系数
**常用**：单层循环 O(n)｜双层 O(n²)｜折半/倍增 O(log n)｜分治排序 O(n log n)

**6 策略**：递推（初始值往前推）· 迭代（循环逼近）· 递归（自调用+出口）· 贪心（局部最优，不保证全局最优）· 分治（分—治—合）· 动态规划（重叠子问题+记表）
**贪心与分治常考**：哈夫曼/Prim/Kruskal/Dijkstra＝贪心；二分查找/快排/归并＝分治；Floyd/背包＝动态规划

**最爱考**：逻辑结构与存储结构的区别与联系；4 种存储方法及特点；ADT 定义；算法 5 特性；程序段时间复杂度分析（写频度、化简为 O）；递归与迭代的区别；分治/贪心/动规的适用与差别

# 第二章 线性表 · 考前简记（关键词版）

> 课程：13003 数据结构与算法（080901 自考）｜状态：✅ 已生成

## 一、定义与术语

**线性表**：n（≥0）个数据元素的**有限序列** (a₁,…,aₙ)；n=0 空表，n 为**表长**
**表头元素 a₁｜表尾元素 aₙ**
**直接前驱/直接后继**＝唯一且相邻；**前驱/后继**＝其前（后）的所有元素
**位置（序号）i**：元素逻辑次序（教材多从 1 开始 ⚠️）
**有序表**＝按关键字有序（可折半查找）；**无序表**＝未排序（只能顺序查找）
**特点**：有限 · 同类型 · 1:1（首无前驱、尾无后继）· 位置有序 · 元素可重复

**ADT 操作**：Init · Destroy · Empty · Length · GetElem(按位置取) · LocateElem(按值找) · PriorElem/NextElem · **Insert(1≤i≤n+1，表长+1)** · **Delete(1≤i≤n，表长−1)** · Traverse

## 二、顺序表（顺序存储）

**思想**：地址连续的单元依次存元素，逻辑相邻=物理相邻（逻辑关系隐含在物理连续性中）
**地址公式**：**LOC(aᵢ) = LOC(a₁) + (i−1) × L**（0 起：LOC(a[i]) = LOC(a[0]) + i×L）
**随机访问**：任一元素 O(1)，与位置无关
**表空**：length==0（删除判空，否则**下溢**）｜**表满**：length==maxSize（插入判满，否则**上溢**）

| 操作 | 移动比较次数 | 复杂度 |
|---|---|---|
| 插入 | 最好 0 / 最坏 n / **平均 n/2** | O(n) |
| 删除 | 最好 0 / 最坏 n−1 / **平均 (n−1)/2** | O(n) |
| 按位置取值 | — | **O(1)** |
| 按值查找 | 最好 1 / 最坏 n / 平均 (n+1)/2 | O(n) |
| 求长 / 判空 | — | O(1) |

**插入要点**：判满 + 判位置 → **从后往前**后移 → 写入 → length+1
**删除要点**：判空 + 判位置 → 取出 → **从前往后**前移 → length−1
**优缺点**：优点＝随机访问 O(1)、存储密度 1、简单｜缺点＝插删 O(n)、容量固定（上溢/浪费）
**常用算法**：就地逆置 · 删所有 x · 有序表去重 · 两有序表归并 · 交并集 · 划分奇偶（均 O(n)）

## 三、链表（链式存储）

**思想**：结点＝数据域+指针域，用指针表示后继，物理可不连续，动态分配
**术语**：**头指针**（指向第一个结点，链表唯一标识）｜**头结点/表头结点**（哑结点，在首结点前，空表也在）｜**首结点**（第一个数据结点）｜**表尾结点/终端结点**（next = NULL）｜**单向循环链表**（尾 next 指回头结点）｜**双向链表**（prior+next）｜**双向循环链表**（首尾相连）｜**静态链表**（数组+游标）
**空表判定**：带头结点 `head->next == NULL`；循环链表 `head->next == head`
**头结点作用**：统一空表/非空表 · 首位置插删与中间一致 · 简化循环链表与操作接口 · 可存表长

**顺序访问**：访问第 i 个需从头走 i 步 → O(i)，不能随机定位
**结构性开销**＝指针域字节 / 结点总字节（4B 数据+4B 指针 → **50%**；双指针 → ≈66.7%）

| 操作 | 复杂度 |
|---|---|
| 建表（头插） | O(n)，**逆序** |
| 建表（尾插，带尾指针） | O(n)，**保持原序** |
| 按位置 / 按值查找 | O(n) |
| 插入 / 删除（**已知前驱**） | **O(1)** |
| 插入 / 删除（只给位置 i） | O(n)（先定位） |
| 删除给定结点自身（非尾） | O(1)（复制后继数据再删后继） |
| 求表长 | O(n)（无长度域时） |

**选型**：表头频繁插删→带头结点单链表；需双向/删指定结点→双向链表；循环往复（约瑟夫）→循环链表；频繁尾部操作→带尾指针；不支持指针→静态链表

**单链表常用算法**：就地逆置 · 删 x · 去重 · 倒数第 k 个（快慢指针）· 中间结点/判环 · 合并有序链表 · 交集并集 · 多项式相加 · 相交结点

## 四、空闲单元链表与静态链表

**空闲单元链表（备用链表）**：把未使用结点用指针域串成链表，avail 指向表头；**取结点**：`p=avail; avail=S[avail].next;`　**归还**：`S[p].next=avail; avail=p;`
**作用**：数组内模拟动态分配回收 · 复用被删结点 · 支撑链式栈/队列的结点回收

**静态链表**：数组 `S[maxSize]`，元素 `{data, next(游标下标)}`；`S[0]` 为头结点，`S[0].next` 为首结点下标；0 表示空/结束 ⚠️
**机制**：初始化建空闲链（avail=1）→ 插入时取结点挂链 → 删除时摘链归还 → 定位第 i 个仍需沿游标走 O(n)
**特点**：不用指针（适合无指针语言）· 容量固定 · 插删不移动元素

## 五、对比与选型（一句话版）

**随机访问（O(1)）＝顺序表；顺序访问（O(n)）＝链表/静态链表**
| 结构 | 适用 |
|---|---|
| 顺序表 | 表长可预估且稳、**频繁按位置访问**、读多写少 |
| 动态链表 | 表长变化大、**频繁插删**、不需随机访问 |
| 静态链表 | 表长有上限、**无指针**语言、需结点回收 |

**顺序表 vs 链表**：存取 O(1)↔O(n)｜插删 O(n)（平均移动一半）↔已知前驱 O(1)｜存储密度 1 ↔ 有结构性开销｜预分配可能上溢 ↔ 动态分配无上溢

## 六、易混点一句
头指针（变量·唯一标识）≠ 头结点（哑结点·可无）≠ 首结点（第一个数据结点）｜直接前驱唯一 ↔ 前驱可有多个｜顺序存储（物理连续）≠ 顺序访问（逐个走）｜表长 length ≠ 容量 maxSize｜满表插入=上溢，空表删除=下溢｜静态链表插删**不移动元素**（用游标+空闲链）｜"链表插删 O(1)"**前提是已知前驱**

## 七、算法步骤链（背诵用）

**顺序表插入**：判满→判位置→从后往前后移→写 e→length+1
**顺序表删除**：判空→判位置→取出 e→从前往后前移→length−1
**单链表插入（p 后插 s）**：`s->next=p->next; p->next=s;`
**单链表删除（p 为前驱）**：`q=p->next; p->next=q->next; free(q);`
**头插法建表**：新结点 next 指向首结点 → 头结点 next 指向新结点（结果逆序）
**尾插法建表**：r->next=s; r=s（结果保持原序）
**静态链表取结点**：p=avail; avail=S[avail].next　**归还**：S[p].next=avail; avail=p

# 第三章 栈和队列 · 考前简记（关键词版）

> 课程：13003 数据结构与算法（080901 自考）｜状态：✅ 已生成

## 一、总纲
**栈和队列都是操作受限的线性表**：栈＝一端（栈顶）插删，**LIFO**；队列＝一端入队一端出队，**FIFO**

## 二、栈
**术语**：栈顶（操作端）· 栈底（固定端）· 栈顶元素 · 入栈 · 出栈 · 栈的容量 · 出栈序列 · 栈空/栈满
**顺序栈**：top 指栈顶元素 → **空 top=−1**，**满 top=maxSize−1**；入 `S[++top]=x`；出 `x=S[top--]`；取顶 `x=S[top]`；全 **O(1)** ⚠️约定不同（top=0 为空）
**链式栈**：**栈顶在表头**（带头结点单链表）；空 `top->next==NULL`；**无固定栈满**（仅内存耗尽）；入栈=头插 O(1)；出栈=删首结点 O(1)
**双底栈（两栈共享空间）**：栈1底在下标0、栈2底在下标 maxSize−1，top1/top2 相向生长；**满：top1+1==top2**；空：top1=−1 / top2=maxSize；优点=提高空间利用率

**合理出栈序列**
判定＝**模拟法**：按入栈序依次入栈，栈顶等于当前待出元素就弹出，能全部弹出即合法
个数＝**Catalan 数 Cₙ=(2n)!/[n!(n+1)!]**：n=3→**5**，n=4→**14**
例（入栈 1,2,3,4）：1234 合法；4321 合法；3241 合法；**3124 非法**；**2413 非法**

## 三、队列
**术语**：队头（出队端）· 队尾（入队端）· 队头/队尾元素 · 入队 · 出队 · 队列长度 · 队头指针 front · 队尾指针 rear · 队列空/满
**假溢出**：顺序队列 rear 到下界但数组前面有空位 → 用**循环队列（取模回绕）** 解决
`rear=(rear+1)%maxSize;`　`front=(front+1)%maxSize;`

**循环队列空满判定（三方案）**
| 方案 | 空 | 满 | 元素个数 |
|---|---|---|---|
| ①**牺牲一个单元**（常用） | `front==rear` | `(rear+1)%maxSize==front` | `(rear−front+maxSize)%maxSize` |
| ②设 size 计数 | `size==0` | `size==maxSize` | size |
| ③设 tag 标志 | `front==rear && tag==0` | `front==rear && tag==1` | 由 tag 推 |

**队头队尾设定方式** ⚠️：front 指队头元素（或指其前一位）；rear 指队尾元素（或指其后一位）→ 公式随之变化，**答题先声明约定**
**链式队列**：带头结点单链表，front→**头结点**、rear→**队尾结点**；空 `front==rear`；入队=尾插 O(1)；出队=删首结点 O(1)，**出队后若变空须 `rear=front`**；无固定队满
**带空闲单元链表的链式队列（静态实现）**：数组 `{data,next游标}`；**取结点** `p=avail; avail=Q[avail].next;`　**归还** `Q[p].next=avail; avail=p;`；**队满＝avail==0**；作用＝数组内模拟动态分配回收、复用结点

## 四、双端队列与双底栈
**双端队列 deque**：两端都可插入删除
**输入受限**：只能**一端插入**，两端可删｜**输出受限**：两端可插，只能**一端删除**
数组循环实现（牺牲单元法）：空 `front==rear`；满 `(rear+1)%maxSize==front`
前端插入 `front=(front−1+maxSize)%maxSize`；后端插入 `data[rear]=x; rear=(rear+1)%maxSize`；后端删除 `rear=(rear−1+maxSize)%maxSize`

## 五、三大应用算法（必背步骤）
**括号匹配**：左括号入栈 → 遇右括号：栈空则不匹配，否则弹栈比对是否配对 → 结束需栈空
**中缀转后缀**：操作数直接输出；运算符——栈空/栈顶为`(`/优先级更高则入栈，否则弹栈输出再比较；`(`入栈；`)`弹出至`(`并丢弃；结束弹出全部运算符
　例：`A+B*C−D/E` → **`A B C * + D E / −`**
**后缀求值**：遇操作数入栈；遇运算符弹**两个**（**先弹的是右操作数**）做 `左 op 右`，结果入栈；结束栈顶＝结果
　例：`3 4 + 5 *` → **35**
**其他应用**：递归/消除递归、进制转换（除基取余逆序）、DFS 非递归；队列→BFS/层次遍历、缓冲区、任务调度、模拟排队；双端队列→滑动窗口最大值

## 六、易混点一句
栈顶指针（下标）≠ 栈顶元素（值）｜顺序栈空：top=−1（或 0，看约定）｜**假溢出≠真满**（用循环队列解决）｜循环队列 `front==rear` 既是空也可能是满→用牺牲单元/size/tag 区分｜链式结构**无固定"满"**｜链式队列**出队变空必须 `rear=front`**｜双底栈判满 `top1+1==top2`｜输入受限=只能一端插 ／ 输出受限=只能一端删

## 七、算法步骤链（背诵用）
顺序栈入栈：判满 → `S[++top]=x`
顺序栈出栈：判空 → `x=S[top--]`
链式栈入栈：`s->next=top->next; top->next=s;`
链式栈出栈：`q=top->next; top->next=q->next; x=q->data; free(q);`
循环队列入队：判满 → `Q[rear]=x; rear=(rear+1)%maxSize`
循环队列出队：判空 → `x=Q[front]; front=(front+1)%maxSize`
链式队列入队：`s->next=NULL; rear->next=s; rear=s;`
链式队列出队：`q=front->next; front->next=q->next; if(rear==q) rear=front; free(q);`

# 第四章 数组、广义表和串 · 考前简记（关键词版）

> 课程：13003 数据结构与算法（080901 自考）｜状态：✅ 已生成

## 一、数组
**特点**：元素**个数固定**、**类型相同**、一般只存取不插删 → **只采用顺序存储**
**术语**：多维数组（二维＝元素为一维数组的线性表）· 数组首地址 · 下标 · **行主序/列主序** · 地址映射函数
**地址公式（0 基，L 为每元素字节数）**
| 情形 | 公式 |
|---|---|
| 二维 行主序 | `LOC(aᵢⱼ)=LOC(a₀₀)+(i×n+j)×L` |
| 二维 列主序 | `LOC(aᵢⱼ)=LOC(a₀₀)+(j×m+i)×L` |
| 三维 行主序 | `LOC=基址+(i×d₂×d₃+j×d₃+k)×L` |
| n 维 行主序 | `基址+(i₁d₂…d_n + i₂d₃…d_n + … + i_n)×L` |
| 1 基写法 ⚠️ | `LOC(aᵢⱼ)=LOC(a₁₁)+((i−1)n+(j−1))×L` |
**例**：A[4][5]，L=4，基址 2000：行主序 a₂₃ → 2000+(2×5+3)×4=**2052**；列主序 → 2000+(3×4+2)×4=**2056**

**特殊矩阵压缩**
| 矩阵 | 存储量 | 地址公式（0 基，行优先） |
|---|---|---|
| **对称矩阵** aᵢⱼ=aⱼᵢ | **n(n+1)/2**（只存下三角含对角线） | i≥j：**k=i(i+1)/2+j**；i<j：存 aⱼᵢ → **k=j(j+1)/2+i** |
| **三角矩阵** | **n(n+1)/2+1**（含常数 c） | 同上；访问另一三角取常数 c |
| **三对角矩阵** | **3n−2** | **k=2i+j**（1 基 k=2i+j−2） |
| **稀疏矩阵** | 三元组表（行,列,值，按行序） | 省空间但**不能随机存取** |

**由 k 反求对称矩阵下标**：先取满足 i(i+1)/2 ≤ k 的**最大 i**，则 j = k − i(i+1)/2

**数组算法（综合）**：矩阵转置（普通 O(n·t)／**快速转置 O(n+t)** 用 num[]+cpot[]）· 矩阵加/乘 · 杨辉三角 · 循环移位（三段逆置）· 螺旋矩阵 · 行列有序二维查找 O(m+n)

## 二、广义表
**定义**：LS=(a₁,…,aₙ)，元素可为**原子**或**子表**
**表头 head**＝第一个元素｜**表尾 tail**＝**其余元素构成的表（一定是表，要加括号）**
**长度**＝**最外层**元素个数｜**深度**＝**括号最大嵌套层数**（原子深度 0，**空表 () 深度 1**）
**递归表**（如 A=(a,A)）深度 **∞**
**例** A=((a,b), c, (d,(e)))：长度 **3**，深度 **3**；head=(a,b)；tail=( c,(d,(e)) )；head(tail(A))=c；head(head(A))=a
**例** B=(a,(b,c,d),e)：长度 3，深度 2｜C=(a,(b,(c)))：长度 2，深度 3
**存储（扩展）**：头尾表示法 · 孩子兄弟表示法

## 三、串
**术语**：串（字符有限序列）· 子串（连续字符）· **空串 "" 长度 0**（≠ **空格串 " " 长度 1**）· 串长 · **主串 S** · **模式串 T**
**模式匹配**：在 S 中找 T，返回**首次出现位置**
**比较次数**：BF 最好 m／最坏 **(n−m+1)×m**；KMP **O(n+m)**

**BF 算法**：逐位比较，失配时 `i=i−j+1; j=0`（**主串回退**）→ 最坏 O(nm)

**特征向量 next（0 基）**：`next[j]`＝P[0..j−1] 的**最长相等前后缀长度**；`next[0]=0`
⚠️ 经典教材（1 基，next[1]=0）的取值 = 0 基的 `next[j−1]+1`

**next 计算示例** T = a b a a b c a c

| j | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 前缀 | a | ab | aba | abaa | abaab | abaabc | abaabca | abaabcac |
| **next（0 基）** | 0 | 0 | 1 | 1 | 2 | 0 | 1 | 0 |
| next（1 基 ⚠️） | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |

**KMP 算法**：**主串指针 i 不回退**，失配时 `j = next[j−1]`（0 基）；**O(n+m)**，空间 O(m)
**KMP 改进（了解）**：`P[j]==P[next[j]]` → `nextval[j]=nextval[next[j]]`

## 四、易混点一句
行主序先存行、列主序先存列（**公式与结果不同**）｜下标 0 基/1 基 ⚠️先声明｜对称矩阵存 **n(n+1)/2**、三角矩阵 **+1 个常数**、三对角 **3n−2**｜对称矩阵 i<j 时**转存 aⱼᵢ**｜三元组表省空间但**不能随机存取**｜**空表长度 0、深度 1**｜表尾**一定是表**（加括号）｜空串 ≠ 空格串｜**BF 主串回退 O(nm) ↔ KMP 主串不回退 O(n+m)**

## 五、计算模板
1. 数组地址：写公式（行/列主序＋起点）→ 代入 → 结果
2. 对称矩阵：判 i、j → `k=i(i+1)/2+j` 或 `k=j(j+1)/2+i`
3. 三对角：`k=2i+j`（0 基）
4. 广义表：**长度数最外层、深度数括号层**；表尾记得加括号
5. next：列表法逐前缀求最长相等前后缀长度

# 第五章 树与二叉树 · 考前简记（关键词版）

> 课程：13003 数据结构与算法（080901 自考）｜状态：✅ 已生成

## 一、树的基本概念
**树**：n≥0 结点的有限集合，唯一根 + m 棵互不相交子树（**1:n 层次结构**，除根外前驱唯一、后继可多个）
**术语**：结点的度（孩子数）· 树的度（最大度）· 叶结点（度0）· 分支结点 · 层（根为第1层）· 深度/高度 ⚠️ · 路径长度（边数）· 有序树 · 森林（m 棵不相交树）
**关系**：**边数 = 结点数 − 1**；**Σ所有结点度 = 边数**；**森林边数 = n − m**
**叶结点公式**：**n₀ = 1 + Σ_{i≥2}(i−1)nᵢ**
**表示形式 4**：树形 · 括号（如 A(B(D,E),C(F))）· 嵌套集合 · 凹入缩进

## 二、二叉树核心性质（必背）
| 性质 | 内容 |
|---|---|
| 1 | 第 i 层至多 **2^(i−1)** 个结点 |
| 2 | 深度 k 至多 **2ᵏ − 1** 个结点 |
| 3 | **n₀ = n₂ + 1**（证：n=n₀+n₁+n₂，边=n−1=n₁+2n₂） |
| 4 | 完全二叉树 n 个结点 → 深度 **k = ⌊log₂n⌋ + 1** |
| 5 | 层序编号（**1 基**）：父 **⌊i/2⌋**、左 **2i**、右 **2i+1**；i > ⌊n/2⌋ 为叶 |
| 推论 | 二叉链表 n 个结点有 **n+1 个空指针域** |

**0 基下标**：父 ⌊(i−1)/2⌋、左 2i+1、右 2i+2、最后一个非叶 = ⌊n/2⌋−1
**满二叉树**：每层都满，深度 k → 2ᵏ−1 个结点｜**完全二叉树**：编号与满二叉树一一对应，最下层集中**左侧**
**顺序存储**：适合完全二叉树；一般二叉树浪费（最坏 2ᵏ−1）｜**链式存储**：二叉链表(lchild,rchild)／三叉链表(+parent)
**二叉树 vs 树**：二叉树可空 · 左右有序 · 度为2的有序树 ≠ 二叉树

## 三、遍历（必考）
| 遍历 | 顺序 | 辅助结构 |
|---|---|---|
| 先序 | 根→左→右 | 栈（非递归） |
| 中序 | 左→根→右 | 栈 |
| 后序 | 左→右→根 | 栈（双栈/标记） |
| 层次 | 按层从左到右 | **队列** |

**还原**：**先序+中序**、**后序+中序**、**层次+中序** → 唯一确定；**先序+后序 → 不能**
　方法：先序首元（后序末元）＝根 → 中序划分左右 → 递归
**例**：先序 **ABDECF**、中序 **DBEACF** → 树 `A(B(D,E), C(∅,F))`，**后序 = D E B F C A**
**表达式树**：叶=操作数、分支=运算符；中序→中缀、先序→前缀（波兰）、后序→后缀（逆波兰）
**常用递归算法**：Count（结点数）· LeafCount（叶子）· Depth（深度＝max(左,右)+1）· 复制/交换左右↔镜像 · 判断相同/相似 · 判断完全二叉树（层次遍历遇空后不得再有非空）

## 四、堆与优先队列
**堆**＝满足"父 ≥ 子（最大堆）/ 父 ≤ 子（最小堆）"的**完全二叉树**；**堆顶＝极值**；**子堆**仍是堆
**存储**：一维数组（0 基：左 2i+1、右 2i+2、父 ⌊(i−1)/2⌋；最后非叶 ⌊n/2⌋−1）
**有序性**：只保证父与子，**兄弟无序**；堆**不能查找任意元素**（≠二叉查找树）
**建堆**：从最后一个非叶 ⌊n/2⌋−1 起**自底向上筛选** → **O(n)**
**插入**：放末尾 → **上浮** O(log n)｜**删除堆顶**：末尾顶替 + **下沉** O(log n)
**例** [5,8,3,9,1] 建最小堆：处理 i=1(8) 交换 1 → [5,1,3,9,8]；处理 i=0(5) 交换 1 → **[1,5,3,9,8]**；插 0 → **[0,5,1,9,8,3]**；删堆顶 → **[1,5,3,9,8]**
**优先队列**：出队按优先级（极值优先），用堆实现；应用＝任务调度、Dijkstra/Prim、Top-K、双堆求中位数、堆排序 O(n log n)

## 五、树和森林
**4 种表示法**：父结点（双亲）表示法（找父易）· 孩子结点表示法（找子易）· 父结点-孩子结点表示法 · **孩子-兄弟表示法**（firstchild + nextsibling → **把树变成二叉树**）
**转换（孩子-兄弟法）**：**左指针=第一个孩子**，**右指针=下一个兄弟**；森林→二叉树：各树根用**右链**串成兄弟
**遍历对应（必背）**
| 树/森林 | 二叉树 |
|---|---|
| 树的**先根**遍历 | **先序**遍历 |
| 树的**后根**遍历 | **中序**遍历 |
| 森林的**先序**遍历 | **先序**遍历 |
| 森林的**中序（后根）** 遍历 | **中序**遍历 |

## 六、哈夫曼树与哈夫曼编码
**术语**：定长编码（等长，⌈log₂n⌉ 位）· 变长编码（高频短码）· **前缀特性**（任一编码都不是另一个的前缀 → 译码唯一、无需分隔符）· 编码树 · **哈夫曼树（WPL 最小的二叉树）** · **WPL = Σwᵢlᵢ** · 带权平均码长 = **WPL / Σwᵢ**
**构造**：每次取**两个根权最小**的树合并（新权=和），重复 **n−1** 次；**无度为1的结点**，共 **2n−1** 个结点
**WPL 快速算法**：**WPL = 所有合并产生的新权值之和**
**经典例**（a5,b29,c7,d8,e14,f23,g3,h11，Σw=100）
合并：3+5=8 → 7+8=15 → 8+11=19 → 14+15=29 → 19+23=42 → 29+29=58 → 42+58=100
**WPL = 8+15+19+29+42+58+100 = 271**；**平均码长 = 271/100 = 2.71**（定长需 3 位）
**编码**：左 0 右 1；例 d=000, h=001, f=01, e=100, c=1010, g=10110, a=10111, b=11（**不唯一**）
**译码**：从根按位走，到叶输出并回根
**不唯一性**：左右可交换、同权合并顺序可变 → 编码不同；但 **WPL 与各字符码长唯一**

## 七、易混点一句
满二叉树（每层满）↔ 完全二叉树（编号一一对应、右侧可缺）｜结点的度 ≠ 树的度｜深度（根往下）≠ 高度（叶往上）⚠️｜**先序+后序不能还原**｜**树的后根遍历 = 二叉树的中序**（不是后序）｜二叉链表空指针 **n+1**｜堆 ≠ 二叉查找树（堆不能查任意元素）｜**建堆 O(n)**（不是 O(n log n)）｜哈夫曼树**无度为 1 的结点**、共 2n−1 个结点｜哈夫曼编码不唯一但 WPL/码长唯一

## 八、公式速记
边数=n−1｜Σ度=边数｜森林边数=n−m｜n₀=n₂+1｜n₀=1+Σ_{i≥2}(i−1)nᵢ｜第i层≤2^(i−1)｜深度k≤2ᵏ−1｜k=⌊log₂n⌋+1｜父⌊i/2⌋·左2i·右2i+1（1基）｜二叉链表空指针 n+1｜哈夫曼结点数 2n−1｜WPL=Σwᵢlᵢ=Σ合并权｜平均码长=WPL/Σw

# 第六章 图结构 · 考前简记（关键词版）

> 课程：13003 数据结构与算法（080901 自考）｜状态：✅ 已生成

## 一、基本概念
**图 G=(V,E)**：顶点集 + 边集｜**子图**｜无向边 (v,w)｜**有向边/弧 <v,w>**：v=**弧尾**、w=**弧头**｜带权图（网）
**邻接点**（顶点—顶点）↔ **关联**（顶点—边）｜**度 TD**：无向＝关联边数；有向＝**入度 ID + 出度 OD**
**关键关系**：**ΣTD = 2e**（无向）；有向 **ΣID = ΣOD = e**｜**无向完全图 n(n−1)/2**｜**有向完全图 n(n−1)**｜稀疏图 e ≪ n²（e < n·log n）
**路径**（顶点序列）· **有向路径**（沿弧）· **简单路径**（顶点不重复）· **回路**· **简单回路** · **路径长度**（边数 / 带权为权和）· **DAG**（有向无环）
**连通图**（无向任意两点有路）· **连通分量**（极大连通子图）· **强连通图**（有向互相可达）· **弱连通图**（忽略方向连通）

## 二、存储结构
| | 邻接矩阵 | 邻接表 | 逆邻接表 |
|---|---|---|---|
| 结构 | `vexs[n]` + `arcs[n][n]` | 顶点表 `data+firstarc` + 边表**表结点** `adjvex+nextarc(+info)` | 同邻接表，但存**入边** |
| 空间 | **O(n²)** | **O(n+e)** | O(n+e) |
| 适合 | **密集图** | **稀疏图** | 稀疏图（求入度） |
| 判相邻 | **O(1)** | O(度) | O(度) |
| 求邻接点 | O(n) | **O(度)** | O(入度) |
| 无向图 | **对称**，行/列非零数＝**度** | 边结点数＝**2e** | 同 |
| 有向图 | **行＝出度、列＝入度** | 边结点数＝e；**求入度难** | **求入度易** |

## 三、图的搜索
**特性**：需 **visited[]** 防重复；**非连通图**对每个未访问顶点重新发起（每次得一个连通分量）；搜索序列随**起点与存储次序**变化
**DFS**（似先序）：**栈**（递归）；**BFS**（似层次）：**队列**
**复杂度**：邻接矩阵 **O(n²)**；邻接表 **O(n+e)**
**示例** 边 1-2,1-3,2-4,3-4,4-5（升序）→ **DFS: 1,2,4,3,5**；**BFS: 1,2,3,4,5**
**应用**：连通分量计数 · 路径查找 · 判环（回边）· 二分图染色 · 迷宫/岛屿 · 拓扑排序

## 四、生成树与最小生成树
**生成树**：连通图的**极小连通子图**，**n 个顶点 + n−1 条边**，**可能不唯一**；DFS/BFS 生成树（非连通图→生成森林）
**最小生成树 MST**：边权之和最小；**MST 可能不唯一但最小代价唯一**
**Prim（加点法）**：从任一顶点开始，每次在"已选集 ↔ 未选集"的边中取**权最小**者加入；**O(n²)**，适合**密集图**
**Kruskal（加边法）**：边按权**升序**，只要两端**不在同一连通分量**就选入；直到 n−1 条；**O(e log e)**，适合**稀疏图**
**经典例**（A-B6, A-C1, A-D5, B-C5, B-E3, C-D5, C-E6, C-F4, D-F2, E-F6）
- Prim(A)：AC1 → CF4 → FD2 → CB5 → BE3 → **代价 15**
- Kruskal：AC1, DF2, BE3, CF4,（AD5 舍）, BC5 → **代价 15**

## 五、有向无环图及其应用
**AOV 网**：**顶点=活动**、弧=先后关系 → **拓扑排序**
**拓扑排序步骤**：① 选**入度为 0** 顶点输出 → ② 删除该顶点及其出边（相关入度−1）→ ③ 重复；**无法输出全部顶点即有环**；复杂度 **O(n+e)**；序列**可能不唯一**
**AOE 网**：**弧=活动**（权=持续时间）、顶点=事件；**源点**（唯一入度 0）、**汇点**（唯一出度 0）
**关键路径求解（必背）**
- **ve（正向）**：`ve(j)=max{ve(i)+w(<i,j>)}`，源点 ve=0
- **vl（逆向）**：`vl(j)=min{vl(k)−w(<j,k>)}`，**vl(汇点)=ve(汇点)**
- 活动 **e(a)=ve(弧尾)**；**l(a)=vl(弧头) − w**；**余量 = l − e**，**余量为 0 → 关键活动**
- 关键路径＝源点到汇点**最长路径**，长度＝**最短工期**，**可能不唯一**

**经典例**（a1 V1→V2 6, a2 V1→V3 4, a3 V1→V4 5, a4 V2→V5 1, a5 V3→V5 1, a6 V4→V6 2, a7 V5→V7 9, a8 V5→V8 7, a9 V6→V8 4, a10 V7→V9 2, a11 V8→V9 4）
- ve：0, 6, 4, 5, **7**, 7, **16**, **14**, **18**
- vl：**0**, 6, 6, 8, **7**, 10, 16, 14, **18**
- 关键活动：**a1, a4, a7, a8, a10, a11** → 关键路径 V1→V2→V5→V7→V9 与 V1→V2→V5→V8→V9，**工期 18**

## 六、最短路径
**Dijkstra（单源，贪心，非负权）**：S 初始含源点 → 每次选 V−S 中 **dist 最小**者加入 → 以其更新邻接点 `dist[u]+w < dist[w]`；**O(n²)**（堆优化 O(e log n)）
　例（1→2:2, 1→3:5, 2→3:1, 2→4:7, 3→4:3）→ dist：1→2=**2**、1→3=**3**、1→4=**6**
**Floyd（所有点对，动态规划）**：`D⁽ᵏ⁾[i][j]=min(D⁽ᵏ⁻¹⁾[i][j], D⁽ᵏ⁻¹⁾[i][k]+D⁽ᵏ⁻¹⁾[k][j])`，k 逐轮；**O(n³)**；**允许负权（无负环）**
　例（1→2:4, 2→3:1, 1→3:10）→ k=2 时 1→3 = min(10, 5) = **5**
**对比**：Dijkstra 单源 O(n²)、非负权 ↔ Floyd 全点对 O(n³)、可负权｜**Dijkstra vs Prim**：前者更新"到源点距离和"，后者更新"到树的边权"

## 七、复杂度速查
DFS/BFS：矩阵 **O(n²)**、邻接表 **O(n+e)**｜**Prim O(n²)**｜**Kruskal O(e log e)**｜拓扑排序 **O(n+e)**｜关键路径 **O(n+e)**｜**Dijkstra O(n²)**｜**Floyd O(n³)**

## 八、易混点一句
邻接（顶点间）≠ 关联（顶点与边）｜无向完全图 n(n−1)/2 ↔ 有向完全图 n(n−1)｜连通（无向）↔ 强连通（有向互相可达）↔ 弱连通（忽略方向）｜邻接矩阵行=出度、列=入度｜邻接表求入度难→用**逆邻接表**｜无向图邻接表边结点 **2e**｜**DFS 用栈、BFS 用队列**｜生成树（n−1 条边）≠ 最小生成树（权最小）｜**Prim 加点 O(n²)** ↔ **Kruskal 加边 O(e log e)**｜**AOV 顶点=活动**（拓扑）↔ **AOE 弧=活动**（关键路径）｜ve 正推取 **max**、vl 逆推取 **min**｜**关键活动判据：余量 = 0**｜Dijkstra 非负权 ↔ Floyd 可负权

## 九、计算模板
1. 度与边：`2e = ΣTD`；有向 `e = ΣID = ΣOD`
2. 邻接表结点数：无向 **2e**、有向 **e**
3. 搜索序列：按邻接点升序模拟（DFS 栈／BFS 队列）
4. MST：Prim 列候选边表逐次取最小；Kruskal 边排序 + 判环（不同分量才选），凑满 n−1 条；代价=权和
5. 拓扑排序：列各顶点入度 → 反复"输出入度 0 并删出边"
6. 关键路径：正推 ve(max) → 逆推 vl(min) → 活动 e/l/余量 → 余量 0 为关键 → 工期
7. 最短路径：Dijkstra 填 dist 表；Floyd 逐轮更新矩阵

# 第七章 内部排序 · 考前简记（关键词版）

> 课程：13003 数据结构与算法（080901 自考）｜状态：✅ 已生成

## 一、基本概念
**排序**＝按关键字把记录排成升/降序｜**主关键字**（唯一标识）／**次关键字**｜**逆序对**＝i<j 但 kᵢ>kⱼ（≈直接插入的移动次数）｜**内部排序**（全在内存）／**外排序**（需内外存交换）
**稳定**＝关键字相等的记录**相对次序不变**
**稳定**：直接插入 · 起泡 · 归并 · 基数（+箱子）｜**不稳定**：**希尔 · 快速 · 直接选择 · 堆**（口诀"**快些选堆不稳定**"）
**评价标准**：时间复杂度（比较+移动）· 空间 · 稳定性 · 实现难易 · 数据规模与初始排列 · 是否基于比较
**初始排列影响**：直接插入/起泡**正序最好 O(n)**；快速**正序或逆序取端点为枢轴最坏 O(n²)**；**直接选择、堆、归并、基数不受影响**

## 二、八大排序总表（必背）
| 算法 | 平均 | 最好 | 最坏 | 空间 | 稳定 | 特点 |
|---|---|---|---|---|---|---|
| 直接插入 | O(n²) | **O(n)** | O(n²) | O(1) | **稳定** | n 小/基本有序最好；移动≈逆序对 |
| 希尔 | ≈O(n^1.3) | 与增量有关 | 与增量有关 | O(1) | **不稳定** | 增量分组做插入；d=1 即直接插入 |
| 起泡 | O(n²) | **O(n)** | O(n²) | O(1) | **稳定** | 相邻交换；最多 n−1 趟 |
| **快速** | **O(n log n)** | O(n log n) | **O(n²)** | **O(log n)** | **不稳定** | 平均最快；枢轴影响大；分治 |
| 直接选择 | O(n²) | O(n²) | O(n²) | O(1) | **不稳定** | 比较固定；**交换次数最少** |
| **堆排序** | **O(n log n)** | O(n log n) | **O(n log n)** | **O(1)** | **不稳定** | 最坏不退化；就地 |
| **归并** | **O(n log n)** | O(n log n) | O(n log n) | **O(n)** | **稳定** | 需辅助数组；外排序基础 |
| **基数** | O(d(n+r)) | 同 | 同 | O(n+r) | **稳定** | **非比较**；与初始排列无关 |

## 三、各算法要点
**直接插入**：把待排序元素插入前面**有序子段**（从后往前比较、后移插入）；**稳定**；最好 O(n)/平均最坏 O(n²)；O(1)
**希尔**：增量 d 分组 → **组内排序**（插入）→ 缩小增量（如 n/2, n/4, …, 1）；**不稳定**；≈O(n^1.3)；与直接插入关系＝**d=1 时就是直接插入**
**起泡**：相邻比较逆序交换，每趟最值到位（**整体有序**区扩大）；**稳定**；加"本趟无交换"标志可正序 O(n)
**快速**：选**枢轴** → 一趟**划分**（枢轴到位，左小右大）→ 递归左右；枢轴选取：首/尾/中间/随机/**三元取中**；枢轴偏斜 → 退化 O(n²)；**不稳定**；平均 O(n log n)、空间 O(log n)
**直接选择**：每趟选最值与无序区首位交换；**不稳定**；**恒 O(n²)**、**交换最少**（≤n−1 次）
**堆排序**：**建初始堆**（升序用大顶堆；最后非叶 ⌊n/2⌋−1 起自底向上筛选，**建堆 O(n)**）→ 堆顶与末尾交换 → 调整剩余堆 → 重复；**不稳定**；**恒 O(n log n)**、O(1)
**归并**：**合并**两个有序段；递归（自顶向下）/非递归（自底向上，长度 1→2→4→…）；**稳定**；恒 O(n log n)、**空间 O(n)**；外排序基础
**基数**：按位"**分配—收集**"（LSD 从个位起，十位、百位…），d 趟；**稳定**；**O(d(n+r))**、空间 O(n+r)；**不比较关键字**，不受 O(n log n) 下界限制

## 四、经典示例（`49 38 65 97 76 13 27 49`）
**直接插入逐趟**：49|38… → 38 49|65… → … → **13 27 38 49 49 65 76 97**
**希尔(4,2,1)**：d=4 → `49 13 27 49 76 38 65 97`；d=2 → `27 13 49 38 65 49 76 97`；d=1 → 有序
**起泡**：趟1 `38 49 65 76 13 27 49 [97]` → 趟5 完成
**快速（首元素 49 为枢轴）一趟**：`27 38 13 [49] 76 97 65 49`（**枢轴到位**）
**归并**：趟1 `38 49 | 65 97 | 13 76 | 27 49` → 趟2 `38 49 65 97 | 13 27 49 76` → 趟3 有序
**基数**（`278 109 63 930 589 184 505 269 8 83`）按个位一趟 → `930, 63, 83, 184, 505, 278, 8, 109, 589, 269`；再做十位、百位 → 有序

## 五、选型建议（必背）
| 条件 | 选 |
|---|---|
| n 小（n<50） | **直接插入**（稳定）／直接选择 |
| n 大、要求**稳定** | **归并**（或基数） |
| n 大、**平均最快** | **快速** |
| n 大、要求**最坏 O(n log n)** 且省空间 | **堆排序** |
| **基本有序** | 直接插入／起泡 |
| 关键字**位数少、范围小、记录多** | **基数／箱子** |
| **记录大、移动代价高** | 直接选择（少交换）／索引、链表排序 |
| **外排序** | 多路**归并** |

## 六、由结果推测算法
**枢轴到位、左小右大** → 快速｜**最大/最小元素到位** → 起泡／直接选择｜**前段局部有序** → 直接插入｜**按增量 d 分组组内有序** → 希尔｜**呈现长度 2ᵏ 的有序段** → 归并｜**每趟把最值放到无序区一端** → 直接选择｜**个位/十位先有序** → 基数｜**末尾逐步堆积最大值** → 堆排序

## 七、关键结论
1. 与初始排列**无关**：直接选择、堆、归并、基数
2. 正序最好 O(n)：直接插入、起泡
3. 最坏 O(n²) 的高效算法：快速（用三元取中/随机化改善）
4. 空间：O(1)＝插入/希尔/起泡/选择/堆；O(log n)＝快速；O(n)＝归并；O(n+r)＝基数
5. **交换最少**：直接选择｜**比较类排序下界 O(n log n)**，基数排序不受限

## 八、易混点一句
稳定＝相等记录相对次序不变（不是值不变）｜**d=1 的希尔 = 直接插入**（希尔不稳定）｜枢轴取固定端点 + 序列已有序 → 快速**退化 O(n²)**｜升序堆排序用**大顶堆**｜直接选择 O(n²) ↔ 堆排序 O(n log n)｜归并**稳定但 O(n) 空间** ↔ 快速**就地但不稳定、最坏 O(n²)**｜基数排序**不比较关键字**

## 九、过程题模板
1. 写逐趟结果（直接插入→左有序区；希尔→按增量分组；起泡→每趟最值到位；快速→枢轴+左右分区；归并→长度 2ᵏ 有序段；堆→建堆+交换+调整）
2. 复杂度/稳定性判断 → 查八大排序总表
3. 选型题 → 按"n 大小 → 是否要求稳定 → 初始排列 → 空间限制"逐条排除并给理由
4. 推测算法 → 按特征对号入座

# 第八章 查找 · 考前简记（关键词版）

> 课程：13003 数据结构与算法（080901 自考）｜状态：✅ 已生成

## 一、基本概念
**查找**＝在查找表中找关键字等于给定值的记录｜**单值查找**／**范围查找**｜**查找表**（静态/动态）｜**成功/不成功查找**｜**内部/外部查找**
**ASL = Σ pᵢ·cᵢ**（平均查找长度；等概率 pᵢ=1/n）——分**成功 ASL** 与**不成功 ASL**
**适用条件速记**：无序+链式→**顺序查找**；**有序+顺序存储→折半查找**；块间有序块内无序→**分块查找**；动态→**BST/AVL/B 树**；精确查找→**哈希**

## 二、顺序表查找（必背 ASL）
| 方法 | 条件 | ASL | 复杂度 |
|---|---|---|---|
| **顺序查找** | 顺序/链式、**不需有序** | 成功 **(n+1)/2**、不成功 **n+1** | O(n) |
| **折半查找** | **必须有序 + 顺序存储** | ≈ **log₂(n+1) − 1**；最大比较次数 = **⌊log₂n⌋+1** | O(log₂n) |
| **分块（索引顺序）查找** | 顺序存储 + 索引表；**块间有序、块内无序** | **(b+1)/2 + (s+1)/2**；**最优 s = b = √n → ≈ √n + 1** | O(√n) |

**折半判定树（n=11）**：各层结点数 **1、2、4、4** → ASL = (1×1+2×2+3×4+4×4)/11 = **33/11 = 3**；树高 = 4
```
        6
      /   \
     3     9
   /  \   /  \
  1   4  7   10
   \   \  \    \
    2   5  8   11
```
**分块示例**：n=100、s=b=10 → ASL = 5.5+5.5 = **11**（≈√n+1）

## 三、树形结构的查找
**BST 性质**：左子树 < 根 < 右子树；**中序遍历得递增序列**
**查找**：小走左、大走右；比较次数 ≤ 树高｜**插入**：总是插在**叶子**（查找失败处）｜**效率取决于树形**：接近平衡 O(log₂n)、**有序插入退化为单支树 O(n)**
**删除三情况**：① 叶子→直接删 ② 只有一个子树→**子树顶替** ③ 左右都有→**中序前驱/后继顶替**其值，再删该结点
**示例**：插入 45,24,53,12,37,93 → 删 24（双子树）用中序后继 **37** 顶替

**AVL 树**：任一结点左右子树高差 ≤1；**平衡因子 BF ∈ {−1,0,1}**
| 类型 | 情形 | 旋转 |
|---|---|---|
| **LL** | 插在左子树的**左侧** | **右单旋** |
| **RR** | 插在右子树的**右侧** | **左单旋** |
| **LR** | 插在左子树的**右侧** | **先左后右**（双旋） |
| **RL** | 插在右子树的**左侧** | **先右后左**（双旋） |
例：插入 **16,3,7** → 16 处 BF=2、LR 型 → 结果根 **7**（左 3、右 16）
AVL 树高 ≈ 1.44log₂n → 查找/插入/删除 **O(log₂n)**

**B 树**：**m 阶**——每结点最多 **m 棵子树 / m−1 个关键字**；根≥2 棵子树；非根非叶结点≥**⌈m/2⌉** 棵子树；**所有叶在同一层（绝对平衡）**
**查找**：结点内顺序/折半 → 沿指针下移｜**插入**：插入最底层叶结点 → **溢出（关键字数 > m−1）则分裂**：**中间关键字上移父结点**，左右两半成两个结点；可能**向上传播**（根分裂则树高 +1）
**示例（3 阶）**：插 1,2 → [1 2]；插 3 → 溢出 → 根 **[2]**，叶 [1] [3]；插 4,5 → 根 **[2 4]**，叶 [1] [3] [5]

## 四、哈希表
**术语**：哈希表 · **哈希函数 H(k)** · 哈希地址 · **冲突**（不同关键字同地址）· **同义词** · **完美哈希函数** · **装填因子 α = n/m** · **基本聚集**（线性探测的连续占用）· **二级聚集**（二次探测同义词同序列）
**哈希函数构造 6 法**：直接定址法 `H=a·k+b`｜数字分析法（取分布均匀位）｜**平方取中法**（取 k² 中间位）｜**折叠法**（分段相加）｜**除留余数法 `H=k mod p`（p 取 ≤m 的质数，最常用）**｜基数转换法
**冲突解决 4 类**
| 方法 | 做法 | 特点 |
|---|---|---|
| 开放地址法 | `H_i=(H(k)+d_i) mod m` | 表内寻空位 |
| ├ **线性探测** | d = 1,2,3,… | 简单但**基本聚集** |
| ├ **二次探测** | d = ±1²,±2²,… | 减轻基本聚集，有**二级聚集** |
| └ 伪随机/再散列 | d 取伪随机或另一函数 | 聚集更少 |
| **链地址法** | 同义词链成单链表 | **不产生聚集**、可动态插删、α 可 >1 |
| 公共溢出区 | 冲突者统一放溢出区 | 简单 |
**影响效率因素**：哈希函数**均匀性** · **冲突处理方法** · **装填因子 α（最主要）** · 关键字特点 · m/p 取值

**经典例（m=13，H(k)=k mod 13，线性探测）**：19,14,23,1,68,20,84,27,55,11,10,79
表：0 空｜1:14｜2:1｜3:68｜4:27｜5:55｜6:19｜7:20｜8:84｜9:79｜10:23｜11:11｜12:10
**成功 ASL = 30/12 = 2.5**｜**不成功 ASL ≈ 91/13 = 7**（α = 12/13 ≈ 0.92，聚集严重）
**链地址法同一组关键字**：`1: 14→1→27→79｜3: 68→55｜6: 19→84｜7: 20｜10: 23→10｜11: 11`
**成功 ASL = 21/12 = 1.75**（优于线性探测；期望 ≈ **1 + α/2**）
**特点**：平均查找/插入/删除 **O(1)**（与 n 无关、只看 α）；**不支持范围查找与有序遍历**

## 五、各查找方法对比（必背）
| 方法 | 存储 | 有序 | ASL | 复杂度 | 适合 |
|---|---|---|---|---|---|
| 顺序查找 | 顺序/链式 | 不需 | 成功 (n+1)/2 | O(n) | 表小、无序 |
| 折半查找 | **必须顺序** | **必须有序** | ≈ log₂(n+1)−1 | O(log₂n) | 有序表频繁查询 |
| 分块查找 | 顺序+索引 | 块间有序 | (b+1)/2+(s+1)/2 → ≈√n+1 | O(√n) | 大表、分块组织 |
| BST | 链式 | BST 性质 | 与树高有关 | 最好 O(log₂n)、最坏 O(n) | 动态查找表 |
| AVL | 链式 | BST+平衡 | O(log₂n) | 稳定 O(log₂n) | 查/插/删都要求快 |
| B 树/B+ 树 | 外存块 | 多路平衡 | O(log_m n) | 稳定 | **外存索引/数据库** |
| 哈希 | 散列表 | 不需 | 与 α 有关（1+α/2） | 平均 **O(1)** | 只做精确查找 |

## 六、易混点一句
**折半必须"有序 + 顺序存储"**（链式不行）｜判定树**高度=最大比较次数**、**ASL=平均比较次数**｜顺序查找不成功需 n（或 n+1）次｜**分块最优 s=b=√n**｜BST 插入总在**叶子**｜BST 删除双子树用**中序前驱/后继顶替**｜BST 有序插入→**单支树 O(n)**｜**LL→右单旋、RR→左单旋、LR→先左后右、RL→先右后左**｜m 阶 B 树：≤m 子树、≤m−1 关键字、非根非叶≥⌈m/2⌉ 子树、**叶同层**｜B 树分裂＝**中间关键字上移**｜哈希效率看 **α**（不是 n）｜**线性探测→基本聚集；二次探测→二级聚集**｜链地址法不聚集｜哈希表**不能范围查找**

## 七、计算模板
1. 顺序查找：成功 (n+1)/2、不成功 n+1
2. 折半：画判定树（每次 mid）→ 各层结点数 → ASL=Σ(层×结点数)/n；max 比较 = ⌊log₂n⌋+1
3. 分块：ASL=(b+1)/2+(s+1)/2，最优 s=b=√n
4. BST：按序插入画树 → 中序验证 → 删除按三情况 → ASL=Σ(结点层数)/n
5. AVL：找**最小不平衡子树** → 判 LL/RR/LR/RL → 旋转并验证 BF
6. B 树：逐个插入 → 溢出则**中间关键字上移 + 左右分裂**，可能向上传播
7. 哈希：按 H(k) 定地址 → 冲突按探测序列试放（记录比较次数）→ **成功 ASL=Σcᵢ/n**；**不成功 ASL=Σ(各地址探测到空的次数)/m**；α=n/m

## 四、算法步骤链（背诵用）

- **顺序表插入**：判满 → 判位置 → 从后往前移 → 写 e → 长+1
- **顺序表删除**：判空 → 判位置 → 取出 → 从前往后移 → 长−1
- **单链表插入（p 后插）**：`s->next=p->next; p->next=s;`；**删除**：`q=p->next; p->next=q->next; free(q);`
- **中缀转后缀**：操作数输出 → 运算符按"栈空/栈顶( / 优先级高"入栈，否则弹栈输出 → `)` 弹至 `(` → 结束全弹
- **后缀求值**：操作数入栈；运算符弹两个（先弹的是右操作数）算 `左 op 右` 再入栈
- **先序遍历非递归**：弹栈访问 → 先压右、后压左；**中序**：一路向左入栈 → 弹栈访问 → 转右
- **层次遍历 / BFS**：用**队列**，出队访问后孩子（邻接点）入队
- **建堆**：自最后一个非叶 `⌊n/2⌋−1` 起自底向上筛选
- **哈夫曼构造**：每次取两个最小权合并，共 n−1 次
- **树/森林 → 二叉树**：左指针 = 第一个孩子，右指针 = 下一个兄弟
- **DFS / BFS**：DFS 用**栈**、BFS 用**队列**，均需 visited[]
- **Prim**：每次选"已选集 ↔ 未选集"的最小边；**Kruskal**：边升序 + 判环，凑满 n−1 条
- **拓扑排序**：选入度 0 → 输出 → 删其出边 → 重复（不能全输出即有环）
- **关键路径**：正推 ve(max) → 逆推 vl(min) → 算 e、l、余量 → 余量 0 为关键活动
- **Dijkstra**：选 dist 最小者入 S → 用 `dist[u]+w` 更新；**Floyd**：`D[i][j]=min(D[i][j], D[i][k]+D[k][j])`
- **折半查找**：`mid=⌊(low+high)/2⌋` 比较后缩区间
- **BST 插入**：查找到空位置插入（总在叶子）；**删除双子树结点**：中序前驱/后继顶替再删
- **AVL 旋转**：LL→右单旋 · RR→左单旋 · LR→先左后右 · RL→先右后左
- **B 树插入分裂**：中间关键字上移父结点，左右分裂，可向上传播
- **哈希建表**：`H(k)` 定地址 → 冲突按探测序列（线性 +1,+2,…；二次 ±1²,±2²…）试放 → 统计比较次数算 ASL
