一、第一章 绪论

1. 基本概念与术语

  • 【4卷】数据：信息的载体，能被计算机识别、存储和加工处理的符号集合。
  • 数据元素：数据的基本单位，又称结点/记录（一个元素可由若干数据项组成，数据项是不可分割的最小单位）。
  • 【6卷】数据结构：相互之间存在一种或多种特定关系的数据元素的集合；三要素＝逻辑结构 ＋ 存储结构 ＋ 数据的运算。
  • 【9卷】逻辑结构四类：集合 · 线性结构 · 树形结构（层次）· 图形结构（网状）；前两者为线性结构，后两者为非线性结构。
  • 【易混】给出若干结构判断"与其它不同" → 看到二叉树/树/图就是非线性，答案是它。
  • 【3卷】存储结构（物理结构）四种基本方法：顺序存储 · 链接存储 · 索引存储 · 散列存储。
    【6卷】逻辑结构与存储结构的关系：逻辑结构独立于存储结构，是面向问题的；存储结构是逻辑结构在计算机中的表示（映像/实现），同一逻辑结构可有多种存储结构，存储结构决定基本操作的实现效率。
  • 【易混】"逻辑结构与存储结构一一对应"＝错；"存储结构不同则逻辑结构一定不同"＝错。

2. 抽象数据类型 ADT

  • 【2卷】抽象数据类型：一个数学模型以及定义在该模型上的一组操作；与具体实现无关。
  • 表示：ADT 名字 { 数据对象 D；数据关系 R；基本操作 P }；描述算法用类 C 语言（伪码），不依赖具体机器与语言。

3. 算法及其 5 个特性

  • 【7卷】算法：对特定问题求解步骤的描述，是指令的有限序列。
  • 5 个准则/特性：有穷性 · 确定性 · 可行性 · 输入（0 个或多个）· 输出（至少 1 个）。
  • 【易混】"算法至少有 1 个输入"＝错（输入可以没有）；"算法必须有输出、可以没有输出" → 选"至少有一个输出"。
  • 【易混】"一个算法可以没有输出"＝错；"算法必须在有限步内结束"＝有穷性。
  • 程序 ＝ 算法 ＋ 数据结构（沃思 Wirth 名言，真题填空原题）。

4. 时间复杂度与空间复杂度（每卷必考 1～3 题）

  • 【2卷】问题规模 n：算法求解问题输入量的多少。
  • 时间复杂度：算法执行时间的相对度量，＝基本操作重复执行的次数（频度）关于 n 的函数 T(n)。
  • 【2卷】空间复杂度：算法执行时所需辅助存储空间的大小（不含输入数据本身）。
  • 大 O 表示法：只取最高阶项、去掉系数。
  • 性能优劣排序（从小到大／越优）：O(1) ＜ O(log₂n) ＜ O(n) ＜ O(n log₂n) ＜ O(n²) ＜ O(n³) ＜ O(2ⁿ) ＜ O(n!)
  • 【易混】真题给 O(2ⁿ)、O(n²)、O(n^{1/2})、O(n log n) 让选"最优" → 选阶最低的（如 O(n^{1/2}) 优于 O(n log n)）。
  • 【易混】常数阶：for(i=0;i<100;i++) 循环 100 次 → O(1)；双重循环 for i<n for j<n → O(n²)；for i<n for j<i → 仍是 O(n²)；i*=2 型 → O(log₂n)。
  • 最好/最坏/平均时间复杂度：例题若给的是"某些输入下"，注意问的是哪一种。
  • 算法设计策略：递推法 · 迭代法 · 递归法 · 贪心法 · 分治法 · 动态规划法（快速排序＝分治，哈夫曼＝贪心，Fibonacci＝递归/迭代）。
  • 【易混】递归必须有终止条件，否则栈溢出；递归可用栈实现非递归。

二、第二章 线性表

1. 定义与术语

  • 【4卷】线性表：n（n≥0）个数据元素的有序序列；有唯一表头元素与唯一表尾元素，除首尾外每个元素有唯一直接前驱与直接后继。
  • 表长＝元素个数；空表＝n=0；有序表/无序表按元素是否按关键字有序区分。
  • 【易混】"线性表是线性结构，元素类型必须相同（同一数据类型）"；栈、队列、串、数组都是线性结构（图、树不是）。

2. 顺序表（顺序存储）

  • 【2卷】顺序表：用一组地址连续的存储单元依次存放线性表元素 ⇒ 逻辑相邻一定物理相邻。
  • 随机访问：可随机存取任一元素，时间复杂度 O(1)。
  • 【9卷】地址计算（每年 1～2 题，必练）：
  • 下标从 0 起：LOC(a_i) = LOC(a_0) + i × c；LOC(a_i) = LOC(a_j) + (i−j) × c
  • 下标从 1 起：LOC(a_i) = LOC(a_1) + (i−1) × c
  • 【算装】给首地址 2000、每元素 4 字节 → 第 41 个元素（下标 1 起）＝2000＋40×4＝2160；给"第 1 个 1000、第 6 个 1040"→先求 c＝(1040−1000)/5＝8，再代第 16 个。
  • 【易混】"存储空间个数"（＝元素总个数）与"地址/单元数"（＝个数×c）不同；a[8][10] 每元素 3 个存储空间 → 空间个数＝8×10×3。
  • 【5卷】插入：在第 i 个位置插入，需移动 n−i+1 个元素；平均移动 n/2；时间复杂度 O(n)。
  • 删除：删除第 i 个元素，需移动 n−i 个元素；平均移动 (n−1)/2；O(n)。
  • 【易混】顺序表插入/删除慢、查找快；"按值查找"是 O(n)（需比较），"按位置查找"是 O(1)。

3. 链表（链式存储）

  • 链式存储：用任意的存储单元存元素，逻辑相邻不一定物理相邻（用指针表示逻辑关系）。
  • 【5卷】术语区分（高频易混）：
  • 【1卷】头结点：第一个结点之前附加的结点，数据域不存数据（或存表长），指针域指向首结点。
  • 首结点：第一个真正存数据的结点（即开始结点）。
  • 尾结点/终端结点：最后一个结点，其指针域为 NULL。
  • 头指针：指向头结点（无头结点时指向首结点）的指针，头指针一定存在，头结点可以不存在。
  • 头结点的作用：使空表与非空表统一处理、首结点与其他结点操作统一（插入/删除不用改头指针）。
  • 【2卷】单链表为空：head->next == NULL（带头结点）；head == NULL（不带头结点）。
  • 【4卷】单循环链表为空：head->next == head；尾结点判定：p->next == head（头指针 head）；若仅有尾指针 rear，则 rear->next == head，且 尾指针->next->next 是第二个结点，在表尾/表头插入均只需 O(1)。
  • 【2卷】双向链表：结点含 prior、data、next；删除 p：p->prior->next = p->next; p->next->prior = p->prior;。
  • 双向循环链表：head->prior 指向尾结点（用于找尾结点非常方便）。
  • 【1卷】静态链表：用数组模拟链表，用游标（下标）代替指针；空闲单元链表把所有空单元链成一张表。
  • 结构性开销：链表每个结点除数据外还要存指针域，故存储密度 < 1；顺序表存储密度 ＝ 1。

4. 三种存储方式对比与选择（选择题必考）

对比项 顺序表 单链表 静态链表
存储空间 连续 任意（离散） 数组内，游标链接
随机/顺序访问 随机访问 O(1) 顺序访问 O(n) 顺序访问
按位置插入/删除 O(n)（移动元素） O(1)（已知位置时改指针） O(1)
表长 需预先估计，可能溢出 动态、不需预估 预先定数组，可扩容难
存储密度 1（高） < 1（低） < 1
结构开销 无 有（指针） 有（游标）
  • 【5卷】选择口诀：频繁查找/随机访问 → 顺序表；频繁插入删除、长度变化大 → 链表；不能动态申请内存又要链表特性 → 静态链表。
  • 【易混】"能够随机存取任一元素的存储结构"＝顺序存储结构；"既适用于顺序存储也适用于链式存储的查找方法"＝顺序查找（二分查找只能用于顺序存储的有序表）。

三、第三章 栈和队列

1. 栈

  • 【4卷】栈（Stack）：只允许在一端（栈顶 top）进行插入（入栈/压栈）和删除（出栈/弹栈）的线性表 ⇒ 后进先出 LIFO（先进后出）。
  • 栈底：固定端，不允许操作；栈顶：可操作端。
  • 顺序栈：S[0..MaxSize-1]，top == -1 表空；top == MaxSize-1 表满。
  • 入栈：S[++top] = x;（或 top++; S[top]=x;）
  • 出栈：x = S[top--];
  • 【易混】若栈底设在 MaxSize-1 端（栈顶向低地址增长），则入栈是 top--; S[top]=x;（真题 2015 年 10 月原题）。
  • 两栈共享空间：S[0..n-1]，栈 1 底在 0、栈 2 底在 n−1，栈满条件 top1+1 == top2；两个栈底分别在最两端时空间利用率最高。
  • 链式栈：用单链表实现，栈顶在表头（头插头删，O(1)）；链栈不必设置头结点（栈顶指针即表头指针，空栈时 top==NULL；设了头结点反而多一层）。
  • 【4卷】栈空/栈满判定（真题反复考）：顺序栈空 top == -1（若 top 指向栈顶元素下标）；链式栈空 top == NULL。

2. 合理出栈序列的判定（每 2～3 套卷 1 题）

  • 【11卷】判别准则：以入栈序列为自然顺序时，输出序列中每个元素之后不得出现"比它小但比它后面的某个更小数更大"的倒置形态。最实用的判定法：
  • 在出栈序列中，若出现 i ＜ j 且 i 在 j 之后，则所有大于 i 且小于 j 的元素必须都在 i 之前出现。
  • 快速手算法：按出栈序列逐个还原"入栈→出栈"操作串，栈中元素必须始终满足从栈底到栈顶递增。
  • 【易混】入栈序列 1,2,3,4,5，不可能的出栈序列：出现"3 比 4 先出、5 又比 3 先出"型组合（如 4,5,1,3,2 或 1,2,5,3,4）；可能的：1,2,3,4,5；4,5,3,2,1；1,2,5,4,3；2,1,3,5,4。
  • 【1卷】n 个元素共有 Catalan 数种合法出栈序列：C(2n,n)/(n+1)（了解）。

3. 队列

  • 队列（Queue）：只允许在队尾 rear 插入（入队）、在队头 front 删除（出队）的线性表 ⇒ 先进先出 FIFO。
  • 顺序队列的"假溢出" → 用循环队列（把数组看成环，指针用 % MaxSize 回绕）。
  • 【5卷】循环队列判空判满（每年 1～3 题，必须背熟）：
约定 队空 队满 队长（元素个数）
牺牲一个单元（rear 指向队尾元素的下一空位） front == rear (rear+1)%m == front (rear − front + m) % m
牺牲一个单元（front 指向队头，rear 指向队尾元素） front == rear (rear+1)%m == front (rear − front + m) % m
设标志位/计数器 front == rear && tag == 0 front == rear && tag == 1 count（或按标志判断）
  • 【2卷】链式队列：队头在表头、队尾在表尾；带头结点的链队列用一个头指针＋一个尾指针唯一确定；头指针与尾指针相等 ⇒ 队空（带头结点时）。
  • 【易混】不带头结点的链队列队空条件 front == NULL && rear == NULL。
  • 入队：rear->next = p; rear = p;（注意先改指针再移 rear）
  • 出队：p = front->next; x = p->data; front->next = p->next;
  • 队列的应用：层次遍历（二叉树/图 BFS）· 缓冲区 · 打印机任务调度 · 离散事件模拟。

4. 双端队列

  • 【1卷】双端队列：两端都可插入和删除；输入受限＝只允许一端插入、两端删除；输出受限＝只允许一端删除、两端插入。
  • 【3卷】对顶栈（双栈共享一维数组）：出栈/入栈需用标志区分操作的是左栈还是右栈。

5. 栈与队列的应用（大题与算法题题源）

  • 【1卷】括号匹配：遇左括号入栈，遇右括号与栈顶匹配并出栈；扫描完栈为空则匹配成功。
  • 【4卷】中缀转后缀（中缀转后缀表达式）：
    1. 遇操作数直接输出；
    2. 遇左括号入栈；遇右括号依次弹出并输出直到左括号（左括号弹出但不输出）；
    3. 遇运算符：若其优先级 ≤ 栈顶运算符，则反复弹出栈顶并输出，然后该运算符入栈；
    4. 扫描结束把栈中剩余运算符依次弹出输出。
  • 【例】9 − (2 + 4 × 7) 的后缀表达式＝ 9 2 4 7 × + −
  • 【例】中缀 A+B*C−D/E → 后缀 A B C * + D E / −
    【0卷】后缀表达式求值：遇操作数入栈，遇运算符弹出两个操作数（先弹出的是右操作数）运算后结果再入栈；所需数据结构＝一个保存操作数及运算结果的栈。
  • 【1卷】递归与栈：递归调用用栈保存返回地址与参数（系统工作栈）。
  • 【易混】后缀表达式求值"用几个栈" → 一个栈（保存操作数与中间结果）；中缀转后缀用一个运算符栈。

四、第四章 数组、广义表和串

1. 多维数组与地址计算（每年 1～2 题，必拿分）

  • 数组：定长线性表的推广，元素类型相同、下标有序、本身是随机存取结构（一旦建立，元素个数固定）。
  • 【1卷】行主序（行优先、按行存放）＝C 语言/BASIC：先存第 0 行全部元素，再存第 1 行……
  • 【2卷】列主序（列优先）＝FORTRAN：先存第 0 列全部元素。
  • 【7卷】地址公式（下标从 0 起，m 行 n 列，每个元素占 d 个单元，首地址 SA）：
  • 行主序：Loc(a[i][j]) = SA + (i × n + j) × d
  • 列主序：Loc(a[i][j]) = SA + (j × m + i) × d
  • 下标从 1 起（m 行 n 列）：行主序 Loc(a[i][j]) = SA + ((i−1) × n + (j−1)) × d
  • 【算装示例】A[9][5]，d＝4，A[1][4] 地址 2000（下标从 0 起）→ SA = 2000 − (1×5+4)×4 = 1964；A[7][3] = 1964 + (7×5+3)×4 = 2116。
  • 【易混】三维数组 a[c1][c2][c3] 行主序：Loc(a[i][j][k]) = SA + ((i×c2 + j)×c3 + k) × d（2015 年 10 月、2023 年 4 月原题）；求"存储单元总数"就直接 c1×c2×c3×d（a[8][10] 每元素 3 个单元 → 240）。

2. 特殊矩阵的压缩存储

  • 【2卷】对称矩阵 a[n][n]（a[i][j] == a[j][i]）：只存下三角（含对角线），共 n(n+1)/2 个元素，存入一维数组 sa[0 .. n(n+1)/2 − 1]（行主序，下标从 0 起）：
  • 当 i ≥ j：k = i(i+1)/2 + j
  • 当 i ＜ j：k = j(j+1)/2 + i
  • 【记法】先数前 i 行共 i(i+1)/2 个（第 0 行 1 个、第 1 行 2 个……第 i−1 行 i 个），再加本行内的 j。
  • 【1卷】三角矩阵（上三角或下三角全为常数 c）：存 n(n+1)/2 个非零元素 ＋ 1 个常数 c，共 n(n+1)/2 + 1 个存储单元。
  • 对角矩阵（带状矩阵）：三对角矩阵（带宽 3）只需存 3n − 2 个元素；五对角 5n−6。
  • 【1卷】稀疏矩阵：非零元素个数 s 远小于 m×n（一般 s ≤ 0.05×m×n）；压缩存储方法＝三元组表（顺序存储）与十字链表（链式存储）。
  • 三元组＝(行下标 i, 列下标 j, 值 v)；三元组表用一维数组顺序存储（真题原题：三元组表采用的是一维数组）。
  • 三元组表通常按行优先（行序）排列；转置/相加需按序处理。
  • 【易混】稀疏矩阵压缩后失去随机存取特性（要按三元组表顺序查）。
  • 【易混】"数组的压缩存储"不等于"三元组表"，对称/三角矩阵用一维数组按公式映射。

3. 广义表

  • 【20卷】广义表（列表）：n（n≥0）个元素的有限序列，元素可以是原子（单个数据）也可以是子表（广义表）；记作 LS = (a₁, a₂, …, aₙ)。
  • 表长＝最外层（第一层）元素个数（＝最外层逗号数 ＋ 1）。
  • 深度＝括号的嵌套层数（＝所有元素中括号嵌套的最大层数 ＋ 1）；原子深度为 0；空表 () 长度为 0、深度为 1。
  • 表头 head＝第一个元素（可以是原子，也可以是子表）。
  • 表尾 tail＝去掉表头后剩下的元素构成的广义表 ⇒ 表尾一定是表，一定带括号！
  • 【算装示例】
  • A = (3, 5)：head(A) = 3；tail(A) = (5)
  • A = (a, (b, c, (e, f, g, h)))：表长 = 2，深度 = 3；tail(A) = ((b, c, (e, f, g, h)))
  • A = (a, (b, c, (e, f, g, h))) 的 head(tail(A)) = (b, c, (e, f, g, h))；再 tail(head(tail(A))) = (c, (e, f, g, h))
  • LS = ((a), a)：head = (a)，tail = (a)（注意两者字形相同、含义不同）
  • C = (A)：head(C) = A（子表本身），tail(C) = ()（空表）
  • 【2卷】递归表：表内直接或间接包含自身（如 G = (27, G)），深度为 ∞。
  • 【易混】"长度为 0 的广义表"＝空表 ()；"空表的表尾"＝不合法/空表定义；"深度是 ∞"＝递归表。

4. 串

  • 串（字符串）：由零个或多个字符组成的有限序列，记作 s = "a₁a₂…aₙ"。
  • 串长＝字符个数；空串＝长度为 0 的串 ""；空格串＝由空格组成的串（长度 ≠ 0）。
  • 【1卷】子串：串中任意个连续字符组成的子序列；主串：包含子串的串；模式串：用于匹配的子串。
  • 串相等：长度相同且对应位置字符相同。
  • 【易混】若模式串长 m、主串长 n，则子串个数 = n(n+1)/2 + 1（含空串）；模式匹配的合法起始位置数 = n − m + 1。
  • 【真题盲区·从未出题】BF（朴素/简单）模式匹配：从主串第 1 个字符起与模式串逐字符比较，失配则主串指针回溯到上一次起始位置 + 1。
  • 最坏比较次数 = m × (n − m + 1)，时间复杂度 O(m×n)。
  • 【真题盲区·从未出题】KMP 算法：利用模式串自身的特征向量 next，失配时主串指针不回溯，只移动模式串指针；时间复杂度 O(m + n)。
  • next[j]＝模式串前 j 个字符中最长相等前后缀的长度（不同教材下标约定不同：有的定 next[1] = 0、next[2] = 1；有的用 −1 起）。
  • 【易混】KMP 的关键在于求 next（特征向量），与主串无关，只与模式串有关。
  • 【易混】"空串"与"空格串"；"子串"必须连续（子序列无需连续）。

五、第五章 树与二叉树（第一大章，约 16%）

1. 树的基本概念与性质

  • 【4卷】树：n（n≥0）个结点的有限集合；有且仅有一个根；其余结点分成 m 个互不相交的子集，每集又是一棵树（递归定义）。
  • 术语：结点的度＝该结点的孩子个数；树的度＝所有结点度的最大值；叶子（终端）结点＝度为 0；分支结点＝度 > 0。
  • 层/深度：根为第 1 层（有的教材根为第 0 层 ⚠️ 看题干括号说明）；树的深度（高度）＝结点的最大层数；路径＝两结点间经过的分支（边）序列；路径长度＝路径上边的条数。
  • 森林＝m（m≥0）棵互不相交的树的集合（树去掉根就变成森林）。
  • 【1卷】结点数与边数关系：n 个结点的树有 n−1 条边；所有结点的度之和 ＝ n−1；n 个结点的森林含 m 棵树则边数 ＝ n − m。
  • 【易混】真题"森林有 N 个顶点 K 条边 → 树的棵数 m ＝ N − K"。给出"度之和为 k、结点 n"也能反求。

2. 二叉树的定义与 5 条性质（每年必考）

  • 【1卷】二叉树：每个结点至多有两棵子树（左子树、右子树），且左右次序不能颠倒（不是树的特例，不是度为 2 的有序树）。
  • 【8卷】5 条性质（必须背熟）：
    1. 第 i 层至多有 2^(i−1) 个结点（i ≥ 1）
    2. 深度为 k 的二叉树至多有 2^k − 1 个结点（k ≥ 1）
    3. 叶结点数 n₀ ＝ 度为 2 的结点数 n₂ ＋ 1（n₀ = n₂ + 1）
    4. n 个结点的完全二叉树深度为 ⌊log₂ n⌋ + 1（＝⌈log₂(n+1)⌉）
    5. 完全二叉树顺序存储（从 1 开始编号，结点 i）：双亲 ⌊i/2⌋、左孩子 2i、右孩子 2i+1；结点 i 有左孩子 ⇔ 2i ≤ n；从 0 开始编号：双亲 ⌊(i−1)/2⌋、左孩子 2i+1、右孩子 2i+2
  • 【1卷】满二叉树：深度 k、2^k − 1 个结点（每层都满）；完全二叉树：只有最下两层结点度可以小于 2，且最下层结点集中在左边。
  • 【3卷】二叉链表空指针域个数（真题高频）：n 个结点的二叉链表共有 2n 个指针域，其中指向孩子的 n−1 个 ⇒ 空指针域 ＝ 2n − (n−1) ＝ n + 1。
  • 【易混】含 80 个结点、79 个分支的二叉树 → 空指针域 ＝ 2×80 − 79 = 81。
  • 顺序存储的实用性：完全二叉树顺序存储不浪费空间；一般二叉树顺序存储最坏浪费很多（深度 k 的单支树需 2^k − 1 个单元）。
  • 【易混】"深度为 3 的二叉树至多 7 个结点"；"只有度 0 与度 2 的结点、深度 k 的二叉树最少结点数"＝2k − 1（每层 2 个，最下一层 1 个：k+(k−1)）。

3. 二叉树的遍历（每年 2～4 题）

  • 前序（先序）遍历 DLR：根 → 左 → 右 ｜ 中序遍历 LDR：左 → 根 → 右 ｜ 后序遍历 LRD：左 → 右 → 根 ｜ 层次遍历：按层从左到右（用队列）。
  • 遍历的递归定义：三种遍历都递归地先/中/后访问子树；非递归实现需用栈（层次遍历用队列）。
  • 【5卷】遍历序列的性质（考点）：
  • 前序的第一个结点 ＝ 根；后序的最后一个结点 ＝ 根；中序中根结点左边是左子树、右边是右子树。
  • 中序遍历最后一个结点＝根结点右子树中最右下的结点（若根无右子树则就是根）。
  • 前序第一个元素＝根；中序第一个元素＝最左下结点。
  • 【4卷】唯一确定一棵二叉树：前序 ＋ 中序 或 后序 ＋ 中序（必须含中序）；层次 ＋ 中序 也可以。
  • 【易混】前序 ＋ 后序、前序 ＋ 层次、后序 ＋ 层次 都不能唯一确定。
  • 【10卷】由序列还原/写序列的步骤（解答题必练）：前序取根 → 中序划分左右子树 → 递归；或后序取根（从后往前）。
  • 【6卷】线索二叉树：利用空指针域存放前驱/后继信息；线索＝指向结点在某种遍历次序下前驱或后继的指针；中序线索化后空指针域个数：n+1 个空域中被线索占用一部分——题给"左子树为空的二叉树在中序线索化后空指针域个数"＝2（该结点左空域存前驱、最右下结点右空域为 NULL），后序线索化同理。
  • 【易混】中序线索树中，找某结点的后继方便（右指针是线索就直接用，否则找右子树最左下）；后序线索树找后继需知道双亲。
  • 表达式树：运算符作内部结点，操作数作叶结点；中序遍历得中缀表达式（需加括号）、后序得后缀（逆波兰）式、前序得前缀式。

4. 堆与优先队列

  • 【5卷】堆：完全二叉树的顺序存储，满足堆序性：最大堆（大根堆）＝每个结点 ≥ 其孩子（堆顶是最大值）；最小堆＝每个结点 ≤ 其孩子（堆顶最小）。
  • 堆与完全二叉树的关系：堆一定用完全二叉树的顺序存储（下标从 1 起，结点 i 的孩子 2i、2i+1），不是二叉排序树（左孩子不必小于右孩子）。
  • 【8卷】建堆（自下而上筛选）：从最后一个非叶结点（⌊n/2⌋）开始，向前逐个向下调整（筛选）到根，时间复杂度 O(n)。
  • 【算装】序列 73,14,21,2,5,34,44,52,61 建最大堆 → 层序结果 73, 61, 44, 52, 14, 34, 21, 2, 5（2026 年真题）。
  • 插入：新元素放末尾，然后向上调整（与双亲比较交换），O(log₂n)。
  • 删除堆顶：用最后一个元素填补堆顶，再向下调整，O(log₂n)。
  • 【1卷】堆排序：反复"取堆顶 + 重建堆"，O(n log₂n)、空间 O(1)、不稳定；升序用最大堆，降序用最小堆（把堆顶换到尾部）。
  • 优先队列：每次出队的是优先级最高（最大或最小）的元素，用堆实现最合适（插入/删除 O(log₂n)）。
  • 【易混】"第 2 大元素可能位置有 2 个"（堆顶的两个孩子）；"第 3 大元素可能位置个数"要画图数（真题 2016 年 10 月答案 6）。

5. 树与森林

  • 树的三种常用存储表示：双亲（父结点）表示法 · 孩子表示法 · 孩子-兄弟（左孩子右兄弟，即二叉链表）表示法（父结点-孩子结点表示法＝结合法）。
  • 树、森林与二叉树的转换（口诀）：
  • 树 → 二叉树：左孩子右兄弟——每个结点的第一个孩子作左孩子，其余兄弟依次作右孩子的右孩子链。
  • 森林 → 二叉树：先把每棵树转成二叉树，再把后一棵树的根作为前一棵树根的右孩子。
  • 二叉树 → 树/森林：逆过程；若根有右子树就是森林，否则是树。
  • 【5卷】树的遍历：先根遍历 ↔ 对应二叉树的先序遍历；后根遍历 ↔ 对应二叉树的中序遍历。
  • 森林的遍历：先序遍历森林 ↔ 二叉树先序；中序遍历森林 ↔ 二叉树中序。
  • 【易混】树的后根遍历 = 二叉树的中序遍历（不是后序）；"森林的中序遍历"又叫"后根遍历森林"。

6. 哈夫曼树与哈夫曼编码（必出 1 道大题或 1 题选择）

  • 路径长度＝路径上分支（边）的条数；结点的带权路径长度＝从根到该结点的路径长度 × 该结点的权。
  • 树的带权路径长度 WPL＝所有叶结点的带权路径长度之和（⚠️ 只算叶结点）。
  • 【4卷】哈夫曼树（最优二叉树）：WPL 最小的二叉树；权值越大离根越近。
  • 构造步骤（必背）：
    1. 把 n 个权值看作 n 棵只有根的单结点树，组成森林；
    2. 每次从森林中选出两棵根权值最小的树，合并成一棵新树，新根权值＝两子树根权之和；
    3. 把新树放回森林，重复直到只剩一棵树。
  • 共需合并 n−1 次；哈夫曼树的结点总数 ＝ 2n − 1（n 个叶结点 ＋ n−1 个新结点）；n 个叶结点的哈夫曼树没有度为 1 的结点。
    【4卷】哈夫曼编码：从根到叶的路径上，左分支记 0、右分支记 1（反之亦可，编码方案不唯一）；
  • 一定是前缀编码（前缀码）：任一编码都不是另一编码的前缀，故译码无歧义；
  • 带权平均码长 ＝ WPL / Σ权值；WPL 最小 ⇔ 平均码长最短。
  • 【易混】"变长编码比定长编码更节省"（正确）；"哈夫曼树唯一"（错误，同权值选择次序不同 → 树形不同，但 WPL 相同）；"哈夫曼树中不存在度为 1 的结点"（正确）。

六、第六章 图结构（约 15%）

1. 基本概念与术语

  • 图 G = (V, E)：V 是顶点集（非空），E 是边集。
  • 有向图/无向图：边有方向为弧（〈v,w〉，v 为弧尾/起点，w 为弧头/终点）；无方向为边（(v,w)）。
  • 顶点的度：无向图中与该顶点相关联的边数；有向图中 度 = 入度 + 出度。
  • 【8卷】度与边数的关系（必考）：无向图 Σ度 = 2e（所有顶点度之和一定是偶数）；有向图 Σ入度 = Σ出度 = e。
  • 【易混】"无向图所有顶点的度之和为偶数"＝正确（真题原题）；"无向连通图边数大于顶点数减 1"＝错（至少等于 n−1）。
  • 完全图：无向完全图有 n(n−1)/2 条边；有向完全图有 n(n−1) 条弧。
  • 稀疏图/密集图（按 e 与 n² 的关系）；带权图/网：边上有权。
  • 路径/简单路径/回路（环）/简单回路；路径长度＝路径上边（弧）的数目。
  • 【5卷】连通图：无向图中任意两顶点间都有路径；连通分量＝无向图的极大连通子图；强连通图＝有向图中任意两顶点互相可达。
  • 【2卷】生成树：含全部 n 个顶点、恰好 n−1 条边的极小连通子图；n 个顶点的连通图至少 n−1 条边。
  • 【易混】"连通图的生成树唯一"（错，DFS/BFS 不同则不同）；"n 个顶点的连通图至少有 n−1 条边"（对）；"e 的取值范围"：无向连通图 n−1 ≤ e ≤ n(n−1)/2。

2. 图的存储结构

存储 结构 无向图 有向图 空间 适用
邻接矩阵 n×n 数组 A 对称矩阵，A[i][j]=1 表示 i−j 有边 一般不对称，行=出度、列=入度 O(n²) 密集图，判断两点是否相邻 O(1)

  • 【6卷】无向图邻接矩阵的性质：对称；第 i 行（列）非零元素个数 ＝ 顶点 i 的度；矩阵中 1 的总数 ＝ 2e。
  • 【易混】"图的另一种链式存储方式（除邻接表外）"＝逆邻接表（真题填空原题）。
  • 【易混】无向图邻接表表结点（边结点）总数的奇偶性：无向图中度数为奇数的顶点个数必为偶数；DFS 的时间复杂度：邻接矩阵 O(n²)、邻接表 O(n+e)。

3. 图的遍历（每年 1～3 题）

  • 【12卷】深度优先搜索 DFS：类似树的先根遍历，沿一条路走到底再回溯；用栈（或递归）；时间复杂度：邻接矩阵 O(n²)、邻接表 O(n+e)。
  • 广度优先搜索 BFS：类似树的层次遍历，逐层向外扩展；用队列；同样 O(n²)/O(n+e)。
  • 【4卷】关键性质：
  • BFS 可以求出无权图的最短路径（边数最少）；
  • DFS/BFS 的序列一般不唯一（邻接点访问次序不同则不同），但给定邻接表/邻接矩阵的存储次序时序列确定；
  • 遍历一次只能访问一个连通分量；对整个图遍历得到生成森林（连通图则是生成树）。
  • 【易混】"图的遍历是从某顶点出发对每个顶点访问且仅访问一次"＝正确；"BFS 序列唯一"＝错；"图的深度优先遍历是非递归过程"＝错（可以用递归）；"DFS 序列一定唯一"＝错。
  • 【易混】图的遍历需访问标志数组 visited[]，用于判重。

4. 最小生成树（MST）

  • 生成树：深度优先生成树 / 广度优先生成树；最小生成树：各边权值之和最小的生成树。
  • 【1卷】普里姆（Prim）算法：从任一顶点出发，每次选一条"连接已选点集与未选点集"的最小权边，把新顶点并入 ⇒ 适合稠密图，复杂度 O(n²)。
  • 【5卷】克鲁斯卡尔（Kruskal）算法：按权值从小到大考虑每条边，不选会构成回路的边，直到选满 n−1 条边 ⇒ 适合稀疏图，复杂度 O(e log e)。
  • 答题步骤（2026 年真题原样要求）：
    1. 把图中所有边按权值从小到大排序；
    2. 初始化生成树边集为空；
    3. 依次取最小权边，若加入后不形成回路就加入，否则丢弃；
    4. 重复直到边集包含 n−1 条边。
  • 【易混】"最小生成树唯一"（错，存在相同权值边时不唯一）；"生成树中一定含权值最小的 n−1 条边"（错）；"可能含权值最小的 n−1 条边"（正确，真题原题 2014 年 10 月）；MST 的边数恒为 n−1、"生成树中顶点数 n、边数 n−1"。

5. 有向无环图及其应用

  • 【2卷】AOV 网：顶点表示活动、弧表示活动间先后关系的有向无环图（拓扑排序用它）。
  • AOE 网：弧表示活动、权值表示活动持续时间、顶点表示事件（关键路径用它）。
  • 【2卷】拓扑排序（步骤必背）：
    1. 在有向图中选一个入度为 0 的顶点输出；
    2. 删除该顶点及其所有出边（相关顶点入度减 1）；
    3. 重复直到全部顶点输出（⇒ 无环）或找不到入度为 0 的顶点（⇒ 有环，不能拓扑排序）。
  • 【5卷】拓扑序列个数：入度为 0 的顶点越多，拓扑序列越多（若同时有 2 个入度为 0 的顶点 ⇒ 至少 2 个拓扑序列）。
  • 【易混】"顶点表示活动的有向无环图称为 AOV 网"（真题填空原题）；AOV 网中不允许出现回路。
  • 【真题盲区·从未出题·考纲要求掌握】关键路径（AOE 网）：
  • 事件 v 的最早发生时间 ve：从源点到 v 的最长路径长度（正向递推，取 max）
  • 事件 v 的最迟发生时间 vl：在不推迟整个工期的前提下 v 最迟必须发生的时间（逆向递推，取 min）
  • 活动 a = 〈i, j〉的最早开始时间 e(a) = ve(i)；最迟开始时间 l(a) = vl(j) − 持续时间
  • 时间余量（松弛时间）d(a) = l(a) − e(a)；d(a) = 0 的活动＝关键活动
  • 关键路径 ＝ 关键活动组成的路径 ＝ 从源点到汇点的最长路径；关键路径可能不唯一；缩短关键活动可缩短工期。
  • 【易混】关键路径 ≠ 最短路径；AOE 网只有一个源点和一个汇点才谈关键路径。

6. 最短路径

  • 【6卷】迪杰斯特拉（Dijkstra）算法：求单源（一个源点到其余各顶点）最短路径；按路径长度递增次序逐个产生；不能处理负权边；时间复杂度 O(n²)。
  • 步骤：① 初始化 dist[]、S 集合；② 每次从未在 S 中选 dist 最小的顶点 u 并入 S；③ 以 u 为中间点"松弛"更新其余顶点的 dist；④ 重复 n−1 次。
  • 【2卷】弗洛伊德（Floyd）算法：求所有顶点对之间的最短路径；三重循环，时间复杂度 O(n³)；可处理负权边（不能有负环）。
  • 递推思想：D^(k)[i][j] = min(D^(k−1)[i][j], D^(k−1)[i][k] + D^(k−1)[k][j])（依次以每个顶点为中间点迭代）。
  • 【易混】"某给定顶点到其余各顶点最短路径的条数"＝n−1（真题填空原题）；Dijkstra 贪心、Floyd 动态规划。

七、第七章 内部排序（约 13%）

1. 基本概念

  • 排序：把一组无序记录按关键字调整为有序的过程；内部排序＝数据全在内存中处理；外部排序＝数据量大，需内外存交换。
  • 【10卷】稳定排序：关键字相同的记录的相对次序排序前后不变；否则不稳定。
  • 评价标准：时间复杂度（比较/移动次数）· 空间复杂度 · 稳定性；数据初始排列状态也会影响某些算法。
  • 【易混】"不改变关键字相同元素相对位置的排序方法"＝稳定（2026 真题原题）。

  • "效率较高且使用辅助空间最少"→ 堆排序（O(1)）。
  • "平均比较次数最少"→ 快速排序（平均）。
  • "时间复杂度与数据初始状态相关"→ 快速排序 / 直接插入排序 / 起泡排序（不是选择排序、堆排序、归并排序、基数排序）。
  • "每一趟都能选出一个元素放在其最终位置上，且不稳定"→ 快速排序（选择排序也能定终位但稳定? ⚠️ 选择排序不稳定，此题多选条件必须叠加"不稳定"，真题答案多为快速排序）。
  • "不需要进行关键字比较的排序"→ 基数排序。
  • "最坏时间复杂度 O(n log n)"→ 归并、堆排序（快速排序最坏 O(n²)）。
  • "n 很小时最好的排序"→ 直接插入/直接选择。
  • "基本有序时最快"→ 直接插入排序（O(n)）；此时快速排序反而最慢（O(n²)）。
  • "第 k 趟排序结果（给中间状态反推算法）"→ 看"每趟是否把最大/最小放到端点"（起泡）、"是否是若干有序子段的两两归并"（归并）、"分块有序（前一段全小于后一段）"（快速排序）、"前 i 个局部有序"（插入/选择）。
  • 【易混】稳定性只有 4 个稳定算法：直接插入、起泡（冒泡）、归并、基数；希尔、快速、选择、堆排序都不稳定（口诀："插泡归基"稳定）。
  • 【易混】空间复杂度 O(n) 的只有归并排序（其他多为 O(1)，快速排序 O(log n)～O(n)）。
  • 【易混】"一趟排序后不一定能确定一个元素的最终位置"（起泡/归并的早期趟、插入/希尔）。

3. 排序过程题（解答题题源）

  • 【6卷】给一趟结果反推算法：看首尾（起泡把极值送到末端/前端）、看是否两两合并的有序段长度翻倍（归并）、看是否存在"前面全小于后面全大于"的分界（快速排序）、看是否有整块有序前缀（插入、选择）。
  • 【4卷】写各趟排序结果（归并/希尔/快速/起泡）：必须写"趟"，不得跳步；归并写"两两合并 → 四四合并 → ……"。
  • 【4卷】快速排序划分（partition）过程：以第一个元素为枢轴（或三元取中），左右交替扫描交换，最后枢轴归位；给出每趟划分后的序列。
  • 建堆过程题：写出初始堆；或给出初始序列建最大堆/最小堆并画完全二叉树；降序排序要建最小堆（⚠️ 真题 2024 年 4 月要求"降序排序，空间 O(1)"→ 建最小堆）。

八、第八章 查找（约 16%）

1. 基本概念

  • 查找：在查找表中确定关键字等于给定值的记录；查找成功/不成功。
  • 平均查找长度 ASL＝Σ(pᵢ × cᵢ)，pᵢ 为查找第 i 个元素的概率、cᵢ 为比较次数（等概率时 pᵢ = 1/n）。
  • 查找方法两大类：静态查找（顺序表/有序表：顺序、折半、分块） 与 动态查找（二叉排序树、AVL 树、B 树、散列表）。

2. 线性表查找

  • 【4卷】顺序查找：适用于顺序存储与链式存储，表可以无序；ASL成功 = (n+1)/2，ASL失败 = n（含与哨兵比较为 n+1）；时间复杂度 O(n)。
  • 【易混】"既能在顺序存储也能在链式存储上进行查找"＝顺序查找。
  • 【易混】在无序数组中进行查找 → 用顺序查找。
  • 【9卷】折半（二分）查找：前提＝有序表且顺序存储（能随机存取）；每次与 mid = ⌊(low+high)/2⌋ 比较后折半收缩区间。
  • 比较次数 ≤ 判定树高度 = ⌊log₂n⌋ + 1；ASL成功 ≈ log₂(n+1) − 1（近似）；时间复杂度 O(log₂n)。
  • 【算装】n = 16 的有序表 → 最多 5 次；n = 14 → 最多 4 次（⌊log₂14⌋+1 = 4）；查找失败的最大比较次数也是判定树高度（n = 14 → 4 次）。
  • 【易混】查找失败时的比较次数与"判定树的外部结点层次"有关，一般等于树高（有的教材为树高−1，⚠️ 看题干）；mid 下取整时，查找区间变化各不相同，需按步骤写。
  • 【易混】折半查找不适用于链表（不能随机定位 mid）。
  • 【2卷】分块查找（索引顺序查找）：把表分成若干块，块间有序（第 i 块所有元素 < 第 i+1 块所有元素）、块内无序；建立索引表（每块最大关键字 + 块起始地址）。
  • 查找过程：先在索引表中查（可顺序可折半），再在块内顺序查找。
  • ASL = 索引查找 ASL + 块内查找 ASL；最优块长 √n（等分块时平均查找长度最小）。
  • 【易混】"分块查找要求块内有序"＝错；要求"块间有序"＝对；"索引顺序查找"又名分块查找。
  • 【易混】"索引存储"是一种存储方法，与分块查找的"索引表"关联。

3. 树形结构的查找

  • 【2卷】二叉排序树（二叉查找树 BST）：
  • 定义（递归）：左子树上所有结点关键字 < 根；右子树上所有结点关键字 > 根；左右子树也各是 BST。
  • 重要性质：中序遍历得到一个递增有序序列（判 BST 的最快方法）。
  • 查找：从根开始，比根小往左、比根大往右；比较次数 ≤ 树高。
  • 插入：总是插在叶结点位置（不改变已有形态）；n 个结点的不同插入序列 → 不同形态的 BST。
  • 删除：① 叶结点直接删；② 只有一个孩子则孩子顶替；③ 有两个孩子则用中序前驱（左子树最右）或中序后继（右子树最左）替换，再删该结点。
  • ASL 与树形：形态越接近平衡越好（ASL ≈ log₂n）；最坏情况退化为单支树，深度 n，ASL = (n+1)/2（"构造 n 个结点的二叉排序树，最坏深度"＝n；高度最小的插入序列＝用折半法取中值构造）。
  • 【算装】给数据序列构造 BST，求查找成功的 ASL＝Σ(深度 × 该层结点数)/结点总数（2026 真题要求"保留 1 位小数"）。
  • 【真题盲区·考纲要求掌握】平衡二叉树（AVL 树）：任一结点的左右子树高度差（平衡因子 BF）的绝对值 ≤ 1；插入/删除后不平衡需旋转调整：
  • LL 型（左子树的左子树插入）→ 单向右旋；RR 型 → 单向左旋；LR 型 → 先左旋后右旋；RL 型 → 先右旋后左旋。
  • AVL 树查找时间复杂度 O(log₂n)。
  • 【4卷】B 树（m 阶 B 树/多路平衡查找树）：
  • 每个结点至多 m 棵子树（至多 m−1 个关键字）；根结点至少 1 个关键字（若非叶至少 2 棵子树）；除根外的非叶结点至少有 ⌈m/2⌉ 棵子树（⌈m/2⌉−1 个关键字）；所有叶结点在同一层。
  • 关键字在结点内有序；B 树是平衡的（所有叶在同一层）；新关键字只在最底层（叶结点层）插入，插入后若关键字数超过 m−1 则"分裂"，中间关键字上移到双亲。
  • 【算装】5 阶 B 树中除根之外每个结点最少 2 个关键字（⌈5/2⌉−1 = 2）；m 阶 B 树最少子树数 ⌈m/2⌉。
  • 【易混】B 树不是二叉树；"B 树插入总在叶结点层"（2026 真题原题）；B+ 树所有关键字都出现在叶结点、叶结点用指针链接、支持顺序（范围）查找。
  • 【易混】"不符合 m 阶 B 树定义"的选项常是"叶结点之间通过指针链接"（那是 B+ 树的特征）——2014 年 10 月、2015 年 4 月真题答案均为该项。

4. 哈希（散列）表及其查找（必出 1～2 题＋常出大题）

  • 【4卷】哈希方法（散列）：根据关键字计算元素的物理存储位置的存储方法（查找时间复杂度可接近 O(1)）。
  • 哈希函数：H(key) → 哈希地址；常见构造法：直接定址法 · 除留余数法（最常用：H(key) = key % p，p 取不超过表长的最大质数）· 数字分析法 · 平方取中法 · 折叠法。
  • 【4卷】冲突（碰撞）：不同关键字得到同一哈希地址；同义词＝哈希地址相同的两个关键字。
  • 解决冲突的方法：
  • 开放地址法（开放定址）：Hᵢ = (H(key) + dᵢ) % m；线性探查法（线性探测再散列）dᵢ = i（会产生聚集/堆积）；二次探查法 dᵢ = ±1², ±2²…；伪随机探测。
  • 链地址法（拉链法）：同一地址的记录链成单链表。
  • 【易混】"线性探查法和拉链法解决的是散列存储中的冲突问题"（真题填空原题）；线性探查法处理冲突时"探查次数"要逐个数（含第 1 次直接命中）。
  • 装填因子 α = 表中记录数 / 表长：α 越大冲突越多；ASL 只与 α 有关，与表长 m 无关（同一哈希函数与冲突法下）。
  • 【4卷】ASL 计算（大题必练）：
  • 查找成功的 ASL = 每个关键字的比较（探查）次数之和 / 关键字个数；
  • 查找失败的 ASL = 哈希函数每个可能地址上失败查找的比较次数之和 / 表长（或地址个数）。
  • 【算装示例】H(key) = key % 11，关键字 {65,23,31,26,7,91,53,15,72,52}，线性探测 → 逐个算地址、冲突则后移一位，记录每个关键字的探查次数，最后求 ASL。
  • 【易混】哈希方法使用的存储结构是数组（2026 真题原题）；"哈希查找不需要比较"＝错（发生冲突时仍需比较）；"装填因子越大查找越快"＝错。

⑥ 图算法过程 写邻接矩阵、求最小生成树（Prim/Kruskal 依次选的边）、求最短路径（Dijkstra 路径与长度）、写拓扑序列、求关键路径 每步写出已选集合/边集/距离数组的变化；最短路径要写出途经顶点序列及长度
⑦ 排序/查找过程 写各趟排序结果、反推算法、建堆并画堆、建散列表求 ASL、画折半查找判定树、构造 BST/AVL 并求 ASL 逐趟写全；ASL 写出算式（Σ 比较次数 / 元素个数）；保留小数位按题干

2. 算法题（阅读 ＋ 设计，题源高度固定）

  • 算法阅读题（4～5 题 × 5 分） 的固定形态：
  • 给一段含空白的函数，要求填 3 个空（链表插入/删除、栈出入栈、循环队列、二叉树遍历、图的度统计）；
  • 给函数问"该函数的功能是什么"（常见答案：求单链表长度/逆置/删除重复元素/求二叉树结点数、叶结点数、度为 1 的结点数、树的深度、交换左右孩子、中序遍历、统计图中各顶点度并返回最大度、按层遍历）；
  • 给程序问"输出结果是什么"（按 二叉树遍历序列、单链表输出、栈/队列模拟 手算）。
  • 【8卷】算法设计题（1 题 × 10 分） 的固定题源：
    1. 单链表：删除值重复的结点、删除所有值为 x 的结点、就地逆置、按序插入、求倒数第 k 个、合并两个有序链表
    2. 顺序表：删除某值的所有元素、统计 min ≤ x ≤ max 的个数、两有序表归并、就地逆置
    3. 栈与队列：判断出栈序列合法性、括号匹配、循环队列的入队出队函数、后缀表达式求值
    4. 二叉树：递归统计结点数/叶结点数/深度/度为 1 的结点数、交换左右子树、判断相似/相等、求指定层结点数
    5. 图：统计各顶点度、DFS/BFS 序列、判断是否有环、求拓扑序列
    6. 排序：直接插入/直接选择/起泡的实现（单链表上的选择排序、数组上的插入排序）
  • 答题模板（写算法时的得分点）：
    1. 写出结构定义（题目一般已给，直接引用）；
    2. 写出函数头（返回类型、参数）；
    3. 空表/边界判断（if (head == NULL) return;）；
    4. 核心循环（注意先连后断、q 与 p 双指针、free 掉被删结点）；
    5. return 正确结果。
  • 【易混】指针语句顺序：在 p 之后插入 s → s->next = p->next; p->next = s;（顺序不能颠倒）；删除 p 的后继 → q = p->next; p->next = q->next; free(q);

十、易混点一句判别（真题反复设的陷阱）

  1. 逻辑结构 vs 存储结构：逻辑结构面向问题且独立于存储；"两者一一对应"＝错。
  2. 顺序存储 vs 链式存储：逻辑相邻 → 顺序存储一定相邻、链式存储不一定（真题反复考）。
  3. 随机存取 vs 顺序存取：顺序表随机、链表顺序。
  4. 栈 LIFO vs 队列 FIFO：题目问"队列和栈的特征"→ 答"先进先出，先进后出"。
  5. 入栈序列合法性：出栈序列中出现"小、大、更小"的交叉倒置即非法。
  6. 循环队列：牺牲一个单元时 (rear+1)%m == front 为满（不是待判空）；front == rear 是空；队长 = (rear−front+m)%m。
  7. tail(A) 一定带括号；head(tail(A)) 先剥一层再取第一个。
  8. 广义表深度＝嵌套层数（含最外层括号算 1 层）；原子深度 0；空表深度 1。
  9. 满二叉树＝结点最多（2^k−1）；完全二叉树＝只有最下两层可不满且左集中；"深度 k 只有 0/2 度结点"最少 2k−1 个结点。
  10. n₀ = n₂ + 1（叶结点比双分支结点多 1）；n = n₀ + n₁ + n₂；边数 = n − 1 = n₁ + 2n₂。
  11. 二叉链表空指针域 = n + 1（n 个结点）；有 n 个结点的二叉树有 n+1 个空指针域，可与线索二叉树联系。
  12. 唯一确定二叉树必须含中序（前序＋后序不行）。
  13. 树的先根 = 二叉树先序；树的后根 = 二叉树中序（森林同理）。
  14. 哈夫曼树结点总数 = 2n − 1；WPL 只算叶结点；哈夫曼树没有度为 1 的结点；编码不唯一但 WPL 最小。
  15. 生成树边数恒为 n−1；无向连通图至少 n−1 条边；所有顶点度之和 = 2e 一定是偶数。
  16. Prim 适合稠密图、Kruskal 适合稀疏图；MST 不唯一但权值和最小。
  17. AOV 顶点表示活动（拓扑排序）；AOE 弧表示活动（关键路径）；AOV 有环则不能拓扑排序。
  18. Dijkstra 单源、Floyd 全对；Dijkstra 不能有负权；某源点到其余顶点最短路径条数 = n−1。
  19. 稳定排序只有 4 个：直接插入、起泡、归并、基数；不稳定：希尔、快速、选择、堆。
  20. 快速排序平均最快（O(n log n)）但最坏 O(n²)、空间 O(log n)；归并排序需 O(n) 辅助空间且稳定；堆排序空间 O(1)。
  21. "效率高且稳定"→ 归并；"效率高且辅助空间最省"→ 堆排序；"不需比较"→ 基数排序。
  22. 折半查找要求"有序 + 顺序存储"；顺序查找对存储无要求；分块查找要求块间有序、块内无序。
  23. 折半查找最大比较次数 = ⌊log₂n⌋ + 1（判定树高度）。
  24. BST 中序遍历有序；删除有两个孩子的结点用中序前驱/后继替换；BST 最坏深度 n。
  25. AVL 平衡因子 ≤ 1；LL 右旋、RR 左旋、LR 先左后右旋、RL 先右后左旋。
  26. m 阶 B 树：根至少 1 个关键字，非根非叶至少 ⌈m/2⌉−1 个关键字、⌈m/2⌉ 棵子树，最多 m−1 个关键字、m 棵子树；叶结点同层；"叶结点用指针链接"是 B+ 树。
  27. 哈希：线性探查法产生聚集；ASL 只与装填因子有关；哈希表用数组存储。
  28. "空串"长度 0，"空格串"长度不为 0；子串必须连续。
  29. KMP 的 next 只与模式串有关，主串指针不回溯；BF 最坏 O(mn)。
  30. 栈底在数组高端时入栈是 top−1；链栈不需要头结点。
