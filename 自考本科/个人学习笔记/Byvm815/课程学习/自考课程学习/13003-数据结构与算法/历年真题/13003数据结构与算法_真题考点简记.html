0.2 四条贯穿全课的主线

主线 1：三种存储结构 + 一种特殊存储（第 1、2 章——所有"为什么选它"的问题都从这张表出）

存储方式 逻辑相邻是否物理相邻 存取方式 插入删除代价 典型考点
顺序存储 一定相邻 随机存取 需移动元素（插入 n−i+1、删除 n−i） 地址公式、移动次数、二分查找前提
链式存储 不一定相邻 顺序存取 只改指针（先连后断） 判空、指针操作、静态链表
索引存储 — 先查索引再查数据 需维护索引表 分块查找要求块间有序、块内无序
散列（哈希）存储 — 按关键字直接计算地址 冲突需处理 散列函数、ASL、装填因子

主线 2：顺序表 vs 链表，怎么选（第 2 章，大题第 ⑧ 类模板的原题）

判据 选顺序表 选链表
主要操作 查找多（随机存取、时间复杂度 O(1)） 插入删除多（改指针即可）
表长变化 长度基本固定 长度变化大、难以预估
存储开销 无需额外指针域，但需预分配 有指针域开销，但可动态增长

主线 3：排序算法总表（第 7 章最重要的一张表）

排序方法 平均时间 最坏时间 辅助空间 稳定性 一句话特征
直接插入排序 O(n²) O(n²) O(1) 稳定 基本有序时最快；可用哨兵 r[0]
起泡（冒泡）排序 O(n²) O(n²) O(1) 稳定 相邻比较交换；趟数固定
简单选择排序 O(n²) O(n²) O(1) 不稳定 每趟选最小放到前面
希尔排序 O(n^1.3) O(n²) O(1) 不稳定 缩小增量的插入排序
快速排序 O(n log n) O(n²) O(log n) 不稳定 平均最快；以基准划分
堆排序 O(n log n) O(n log n) O(1) 不稳定 空间最省；建大根堆从小往上筛
归并排序 O(n log n) O(n log n) O(n) 稳定 效率高又稳定；适合链式存储
基数排序 O(d(n+r)) O(d(n+r)) O(r) 稳定 不比较关键字
  • 20 字口决：稳定只有"插、泡、归、基"；O(n log n) 是"快、堆、归"；空间最省是堆、最费是归。
  • 三个"看题干选算法"的固定搭配：基本有序 → 直接插入或冒泡；效率高且稳定 → 归并；效率高且辅助空间最省 → 堆排序。

主线 4：查找三结构 + 哈希（第 8 章）

查找方法 前提条件 ASL（等概率） 最大比较次数 对应存储
顺序查找 无要求 (n+1)/2（成功） n 顺序／链式皆可
二分（折半）查找 有序 ＋ 顺序存储 log₂(n+1) − 1 ⌊log₂n⌋ + 1 必须是顺序表
分块（索引顺序）查找 块间有序，块内无序 索引表 + 块内 — 索引 ＋ 顺序
BST 查找 建二叉排序树 Σ(深度×概率) 树高（最坏 n） 二叉链表
哈希查找 选好散列函数 与装填因子有关，与 n 无关 由冲突处理定 数组
  • 一句话："有序 + 顺序存储"是二分查找的门槛；哈希的 ASL 与元素个数 n 无关，只与装填因子有关。

第 1 章 绪论（C1，6 空）

本章知识地图：逻辑结构（线性／非线性）→ 存储结构（4 种）→ 数据类型 → 运算定义在哪 → 复杂度。

  • 线性 / 非线性结构的判定（2 空：同一个判定的两种问法——正面问"叫什么"，反面问"特征是什么"）
  • 在数据结构中，线性结构是数据元素之间存在着先后次序关系的结构。（A#25）
  • 非线性结构的特征是数据结点之间存在着一对多或多对多的关系。（C#11）
  • 【对照表】：线性＝一对一；树＝一对多；图＝多对多；集合＝无逻辑关系。
  • 数据的逻辑结构与存储结构（1 空）
  • 数据的运算是定义在数据的逻辑结构上的。（C#12）
  • 【一句话】"运算定义在逻辑结构上，实现落在存储结构上"。
  • 算法的时间复杂度与空间复杂度（1 空）
  • 如果一个算法的执行时间是一个与问题规模 n 无关的常数，则时间复杂度记作 T(n)＝O(1)。（B#11）
  • 数据类型与抽象数据类型（1 空）
  • 数据类型分为原子类型和结构类型。（B#12）
  • 存储结构的四种基本方法（1 空：只要看到"按关键字计算位置"就是散列）
  • 根据数据元素的关键字计算该元素物理存储位置的存储方法是散列（哈希）存储方法。（D#11）
  • 【四种存储方法】顺序 · 链式 · 索引 · 散列（见 0.2 主线 1）。

第 2 章 线性表（C2，7 空，填空数并列第一）

本章知识地图：线性表术语（表头／终端元素／前趋后继）→ 顺序表（地址计算、移动次数）→ 链表（判空、指针、静态链表）→ 选型。

  • 线性表的基本术语（1 空）
  • 线性表有且仅有一个终端元素，它没有后继，仅有一个直接前趋。（B#15）
  • 【术语对照】表头元素（无前趋）· 表尾/终端元素（无后继）· 前趋 · 后继。
  • 顺序表元素地址计算（1 空：必考公式题）
  • 设顺序表的每个元素占 8 个存储单元，第 1 个元素的存储首地址为 100，则第 6 个元素占用的最后一个存储单元的地址是 147（＝100＋5×8＋7）。（A#26）
  • 【公式】Loc(a_i) ＝ SA ＋ (i−1)×d（下标从 1 起）；Loc(a_i) ＝ SA ＋ i×d（下标从 0 起）。注意问的是"末地址"还是"首地址"。
  • 顺序表插入删除的移动次数（1 空）
  • 在长度为 n 的顺序表的第 i 个位置上插入一个元素，元素的移动次数为 n−i＋1。（B#14）
  • 【对照】插入 n−i＋1、删除 n−i；平均移动 n/2 与 (n−1)/2。
  • 线性表的存储结构（顺序 / 链式 / 静态链表）（1 空）
  • 在数组中保存的链表称为静态链表。（A#27）
  • 单链表的结构与判空（1 空："带头结点"是关键词）
  • 带头结点的单链表（以 head 为头指针）为空的判断条件是 head->next==NULL。（B#13）
  • 【对照】带头结点：head->next == NULL；不带头结点：head == NULL；循环链表（带头结点）：head->next == head。
  • 单链表的指针操作（1 空）
  • 单链表中每个结点的存储地址存放在其直接前趋结点的指针域中。（C#13）
  • 【指针语句铁律】在 p 之后插入 s：s->next = p->next; p->next = s;（顺序不能颠倒）；删除 p 的后继：q = p->next; p->next = q->next; free(q);
  • 线性表的查找操作（1 空：注意返回值是"位置"而不是"是否存在"）
  • 设线性表 s＝(1,3,5,7,9)，执行 find(s,3) 操作后的返回值为 2。（D#12）【注意】参考答案按"第 2 个位置"给出；若按 0 起始下标则为 1，原卷答案与教材下标约定不一致。

第 3 章 栈和队列（C3，2 空）

本章知识地图：栈（LIFO）→ 出栈序列判定／应用；队列（FIFO）→ 循环队列判空判满、链式队列。

  • 栈的基本操作与判空判满（1 空）
  • 栈操作中，只要栈不满，就允许入栈。（D#13）
  • 队列的存储与实现（1 空）
  • 链式队列采用带头指针及尾指针的单链表作为队列的存储结构。（A#30）
  • 【本课程第 3 章的核心表格】（虽然填空只 2 空，但解答题常问）
栈 队列
特点 后进先出（LIFO） 先进先出（FIFO）
顺序存储判空 top == -1（或 top == 0 视约定） front == rear
顺序存储判满 top == MaxSize−1 牺牲一个单元：(rear+1)%M == front
元素个数 top+1 (rear−front+M)%M
链式存储 链栈（不需要头结点） 链式队列（带头指针＋尾指针的单链表）

第 4 章 数组、广义表和串（C4，6 空）

本章知识地图：多维数组（行/列优先 → 地址计算）→ 特殊矩阵与稀疏矩阵 → 广义表（head/tail/长度/深度、递归性）→ 串。

  • 多维数组的行 / 列优先存储（2 空：同一概念的两个侧面——"按什么顺序存"和"第 k 个元素是谁"）
  • N 是一个 3×8 的二维数组，当 N 按行优先方式存储时，该数组的第 10 个元素应表示为 N[1][1]。（B#16）
  • 数组在 C 语言中是按行优先顺序存储的。（C#14）
  • 【公式】行优先 Loc(A[i][j]) ＝ SA ＋ (i×列数 ＋ j)×d；第 k 个元素（下标 0 起）＝ ⌊k/列数⌋ 行、k mod 列数 列。
  • 广义表的定义与性质（2 空"同一性质的两个侧面"）
  • 在描述广义表时又用到了广义表的概念，所以广义表具有递归的性质。（C#16）
  • 长度为 0 的广义表称为空表。（D#14）
  • 广义表的表头 / 表尾 / 长度 / 深度（1 空）
  • 广义表 G＝(a,b,(c,d,(e,f)),g) 的长度为 4。（A#29）
  • 【四条铁律】① 长度＝最外层元素个数；② head 取第一个元素本身；③ tail 取去掉第一个元素后剩下的表，一定带括号；④ 深度＝括号嵌套层数（原子深度 0、空表深度 1、最外层括号算 1 层）。
  • 特殊矩阵与稀疏矩阵（1 空）
  • 特殊矩阵中，非零元素个数远远小于矩阵元素总数的矩阵称为稀疏矩阵。（C#15）
  • 【对照】特殊矩阵（对称、三角、对角 → 压缩存储有规律）／稀疏矩阵（非零元素远少于总数 → 三元组表）。

第 5 章 树与二叉树（C5，4 空）

本章知识地图：树的术语 → 二叉树性质（n₀＝n₂＋1）→ 遍历与还原 → 存储（空指针域）→ 哈夫曼树 → 树/森林转换。

  • 二叉树性质：结点数与度的关系（1 空：计算题）
  • 一棵二叉树共有 20 个结点，其中叶结点为 5 个，则度为 1 的结点的个数是 11（n₁＝20−5−4）。（A#31）
  • 【公式组】n ＝ n₀ ＋ n₁ ＋ n₂；n₀ ＝ n₂ ＋ 1；边数 ＝ n−1 ＝ n₁ ＋ 2n₂。
  • 由遍历序列确定二叉树（1 空）
  • 根据先序遍历序列和中序遍历序列可以唯一确定一棵二叉树。（D#15）
  • 【判别】唯一确定二叉树必须含中序；前序＋后序不能唯一确定。
  • 哈夫曼树与带权路径长度（1 空）
  • 二叉树叶结点的带权路径长度定义为叶结点的权值与其到根结点的路径长度之积。（D#16）
  • 【哈夫曼树三句话】每次取两个最小权值合并；WPL 只算叶结点；结点总数 2n−1，没有度为 1 的结点。
  • 树与森林的相互转换（1 空）
  • 若一棵树的根结点删除，就得到该树的子树所构成的森林。（C#17）
  • 【转换口诀】树→二叉树："左孩子右兄弟"；树的先根遍历 ↔ 二叉树先序，树的后根遍历 ↔ 二叉树中序。
  • 【本章必背表】二叉树的 5 条性质：
序号 性质
1 第 i 层上至多 2^(i−1) 个结点
2 深度为 k 的二叉树至多 2^k − 1 个结点
3 n₀ ＝ n₂ ＋ 1（叶结点比双分支结点多 1）
4 n 个结点的完全二叉树深度 ＝ ⌊log₂n⌋ ＋ 1
5 顺序存储（下标从 1 起）：i 的左孩子 2i、右孩子 2i+1、双亲 ⌊i/2⌋

  • 无向图的邻接矩阵是对称矩阵。（D#17）

存储结构 空间 适合 求某顶点度 判断两边是否相邻

模板 ⑥ 排序（4 道，4/4 卷）

  • 出现形态：给一段排序程序，问"这是哪一种排序、是否稳定、哨兵 r[0] 的作用"；给序列写直接插入排序的每一趟；写快速排序每一趟划分；建立最大堆（大根堆）并画堆。

  • 稳定性口诀：稳定＝直接插入、起泡、归并、基数（"插泡归基"）。
  • 【程序识别速查表】（看到代码特征就能报出算法名）
代码特征 是哪种排序
r[0]=r[i]，从后往前边比较边后移 直接插入排序（带哨兵）
相邻两两比较交换，有"交换标志" 起泡（冒泡）排序
每趟扫描选最小，与第 i 个交换 简单选择排序
pivotkey = r[low]，两侧指针相向移动交换 快速排序
从 ⌊n/2⌋ 开始筛选下沉 堆排序（建堆）
相邻长度 1、2、4… 两两归并 归并排序

2.1 绪论与线性表

对照项 一句话判别
逻辑结构 vs 存储结构 逻辑结构面向问题、独立于存储；说"一一对应"＝错
顺序存储 vs 链式存储 逻辑相邻 → 顺序存储一定物理相邻，链式存储不一定
随机存取 vs 顺序存取 顺序表随机、链表顺序
插入 vs 删除移动次数 插入 n−i＋1、删除 n−i
带头结点 vs 不带头结点判空 head->next==NULL vs head==NULL

2.2 栈、队列、数组、广义表

对照项 一句话判别
栈 vs 队列 LIFO vs FIFO
循环队列 空 front==rear；牺牲一个单元时满 (rear+1)%m==front；队长 (rear−front+m)%m
出栈序列合法性 出现"小、大、更小"的交叉倒置即非法
head / tail tail(A) 一定带括号；head(tail(A)) 先剥一层再取第一个
广义表深度 嵌套层数（原子 0、空表 1、最外层括号算 1 层）
空串 vs 空格串 空串长度 0；空格串长度不为 0；子串必须连续

2.3 树与二叉树

对照项 一句话判别
满二叉树 vs 完全二叉树 满＝结点最多 2^k−1；完全＝只有最下两层可不满且左集中
n₀ 与 n₂ n₀ ＝ n₂ ＋ 1
二叉链表空指针域 n＋1（n 个结点）
唯一确定二叉树 必须含中序（前序＋后序不行）
树的先根 / 后根 树的先根 ↔ 二叉树先序；树的后根 ↔ 二叉树中序
哈夫曼树 结点总数 2n−1；WPL 只算叶结点；无度为 1 的结点

2.4 图

对照项 一句话判别
度之和 Σd ＝ 2e，一定是偶数
生成树边数 恒为 n−1
Prim vs Kruskal Prim 适合稠密图、Kruskal 适合稀疏图；MST 不唯一但权值和最小
AOV vs AOE AOV 顶点表活动（拓扑排序）；AOE 弧表活动（关键路径）；AOV 有环则不能拓扑排序
Dijkstra vs Floyd 单源 vs 全对；Dijkstra 不能有负权

2.5 排序与查找

对照项 一句话判别
稳定排序 只有"插、泡、归、基"（直接插入、起泡、归并、基数）
高效三兄弟 快排（平均）· 堆排 · 归并；空间最省＝堆（O(1)）、最费＝归并（O(n)）
选算法的固定搭配 基本有序 → 插入/冒泡；高效且稳定 → 归并；高效且省空间 → 堆；不比较 → 基数
折半查找前提 有序 ＋ 顺序存储；最大比较次数 ⌊log₂n⌋＋1
分块查找前提 块间有序、块内无序
BST 中序遍历一定有序；删除双孩子结点用中序前驱/后继替换
m 阶 B 树 非根非叶关键字 ⌈m/2⌉−1 ～ m−1，子树 ⌈m/2⌉ ～ m；叶结点同层；插入只在最底层；"叶结点用指针链接"＝B＋树
哈希 线性探查产生聚集；ASL 只与装填因子有关；哈希表用数组存储

附三、考前 30 分钟清单（只看这一页）

  • 复杂度排序：O(1) ＜ O(log n) ＜ O(n) ＜ O(n log n) ＜ O(n²) ＜ O(2ⁿ) ＜ O(n!)
  • 地址公式：行主序 SA + (i×列数 + j)×d（下标 0 起）；对称矩阵 i≥j 时 k ＝ i(i+1)/2 ＋ j
  • 顺序表：插入移动 n−i＋1、删除移动 n−i；平均移动 n/2 与 (n−1)/2
  • 循环队列：空 front==rear；满 (rear+1)%m==front；长 (rear−front+m)%m
  • 中缀→后缀：(8+2*5)/7 ⇒ 8 2 5 * + 7 /
  • 二叉树 5 性质：第 i 层 ≤ 2^(i−1)；深 k 至多 2^k−1；n₀＝n₂＋1；深 ⌊log₂n⌋＋1；顺序存储 i ↔ 2i、2i+1
  • 空指针域 ＝ n＋1；唯一确定二叉树：前序＋中序／后序＋中序
  • 哈夫曼：合并 n−1 次、结点 2n−1、WPL 只算叶结点
  • 树的先根 ↔ 二叉树先序；树的后根 ↔ 二叉树中序
  • 图：Σ度＝2e；完全无向图 n(n−1)/2 边；n 顶点有向图最多 n(n−1) 条边；生成树 n−1 边
  • Prim 稠密、Kruskal 稀疏；Dijkstra 单源、Floyd 全对
  • 拓扑排序：反复"取入度 0 顶点并删其出边"；关键活动：时间余量 ＝ 最迟开始 − 最早开始 ＝ 0
  • 稳定排序：直接插入、起泡、归并、基数
  • O(n log n)：快速（平均）、堆、归并；空间 O(1)：堆；空间 O(n)：归并
  • 折半查找最大比较次数 ＝ ⌊log₂n⌋＋1，前提"有序＋顺序存储"
  • BST 中序有序；AVL 平衡因子的绝对值 ≤ 1；LL 右旋、RR 左旋、LR 先左后右、RL 先右后左
  • m 阶 B 树：非根非叶关键字 ⌈m/2⌉−1 ～ m−1，叶同层，插入只在最底层
  • 哈希：除留余数 H(key)=key % p；ASL 成功 ＝ 探查次数和 ／ 元素个数
  • 图算法大题写三步：选中的边／确定的顶点、更新的数组、最终结果
  • 算法题最后写边界判断：空表、空树、单结点、return 不要漏
  • 解答题必须写过程：排序写"趟"、图算法写"每步"、还原二叉树写"递归划分"
