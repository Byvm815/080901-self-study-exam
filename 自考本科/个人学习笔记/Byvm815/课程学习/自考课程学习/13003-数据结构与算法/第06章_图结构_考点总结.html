二、图的基本概念与基本操作

（一）识记（术语）

术语 含义
图 G = (V, E) 顶点集 V + 边集 E；
子图 顶点集、边集分别是原图的子集（E' ⊆ E 且边的端点都在 V' 中）
无向边 (v, w) 无方向的边；有向边/弧 ：v 为弧尾（始点），w 为弧头（终点）
无向图 / 有向图 边无方向 / 边有方向
带权图（网） 每条边（弧）附带权值（表示距离、代价、时间等）
邻接点 无向图：(v,w) 存在则 v、w 互为邻接点；有向图： 存在则 v 邻接到 w
关联 边与其两端顶点相关联（一条边关联两个顶点）
顶点的度 TD(v) 无向图：与该顶点关联的边数；有向图：入度 ID(v) + 出度 OD(v)
入度 / 出度 以该顶点为弧头的弧数 / 以该顶点为弧尾的弧数
稀疏图 / 密集图 e 远小于 n²（一般 e < n·log n）/ e 接近 n²
完全图 无向完全图：n(n−1)/2 条边；有向完全图：n(n−1) 条弧
路径 / 有向路径 顶点序列 v₀v₁…vₖ（相邻顶点间有边）/ 沿弧方向的路径
简单路径 / 简单回路 顶点不重复出现 / 除首尾外顶点不重复的回路
回路（环） 首尾顶点相同的路径
路径长度 路径上的边数；带权图中为各边权之和
连通图 无向图中任意两顶点间都有路径
连通分量 无向图中的极大连通子图
强连通图 / 强连通分量 有向图中任意两顶点互相可达 / 极大强连通子图
弱连通图 有向图忽略方向后连通
有向无环图（DAG） 不含回路的有向图

（二）领会

  • 1. 顶点与边的关联性：每条边关联两个顶点（无向边）或一个弧尾、一个弧头（有向边）；顶点的度正是由"关联的边数"定义的。

  • 2. 邻接的含义：邻接描述顶点与顶点之间的关系（有边相连）；关联描述顶点与边之间的关系——两者不是一回事。

  • 3. 边与顶点的度的关系（必考）

  • 无向图：ΣTD(v) = 2e（每条边给两端各贡献 1 度）；

  • 有向图：ΣID(v) = ΣOD(v) = e；ΣTD(v) = 2e。

  • 4. 有向路径：必须沿着弧的方向前进；有向图中"(v,w) 有路径"与"(w,v) 有路径"是两回事（这正是强连通与弱连通的区别）。

（三）简单应用（特性小计算）

  • n 个顶点的无向完全图边数 = n(n−1)/2（n=5 → 10）；有向完全图弧数 = n(n−1)（n=5 → 20）；
  • 由度求边数：e = ΣTD / 2；
  • 例：无向图中有 3 个度为 4 的顶点、4 个度为 3 的顶点，其余顶点度均小于 3，求顶点数最少是多少？
    已知度和 = 3×4 + 4×3 = 24 → 2e ≥ 24 需为偶数（成立）；余下度和 = 2e − 24，且每个小于 3 的顶点度 ≤ 2 → 余下顶点数 ≥ (2e−24)/2；取 e = 12（度和 24）时余下度为 0，最少顶点 = 3+4 = 7；
  • 判断图是否连通、是否为完全图、是否含环、某序列是否为路径等。

三、图的存储结构及基本操作的实现

（一）识记

存储结构 结构描述
邻接矩阵 一维数组 vexs[n] 存顶点 + 二维数组 arcs[n][n] 存边（0/1 或权值；无边用 0 或 ∞ 【注意】）
邻接表 顶点表（表头结点） 数组：data + firstarc；每个顶点挂一条边表，表结点为 adjvex（邻接点在顶点表中的下标）+ nextarc（+ info 权值）
逆邻接表 与邻接表结构相同，但边表中存放的是指向该顶点的弧（入边），便于求入度
表结点 邻接表中表示一条边的结点（adjvex + nextarc）
（扩展）十字链表 / 邻接多重表 便于同时求有向图出入度 / 处理无向图每条边存储两次的问题

（二）领会：三种结构与图的对应关系

  • 空间：邻接矩阵：O(n²)（与边数无关）；邻接表：O(n + e)；逆邻接表：O(n + e)
  • 适合：邻接矩阵：密集图；邻接表：稀疏图；逆邻接表：稀疏图（侧重入度）
  • 判断 (i,j) 是否相邻：邻接矩阵：O(1)；邻接表：O(度)；逆邻接表：O(度)
  • 求某顶点的所有邻接点：邻接矩阵：O(n)；邻接表：O(度)；逆邻接表：O(入度)
  • 无向图：邻接矩阵：矩阵对称；第 i 行（列）非零个数 = 顶点 i 的度；邻接表：边表结点总数 = 2e；逆邻接表：同邻接表
  • 有向图：邻接矩阵：第 i 行非零个数 = 出度；第 i 列非零个数 = 入度；邻接表：边表结点总数 = e，求出度易、求入度难；逆邻接表：便于求入度，求出度难

（三）简单应用（实现与信息获取）

// 邻接矩阵存储
#define MAXV 100
typedef struct { ElemType vexs[MAXV]; int arcs[MAXV][MAXV]; int n, e; } MGraph;

// 邻接表存储
typedef struct ArcNode {            // 表结点（边结点）
    int adjvex;                     // 该边另一顶点在顶点表中的下标
    struct ArcNode *nextarc;
    int info;                       // 权值（网）
} ArcNode;
typedef struct VNode {              // 表头结点（顶点结点）
    ElemType data; ArcNode *firstarc;
} VNode, AdjList[MAXV];
typedef struct { AdjList vertices; int n, e; } ALGraph;
  • 根据存储结构实现基本操作 / 获取图的基本信息
  • 邻接矩阵：求顶点度（数行/列非零个数）、判断两点是否相邻、求所有邻接点；
  • 邻接表：遍历某顶点的边表可得其所有邻接点与出度；统计全表可得入度（或改用逆邻接表直接求入度）；
  • 无向图邻接表的边表结点数 = 2e；有向图 = e（由此可校验建表是否正确）。

（四）综合应用

按问题特点选择存储结构：密集图 + 频繁判断相邻 → 邻接矩阵；稀疏图 + 频繁求邻接点/遍历 → 邻接表；频繁求入度 → 逆邻接表（或十字链表）；然后设计算法（如求度、判连通、路径查找）。

四、图的搜索

（一）识记

术语 含义
图的搜索（遍历） 从某顶点出发，沿边访问图中所有顶点且每个顶点仅访问一次的过程
深度优先搜索（DFS） 类似树的先序遍历：访问顶点 → 递归访问其未访问的邻接点 → 回溯
广度优先搜索（BFS） 类似树的层次遍历：访问顶点 → 依次访问其所有未访问邻接点 → 再按访问顺序处理下一层

（二）领会

  • 1. 图搜索的特性：图可能有回路且可能不连通，因此必须设 visited[] 访问标志数组防止重复访问；对非连通图需对每个未访问顶点重新发起一次搜索（每次得到一个连通分量）。

  • 2. 图的搜索序列：与起始顶点和邻接点的访问次序（存储结构中的顺序） 有关——同一图不同起点或不同存储顺序，搜索序列不同。

  • 3. 图搜索时使用的辅助数据结构

  • DFS：栈（递归时用系统栈；非递归时显式栈）+ visited[]；
  • BFS：队列 + visited[]。
  • 都需要 visited[n]。

（三）简单应用（实现与搜索序列）

int visited[MAXV];
void DFS(ALGraph G, int v) {                 // 邻接表 DFS（递归）
    visit(v); visited[v] = 1;
    for (ArcNode *p = G.vertices[v].firstarc; p; p = p->nextarc)
        if (!visited[p->adjvex]) DFS(G, p->adjvex);
}
void BFS(ALGraph G, int v) {                 // 邻接表 BFS（队列）
    int q[MAXV], front = 0, rear = 0;
    visit(v); visited[v] = 1; q[rear++] = v;
    while (front < rear) {
        int u = q[front++];
        for (ArcNode *p = G.vertices[u].firstarc; p; p = p->nextarc)
            if (!visited[p->adjvex]) { visit(p->adjvex); visited[p->adjvex] = 1; q[rear++] = p->adjvex; }
    }
}
  • 示例：V = {1,2,3,4,5}，边 1-2, 1-3, 2-4, 3-4, 4-5（邻接点按序号升序）
  • DFS 序列：1, 2, 4, 3, 5（1→2→4→3（4 的邻接点按序）→回退→5）

  • BFS 序列：1, 2, 3, 4, 5

  • 复杂度：邻接矩阵 O(n²)；邻接表 O(n + e)（DFS、BFS 相同）。

（四）综合应用（基于搜索思想）

① 求连通分量个数；② 判断两顶点间是否有路径、求一条简单路径；③ 判断图中是否有环（DFS 中出现回边）；④ 判断二分图（BFS/DFS 染色）；⑤ 迷宫求解、连通块统计（岛屿问题）；⑥ 无向图求割点/桥（扩展）；⑦ 拓扑排序的 DFS 实现。

五、图的生成树

（一）识记

术语 含义
生成树 连通图的极小连通子图：含全部 n 个顶点和 n − 1 条边（再加一条边必成环，少一条边必不连通）
深度优先生成树 由 DFS 得到的生成树（非连通图得到生成森林）
广度优先生成树 由 BFS 得到的生成树
最小生成树（MST） 带权连通图中边权之和最小的生成树

（二）领会

  • 1. 生成树的特性：n 个顶点、恰好 n−1 条边、连通且无环；生成树可能不唯一（DFS/BFS 生成树通常不同，最小生成树也可能不唯一——当存在等权边时）。

  • 2. 最小生成树的特性：权值之和最小；包含 n 个顶点、n−1 条边；MST 不唯一但最小代价唯一。

  • 3. 普里姆（Prim）算法的求解策略："加点法"

  • 从任一顶点出发，把顶点逐步加入集合 U（已入选）；
  • 每次在"U 中顶点 ↔ V−U 中顶点"的所有边中选权最小的一条，把对应顶点加入 U；
  • 重复 n−1 次；

  • 适合密集图，时间复杂度 O(n²)（邻接矩阵；用堆可优化到 O(e log n)）。

  • 4. 克鲁斯卡尔（Kruskal）算法的求解策略："加边法"

  • 把所有边按权值从小到大排序；
  • 依次考察每条边，若它的两个端点不在同一连通分量（加入后不形成回路）则选入；
  • 直到选够 n−1 条边；

  • 适合稀疏图，时间复杂度 O(e log e)（排序 + 并查集）。

  • 5. 最小生成树代价的计算：把选中的 n−1 条边权值相加。

（三）简单应用（必考过程题）

  • 示例：顶点 A、B、C、D、E、F，边权 A-B 6、A-C 1、A-D 5、B-C 5、B-E 3、C-D 5、C-E 6、C-F 4、D-F 2、E-F 6

  • 用 Prim 求 MST（从 A 出发）

  • 1：入选顶点集：{A}；可选的最小边：A-C(1)；选入边（权）：A-C (1)

  • 2：入选顶点集：{A,C}；可选的最小边：C-F(4)；选入边（权）：C-F (4)
  • 3：入选顶点集：{A,C,F}；可选的最小边：F-D(2)；选入边（权）：F-D (2)
  • 4：入选顶点集：{A,C,D,F}；可选的最小边：C-B(5)；选入边（权）：C-B (5)

  • 5：入选顶点集：{A,B,C,D,F}；可选的最小边：B-E(3)；选入边（权）：B-E (3)

  • MST 代价 = 1 + 4 + 2 + 5 + 3 = 15

  • 用 Kruskal 求 MST
    边按权排序：AC(1), DF(2), BE(3), CF(4), AD(5), BC(5), CD(5), AB(6), CE(6), EF(6)

  • AC(1) 选入（{A,C}）；DF(2) 选入（{D,F}）；BE(3) 选入（{B,E}）；
  • CF(4)：C∈{A,C}、F∈{D,F} 不同 → 选入（合并为 {A,C,D,F}）；
  • AD(5)：同在 {A,C,D,F} → 舍去（成环）；
  • BC(5)：C∈{A,C,D,F}、B∈{B,E} 不同 → 选入（全图连通）；
  • 已有 5 = n−1 条边 → 结束。
  • MST 代价 = 1 + 2 + 3 + 4 + 5 = 15（与 Prim 结果一致，MST 边集相同）

（四）综合应用

① 网络布线/管道铺设的最小成本设计；② 判断图是否连通（生成树能否覆盖全部顶点）；③ 求"次小生成树"（扩展）；④ 基于 Prim/Kruskal 策略的贪心算法设计。

六、有向无环图及其应用

（一）识记

术语 含义
AOV 网 顶点表示活动、弧表示活动间先后关系的有向图（Activity On Vertex）
AOE 网 顶点表示事件、弧表示活动、弧权表示活动持续时间的有向图（Activity On Edge）
源点 / 汇点 AOE 网中唯一入度为 0 的顶点（开始事件）/ 唯一出度为 0 的顶点（结束事件）
前驱 / 后继 / 直接前驱 / 直接后继 活动间的先后关系（弧的指向）
活动 / 事件 弧 / 顶点
拓扑排序 / 拓扑序列 把 AOV 网顶点排成线性序列，使每条弧 中 u 都排在 v 之前 / 这样的序列
入度值表 记录各顶点当前入度的表（拓扑排序中用）
关键路径 / 关键活动 从源点到汇点路径长度最长的路径 / 关键路径上的活动（时间余量为 0）
事件最早开始时间 ve / 最迟开始时间 vl 事件可能发生的最早 / 最迟时刻
时间余量（松弛时间） 活动的最迟开始时间 − 最早开始时间；为 0 即关键活动
活动的持续时间 弧的权值

（二）领会 + （三）简单应用

  • 1. 拓扑排序的过程（必考）
    ① 在 AOV 网中选一个入度为 0 的顶点并输出；
    ② 删除该顶点及其所有出边（相关顶点入度减 1）；
    ③ 重复 ①②，直到全部顶点输出（成功）或找不到入度为 0 的顶点而仍有顶点未输出（说明有环）。
  • 用栈/队列保存入度为 0 的顶点；复杂度 O(n + e)；

  • 拓扑序列可能不唯一；判断有向图是否存在环：拓扑排序能否输出全部顶点。

  • 2. 关键路径的求解过程（必考，AOE 网）
    ① 正向递推求事件最早开始时间：ve(j) = max{ ve(i) + w(<i,j>) }（源点 ve = 0）；
    ② 逆向递推求事件最迟开始时间：从汇点开始 vl(j) = min{ vl(k) − w(<j,k>) }，vl(汇点) = ve(汇点)；
    ③ 求活动的最早开始时间：e(a) = ve(弧尾)；
    ④ 求活动的最迟开始时间：l(a) = vl(弧头) − 活动持续时间；
    ⑤ 时间余量 = l(a) − e(a)；余量为 0 的活动即关键活动；
    ⑥ 关键活动构成的从源点到汇点的路径即关键路径（可能不唯一），其长度即最短工期。

  • 3. 关键路径计算示例（经典 AOE 网）

活动 弧 权
a1 V1→V2 6
a2 V1→V3 4
a3 V1→V4 5
a4 V2→V5 1
a5 V3→V5 1
a6 V4→V6 2

七、最短路径

（一）识记

术语 含义
源点 / 终点 路径的起点 / 终点
带权图中的路径长度 路径上各边权值之和
单源最短路径 从一个源点到其余各顶点的最短路径（Dijkstra 算法）
所有点对间的最短路径 图中每一对顶点之间的最短路径（Floyd 算法）

（二）领会 + （三）简单应用

  • 1. 迪杰斯特拉（Dijkstra）算法的求解过程（单源，贪心）
  • 设集合 S（已确定最短路径的顶点，初始只含源点 v₀），数组 dist[i] 记录 v₀ 到 i 的当前最短距离（初始为直接边的权，无直接边为 ∞）；
  • ① 选：从 V−S 中选 dist 最小的顶点 u 加入 S；
  • ② 更新：对 u 的每个邻接点 w，若 dist[u] + w(u,w) < dist[w] 则更新 dist[w]（并记录前驱 p[w] = u）；
  • ③ 重复 ①② 共 n−1 次，直到所有顶点加入 S；

  • 要求所有边权非负；邻接矩阵实现 O(n²)（堆优化 O(e log n)）；dist 数组给出最短距离，p 数组可还原路径。

  • Dijkstra 计算示例（有向图，源点 1）
    边：1→2 (2)、1→3 (5)、2→3 (1)、2→4 (7)、3→4 (3)

  • 初始：S：{1}；dist[2]：2；dist[3]：5；dist[4]：∞；选入：—

  • ①：S：{1,2}；dist[2]：2；dist[3]：min(5, 2+1)=3；dist[4]：min(∞, 2+7)=9；选入：2
  • ②：S：{1,2,3}；dist[2]：2；dist[3]：3；dist[4]：min(9, 3+3)=6；选入：3

  • ③：S：{1,2,3,4}；dist[2]：2；dist[3]：3；dist[4]：6；选入：4

  • 结果：1→2 = 2；1→2→3 = 3；1→2→3→4 = 6

  • 2. 弗洛伊德（Floyd）算法的求解过程（所有点对，动态规划）

  • 用邻接矩阵 D（D[i][j] 为 i→j 的当前最短距离，无边为 ∞）；
  • 递推公式：D⁽ᵏ⁾[i][j] = min( D⁽ᵏ⁻¹⁾[i][j], D⁽ᵏ⁻¹⁾[i][k] + D⁽ᵏ⁻¹⁾[k][j] )
    即"允许经过顶点 k 中转"时是否更短；k 从 1 到 n 逐轮更新；
  • 时间复杂度 O(n³)；允许负权边（但不能有负权回路）；

  • 可同时用 path[i][j] 记录路径经过的中间顶点。

  • Floyd 计算示例（3 个顶点：1→2 权 4、2→3 权 1、1→3 权 10）

  • D⁽⁰⁾ = [[0,4,10],[∞,0,1],[∞,∞,0]]
  • k=2 时：D[1][3] = min(10, 4+1=5) = 5 → D = [[0,4,5],[∞,0,1],[∞,∞,0]]

  • k=1、k=3 无改进 → 1→3 最短距离 = 5（路径 1→2→3）

  • 3. 三种算法对照

  • Dijkstra：解决的问题：单源最短路径；思想：贪心（逐步扩充 S）；时间复杂度：O(n²) / O(e log n)；权值限制：非负权

  • Floyd：解决的问题：所有点对最短路径；思想：动态规划（逐轮加中转点）；时间复杂度：O(n³)；权值限制：可含负权（无负环）
  • （对比）Prim：解决的问题：最小生成树；思想：贪心加点；时间复杂度：O(n²)；权值限制：无向连通带权图

（四）综合应用

① 交通/网络路由的最短代价路径；② 地图导航、物流配送；③ 城市间最短里程/最少费用/最快时间；④ 结合路径数组输出具体路径；⑤ 判断负权回路（Bellman-Ford，扩展）。

八、本章对比与易混点

易混点 正确理解
邻接 vs 关联 邻接＝顶点与顶点；关联＝顶点与边
无向图度 vs 有向图入/出度 无向：关联边数；有向：入度 + 出度
完全图边数 无向 n(n−1)/2；有向 n(n−1)
连通 vs 强连通 vs 弱连通 无向图连通 / 有向图互相可达 / 有向图忽略方向后连通
连通分量 vs 强连通分量 无向图的极大连通子图 / 有向图的极大强连通子图
邻接矩阵 vs 邻接表 矩阵 O(n²) 适合密集图、判断相邻 O(1)；邻接表 O(n+e) 适合稀疏图、求邻接点快
邻接表求入度 需遍历全表（O(n+e)）→ 用逆邻接表解决
无向图邻接表边结点数 2e（每条边存两次）；有向图为 e
DFS vs BFS DFS 用栈（似先序）、BFS 用队列（似层次）；复杂度：矩阵 O(n²)、邻接表 O(n+e)
生成树 vs 最小生成树 生成树只要极小连通（n−1 条边）；MST 要求权和最小
Prim vs Kruskal Prim 加点、稠密图、O(n²)；Kruskal 加边（排序 + 判环）、稀疏图、O(e log e)
AOV vs AOE AOV 顶点=活动（拓扑排序）；AOE 弧=活动、顶点=事件（关键路径）
拓扑排序 vs DFS 拓扑排序用"入度为 0"逐步删除；也可用 DFS 按完成时间逆序
ve / vl 方向 ve 正向递推取 max；vl 逆向递推取 min
关键活动判据 时间余量 l(a) − e(a) = 0
Dijkstra vs Prim 都是"选最小、更新"，但 Dijkstra 更新的是到源点的距离和（dist[u]+w），Prim 更新的是到树的距离（只看 w）
Dijkstra vs Floyd 单源 O(n²)（非负权）vs 全点对 O(n³)（可负权、无负环）
最短路径 vs 最小生成树 前者是两点间路径和最小；后者是整棵树边权和最小
  • 复杂度速查：DFS/BFS 矩阵 O(n²)、邻接表 O(n+e)；Prim O(n²)；Kruskal O(e log e)；拓扑排序 O(n+e)；关键路径 O(n+e)；Dijkstra O(n²)；Floyd O(n³)

（三）计算题模板

  • 度与边：2e = ΣTD；有向图 e = ΣID = ΣOD；由"度为 k 的顶点数"列方程求 e、n、叶子类顶点数。
  • 存储结构：无向图邻接表边结点数 = 2e；邻接矩阵第 i 行非零个数 = 度（有向图 = 出度）。
  • 搜索序列：按邻接点递增次序手工模拟，标注 visited；DFS 用栈、BFS 用队列。
  • 最小生成树：Prim → 画"候选边表"逐步选最小边；Kruskal → 边按权排序、逐个判环（不同分量才选），直到 n−1 条；代价=所选边权和。
  • 拓扑排序：列出各顶点入度 → 反复"输出入度 0 的顶点并删除其出边" → 写出序列（可能不唯一）。
  • 关键路径：先正推 ve（max）、再逆推 vl（min）→ 算各活动 e、l、余量 → 余量为 0 者为关键活动 → 写出关键路径与工期。
  • 最短路径：Dijkstra → 填"dist 表 + 每步选入顶点"；Floyd → 逐轮按 min(D[i][j], D[i][k]+D[k][j]) 更新矩阵。
