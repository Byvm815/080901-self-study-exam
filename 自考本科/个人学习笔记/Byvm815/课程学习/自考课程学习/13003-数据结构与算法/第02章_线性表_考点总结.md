## 二、线性表的定义和基本操作

### （一）识记

- **1. 线性表的定义**
由 **n（n ≥ 0）个数据元素**组成的**有限序列**，记作 **(a₁, a₂, …, aₙ)**：
- 元素个数 n 称为**表长**；n = 0 时是**空表**；
- **表头元素** = a₁（第一个元素）；**表尾元素** = aₙ（最后一个元素）；
- **直接前驱**：aᵢ₋₁ 是 aᵢ 的直接前驱；**直接后继**：aᵢ₊₁ 是 aᵢ 的直接后继；
- **前驱**：aᵢ 之前的所有元素（a₁…aᵢ₋₁）；**后继**：aᵢ 之后的所有元素（aᵢ₊₁…aₙ）。
> 直接前驱/后继**唯一**（首元素无直接前驱、尾元素无直接后继）；前驱/后继可有**多个**。

- **2. 有序表与无序表**
- **有序表**：元素按**关键字**递增/递减排列的表（便于折半查找）；
- **无序表**：元素之间没有按关键字排序的表（只能顺序查找）。

- **3. 线性表的特点（高频简答）**
① 元素**个数有限**；  
② 元素**类型相同**（属于同一数据对象）；  
③ 元素之间是**一对一（1:1）** 的逻辑关系：除首元素外每个元素有**唯一直接前驱**，除尾元素外有**唯一直接后继**；  
④ 元素有**确定的位置（序号）**，元素之间有序；  
⑤ 表中元素可以**重复**出现（值相同但位置不同）。

### （二）领会

- **1. 线性表的 ADT 定义**

```
ADT List {
    数据对象: D = { aᵢ | aᵢ ∈ ElemSet, i = 1, 2, …, n, n ≥ 0 }
    数据关系: R = { <aᵢ₋₁, aᵢ> | aᵢ₋₁, aᵢ ∈ D, i = 2, …, n }
    基本操作:
        InitList(&L)             初始化，构造空表
        DestroyList(&L)          销毁表
        ListEmpty(L)             判空（空返回真）
        ListLength(L)            求表长（返回元素个数）
        GetElem(L, i, &e)        取第 i 个元素（i 合法：1 ≤ i ≤ n）
        LocateElem(L, e)         按值查找，返回第一个 e 的位置，无则返回 0
        PriorElem(L, cur, &pre)  求 cur 的直接前驱
        NextElem(L, cur, &next)  求 cur 的直接后继
        ListInsert(&L, i, e)     在第 i 个位置插入 e（1 ≤ i ≤ n+1）
        ListDelete(&L, i, &e)    删除第 i 个元素并用 e 返回（1 ≤ i ≤ n）
        ListTraverse(L, visit)   遍历（对每个元素调用 visit）
} ADT List

```

- **2. 线性表中元素之间的逻辑关系**
相邻元素之间是**前驱—后继**关系；只相邻者构成"直接"关系；表中不允许有"分支"或"环"（否则不是线性结构）。

- **3. 位置（序号）的含义**
- **位置 i** 表示元素在表中的**逻辑次序**，第 i 个元素就是 aᵢ；
- 教材通常**从 1 开始编号**（1 ≤ i ≤ n）【注意】 部分教材从 0 开始，答题按教材；
- "在第 i 个位置插入"＝插入后新元素成为第 i 个元素（即插在 aᵢ 之前）；
- **操作位置**：插入允许 1 ≤ i ≤ n+1（可插到表尾之后）；删除允许 1 ≤ i ≤ n。

- **4. 各基本操作的含义与前提**

| 操作 | 含义 | 前提条件 |
|---|---|---|
| InitList / DestroyList | 建立空表 / 释放整表 | — |
| ListEmpty / ListLength | 判空 / 求表长 | — |
| GetElem(L, i, &e) | 按位置取值 | 1 ≤ i ≤ n |
| LocateElem(L, e) | 按值查找（返回位置或"空"） | 表非空 |
| PriorElem / NextElem | 求直接前驱 / 后继 | 元素存在且非首/尾元素 |
| ListInsert(&L, i, e) | 插入，**表长 +1** | 1 ≤ i ≤ n+1，且未满（顺序表） |
| ListDelete(&L, i, &e) | 删除，**表长 −1** | 1 ≤ i ≤ n，且非空 |
| ListTraverse(L, visit) | 遍历所有元素 | — |

### （三）简单应用

- **基于逻辑定义给出操作结果的逻辑表示（会写序列变化）**
设 L = (a, b, c, d)：

| 操作 | 结果序列 |
|---|---|
| ListInsert(L, 2, x) | (a, **x**, b, c, d) |
| ListInsert(L, 5, y) | (a, b, c, d, **y**)（插到表尾） |
| ListDelete(L, 3) | (a, b, d) |
| ListLength(L) | 4 |
| GetElem(L, 2) | b |
| PriorElem(L, c) | b；NextElem(L, c) = d |
| LocateElem(L, c) | 3 |

## 三、线性表的顺序存储及实现

### （一）识记

- **1. 顺序表**：用一组**地址连续**的存储单元**依次存放**线性表的各元素，使得**逻辑上相邻的元素物理上也相邻**。

- **2. 位置与地址**
- **位置（下标）**：元素在表中的逻辑序号 i；
- **地址映射（下标地址计算，必考）**：设首元素 a₁ 的地址为 LOC(a₁)，每个元素占 L 个存储单元，则
- **LOC(aᵢ) = LOC(a₁) + (i − 1) × L**　（i 从 1 开始）
- **LOC(a[i]) = LOC(a[0]) + i × L**　（i 从 0 开始 【注意】）
- 例：LOC(a₁) = 100，L = 4 → LOC(a₅) = 100 + 4 × 4 = **116**。

### （二）领会

- **1. 顺序存储的基本思想**：把逻辑关系"**隐含**"在物理相邻中——不需要额外信息表示前驱后继，靠**连续存放**体现逻辑顺序。

- **2. 随机访问的含义**
因地址可由公式**直接算出**，访问表中**任一元素的时间都相同**，与元素位置无关，均为 **O(1)**，这种存取方式称**随机存取（随机访问）**。

- **3. 表空、表满、长度**
用整型量 `length` 记录**当前元素个数**，`maxSize` 为容量：
- **表空**：length == 0（删除前必须判空，否则**下溢**）；
- **表满**：length == maxSize（插入前必须判满，否则**上溢**）；
- 插入使 length +1，删除使 length −1。

- **4. 顺序表的优缺点**
- 优点：**随机访问 O(1)**；**存储密度 = 1（无结构性开销）**；实现简单、cache 友好；
- 缺点：**插入/删除平均需移动一半元素，O(n)**；容量**预先固定**（可能上溢或浪费）；动态扩容需复制整表。

### （三）简单应用：基本操作的实现与复杂度分析

- **插入** ListInsert(L, i, e)：实现要点：前提 1 ≤ i ≤ n+1 且未满；**从后往前**把 aᵢ…aₙ 后移一位，再写入 e；移动/比较次数：最好 0（表尾插）／最坏 n（表头插）／**平均 n/2**；时间复杂度：**O(n)**
- **删除** ListDelete(L, i, &e)：实现要点：前提 1 ≤ i ≤ n 且非空；取出 aᵢ，**从前往后**把 aᵢ₊₁…aₙ 前移一位；移动/比较次数：最好 0（删表尾）／最坏 n−1（删表头）／**平均 (n−1)/2**；时间复杂度：**O(n)**
- **按位置取值** GetElem(L, i)：实现要点：直接由地址公式定位；移动/比较次数：0；时间复杂度：**O(1)**
- **按值查找** LocateElem(L, e)：实现要点：从表头顺序比较；移动/比较次数：最好 1／最坏 n／**平均 (n+1)/2**；时间复杂度：**O(n)**
- **求表长 / 判空**：实现要点：读 length；移动/比较次数：0；时间复杂度：**O(1)**
- **建表（逐个插入/尾插）**：实现要点：n 次操作；移动/比较次数：—；时间复杂度：**O(n)**

- **必须记住的"移动次数"结论**：插入**平均 n/2**，删除**平均 (n−1)/2**。

### （四）综合应用（常考算法题型）

用顺序表（数组）设计算法，注意**必须原地或另开数组**、下标边界与 length 维护：  
- **就地逆置**：首尾互换，O(n)，空间 O(1)；
- **删除所有值为 x 的元素**：用 k 记录保留个数，一次扫描覆盖写回，O(n)；
- **删除有序表中重复元素**：双指针一次扫描，O(n)；
- **两有序表归并成一个有序表**：双指针比较，O(m+n)；
- **求交集/并集**（有序表）：双指针 O(m+n)；
- **找最大值/次大值、最小值**：一次扫描 O(n)；
- **元素划分（奇数在前偶数在后 / 小于 x 在前）**：双指针交换，O(n)；
- **两个序列的公共前缀/最长公共子序列（顺序表视角）**：一次扫描。

## 四、线性表的链式存储及实现

### （一）识记

- **1. 单链表**：每个结点含**数据域 + 一个指针域**，指针指向其后继结点；结点物理位置**不要求连续**，通过指针体现逻辑关系；链表由**头指针**标识。

- **2. 关键术语（务必分清）**

| 术语 | 含义 |
|---|---|
| **头指针（表头指针）** | 指向链表**第一个结点**的指针；是链表的**唯一标识**，不可丢失。有头结点时指向头结点，无头结点时指向首结点 |
| **头结点（表头结点）** | 附设在**首结点之前**的**哑结点**，数据域通常不存数据（或存表长等），指针域指向首结点；**空表时仍存在**，判空为 `head->next == NULL` |
| **首结点** | 链表中**第一个存放数据的结点**（即 a₁ 所在结点） |
| **表尾结点（终端结点）** | 最后一个数据结点，其指针域为 **NULL**（循环链表则指回头结点） |
| **单向循环链表** | 表尾结点的指针域指向**头结点（或首结点）**，全表成环，可从任一结点出发遍历全表 |
| **双向链表** | 结点含**两个指针域** prior、next，分别指向直接前驱与直接后继 |
| **双向循环链表** | 双向链表首尾相连（首结点 prior 指向尾结点，尾结点 next 指向头结点） |
| **静态链表** | 用**数组**存储结点，以**游标（下标）** 代替指针表示后继位置 |

- **3. 空表与表尾的判定（带头结点单链表）**
- 空表：`head->next == NULL`；
- 表尾结点：`p->next == NULL`；
- 单向循环链表空表：`head->next == head`；表尾：`p->next == head`。

### （二）领会

- **1. 链式存储的基本思想**
用**指针**显式表示元素之间的逻辑关系（后继），结点**不必连续存放**，存储分配**动态**进行。

- **2. 头结点的作用（高频简答）**
① **统一空表与非空表的处理**：空表也含一个头结点，插入/删除无需区分"表是否为空"；  
② **使首位置的插入/删除与中间位置一致**：不用修改头指针、不用特殊处理首结点；  
③ **便于实现循环链表与统一操作接口**，简化判空、遍历、求长等操作；  
④ 头结点的数据域可存放**表长**等辅助信息（可选）。

- **3. 操作位置与顺序访问**
- 链表中的"第 i 个结点"必须**从头指针出发沿 next 逐个走 i 次**，时间 **O(i)**；
- 这种"只能按顺序逐个访问"的方式称**顺序访问（顺序存取）**，与顺序表的**随机访问**相对。

- **4. 结构性开销（会算）**
结点 = 数据域（d 字节） + k 个指针域（每个 p 字节）：
- **结构性开销 = k·p /（d + k·p）× 100%**
- 例：数据 4B + 1 个指针 4B → 4/8 = **50%**；
- 双向链表（2 个指针）：8/(4+8) ≈ **66.7%**；
- 对比：**顺序表无结构性开销（存储密度 = 1）**，但必须预留连续空间。

### （三）简单应用：基本操作实现与复杂度

以**带头结点的单链表**为例：

- **建立（头插法）**：关键步骤：每次把新结点插在头结点之后；时间复杂度：O(n)，但**结果逆序**
- **建立（尾插法）**：关键步骤：用尾指针 r 保持链尾，新结点接在 r 之后；时间复杂度：O(n)，**保持原序**
- **按位置查找** GetElem(i)：关键步骤：从头结点起走 i 步；时间复杂度：**O(n)**（走 i 步为 O(i)）
- **按值查找** LocateElem(e)：关键步骤：逐个比较；时间复杂度：O(n)
- **插入（已知前驱结点 p）**：关键步骤：新结点 s：`s->next = p->next; p->next = s;`；时间复杂度：**O(1)**
- **插入（只给位置 i）**：关键步骤：先找第 i−1 个结点（O(n)），再插；时间复杂度：**O(n)**
- **删除（已知前驱 p）**：关键步骤：`q = p->next; p->next = q->next; free(q);`；时间复杂度：**O(1)**
- **删除（只给位置 i）**：关键步骤：先找第 i−1 个结点；时间复杂度：**O(n)**
- **删除给定结点自身**：关键步骤：非尾结点可用"**把后继数据复制到自身，再删后继**"技巧；时间复杂度：**O(1)** 【注意】
- **求表长**：关键步骤：遍历计数（若不设长度域）；时间复杂度：O(n)
- **就地逆置 / 合并 / 去重**：关键步骤：改指针，边扫边接；时间复杂度：O(n)

> **关键结论**：链表的"插入删除 O(1)"**必须以已知前驱结点（或已知位置已定位）为前提**；按位置操作整体仍是 O(n)。

- **会算结构性开销、会比较"顺序表 vs 链表"的时空代价**（见第六部分对比表）。

- **根据问题选择链表类型**
- 频繁在**表头插删**、无尾部需求 → **带头结点单链表**；
- 需要**双向遍历、删除给定结点、逆序访问** → **双向（循环）链表**；
- 需要**循环往复处理**（约瑟夫环、轮转调度） → **单向循环链表**；
- 需要频繁**尾部插入** → **带尾指针的（循环）链表**；
- 语言**不支持指针/需限定空间** → **静态链表**（见第五部分）。

### （四）综合应用（常考算法题型）

- **单链表就地逆置**（头插法重置链，O(n)、O(1)）；
- **删除所有值为 x 的结点**（双指针遍历，O(n)）；
- **删除有序链表中重复结点**（一次扫描，O(n)）；
- **求倒数第 k 个结点**（快慢指针一次遍历）；
- **找中间结点 / 判断是否有环 / 求环入口**（快慢指针）；
- **合并两个有序链表**（双指针尾插，O(m+n)，O(1) 空间）；
- **求两个链表的交集/并集/差集**；
- **两个多项式相加**（按指数归并，用链表表示多项式）；
- **按值域划分链表（小于 x 的在前）**；
- **找公共后缀/相交结点**（先求长度差，再同步走）。

## 五、进一步讨论两种基本实现方式

### （一）识记

- **1. 空闲单元链表（备用链表、free list / avail list）**
把**当前未被使用的结点**通过其指针域链接成的链表，用 `avail`（空闲链表头指针）标识；**申请结点时从空闲链表头部取出，释放结点时归还到空闲链表头部**。

- **2. 静态链表**
用**数组**存储结点，结点由**数据域 + 游标（next，存放下一个结点的数组下标）** 组成，用游标代替指针表示逻辑关系；数组的某个单元（通常**下标 0**）作为**头结点**，`S[0].next` 存放首结点的下标。

### （二）领会

- **1. 空闲单元链表的作用**
① 用**有限的数组空间**模拟动态分配与回收（支撑静态链表的插入/删除）；  
② 使**被删除的结点能被重新利用**，避免空间浪费；  
③ 在**链式栈/链式队列**中实现结点的回收再利用（第三章的"带空闲单元链表的链式队列"）。

- **2. 静态链表的实现机制**
- 结构定义：`struct { ElemType data; int next; } S[maxSize];`
- **初始化**：`S[0].next = 0`（空表）；把下标 1…maxSize−1 串成**空闲单元链表**，`avail = 1`，`S[maxSize-1].next = 0`（0 表示空/结束 【注意】 视教材约定）；
- **申请结点**：`p = avail; avail = S[avail].next;`
- **释放结点**：`S[p].next = avail; avail = p;`
- **插入**：定位到第 i−1 个结点（游标遍历）→ 从空闲链表取结点 → 挂链；
- **删除**：定位到第 i−1 个结点 → 摘链 → 结点归还空闲链表；
- **定位第 i 个元素**：仍需沿游标从头走 i 步 → **O(n)**（与动态链表相同）。

- **3. 顺序访问与随机访问方式的对比**

- **随机访问**：由地址公式直接定位，时间与位置无关；典型结构：顺序表（数组）；访问第 i 个元素：**O(1)**
- **顺序访问**：必须从表头沿链逐个访问；典型结构：单/双向链表、静态链表；访问第 i 个元素：**O(n)**

- **4. 顺序表、链表和静态链表的使用条件**

- **顺序表**：适用条件：表长**可预估且变化小**；**频繁按位置访问**（读多写少）；要求存储密度高、访问快；主要限制：插删 O(n)；容量固定，可能上溢/浪费
- **动态链表（单/双/循环）**：适用条件：表长**变化大**、**频繁插删**；不需随机访问；要求动态灵活分配；主要限制：有结构性开销；顺序访问 O(n)；指针操作易错
- **静态链表**：适用条件：表长**有上限**；语言**不支持/禁用指针**；需在数组内模拟链表且要**结点回收**；主要限制：容量固定；需维护空闲单元链表；插删仍需定位 O(n)

### （三）简单应用

- **静态链表基本操作实现及复杂度**：取用/归还结点 O(1)；按位置/按值定位 O(n)；已知前驱时插删 O(1)；
- **根据问题选择顺序表、链表或静态链表并实现操作**（判据见上表：长度是否可预估、操作以"访问"还是"插删"为主、语言是否支持指针）。

### （四）综合应用

例：① 用**静态链表**实现集合的插入、删除、合并（并/交）；② 同一问题分别用**顺序表**与**链表**实现并比较时间/空间复杂度（常考"选型说明题"）。

## 六、本章对比与易混点

### 1. 顺序表 vs 单链表（必背对比表）

| 比较项 | 顺序表 | 单链表 |
|---|---|---|
| 存储方式 | **连续**存储单元，逻辑相邻=物理相邻 | 结点分散，**指针**表示逻辑关系 |
| 存取方式 | **随机访问**，按位置 O(1) | **顺序访问**，按位置 O(n) |
| 插入/删除 | 需移动元素，**平均 n/2、(n−1)/2**，O(n) | 已知前驱 **O(1)**，按位置 O(n) |
| 空间 | 存储密度 **1**，无结构性开销；需**预分配**、可能上溢 | **结构性开销**（指针占用）；动态分配、无上溢 |
| 表长 | 需另设 length，可**直接求得 O(1)** | 求长需遍历 O(n)（除非设长度域） |
| 适用 | 表长稳定、频繁按位置访问 | 表长多变、频繁插删 |

### 2. 易混点

| 易混点 | 正确理解 |
|---|---|
| 头指针 vs 头结点 vs 首结点 | **头指针是变量（指针）**，唯一标识链表；**头结点是哑结点**（可无）；**首结点是第一个数据结点** |
| 直接前驱 vs 前驱 | 直接前驱**唯一且相邻**；前驱是**所有在前的元素**（可能多个） |
| 顺序存储 vs 顺序访问 | **顺序存储**指物理连续；**顺序访问**指只能逐个走（链表特性），两者不是一回事 |
| 表长 vs 数组容量 | length 是**当前元素数**；maxSize 是**容量**；length ≤ maxSize |
| 上溢 vs 下溢 | 满表插入→**上溢**；空表删除→**下溢** |
| 静态链表 vs 顺序表 | 两者都用数组；但静态链表用**游标**表示逻辑关系，**插删不需移动元素**（需管理空闲单元链表） |
| 静态链表 vs 动态链表 | 逻辑相同（顺序访问）；静态用**数组下标"指针"**、容量固定 |
| "链表插删 O(1)" | **前提是已知前驱结点指针**（或已定位），否则定位仍 O(n) |
