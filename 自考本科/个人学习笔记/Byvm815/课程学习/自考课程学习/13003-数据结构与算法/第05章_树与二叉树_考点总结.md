## 二、树的基本概念

### （一）识记（术语）

| 术语 | 含义 |
|---|---|
| **树** | n（n ≥ 0）个结点的有限集合：有且仅有一个**根结点**；其余结点可分为 m（m ≥ 0）个**互不相交**的子树 |
| **子树** | 树中某个结点及其所有后代构成的树 |
| **结点 / 边** | 数据元素 / 连接父子结点的连线 |
| **根结点** | 没有父结点的唯一结点 |
| **父结点（双亲）/ 子结点（孩子）** | 直接前驱 / 直接后继 |
| **兄弟结点** | 同一父结点的结点 |
| **祖先结点 / 后代结点** | 从根到该结点路径上的所有结点 / 该结点子树中的所有结点 |
| **结点的度** | 该结点拥有**子树的个数（孩子数）** |
| **树的度** | 树中**所有结点度的最大值** |
| **叶结点（终端结点）** | **度为 0** 的结点 |
| **分支结点（非终端结点）** | **度不为 0** 的结点 |
| **层** | 根的层为 1，其孩子为第 2 层，依次类推 |
| **深度 / 高度** | 结点的深度＝从根到该结点经过的**边数/层数**；树的深度＝所有结点**最大层数**（高度＝从叶到根的最大边数 ⚠️ 教材定义不同） |
| **路径 / 路径长度** | 两结点间经过的结点序列 / 路径上的**边数** |
| **有序树 / 无序树** | 各子树**有先后次序**（不能互换） / 子树无次序 |
| **森林** | m（m ≥ 0）棵**互不相交**的树的集合；**树去掉根就是森林** |

### （二）领会

**1. 层次结构的含义**：树是一种**一对多（1:n）** 的层次结构——每个结点（除根）有**唯一前驱（父结点）**，但可以有**多个后继（子结点）**；与线性结构的"1:1"不同，树适合表示**分类、目录、组织结构、家族关系**。

**2. 层次结构中的前驱和后继**：根结点**无前驱**；叶结点**无后继**；其他结点**有且仅有一个前驱**，可有**0 个或多个后继**。

**3. 树的递归定义**：树是 n（n ≥ 0）个结点的有限集合；n = 0 时为空树；n > 0 时有唯一的根，其余结点分成若干互不相交的子集，每个子集本身又是一棵树（子树）。

**4. 树的表示形式（4 种，简单应用）**
① **树形（图形）表示法**：用连线直观表示父子关系；
② **括号表示法**：如 `A(B(D,E), C(F))`；
③ **嵌套集合（文氏图）表示法**：用包含关系表示；
④ **凹入（缩进）表示法**：用缩进层次表示。

**5. 树中结点个数与边数的关系（必考）**
- 树中 **边数 = 结点数 − 1**（即 n 个结点的树有 n − 1 条边）；
- **所有结点的度之和 = 边数 = n − 1**；
- 森林若有 **m 棵树、n 个结点**，则**边数 = n − m**。

**6. 计算示例（度与叶子数）**
一棵树中度为 1、2、3、4 的结点数分别是 4、2、1、1，求叶结点数。
- 边数 = Σ(i·nᵢ) = 1×4 + 2×2 + 3×1 + 4×1 = **15**
- 结点总数 n = 15 + 1 = **16** → n₀ = 16 − (4+2+1+1) = **8**（叶结点 8 个）
> 通用公式：**n₀ = 1 + Σ_{i≥2}(i − 1)·nᵢ**

## 三、二叉树

### （一）识记

**1. 二叉树**：n（n ≥ 0）个结点的有限集合，或为**空**，或由一个**根结点**及两棵**互不相交**的、分别称为**左子树**和**右子树**的二叉树组成；**左右子树有次序，不能互换**。

| 术语 | 含义 |
|---|---|
| **左子树 / 右子树** | 根结点的左、右两棵子树 |
| **左子结点 / 右子结点** | 根的左、右孩子 |
| **左指针 / 右指针** | 二叉链表中指向左孩子 / 右孩子的指针域 |
| **满二叉树** | 每一层都达到最大结点数的二叉树（深度 k 时有 **2ᵏ − 1** 个结点） |
| **完全二叉树** | 结点按层序编号与**满二叉树一一对应**（只有最下面两层结点的度可小于 2，且最下层结点**集中在左侧**） |
| **二叉链表** | 结点 = `data + lchild + rchild`（两个指针域） |
| **二叉树的遍历** | 按某条搜索路线访问每个结点且每个结点只访问一次的**线性序列**过程 |

> **二叉树 vs 树**：① 二叉树可为**空**（树一般不为空）；② 二叉树每个结点度 ≤ 2 且**左右有序**；③ **度为 2 的有序树 ≠ 二叉树**（如只有一条单支的"度为 2 的有序树"与二叉树的某一形态不同）。

### （二）领会

**1. 二叉树的递归定义**：见上（空 / 根 + 左子树 + 右子树），这决定了**几乎所有二叉树算法都可以用递归实现**。

**2. 二叉树的性质及证明（必考）**
| 编号 | 性质 | 说明/证明要点 |
|---|---|---|
| **性质 1** | 第 i 层上至多 **2^(i−1)** 个结点（i ≥ 1） | 每一层最多是上一层两倍 |
| **性质 2** | 深度为 k 的二叉树至多 **2ᵏ − 1** 个结点（k ≥ 1） | 1+2+…+2^(k−1) |
| **性质 3** | 叶结点数 **n₀ = n₂ + 1**（n₂ 为度为 2 的结点数） | n = n₀+n₁+n₂；边数 = n−1 = n₁+2n₂ → 得证 |
| **性质 4** | n 个结点的**完全二叉树深度 k = ⌊log₂n⌋ + 1** | 2^(k−1) ≤ n < 2ᵏ |
| **性质 5** | 完全二叉树按层序编号（1 基）：**i>1 时父结点为 ⌊i/2⌋**；**左孩子 2i、右孩子 2i+1**（存在时）；**i > ⌊n/2⌋ 时 i 为叶结点** | 顺序存储下标关系 |
| 推论 | n 个结点的二叉链表有 **n + 1 个空指针域** | 2n 个指针域中 n−1 个用于指孩子 |

**3. 二叉树的顺序存储方式与下标位置**
- 用一维数组按**层序**存放结点；空结点留空位；
- **1 基**：根存于 `A[1]`；结点 i 的父为 `⌊i/2⌋`，左孩子 `2i`，右孩子 `2i+1`；
- **0 基**：根存于 `A[0]`；结点 i 的父为 `⌊(i−1)/2⌋`，左孩子 `2i+1`，右孩子 `2i+2`；**最后一个非叶结点下标 = ⌊n/2⌋ − 1**；
- 适合**完全二叉树**（空间 O(n)）；对一般二叉树（尤其单支树）**浪费严重**（最坏需 2ᵏ − 1 个单元）。

**4. 二叉树的链式存储方式**
- **二叉链表**：`typedef struct BTNode { ElemType data; struct BTNode *lchild, *rchild; } BTNode, *BTree;`
- **三叉链表**：再加 `parent` 指针，便于向上查找；
- 二叉链表**找父结点不方便**，但结构简单、应用最广。

**5. 二叉树的遍历过程与使用的辅助数据结构**
| 遍历 | 顺序 | 递归 | 非递归辅助结构 |
|---|---|---|---|
| **先序（前序）** | 根 → 左 → 右 | 先访问根再递归左右 | **栈** |
| **中序** | 左 → 根 → 右 | 先递归左再访问根 | **栈** |
| **后序** | 左 → 右 → 根 | 先递归左右再访问根 | **栈**（常用双栈/标记法） |
| **层次** | 按层从左到右 | 无递归 | **队列** |

**6. 表达式树与表达式的关系**
- 以**叶结点存操作数**、**分支结点存运算符**的二叉树；
- **中序遍历** → **中缀表达式**（需按优先级加括号）；
- **先序遍历** → **前缀表达式（波兰式）**；
- **后序遍历** → **后缀表达式（逆波兰式）**。
> 例：表达式 `(a+b)*c − d/e` 对应表达式树的后序遍历即其后缀式。

### （三）简单应用

**1. 二叉树基本操作的实现（二叉链表，递归为主）**
```c
// 先序遍历（递归）
void PreOrder(BTree T) {
    if (T) { visit(T->data); PreOrder(T->lchild); PreOrder(T->rchild); }
}
// 中序、后序只需调换 visit 位置
// 求结点个数
int Count(BTree T) { return T ? Count(T->lchild) + Count(T->rchild) + 1 : 0; }
// 求叶子个数
int LeafCount(BTree T) {
    if (!T) return 0;
    if (!T->lchild && !T->rchild) return 1;
    return LeafCount(T->lchild) + LeafCount(T->rchild);
}
// 求深度
int Depth(BTree T) {
    if (!T) return 0;
    int l = Depth(T->lchild), r = Depth(T->rchild);
    return (l > r ? l : r) + 1;
}
```

**2. 遍历的非递归实现（用栈）与层次遍历（用队列）**
```c
// 先序非递归
void PreOrderNR(BTree T) {
    BTree st[100]; int top = -1;
    if (T) st[++top] = T;
    while (top >= 0) {
        BTree p = st[top--]; visit(p->data);
        if (p->rchild) st[++top] = p->rchild;   // 先压右孩子
        if (p->lchild) st[++top] = p->lchild;   // 后压左孩子（先出）
    }
}
// 中序非递归：一路向左入栈，弹栈访问后转向右子树
void InOrderNR(BTree T) {
    BTree st[100]; int top = -1; BTree p = T;
    while (p || top >= 0) {
        while (p) { st[++top] = p; p = p->lchild; }   // 一路向左
        p = st[top--]; visit(p->data);                // 弹栈访问
        p = p->rchild;                                // 转右
    }
}
// 层次遍历（队列）
void LevelOrder(BTree T) {
    BTree q[100]; int front = 0, rear = 0;
    if (T) q[rear++] = T;
    while (front < rear) {
        BTree p = q[front++]; visit(p->data);
        if (p->lchild) q[rear++] = p->lchild;
        if (p->rchild) q[rear++] = p->rchild;
    }
}
```

**3. 根据遍历序列还原二叉树（必考）**
- **先序 + 中序** → 可**唯一**确定；**后序 + 中序** → 可**唯一**确定；**层次 + 中序** → 可唯一确定；
- **先序 + 后序** → **不能**唯一确定（无法区分左右单支）；
- **方法**：先序的**第一个**（或后序的**最后一个**）是**根**；在中序中找到该根，**左边是左子树、右边是右子树**的元素集合；据此递归划分。

**例**：已知先序 **ABDECF**、中序 **DBEACF**，求后序与树形。
- 先序首元 **A** 为根；中序中 A 左边 {D,B,E}、右边 {C,F}；
- 左子树的先序 {B,D,E}，其根 **B**，中序 {D,B,E} → D 在左、E 在右；
- 右子树的先序 {C,F}，其根 **C**，中序 {C,F} → C 无左孩子、F 为右孩子；
- **树形**：`A( B(D, E), C(∅, F) )`；**后序 = D E B F C A**。

**4. 表达式树**：由中缀/后缀表达式构造表达式树；中序、先序、后序分别得到中缀、前缀、后缀表达式。

### （四）综合应用（常考算法）

1. 求结点数 / 叶子数 / 度为 1、2 的结点数；
2. 求深度（高度）、某层结点数、最大宽度；
3. **判断两棵二叉树是否相同/相似**；
4. **交换所有结点的左右子树**（镜像）；
5. 复制二叉树、销毁二叉树；
6. 查找值为 x 的结点、求结点所在层次、求某结点的所有祖先；
7. 由遍历序列建立二叉链表（还原二叉树）；
8. **判断是否为完全二叉树**（层次遍历，遇到空结点后不能再有非空结点）；
9. 求两个结点的最近公共祖先；
10. 先序/中序/后序的非递归实现（用栈）；
11. 用遍历思想求路径、求第 k 个结点、输出所有叶子到根的路径。

## 四、堆及优先队列

### （一）识记

| 术语 | 含义 |
|---|---|
| **堆** | 满足"任一分支结点的值都不大于（不小于）其左右孩子"的**完全二叉树** |
| **最大堆（大顶堆）** | 任一结点的值 **≥** 其孩子的值 → **堆顶是最大值** |
| **最小堆（小顶堆）** | 任一结点的值 **≤** 其孩子的值 → **堆顶是最小值** |
| **堆顶** | 堆的根结点（最大堆为最大元素 / 最小堆为最小元素） |
| **子堆** | 以某结点的孩子为根的子树本身也是一个堆 |
| **优先队列** | 出队顺序由**优先级**决定的队列（每次取出优先级最高/最低者），通常用**堆**实现 |

### （二）领会

**1. 堆的存储方式**：堆是**完全二叉树**，因此可直接用**一维数组顺序存储**（不需指针）：
- **0 基**：结点 i 的左孩子 `2i+1`、右孩子 `2i+2`、父结点 `⌊(i−1)/2⌋`；**最后一个非叶结点下标 = ⌊n/2⌋ − 1**；
- 1 基：左 `2i`、右 `2i+1`、父 `⌊i/2⌋`。

**2. 堆与完全二叉树的关系**：**堆一定是一棵完全二叉树**（保证数组存储无空洞）；完全二叉树不一定是堆（还要满足有序性）。

**3. 堆的有序性（重要）**
- 只保证**父结点与孩子之间**的大小关系，**兄弟结点之间、左右子树之间没有大小要求**；
- 因此堆顶一定是极值，但**堆并不是有序的**，不能像二叉查找树那样查找任意元素（查找任意元素需 O(n)）。

**4. 堆的建立过程**：从**最后一个非叶结点**开始，**自底向上、逐个"筛选（下沉）"**，直至根；时间 **O(n)**（不是 O(n log n)）。

### （三）简单应用（建堆、插入、删堆顶、调整）

**1. 建堆（自底向上筛选）**
```
for (i = ⌊n/2⌋ - 1; i >= 0; i--)   SiftDown(i);
```
**2. 堆的插入（上浮）**：把新元素放到数组**末尾**，然后**与父结点比较并向上交换**，直到满足堆序；**O(log n)**。
**3. 删除堆顶（下沉）**：把**最后一个元素**移到堆顶、堆长度减 1，然后从根**向下筛选**；**O(log n)**。
**4. 堆的整理（SiftDown / SiftUp）**：下沉=与较大（较小）的孩子交换；上浮=与父结点交换。

```c
void SiftDown(int a[], int n, int i) {        // 最小堆下沉
    int x = a[i];
    for (int c = 2*i + 1; c < n; c = 2*i + 1) {
        if (c + 1 < n && a[c+1] < a[c]) c++;   // 取较小的孩子
        if (a[c] >= x) break;
        a[i] = a[c]; i = c;
    }
    a[i] = x;
}
void SiftUp(int a[], int i) {                  // 最小堆上浮
    int x = a[i];
    while (i > 0 && a[(i-1)/2] > x) { a[i] = a[(i-1)/2]; i = (i-1)/2; }
    a[i] = x;
}
```

**5. 计算示例**：数组 **[5, 8, 3, 9, 1]** 建**最小堆**
- 最后一个非叶结点下标 = ⌊5/2⌋ − 1 = **1**；
- 处理下标 1（值 8）：孩子 9、1 → 较小者 1，8 > 1 → 交换 → **[5, 1, 3, 9, 8]**
- 处理下标 0（值 5）：孩子 1、3 → 较小者 1，5 > 1 → 交换 → **[1, 5, 3, 9, 8]**；继续下沉：下标 1 的孩子 9、8 → 较小者 8，5 < 8 → 停止；
- 结果 **最小堆 = [1, 5, 3, 9, 8]**。
- **插入 0**：放末尾 → [1,5,3,9,8,0]；与父 3 交换 → [1,5,0,9,8,3]；再与父 1 交换 → **[0,5,1,9,8,3]**。
- **删除堆顶**：用末尾元素 3 顶替 → [3,5,1,9,8] → 下沉（与较小孩子 1 交换）→ **[1,5,3,9,8]**。

### （四）综合应用
① **优先队列**（任务调度、事件驱动模拟、Dijkstra/Prim 的顶点选择）；② **堆排序**（建大顶堆 → 反复交换堆顶与末尾并调整，O(n log n)，见第七章）；③ 求 Top-K 大/小元素；④ 求中位数（双堆）；⑤ 多路归并。

## 五、树和森林

### （一）识记

| 术语 | 含义 |
|---|---|
| **父结点表示法（双亲表示法）** | 用数组存 `{data, parent}`，parent 为父结点下标；**找父容易、找孩子难** |
| **孩子结点表示法（多重链表）** | 每个结点带一个孩子链表（把所有孩子串起来）；**找孩子容易、找父难** |
| **父结点-孩子结点表示法** | 上述两者结合：数组存 `{data, parent, 孩子链}`，双向都方便 |
| **孩子-兄弟表示法** | 结点含 `firstchild`（第一个孩子）与 `nextsibling`（下一个兄弟）两个指针 → **把树表示成二叉树** |
| **森林** | m（m ≥ 0）棵互不相交的树的集合 |
| **树、森林的遍历** | 树的**先根遍历**（根→各子树）、**后根遍历**（各子树→根）；森林的**先序遍历**、**中序（后根）遍历** |

### （二）领会

**1. 树、森林之间的关系**：**树去掉根结点即得森林**；**森林加上一个根结点（各树根作为其孩子）即得树**；森林是"树的集合"，m = 1 时退化为树。

**2. 树、森林与二叉树之间的相互转换（难点，必考）**
统一采用**孩子-兄弟表示法**：
- **左指针（lchild）指向第一个孩子**，**右指针（rchild）指向下一个兄弟**；
- **树的转换**：每个结点左指针连第一个孩子、右指针连下一个兄弟 → 得到一棵**二叉树**；
- **森林的转换**：先各自转换为二叉树，再把**各棵树根用右链连成一串**（视为兄弟）；**森林中第一棵树的根就是所得二叉树的根**；
- **逆转换**：二叉树中"沿左走是孩子、沿右走是兄弟"→ 还原为树/森林。

**3. 树、森林的遍历与二叉树遍历的关系（必背对应表）**
| 树 / 森林的遍历 | 对应二叉树的遍历 |
|---|---|
| **树的先根遍历** | **先序遍历** |
| **树的后根遍历** | **中序遍历** |
| **森林的先序遍历** | **先序遍历** |
| **森林的中序（后根）遍历** | **中序遍历** |
> 结论：**树的先根 = 二叉树的先序；树的后根 = 二叉树的中序**；因此树/森林的遍历可**直接借用二叉树的遍历算法**。

### （三）简单应用
① 实现树/森林的遍历（先根、后根、层次）；② 求树的深度、结点数、叶子数；③ 求树中某结点的层次/路径；④ 由孩子-兄弟表示法实现"找第 i 个孩子、找兄弟、求度数"等操作；⑤ 统计森林中树的棵数（沿右链计数）。

### （四）综合应用
森林的层次遍历、树的括号表示法与树形表示法的相互转换、由广义表建立树/森林（与前章广义表衔接）、统计树叶/度为 k 的结点数等。

## 六、哈夫曼树及哈夫曼编码

### （一）识记

| 术语 | 含义 |
|---|---|
| **定长编码** | 每个字符用**相同长度**的编码（需 ⌈log₂n⌉ 位），简单但**总码长长** |
| **变长编码** | 不同字符用**不同长度**编码，让**高频字符用短码**，节省空间 |
| **编码长度** | 某个字符编码的位数 |
| **前缀特性（前缀码）** | **任一编码都不是另一个编码的前缀** → 译码**唯一**、**无需分隔符** |
| **编码 / 译码** | 字符 → 编码串 / 编码串 → 字符 |
| **字符的权** | 字符出现的**次数或频率**（体现重要性） |
| **编码树** | 叶结点为字符、左/右分支分别标 0/1 的二叉树 |
| **哈夫曼树（最优二叉树）** | **WPL 最小**的二叉树 |
| **哈夫曼编码** | 由哈夫曼树得到的**变长前缀编码**（最优前缀码） |
| **叶结点的带权路径长度** | 该叶的**权 × 从根到该叶的路径长度（边数）** |
| **WPL（树的带权路径长度）** | 所有**叶结点**带权路径长度之和：**WPL = Σ wᵢ·lᵢ** |
| **带权平均码长** | **WPL / Σwᵢ**（当权为频率/次数时即平均码长） |

### （二）领会

**1. 具有前缀特性的编码方案**
- 若把所有编码都放在一棵二叉树的**叶结点**上（约定"左 0 右 1"），则该方案**天然具有前缀特性**（因为一个叶不可能是另一个叶的祖先）；
- 反之，若某个编码是另一个的前缀，则必然有一个编码落在**非叶结点**上，译码产生**二义性**。

**2. 哈夫曼树与哈夫曼编码的不唯一性**
- **左右子树可以交换**（0/1 互换）→ 编码不同但**码长不变**；
- **权值相同的结点合并顺序可以不同** → 树形可能不同；
- 但所有哈夫曼树的 **WPL 相同（都是最小）**，且**每个字符的码长不变**（只是 0/1 串不同）。

### （三）简单应用（必考）

**1. 哈夫曼树的构造（贪心算法，n 个叶结点需 n−1 次合并）**
① 把 n 个权值看作 n 棵**只有一个根**的二叉树，构成集合 F；
② 从 F 中选取**两棵根权最小**的树，合并成一棵新树（新根权 = 两权之和）；
③ 从 F 中删除这两棵树，把新树加入 F；
④ 重复 ②③ 直到 F 中只剩**一棵树**，即哈夫曼树。
> 特性：哈夫曼树中**没有度为 1 的结点**，共 **2n − 1 个结点**（n 个叶 + n−1 个分支）。

**2. 构造示例（经典题）**
字符权值：a=5, b=29, c=7, d=8, e=14, f=23, g=3, h=11（Σw = 100）

合并过程（每次取最小的两个根权）：
| 步骤 | 合并 | 新权 |
|---|---|---|
| 1 | g(3) + a(5) | 8 |
| 2 | c(7) + 8 | 15 |
| 3 | d(8) + h(11) | 19 |
| 4 | e(14) + 15 | 29 |
| 5 | 19 + f(23) | 42 |
| 6 | 29 + b(29) | 58 |
| 7 | 42 + 58 | **100（根）** |

**WPL = 8+15+19+29+42+58+100 = 271**
（也可按码长验证：d=3, h=3, f=2, e=3, c=4, g=5, a=5, b=2 → WPL = 8×3+11×3+23×2+14×3+7×4+3×5+5×5+29×2 = **271** ✓）

**一串可能编码（左 0 右 1，不唯一）**：d=000, h=001, f=01, e=100, c=1010, g=10110, a=10111, b=11
**带权平均码长 = WPL / Σw = 271 / 100 = 2.71 位/字符**（定长编码需 ⌈log₂8⌉ = 3 位 → 哈夫曼更优）

**3. 哈夫曼编码的生成**：从根到每个**叶结点**的路径上，**左分支记 0、右分支记 1**，路径上的 0/1 串即该字符的编码。

**4. 译码**：从**根**出发，按编码串的每一位走（0 走左、1 走右），**走到叶结点就输出该字符并回到根**，继续读下一位；若中途走到空则编码非法。

**5. 验证前缀特性**：检查**任一编码是否都不是其他编码的前缀**（或等价地：所有字符都在叶结点上）。

**6. WPL 的计算**：WPL = Σ(叶权 × 叶的路径长度)；也可用"**所有合并过程产生的权值之和**"快速计算（上例 = 8+15+19+29+42+58+100 = 271）。

### （四）综合应用
① 设计文件压缩/传输的最优编码；② 给定字符频率求**平均码长最短**的编码；③ 判断题给编码是否满足前缀特性、是否最优；④ 由编码串译码或由字符集求编码；⑤ 与堆结合实现"每次取最小的两个"（用最小堆 O(n log n)）。

## 七、本章对比与易混点

### 1. 易混点

| 易混点 | 正确理解 |
|---|---|
| **满二叉树 vs 完全二叉树** | 满：每层都满（深度 k 有 2ᵏ−1 个结点）；完全：编号与满二叉树**一一对应**，最下层可缺**右侧**结点 |
| 结点的度 vs 树的度 | 结点的度＝该结点孩子数；树的度＝**所有结点度的最大值** |
| 深度 vs 高度 | 深度从**根往下**算（根为 1 层）；高度从**叶往上**算 ⚠️ 教材口径不一，**答题先声明** |
| 二叉树 vs 度为 2 的有序树 | 二叉树**可以为空**、左右**严格有序**；度为 2 的有序树不允许"只有左孩子"与"只有右孩子"的区分 |
| 先序+后序能否还原 | **不能**唯一确定（需配合**中序**） |
| 树的后根遍历 vs 二叉树后序 | **树的后根遍历 = 二叉树的中序遍历**（不是后序！） |
| 二叉链表空指针数 | **n + 1 个**（不是 n−1） |
| 堆 vs 二叉查找树 | 堆只保证**父子**大小关系、**不能查找任意元素**；二叉查找树保证**中序有序**、可 O(log n) 查找 |
| 建堆复杂度 | **O(n)**（自底向上筛选），不是 O(n log n) |
| 哈夫曼树是否有度为 1 的结点 | **没有**；n 个叶 → 共 2n−1 个结点 |
| 哈夫曼编码唯一吗 | **编码不唯一**（0/1 可换、同权合并顺序可变），但**码长与 WPL 唯一** |
| 带权路径长度 vs WPL | 前者针对**单个叶结点**，后者是**所有叶结点之和** |

### 2. 必背公式汇总
| 公式 | 用途 |
|---|---|
| 边数 = 结点数 − 1；Σ度 = 边数 | 树 |
| 森林边数 = n − m | 森林 |
| n₀ = n₂ + 1 | 二叉树叶子与度 2 结点 |
| n₀ = 1 + Σ_{i≥2}(i−1)nᵢ | 一般树叶子数 |
| 第 i 层 ≤ 2^(i−1)；深度 k ≤ 2ᵏ−1 | 二叉树 |
| k = ⌊log₂n⌋ + 1 | 完全二叉树深度 |
| 父 ⌊i/2⌋、左 2i、右 2i+1（1 基） | 完全二叉树/堆下标 |
| 二叉链表空指针 = n + 1 | 存储分析 |
| 哈夫曼树结点数 = 2n − 1 | 哈夫曼树 |
| WPL = Σwᵢlᵢ = Σ合并权值 | 哈夫曼树代价 |
| 带权平均码长 = WPL / Σwᵢ | 编码效率 |

### （三）计算题模板
1. **叶子数**：n₀ = n₂ + 1；或 n₀ = 1 + Σ_{i≥2}(i−1)nᵢ；或由"边数 = n−1 = Σ i·nᵢ"列方程。
2. **完全二叉树**：深度 = ⌊log₂n⌋ + 1；n 为偶数时 n₁ = 1、n 为奇数时 n₁ = 0；n₀ = (n + 1 − n₁)/2。
3. **下标关系**：1 基 父 ⌊i/2⌋、左 2i、右 2i+1；0 基 父 ⌊(i−1)/2⌋、左 2i+1、右 2i+2。
4. **遍历还原**：写"先序首元/后序末元为根 → 中序划分左右 → 递归"。
5. **哈夫曼**：列表逐次合并（每次取两个最小）→ WPL = Σ合并权值 → 由路径得编码 → 平均码长 = WPL/Σw。
6. **建堆/插入/删除**：写"最后一个非叶 = ⌊n/2⌋−1 → 自底向上筛选"或"末尾插入后上浮"/"末尾顶替堆顶后下沉"的每一步数组状态。
