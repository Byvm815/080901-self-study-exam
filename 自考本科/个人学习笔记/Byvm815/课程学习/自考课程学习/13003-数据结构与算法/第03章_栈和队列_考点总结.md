## 二、栈

### （一）识记

**1. 栈的定义**：只允许在表的**一端**进行插入和删除的**线性表**；允许操作的一端称**栈顶（top）**，另一端称**栈底（bottom）**，不含元素的栈为**空栈**。

**2. 术语**
| 术语 | 含义 |
|---|---|
| **栈顶 / 栈底** | 允许插入删除的一端 / 固定不动的一端 |
| **栈顶元素** | 当前位于栈顶的元素（下一个出栈的就是它） |
| **入栈（push）** | 在栈顶插入一个元素 |
| **出栈（pop）** | 删除栈顶元素并返回 |
| **栈的容量** | 栈所能容纳元素的最大个数（顺序栈为 maxSize） |
| **顺序栈** | 用**连续的数组**存储栈元素，附设栈顶指针 top |
| **链式栈** | 用**单链表**存储栈元素，栈顶设在表头（头结点之后） |
| **出栈序列** | 按出栈次序排列成的元素序列 |
| **栈空 / 栈满** | 无元素 / 已达容量（顺序栈才有"满"） |

### （二）领会

**1. 栈的先进后出（LIFO）特性**
进栈与出栈都在**同一端**进行 → **后进先出（Last In First Out）**；栈顶元素永远最先被取出；栈底元素最后出栈。

**2. 合理出栈序列（合法出栈序列）**
- **判定方法（模拟法，必考）**：按入栈序列依次入栈，**每当栈顶元素等于待判定序列当前元素就弹出**；若最后能按给定序列全部弹出，则合法，否则非法。
- **合法序列个数**：n 个元素依次入栈，可能的合法出栈序列数为 **Catalan 数**
  **Cₙ = (2n)! / [ n!(n+1)! ]**；n=3 → **5** 个；n=4 → **14** 个；n=5 → 42 个。
- **规律提示**：若某元素先出栈，则**在它之后入栈的元素不可能比它先出**；"先出栈的较大元素之后不能再出现比它小、且比当前栈顶更深的元素"。（本质：合法出栈序列不出现 312 型模式。）

**例**：入栈序列 1, 2, 3, 4 时
| 出栈序列 | 判定 |
|---|---|
| 1 2 3 4 | 合法（每个元素入栈后立即出栈） |
| 4 3 2 1 | 合法（全部入栈后依次出栈） |
| 3 2 4 1 | 合法（push1,2,3→pop3,pop2；push4→pop4；pop1） |
| **3 1 2 4** | **非法**（pop3 后栈顶是 2，不可能先出 1） |
| **2 4 1 3** | **非法**（pop2、push3,4、pop4 后栈顶是 3，不可能先出 1） |

**3. 顺序栈的空、满判定与操作定义**（设 top 为栈顶下标）
- 常见约定：**top = −1 表示空栈**（也有教材用 top = 0 表示空栈 ⚠️）；**top = maxSize − 1 表示栈满**；
- **判空**：`top == -1`　**判满**：`top == maxSize - 1`；
- **入栈**：先判满 → `S[++top] = x;`
- **出栈**：先判空 → `x = S[top--];`
- **取栈顶**：`x = S[top];`（不出栈）
- 全部为 **O(1)**。

**4. 链式栈的空、满判定与操作定义**
- 通常采用**带头结点的单链表**，**栈顶设在表头**（头结点之后）；
- **判空**：`top->next == NULL`；
- **栈满**：链式栈理论上**没有固定"栈满"**，只有**内存耗尽**（若用静态链表+空闲单元链表，则以"空闲链表空"为满）；
- **入栈**：头插（新结点插在头结点之后），O(1)；
- **出栈**：删除头结点之后的第一个结点并释放，O(1)。

**5. 双底栈（两栈共享空间）** ⚠️（有的教材称"共享栈"）
- 用一个数组 `S[0..maxSize-1]` 存放**两个栈**：栈 1 的栈底在下标 0，栈 2 的栈底在下标 maxSize−1，两栈顶 `top1`、`top2` **相向生长**；
- **栈空**：top1 == −1 且 top2 == maxSize 分别表示两栈为空；
- **栈满（共享空间用尽）**：**top1 + 1 == top2**（即两栈顶相邻，中间再无空位）；
- 优点：**提高空间利用率**（两个栈的空间需求此消彼长时互补），减少上溢。

### （三）简单应用

**1. 判定序列是否为合理出栈序列**：用上面的"模拟法"逐个比对（考试可手算或写伪代码）。

**2. 顺序栈实现（类 C）**
```c
#define maxSize 100
typedef struct { ElemType data[maxSize]; int top; } SqStack;

void InitStack(SqStack *S) { S->top = -1; }
int  StackEmpty(SqStack S) { return S.top == -1; }
int  StackFull(SqStack S)  { return S.top == maxSize - 1; }

int Push(SqStack *S, ElemType x) {
    if (StackFull(*S)) return 0;          // 上溢
    S->data[++S->top] = x; return 1;
}
int Pop(SqStack *S, ElemType *x) {
    if (StackEmpty(*S)) return 0;         // 下溢
    *x = S->data[S->top--]; return 1;
}
int GetTop(SqStack S, ElemType *x) {
    if (StackEmpty(S)) return 0;
    *x = S.data[S.top]; return 1;
}
```

**3. 链式栈实现（带头结点，栈顶在表头）**
```c
typedef struct node { ElemType data; struct node *next; } LinkNode, *LinkStack;

int Push(LinkStack top, ElemType x) {       // 头插，O(1)
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    if (!s) return 0;                        // 空间不足
    s->data = x; s->next = top->next; top->next = s; return 1;
}
int Pop(LinkStack top, ElemType *x) {       // 删首结点，O(1)
    if (top->next == NULL) return 0;         // 栈空
    LinkNode *q = top->next; *x = q->data;
    top->next = q->next; free(q); return 1;
}
```

### （四）综合应用（必考算法）

**1. 括号匹配**
思路：遇**左括号**(`(`、`[`、`{`) → 入栈；遇**右括号** → 若栈空则**不匹配**，否则弹出栈顶并检查是否与之**配对**；扫描结束时**栈空**才匹配。
```c
int Match(char *s) {
    SqStack S; InitStack(&S);
    for (int i = 0; s[i]; i++) {
        if (s[i]=='(' || s[i]=='[' || s[i]=='{') Push(&S, s[i]);
        else if (s[i]==')' || s[i]==']' || s[i]=='}') {
            if (StackEmpty(S)) return 0;
            char t; Pop(&S, &t);
            if ((s[i]==')' && t!='(') || (s[i]==']' && t!='[') || (s[i]=='}' && t!='{')) return 0;
        }
    }
    return StackEmpty(S);
}
```
> 时间 O(n)，空间 O(n)。扩展：判断表达式括号是否配对、多层嵌套、可延伸到"括号深度/最长有效括号"。

**2. 中缀表达式转后缀表达式（中缀转后缀）**
思路（运算符栈）：
1. 遇**操作数** → 直接输出；
2. 遇**运算符** op：若栈空、或栈顶为 `(`、或 **op 优先级高于栈顶运算符** → op 入栈；否则**弹出栈顶运算符并输出**，再与新的栈顶比较，直到可入栈为止；
3. 遇 `(` → 入栈；遇 `)` → **弹出并输出运算符直到遇到 `(`**，弹出 `(` 并丢弃；
4. 扫描结束 → **弹出栈中所有运算符**输出。
优先级：`*`、`/` 高于 `+`、`-`；`(` 在栈内优先级最低（除遇 `)` 外不弹出）。
**例**：`A + B * C - D / E` → **`A B C * + D E / -`**

**3. 计算后缀表达式（后缀表达式求值）**
思路（操作数栈）：从左向右扫描：
- 遇**操作数** → 入栈；
- 遇**运算符** → 弹出**两个**操作数（**先弹出的是右操作数**），做运算 `左 op 右`，结果再入栈；
- 扫描完毕，**栈顶元素即为结果**。
**例**：`3 4 + 5 *` → (3+4)*5 = **35**；`A B C * + D E / -` 即 A+B*C−D/E。

**4. 栈的其他应用**：递归的实现与消除递归、表达式/语法检查、进制转换（除基取余逆序）、迷宫/DFS 非递归、函数调用栈、编辑器的撤销操作、深度优先遍历。

## 三、队列

### （一）识记

**1. 队列的定义**：只允许在表的**一端插入、另一端删除**的线性表；**先进先出（FIFO）**。
**2. 术语**
| 术语 | 含义 |
|---|---|
| **队头（front）** | 允许**删除（出队）**的一端 |
| **队尾（rear）** | 允许**插入（入队）**的一端 |
| **队头元素 / 队尾元素** | 当前最前面的元素（最先出队）/ 最后面的元素（最后出队） |
| **入队 / 出队** | 在队尾插入 / 删除队头 |
| **队列长度** | 当前元素个数 |
| **队列空 / 队列满** | 无元素 / 顺序队列已达容量 |
| **队头指针 / 队尾指针** | 指示队头 / 队尾位置的指针（或下标） |
| **循环队列** | 把顺序队列的数组**首尾相连**（用取模运算回绕），解决"假溢出" |
| **链式队列** | 用**单链表**表示队列，队头在表头、队尾在表尾 |

### （二）领会

**1. 顺序队列的"假溢出"问题（引出循环队列）**
顺序队列用 `front`、`rear` 指示队头队尾，每次入队 `rear++`、出队 `front++`；当 `rear == maxSize` 时**可能数组中仍有空位**（前面已出队的位置空着却无法使用），这种现象称**假溢出**。
**解决办法**：把数组看成**环**——**循环队列**，用**取模**实现回绕：
`rear = (rear + 1) % maxSize;`　`front = (front + 1) % maxSize;`

**2. 循环队列的特点、存储结构及实现机制**
- 存储结构：一维数组 + `front`、`rear` 两个整型下标；
- 实现机制：入队/出队时下标**模 maxSize 回绕**，使空间循环使用；
- 优点：**避免假溢出**，空间利用率高；缺点：**空与满的判别需要额外处理**（因为 front == rear 既可能是空也可能是满）。

**3. 循环队列中空、满的含义及判定（必考）**

| 方案 | 队空判定 | 队满判定 | 元素个数 |
|---|---|---|---|
| **① 牺牲一个单元**（最常用） | `front == rear` | `(rear + 1) % maxSize == front` | `(rear − front + maxSize) % maxSize` |
| **② 增设计数变量 size** | `size == 0` | `size == maxSize` | `size` |
| **③ 增设标志位 tag**（入队置 1、出队置 0） | `front == rear && tag == 0` | `front == rear && tag == 1` | 由 tag 与下标推算 |

> 方案①的"满"实际**牺牲一个存储单元**（容量为 maxSize−1 个元素）。

**4. 队头和队尾的不同设定方式** ⚠️（不同教材约定不同，判断公式随之变化）
- **方式 A**：`front` 指向**队头元素**，`rear` 指向**队尾元素的下一个位置**（常见）；
- **方式 B**：`front` 指向**队头元素的前一个位置**，`rear` 指向**队尾元素**；
- 常见变体公式（方式 A、牺牲单元法）：
  队空 `front == rear`；队满 `(rear+1)%maxSize == front`；长度 `(rear−front+maxSize)%maxSize`；
  入队 `Q[rear] = x; rear = (rear+1)%maxSize;`　出队 `x = Q[front]; front = (front+1)%maxSize;`
> 答题时**先声明约定**，再写公式，避免因约定不同被判错。

**5. 链式队列的特点与实现机制**
- 结构：**带头结点的单链表** + `front`（指向**头结点**）、`rear`（指向**队尾结点**）；
- **判空**：`front == rear`（都指向头结点）；
- **入队**：在队尾插入（尾插），`rear->next = s; rear = s;`　O(1)；
- **出队**：删除头结点之后的第一个结点；**若出队后队列变空，必须令 `rear = front`**（关键细节）；
- **队满**：链式队列**无固定队满**，只有内存耗尽；
- 特点：**不需要预估容量、无假溢出**；但每个结点有**结构性开销**。

**6. 在链式队列中实现空闲单元链表的机制（重点）**
用**静态链表**（数组 + 游标）实现链式队列时：
- 数组 `Q[maxSize]` 存结点 `{data, next}`，`next` 为游标（下标）；
- **队头、队尾用游标**表示：`front`、`rear` 为整型下标（或"结点指针"即下标）；
- **空闲单元链表**（备用链表）用 `avail` 串起所有未用单元：**入队时从 `avail` 取结点**，**出队时把结点归还 `avail`**；
- **取结点**：`p = avail; avail = Q[avail].next;`
- **归还结点**：`Q[p].next = avail; avail = p;`
- **队满**：`avail == 0`（无空闲单元，即数组空间用尽）；
- 作用：在**固定数组空间**内实现队列结点的**动态分配与回收**，避免空间浪费。

### （三）简单应用

**1. 循环队列基本操作实现**
```c
#define maxSize 100
typedef struct { ElemType data[maxSize]; int front, rear; } SqQueue;

void InitQueue(SqQueue *Q) { Q->front = Q->rear = 0; }
int  QueueEmpty(SqQueue Q) { return Q.front == Q.rear; }
int  QueueFull(SqQueue Q)  { return (Q.rear + 1) % maxSize == Q.front; }
int  QueueLength(SqQueue Q){ return (Q.rear - Q.front + maxSize) % maxSize; }

int EnQueue(SqQueue *Q, ElemType x) {           // 入队 O(1)
    if (QueueFull(*Q)) return 0;
    Q->data[Q->rear] = x; Q->rear = (Q->rear + 1) % maxSize; return 1;
}
int DeQueue(SqQueue *Q, ElemType *x) {          // 出队 O(1)
    if (QueueEmpty(*Q)) return 0;
    *x = Q->data[Q->front]; Q->front = (Q->front + 1) % maxSize; return 1;
}
```

**2. 链式队列基本操作实现**
```c
typedef struct node { ElemType data; struct node *next; } LinkNode;
typedef struct { LinkNode *front, *rear; } LinkQueue;   // front 指向头结点

void InitQueue(LinkQueue *Q) {
    Q->front = Q->rear = (LinkNode *)malloc(sizeof(LinkNode));
    Q->front->next = NULL;
}
int EnQueue(LinkQueue *Q, ElemType x) {       // 尾插 O(1)
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    if (!s) return 0;
    s->data = x; s->next = NULL;
    Q->rear->next = s; Q->rear = s; return 1;
}
int DeQueue(LinkQueue *Q, ElemType *x) {      // 删首结点 O(1)
    if (Q->front == Q->rear) return 0;         // 队空
    LinkNode *q = Q->front->next; *x = q->data;
    Q->front->next = q->next;
    if (Q->rear == q) Q->rear = Q->front;      // ★ 出队后变空，恢复 rear
    free(q); return 1;
}
```

### （四）综合应用

1. **层次遍历（BFS）**：树/图的广度优先遍历、迷宫最短路；
2. **缓冲区与任务调度**：打印任务队列、CPU 作业调度、消息队列；
3. **模拟排队**：银行/售票窗口排队等待时间统计；
4. **图的广度优先生成树**（第六章）；
5. **滑动窗口 / 双端队列求窗口最大值**（属双端队列应用）。

## 四、进一步讨论：栈与队列（双端队列、双底栈）

### （一）识记
| 术语 | 含义 |
|---|---|
| **双端队列（deque）** | 两端都允许**插入和删除**的线性表 |
| **输入受限的双端队列** | 只允许在**一端插入**，两端都可删除 |
| **输出受限的双端队列** | 两端都可插入，只允许在**一端删除** |
| **双底栈** | **两个栈共享同一个数组空间**，两栈底固定在数组两端、栈顶相向生长（见前文），提高空间利用率 |

### （二）领会
**1. 双端队列的操作机制**：设前端 `front`、后端 `rear`（用数组循环实现），可执行四类操作：
- 前端插入 / 前端删除；后端插入 / 后端删除（各自用取模回绕）。
**2. 空、满的含义及判定（数组循环实现，牺牲单元法）**
- 初始 `front = rear = 0`；
- **空**：`front == rear`；
- **满**：`(rear + 1) % maxSize == front`（与循环队列同）；
- 元素个数：`(rear − front + maxSize) % maxSize`；
- 双底栈：**空**为 `top1 == −1`（栈1空）、`top2 == maxSize`（栈2空）；**满**为 `top1 + 1 == top2`。

### （三）简单应用
```c
// 循环双端队列（牺牲一个单元）
int PushFront(SqDeque *D, ElemType x) {
    if (QueueFull(*D)) return 0;                 // 满
    D->front = (D->front - 1 + maxSize) % maxSize;
    D->data[D->front] = x; return 1;
}
int PushRear(SqDeque *D, ElemType x) {
    if (QueueFull(*D)) return 0;
    D->data[D->rear] = x; D->rear = (D->rear + 1) % maxSize; return 1;
}
int PopFront(SqDeque *D, ElemType *x) {
    if (QueueEmpty(*D)) return 0;
    *x = D->data[D->front]; D->front = (D->front + 1) % maxSize; return 1;
}
int PopRear(SqDeque *D, ElemType *x) {
    if (QueueEmpty(*D)) return 0;
    D->rear = (D->rear - 1 + maxSize) % maxSize;
    *x = D->data[D->rear]; return 1;
}
```

### （四）综合应用
滑动窗口最大值（单调双端队列）、双端队列实现回文判定、受限双端队列的可行输出序列判定、任务双向调度。

## 五、本章对比与易混点

### 1. 栈 vs 队列

| 比较项 | 栈 | 队列 |
|---|---|---|
| 操作端 | **只在一端（栈顶）** 插入删除 | **一端入队（队尾）、一端出队（队头）** |
| 特性 | **LIFO 后进先出** | **FIFO 先进先出** |
| 顺序实现要点 | top = −1 空、top = maxSize−1 满 | 循环队列：front==rear 空、牺牲单元法判满 |
| 链式实现要点 | 栈顶在**表头**，入栈=头插、出栈=删首结点 | 队头在**表头**、队尾在**表尾**；出队变空须 `rear = front` |
| 典型应用 | 括号匹配、表达式转换与求值、递归/DFS、进制转换 | BFS/层次遍历、缓冲区、任务调度、模拟排队 |

### 2. 易混点

| 易混点 | 正确理解 |
|---|---|
| 栈顶指针 vs 栈顶元素 | top 是**指针/下标**；栈顶元素是**值** |
| 顺序栈 top = −1 还是 0 | ⚠️ 约定不同：top 指向栈顶元素时 −1 为空；top 指向"下一个空位"时 0 为空——**先声明约定** |
| 顺序队列的"满" vs "假溢出" | 下标越界但数组仍有空位＝**假溢出**（用循环队列解决）；真满＝全部单元被占 |
| 循环队列空 == 满 | 用**牺牲一个单元 / size 计数 / tag 标志**三者之一区分 |
| 链式栈"栈满" | 链式结构**无固定栈满**，只有内存耗尽（静态实现时为"空闲链空"） |
| 链式队列出队变空 | **必须令 `rear = front`**，否则 rear 悬空导致后续入队错误 |
| 双底栈判满 | `top1 + 1 == top2`（不是 `top1 == top2`） |
| 输入/输出受限双端队列 | **输入受限**＝只能一端插入；**输出受限**＝只能一端删除；两端均可删/插的才是标准双端队列 |
| 队头指针的两种约定 | front 指向队头元素 或 其前一个位置 ⚠️，公式随之不同 |
