# 第一部分 考点总结

## 一、基本概念和术语（识记 + 领会）

### 1. 基本术语（必背）
- **数据**：信息的载体，能被计算机识别、存储和加工处理的符号集合。
- **数据元素**：数据的基本单位，是数据集合中的一个个体（又称结点、记录）。
- **数据项**：构成数据元素的**最小单位**，是数据不可分割的最小标识单位（一个数据元素可由若干数据项组成）。
- **数据结构**：相互之间存在一种或多种**特定关系**的数据元素的集合。包含三要素：**逻辑结构、存储结构、数据的运算（基本操作）**。
- **逻辑结构**：数据元素之间的**抽象关系**，与计算机无关。分 4 类：**集合、线性结构、树结构、图结构（网状结构）**。
- **存储结构（物理结构）**：逻辑结构在计算机存储器中的**表示（映像）**。
- **基本操作**：定义在某种逻辑结构上的一组运算（如插入、删除、查找、遍历）。
- **抽象数据类型（ADT）**：一个**数学模型**及定义在该模型上的一组操作；只关心**逻辑特性**，与实现无关。

### 2. 4 类基本逻辑结构
| 逻辑结构 | 元素间关系 | 举例 |
|---|---|---|
| **集合** | 元素间除"同属一个集合"外无其他关系 | 集合 |
| **线性结构** | 一对一（除首尾外每个元素有唯一直接前驱和直接后继） | 线性表、栈、队列、串 |
| **树结构** | 一对多（层次关系） | 树、二叉树 |
| **图结构** | 多对多（网状） | 图 |

**线性结构与非线性结构特性**
- 线性结构：有唯一"第一个"和"最后一个"元素；每个元素最多一个直接前驱、一个直接后继（1:1）。
- 非线性结构（树、图）:一个元素可有多个后继（1:n、m:n），存在层次或网状关系，不能简单按序号一对一访问。

### 3. 4 种基本存储方法（领会）
1. **顺序存储**：用一组**连续**的存储单元依次存放数据元素，逻辑相邻则物理相邻；**可随机存取**；插入删除需移动元素。
2. **链式存储**：用**指针**表示元素间的逻辑关系，结点可分散存放；**只能顺序存取**；插入删除方便，需额外指针空间（结构性开销）。
3. **索引存储**：存储元素的同时建立**索引表**（关键字→地址）；查找快，需额外索引空间，插入删除要维护索引。
4. **散列（哈希）存储**：由**关键字通过哈希函数直接计算存储地址**；查找快，可能产生冲突，需解决冲突。

### 4. 逻辑结构与存储结构的关系（高频简答）
- **逻辑结构是面向问题的抽象，存储结构是面向计算机的实现**；
- 一种逻辑结构可对应**多种**存储结构（如线性表可用顺序或链式）；
- **存储结构不同，同一基本操作的实现方法、效率（时间/空间）也不同**；
- 设计时通常先确定逻辑结构，再结合操作特点选择存储结构。

### 5. ADT 的定义形式（简单应用）
```
ADT 抽象数据类型名 {
    数据对象: <数据对象的定义>
    数据关系: <数据关系的定义>
    基本操作: <操作名(参数表)>
              初始条件: ...
              操作结果: ...
} ADT 抽象数据类型名
```
**示例：复数 ADT**
```
ADT Complex {
    数据对象: D = { e1, e2 | e1, e2 为实数 }
    数据关系: R = { <e1, e2> }
    基本操作:
        Assign(&C, v1, v2)   初始条件: 无; 操作结果: 构造复数 C = v1 + v2i
        Add(&C, C1, C2)      初始条件: C1、C2 为复数; 操作结果: C = C1 + C2
        GetReal(C)           初始条件: C 为复数; 操作结果: 返回实部
} ADT Complex
```

## 二、算法和算法分析（识记 + 领会 + 简单应用）

### 1. 算法及其 5 个特性（必背）
**算法**：对特定问题求解步骤的一种描述，是**指令的有限序列**。
5 个特性：**有穷性 · 确定性 · 可行性 · 输入（0 个或多个）· 输出（1 个或多个）**。
> 程序 ≠ 算法：程序可以不满足有穷性（如操作系统）；算法必须满足。

### 2. 问题规模
算法执行时间（或空间）随**输入数据量**增长的度量基准，通常记为 **n**（如数组长度、表的元素个数、图的顶点/边数）。

### 3. 时间复杂度
- **定义**：算法中**基本操作重复执行的次数**（语句频度）是问题规模 n 的某个函数 f(n)，则时间复杂度 **T(n) = O(f(n))**。
- **大 O 表示法**：只保留**最高阶项**并舍去系数，表示 **n → ∞ 时的渐进上界（增长量级）**。
- **常见增长函数由小到大**：
  O(1) < O(log₂n) < O(n) < O(n log₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
- **常用结论**：
  - 顺序执行的语句、赋值/比较：O(1)；
  - 单重循环 n 次：O(n)；双重嵌套各 n 次：O(n²)；
  - 每次折半（i *= 2 或 i /= 2）：O(log₂n)；
  - 分治递归（如归并、快排平均）：O(n log₂n)。
- **最坏 / 平均 / 最好时间复杂度**：通常以**最坏情况**为主要衡量（平均复杂度分析较难）。

### 4. 空间复杂度
算法运行所需**辅助存储空间**（除输入数据本身外）随问题规模增长的度量，记 **S(n) = O(f(n))**。
- **原地（就地）算法**：S(n) = O(1)，只用常数个辅助单元（如冒泡、直接插入、堆排序）。

### 5. 分析程序段时间复杂度的方法（简单应用，固定套路）
① 找出**基本操作**（最深层、执行最频繁的语句）；
② 计算它的**语句频度**（含循环次数的乘积）；
③ 取**最高阶项、去系数**，写成 O(…)。
```c
for (i = 1; i <= n; i++)        // 外层 n 次
    for (j = 1; j <= n; j++)    // 内层 n 次
        x++;                    // 基本操作执行 n² 次 → T(n) = O(n²)
```
```c
for (i = 1; i <= n; i *= 2)     // i: 1,2,4,8,... 共 log2n 次
    x++;                        // T(n) = O(log2n)
```

## 三、算法设计策略简介（领会 + 简单应用）

| 策略 | 基本特点 | 典型例子 |
|---|---|---|
| **递推法** | 由已知的**初始条件**出发，按递推公式**逐步推出后续结果** | 斐波那契数列、秦九韶多项式求值 |
| **迭代法** | 用**循环**反复用同一公式（旧值→新值）逼近或更新结果 | 迭代求平方根、牛顿迭代 |
| **递归法** | 问题**分解为同类子问题**，函数**直接或间接调用自身**，需**递归出口** | 阶乘、汉诺塔、二叉树遍历 |
| **贪心法** | 每步都选**当前最优（局部最优）**，期望得到全局最优；**不保证最优** | 哈夫曼树、Prim、Kruskal、Dijkstra |
| **分治法** | 把问题**分成若干规模更小的同类子问题**，分别求解后**合并** | 二分查找、快速排序、归并排序 |
| **动态规划法** | 把问题分解为**重叠子问题**，用**表记录子问题最优解**避免重复计算（最优子结构 + 无后效性） | 最长公共子序列、背包问题、Floyd |

> 简记：**递推=公式往前推；迭代=循环逼近；递归=自己调自己；贪心=只顾眼前；分治=分而治之再合并；动规=记表防重算。**

# 第二部分 考前简记（关键词版）

**数据结构 = 逻辑结构 + 存储结构 + 运算（三要素）**
**4 类逻辑结构**：集合（无关系）· 线性（1:1）· 树（1:n）· 图（m:n）
**4 种存储方法**：顺序（连续、随机存取）· 链式（指针、顺序存取）· 索引（索引表）· 散列（哈希函数算地址）
**关系**：逻辑=抽象（面向问题）；存储=实现（面向机器）；一种逻辑→多种存储；存储不同→操作实现与效率不同
**ADT** = 数学模型 + 其上的一组操作（只讲逻辑，与实现无关）
**术语**：数据 > 数据元素 > 数据项（数据项最小）；基本操作＝定义在逻辑结构上的运算

**算法 5 特性**：有穷 · 确定 · 可行 · 输入 · 输出
**问题规模 n**：输入量的度量
**时间复杂度**：基本操作执行次数 f(n) → T(n)=O(f(n))（只留最高阶、去系数）
**增长阶**：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
**空间复杂度**：辅助空间 S(n)=O(f(n))；原地算法 O(1)
**分析三步**：找基本操作 → 数频度 → 取最高阶去系数
**常用**：单层循环 O(n)｜双层 O(n²)｜折半/倍增 O(log n)｜分治排序 O(n log n)

**6 策略**：递推（初始值往前推）· 迭代（循环逼近）· 递归（自调用+出口）· 贪心（局部最优，不保证全局最优）· 分治（分—治—合）· 动态规划（重叠子问题+记表）
**贪心与分治常考**：哈夫曼/Prim/Kruskal/Dijkstra＝贪心；二分查找/快排/归并＝分治；Floyd/背包＝动态规划

**最爱考**：逻辑结构与存储结构的区别与联系；4 种存储方法及特点；ADT 定义；算法 5 特性；程序段时间复杂度分析（写频度、化简为 O）；递归与迭代的区别；分治/贪心/动规的适用与差别
