## 二、数组

### （一）识记

| 术语 | 含义 |
|---|---|
| **多维数组** | 一维数组是线性表；**二维数组可看成"元素为一维数组的线性表"**，n 维数组递归定义 |
| **数组首地址** | 第一个元素（a₀₀…或 a₁₁…）的存储地址，是地址计算的基准 |
| **数组下标** | 标识元素在数组中的位置（行列号），下标有从 0 开始与从 1 开始两种约定 【注意】 |
| **行主序（行优先）** | 按**行**的顺序存放：先存第 0 行全部元素，再存第 1 行……（C、Pascal 等） |
| **列主序（列优先）** | 按**列**的顺序存放：先存第 0 列全部元素，再存第 1 列……（Fortran 等） |
| **地址映射函数** | 由元素**下标**求其**存储地址（一维下标）** 的函数公式 |
| **三元组** | 表示稀疏矩阵非零元的三元组 **(行下标, 列下标, 值)** |
| **三元组表** | 用**顺序存储**（一维数组）按行序存放所有非零元三元组的存储方式 |

> 数组的两个特点：① 元素**个数固定**（一旦定义不能增删）；② 元素**类型相同**；③ 数组一般**不进行插入删除**，只做存取与修改 → 因此**只采用顺序存储**。

### （二）领会：多维数组地址计算（必考）

- **1. 二维数组（行主序、下标从 0 开始）**
设 A[m][n]，每元素占 L 个字节，首地址 LOC(a₀₀)：
- **LOC(aᵢⱼ) = LOC(a₀₀) + ( i × n + j ) × L**

- **2. 二维数组（列主序、下标从 0 开始）**
- **LOC(aᵢⱼ) = LOC(a₀₀) + ( j × m + i ) × L**

- **3. 下标从 1 开始的写法** 【注意】（A[1..m][1..n]，首地址 LOC(a₁₁)）
行主序：**LOC(aᵢⱼ) = LOC(a₁₁) + ( (i−1) × n + (j−1) ) × L**  
列主序：**LOC(aᵢⱼ) = LOC(a₁₁) + ( (j−1) × m + (i−1) ) × L**

- **4. 三维数组（行主序、0 基）** A[d₁][d₂][d₃]：
- **LOC(a[i][j][k]) = LOC(a₀₀₀) + ( i×d₂×d₃ + j×d₃ + k ) × L**

- **5. n 维数组（行主序、0 基）**
- **LOC = LOC(a₀…₀) + ( i₁×d₂×…×d_n + i₂×d₃×…×d_n + … + i_n ) × L**
> 记忆：**每跨一行（第一维加 1）要跳过"后面所有维度的元素总数"个元素**。

- **6. 计算示例**
- 例 1：A[4][5]，L = 4，LOC(a₀₀) = 2000。
行主序：LOC(a₂₃) = 2000 + (2×5 + 3)×4 = 2000 + 52 = **2052**  
列主序：LOC(a₂₃) = 2000 + (3×4 + 2)×4 = 2000 + 56 = **2056**
- 例 2：A[3][4][5]，L = 2，LOC(a₀₀₀) = 100。
LOC(a[1][2][3]) = 100 + (1×4×5 + 2×5 + 3)×2 = 100 + 66 = **166**

### （二·续）特殊矩阵的压缩存储（领会 + 简单应用，必考）

- **1. 对称矩阵**：满足 **aᵢⱼ = aⱼᵢ**（n×n，关于主对角线对称）。
- **压缩方法**：只存**下三角（含对角线）** 元素，共 **n(n+1)/2** 个，按**行优先**存入一维数组 `SA[0..n(n+1)/2−1]`（下标从 0 开始）：
- 当 **i ≥ j**（下三角）：**k = i(i+1)/2 + j**
- 当 **i < j**（上三角）：利用对称性存 aⱼᵢ → **k = j(j+1)/2 + i**
> 若教材下标从 1 开始：i ≥ j 时 **k = i(i−1)/2 + j − 1**（0 基）或 **k = i(i−1)/2 + j**（1 基）【注意】 按教材约定。

- **2. 三角矩阵**
- **下三角矩阵**：上三角（不含对角线）元素全为常数 c → 存下三角 **n(n+1)/2** 个元素 + **1 个常数 c**，共 **n(n+1)/2 + 1**；
- **上三角矩阵**：下三角（不含对角线）元素全为常数 c → 同理存 **n(n+1)/2 + 1**。
- 地址映射与对称矩阵相同，但"访问上三角"时不取对称元素，而是取常数 c。

- **3. 对角矩阵（带状矩阵）**
- 非零元素集中在主对角线及其上下若干条对角线上；
- **三对角矩阵**（|i − j| ≤ 1，非零元共 **3n − 2** 个）：按**行优先**压缩存储，
0 基：**k = 2i + j**（|i − j| ≤ 1）；1 基：**k = 2i + j − 2**
- 例：三对角矩阵 n = 4 时，非零元个数 = 3×4 − 2 = **10**。

- **4. 稀疏矩阵**
- **定义**：非零元素个数远小于矩阵元素总数（一般非零元占比 < 5%）的矩阵；
- **三元组表（顺序存储）**：用一维数组存 `(行, 列, 值)`，并按**行序（行优先）** 排列；优点=省空间；缺点=**不能随机存取**、矩阵运算（转置/加法）效率低；
- **（链式存储，扩展）**：十字链表 / 行链表（大纲未要求，了解即可）。

### （三）简单应用

- **1. 构造地址映射函数**：由题意写出"下标 → 一维存储下标（或地址）"的公式（注意：行主序/列主序、下标起点、每元素字节数）。

- **2. 访问压缩存储的数组元素**
- 由 (i, j) 求 k：直接代入公式（如对称矩阵 i ≥ j 时 `k = i(i+1)/2 + j`）；
- 由 k 反求 (i, j)（对称矩阵下三角）：
先求满足 **i(i+1)/2 ≤ k** 的**最大 i**，则 **j = k − i(i+1)/2**；
- 三对角矩阵由 k 反求：`i = (k+1)/3` 附近取整后代入 `j = k − 2i` 【注意】（按教材约定与下标起点）。

- **3. 计算示例**：n = 4 的对称矩阵，元素 a₃₁（i=3, j=1，0 基）→ k = 3×4/2 + 1 = **7**（存放在 SA[7]）；元素 a₁₃ → 存 a₃₁ → k = **7**。

### （四）综合应用（以数组为存储结构的简单算法）

- **矩阵转置**：① 普通转置 O(n×t)（t 为非零元个数，需按列扫描）；② **快速转置 O(n+t)**（先统计每列非零元个数 `num[]`，再求列起始位置 `cpot[]`，一次扫描即可定位）；
- **矩阵相加 / 相乘**（三元组表上按行序归并 / 逐行累加）；
- **杨辉三角**（二维数组递推）；
- **数组元素循环移位 / 逆置**（三段逆置法：逆置整体再分别逆置）；
- **螺旋矩阵、矩阵螺旋输出**；
- **在二维数组中查找（行有序 + 列有序：从右上角或左下角出发 O(m+n)）**。

## 三、广义表

### （一）识记

- **1. 广义表（列表）**：n（n ≥ 0）个**元素**组成的有限序列 **LS = (a₁, a₂, …, aₙ)**；其中 aᵢ **可以是单个元素（原子），也可以是一个广义表（子表）**。

| 术语 | 含义 |
|---|---|
| **原子** | 不可再分的单个数据元素（如数字、字符） |
| **子表** | 元素本身又是一个广义表 |
| **表头（head）** | **第一个元素 a₁**（可能是原子或子表） |
| **表尾（tail）** | **除表头外其余元素构成的表 (a₂, …, aₙ)** ——注意表尾**一定是一个表** |
| **广义表的长度** | **最外层**元素的个数 n |
| **广义表的深度** | 括号**嵌套的最大层数**（原子深度为 0；**空表深度为 1**） |

### （二）领会

- **1. 空表**：`()` 长度 0、**深度 1**（注意：长度 0 但仍有"一层括号"）。
- **2. 递归表**：表中直接或间接**包含自身**（如 `A = (a, A)`），其**深度为无穷大（∞）**；递归表不能求深度/长度时需特殊处理（会死循环）。

### （三）简单应用（基本操作）

- **取表头 GetHead(LS) / 取表尾 GetTail(LS)**：注意**表尾是表**，必须在原括号基础上加一层括号。

- **示例**：设 A = ((a, b), c, (d, (e)))
- 长度 = **3**（三个最外层元素：(a,b)、(c)、(d,(e)) 中 c 是原子）；
- 深度 = **3**（第 1 层 A，第 2 层 (a,b) 与 (d,(e))，第 3 层 (e)）；
- GetHead(A) = **(a, b)**；GetTail(A) = **( c, (d, (e)) )**；
- GetHead(GetTail(A)) = **c**；GetTail(GetTail(A)) = **( (d, (e)) )**；
- GetHead(GetHead(A)) = **a**；GetTail(GetHead(A)) = **( b )**。

- **再例**：B = (a, (b, c, d), e) → 长度 **3**，深度 **2**；GetHead(B) = a，GetTail(B) = ( (b, c, d), e )。
- **再例**：C = (a, (b, (c))) → 长度 **2**，深度 **3**。

> **存储方式**（扩展了解）：① **头尾表示法**（每个结点有标志位、表头/表尾指针或数据域）；② **孩子兄弟表示法**（把广义表看成树/二叉树）。

## 四、串

### （一）识记

| 术语 | 含义 |
|---|---|
| **串（字符串）** | 由**零个或多个字符**组成的**有限序列**；元素是**字符**，通常整体处理 |
| **空串** | **长度为 0** 的串，记作 `""`（注意：**空格串** `" "` 长度为 1，二者不同） |
| **串的长度** | 串中**字符的个数** |
| **子串** | 串中**任意个连续字符**组成的子序列；含空串 |
| **主串** | 被匹配（被查找）的串，常记 S |
| **模式串** | 用于在主串中查找的串（**模式**），常记 T |
| **模式匹配（串匹配）** | 在主串 S 中查找模式串 T，找到则返回其**首次出现的位置** |

> 串与线性表的区别：串的元素**必须是字符**，且通常**以整体（子串）为单位**进行操作（连接、取子串、比较、定位、替换）。

### （二）领会

- **1. 比较次数**：模式匹配过程中**字符比较的总次数**，是衡量匹配算法效率的指标。
- BF 算法：最好 **m**（首字符即匹配成功，m 为模式长度）；最坏 **(n − m + 1) × m**（每趟都比较到最后一位才发现不等）；
- KMP 算法：**O(n + m)**。

- **2. 串模式匹配的含义**：在主串中寻找与模式串**相同**的子串，返回其**起始位置**；找不到称匹配失败（返回 0/ −1 【注意】）。

- **3. 特征向量（next 数组 / 失效函数）**
KMP 的核心：**利用模式串自身的结构信息**，当某位失配时，**主串指针不回退**，只把模式串向右"滑动"，滑动的位数由**特征向量**决定。
- **定义（0 基常见约定）**：`next[j]` = 模式串前 j 个字符 `P[0..j−1]` 中**最长相等前后缀（真前缀与真后缀）的长度**；`next[0] = 0`（或 −1，视教材 【注意】）。
> **直观理解**：失配时，模式串前面已经匹配好的部分中，"前缀 = 后缀"的那一截可以**直接复用**，于是模式串只需滑到 next[j] 的位置继续比较。

### （三）简单应用（必考：BF、特征向量、KMP）

- **1. 串的基本操作**：赋值 StrAssign、求长 StrLength、连接 StrConcat、求子串 SubString、比较 StrCompare、定位 StrIndex、插入、删除、替换。

- **2. BF 算法（朴素/暴力匹配）**
思路：从主串的每个位置 i（0 ≤ i ≤ n−m）开始，逐字符与模式串比较；一旦失配，**主串指针回到 i+1，模式串指针回到 0** 重新比较。

```c
int BF(char S[], char T[], int n, int m) {
    int i = 0, j = 0;
    while (i < n && j < m) {
        if (S[i] == T[j]) { i++; j++; }
        else { i = i - j + 1; j = 0; }      // 主串回退到本趟起点的下一位
    }
    return (j >= m) ? i - m : -1;            // 返回起始位置或失败
}

```
- **复杂度**：最好 O(m)，最坏 **O((n−m+1)×m) ≈ O(n×m)**。

- **3. 特征向量（next 数组）计算**（0 基约定）

```c
void GetNext(char P[], int m, int next[]) {
    next[0] = 0;
    int j = 0;                     // j：当前最长相等前后缀长度
    for (int i = 1; i < m; i++) {
        while (j > 0 && P[i] != P[j]) j = next[j - 1];   // 回退
        if (P[i] == P[j]) j++;
        next[i] = j;
    }
}

```
- **手工计算示例**：模式串 **T = a b a a b c a c**（下标 0..7）

- **T[j]**：0：a；1：b；2：a；3：a；4：b；5：c；6：a；7：c
- **前 j+1 个字符**：0：a；1：ab；2：aba；3：abaa；4：abaab；5：abaabc；6：abaabca；7：abaabcac
- **next[j]（0 基，最长相等前后缀长度）**：0：0；1：0；2：1；3：1；4：2；5：0；6：1；7：0

> 【注意】 若教材采用"从 1 开始、next[1] = 0"的经典约定（严蔚敏式），上例对应 **next = 0, 1, 1, 2, 2, 3, 1, 2**（即 0 基的 `next[j−1] + 1`）。**答题必须按教材约定**，并声明起点。

- **4. KMP 算法（利用特征向量加速匹配）**

```c
int KMP(char S[], char T[], int n, int m, int next[]) {
    GetNext(T, m, next);
    int i = 0, j = 0;
    while (i < n && j < m) {
        if (S[i] == T[j]) { i++; j++; }            // 继续比较下一字符
        else if (j == 0) i++;                      // 模式首字符失配：主串后移
        else j = next[j - 1];                      // 主串不回退，模式串滑动
    }
    return (j >= m) ? i - m : -1;
}

```
- **要点**：**主串指针 i 永不回退**，只让模式串指针 j 按 `next` 回退；时间 **O(n + m)**，空间 O(m)（存 next）。
- **示例**：主串 `ababcabcacbab`（n=13），模式 `abcac`（m=5） → BF 需约 3 趟 13 次比较，KMP 只需 1 趟不回退。

> 另可提及 **KMP 改进（nextval）**：当 `P[j] == P[next[j]]` 时令 `nextval[j] = nextval[next[j]]`，避免无效比较（大纲未要求，了解即可）。

## 五、本章对比与易混点

### 1. 易混点

| 易混点 | 正确理解 |
|---|---|
| **行主序 vs 列主序** | 行主序先存同一行所有元素；列主序先存同一列所有元素；**公式不同，结果一般不同** |
| 下标从 0 还是 1 | 【注意】 教材约定不同，公式中体现为 `i` 还是 `i−1`；**答题先声明** |
| 对称矩阵存多少个 | **只存下三角（含对角线）＝ n(n+1)/2**；三角矩阵为 n(n+1)/2 + 1（含常数） |
| 对称矩阵 i<j 的处理 | 利用 aᵢⱼ = aⱼᵢ **转存 aⱼᵢ**（k 用 j 的公式） |
| 三对角矩阵非零元个数 | **3n − 2**（不是 3n） |
| 三元组表 vs 二维数组 | 三元组表**省空间**但不能**随机存取**；二维数组可随机存取但浪费空间 |
| **空表 ()** | 长度 0、**深度 1**（不是 0！） |
| 表头 vs 表尾 | 表头＝**第一个元素**（可原子可子表）；表尾＝**剩余元素构成的表**（一定是表，要加括号） |
| 长度 vs 深度 | 长度＝**最外层元素个数**；深度＝**括号最大嵌套层数** |
| 空串 vs 空格串 | `""` 长度 0；`" "` 长度 1 |
| BF vs KMP | BF：失配时**主串回退**，最坏 O(nm)；KMP：**主串不回退**，按特征向量滑动，O(n+m) |
| 模式匹配 vs 子串 | 定位是"找子串的**位置**"，取子串是"取出**内容**" |

### 2. 计算模板

- **二维数组地址**：先写公式（行/列主序、起点）→ 代入 → 得地址。
- **对称矩阵**：判断 i 与 j 大小 → 选公式 `i(i+1)/2+j` 或 `j(j+1)/2+i` → 代入得 k。
- **三对角矩阵**：0 基 `k = 2i + j`（1 基 `k = 2i + j − 2`）。
- **广义表**：**先数最外层元素个数（长度）**，**再数最大括号层数（深度）**；求表尾时**记得补括号**。
- **next 数组**：逐个前缀求"最长相等前后缀长度"（列表法最稳）。

## 六、必背清单 + 简答预测

### （一）必背清单

- 数组定义与特点（元素个数固定、类型相同、只做存取 → **只用顺序存储**）；
- **行主序/列主序**的含义与**二维、三维、n 维地址公式**；
- **特殊矩阵压缩**：对称矩阵（存 n(n+1)/2，`k=i(i+1)/2+j`）、三角矩阵（+1 个常数）、三对角矩阵（3n−2，`k=2i+j`）、稀疏矩阵与**三元组表**；
- 广义表：表头/表尾/原子/子表/长度/深度；**空表深度为 1**；递归表深度 ∞；GetHead/GetTail 操作；
- 串：串/子串/空串/空格串/主串/模式串；模式匹配含义；
- **BF 算法**思想与复杂度（最坏 O(nm)）；**特征向量（next）** 的定义与手工计算；**KMP 算法**思想与复杂度 O(n+m)。

### （三）计算题模板

- 数组地址：公式 → 代入 → 结果（注意行/列主序与下标起点）
- 对称矩阵：比较 i、j → 套公式 → 求 k；反向由 k 求 (i, j)
- 三对角矩阵：`k = 2i + j`（0 基）
- 广义表：长度＝最外层个数；深度＝最大嵌套层数；表尾要加括号
- next 数组：列表逐前缀求最长相等前后缀长度
