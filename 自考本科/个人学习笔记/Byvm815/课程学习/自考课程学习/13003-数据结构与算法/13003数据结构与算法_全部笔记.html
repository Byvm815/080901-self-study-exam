第一部分 考点总结

一、基本概念和术语（识记 + 领会）

1. 基本术语（必背）

  • 数据：信息的载体，能被计算机识别、存储和加工处理的符号集合。
  • 数据元素：数据的基本单位，是数据集合中的一个个体（又称结点、记录）。
  • 数据项：构成数据元素的最小单位，是数据不可分割的最小标识单位（一个数据元素可由若干数据项组成）。
  • 数据结构：相互之间存在一种或多种特定关系的数据元素的集合。包含三要素：逻辑结构、存储结构、数据的运算（基本操作）。
  • 逻辑结构：数据元素之间的抽象关系，与计算机无关。分 4 类：集合、线性结构、树结构、图结构（网状结构）。
  • 存储结构（物理结构）：逻辑结构在计算机存储器中的表示（映像）。
  • 基本操作：定义在某种逻辑结构上的一组运算（如插入、删除、查找、遍历）。
  • 抽象数据类型（ADT）：一个数学模型及定义在该模型上的一组操作；只关心逻辑特性，与实现无关。

2. 4 类基本逻辑结构

逻辑结构 元素间关系 举例
集合 元素间除"同属一个集合"外无其他关系 集合
线性结构 一对一（除首尾外每个元素有唯一直接前驱和直接后继） 线性表、栈、队列、串
树结构 一对多（层次关系） 树、二叉树
图结构 多对多（网状） 图
  • 线性结构与非线性结构特性
  • 线性结构：有唯一"第一个"和"最后一个"元素；每个元素最多一个直接前驱、一个直接后继（1:1）。
  • 非线性结构（树、图）:一个元素可有多个后继（1:n、m:n），存在层次或网状关系，不能简单按序号一对一访问。

3. 4 种基本存储方法（领会）

  • 顺序存储：用一组连续的存储单元依次存放数据元素，逻辑相邻则物理相邻；可随机存取；插入删除需移动元素。
  • 链式存储：用指针表示元素间的逻辑关系，结点可分散存放；只能顺序存取；插入删除方便，需额外指针空间（结构性开销）。
  • 索引存储：存储元素的同时建立索引表（关键字→地址）；查找快，需额外索引空间，插入删除要维护索引。
  • 散列（哈希）存储：由关键字通过哈希函数直接计算存储地址；查找快，可能产生冲突，需解决冲突。

4. 逻辑结构与存储结构的关系（高频简答）

  • 逻辑结构是面向问题的抽象，存储结构是面向计算机的实现；
  • 一种逻辑结构可对应多种存储结构（如线性表可用顺序或链式）；
  • 存储结构不同，同一基本操作的实现方法、效率（时间/空间）也不同；
  • 设计时通常先确定逻辑结构，再结合操作特点选择存储结构。

5. ADT 的定义形式（简单应用）

ADT 抽象数据类型名 {
    数据对象: <数据对象的定义>
    数据关系: <数据关系的定义>
    基本操作: <操作名(参数表)>
              初始条件: ...
              操作结果: ...
} ADT 抽象数据类型名
  • 示例：复数 ADT
ADT Complex {
    数据对象: D = { e1, e2 | e1, e2 为实数 }
    数据关系: R = { <e1, e2> }
    基本操作:
        Assign(&C, v1, v2)   初始条件: 无; 操作结果: 构造复数 C = v1 + v2i
        Add(&C, C1, C2)      初始条件: C1、C2 为复数; 操作结果: C = C1 + C2
        GetReal(C)           初始条件: C 为复数; 操作结果: 返回实部
} ADT Complex

二、算法和算法分析（识记 + 领会 + 简单应用）

1. 算法及其 5 个特性（必背）

  • 算法：对特定问题求解步骤的一种描述，是指令的有限序列。
    5 个特性：有穷性 · 确定性 · 可行性 · 输入（0 个或多个）· 输出（1 个或多个）。

    程序 ≠ 算法：程序可以不满足有穷性（如操作系统）；算法必须满足。

2. 问题规模

算法执行时间（或空间）随输入数据量增长的度量基准，通常记为 n（如数组长度、表的元素个数、图的顶点/边数）。

3. 时间复杂度

  • 定义：算法中基本操作重复执行的次数（语句频度）是问题规模 n 的某个函数 f(n)，则时间复杂度 T(n) = O(f(n))。
  • 大 O 表示法：只保留最高阶项并舍去系数，表示 n → ∞ 时的渐进上界（增长量级）。
  • 常见增长函数由小到大：
    O(1) < O(log₂n) < O(n) < O(n log₂n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
  • 常用结论：
  • 顺序执行的语句、赋值/比较：O(1)；
  • 单重循环 n 次：O(n)；双重嵌套各 n 次：O(n²)；
  • 每次折半（i *= 2 或 i /= 2）：O(log₂n)；
  • 分治递归（如归并、快排平均）：O(n log₂n)。
  • 最坏 / 平均 / 最好时间复杂度：通常以最坏情况为主要衡量（平均复杂度分析较难）。

4. 空间复杂度

算法运行所需辅助存储空间（除输入数据本身外）随问题规模增长的度量，记 S(n) = O(f(n))。
- 原地（就地）算法：S(n) = O(1)，只用常数个辅助单元（如冒泡、直接插入、堆排序）。

5. 分析程序段时间复杂度的方法（简单应用，固定套路）

① 找出基本操作（最深层、执行最频繁的语句）；
② 计算它的语句频度（含循环次数的乘积）；
③ 取最高阶项、去系数，写成 O(…)。

for (i = 1; i <= n; i++)        // 外层 n 次
    for (j = 1; j <= n; j++)    // 内层 n 次
        x++;                    // 基本操作执行 n² 次 → T(n) = O(n²)


for (i = 1; i <= n; i *= 2)     // i: 1,2,4,8,... 共 log2n 次
    x++;                        // T(n) = O(log2n)

三、算法设计策略简介（领会 + 简单应用）

  • 递推法：基本特点：由已知的初始条件出发，按递推公式逐步推出后续结果；典型例子：斐波那契数列、秦九韶多项式求值
  • 迭代法：基本特点：用循环反复用同一公式（旧值→新值）逼近或更新结果；典型例子：迭代求平方根、牛顿迭代
  • 递归法：基本特点：问题分解为同类子问题，函数直接或间接调用自身，需递归出口；典型例子：阶乘、汉诺塔、二叉树遍历
  • 贪心法：基本特点：每步都选当前最优（局部最优），期望得到全局最优；不保证最优；典型例子：哈夫曼树、Prim、Kruskal、Dijkstra
  • 分治法：基本特点：把问题分成若干规模更小的同类子问题，分别求解后合并；典型例子：二分查找、快速排序、归并排序
  • 动态规划法：基本特点：把问题分解为重叠子问题，用表记录子问题最优解避免重复计算（最优子结构 + 无后效性）；典型例子：最长公共子序列、背包问题、Floyd

简记：递推=公式往前推；迭代=循环逼近；递归=自己调自己；贪心=只顾眼前；分治=分而治之再合并；动规=记表防重算。

二、线性表的定义和基本操作

（一）识记

  • 1. 线性表的定义
    由 n（n ≥ 0）个数据元素组成的有限序列，记作 (a₁, a₂, …, aₙ)：
  • 元素个数 n 称为表长；n = 0 时是空表；
  • 表头元素 = a₁（第一个元素）；表尾元素 = aₙ（最后一个元素）；
  • 直接前驱：aᵢ₋₁ 是 aᵢ 的直接前驱；直接后继：aᵢ₊₁ 是 aᵢ 的直接后继；

  • 前驱：aᵢ 之前的所有元素（a₁…aᵢ₋₁）；后继：aᵢ 之后的所有元素（aᵢ₊₁…aₙ）。

    直接前驱/后继唯一（首元素无直接前驱、尾元素无直接后继）；前驱/后继可有多个。

  • 2. 有序表与无序表

  • 有序表：元素按关键字递增/递减排列的表（便于折半查找）；

  • 无序表：元素之间没有按关键字排序的表（只能顺序查找）。

  • 3. 线性表的特点（高频简答）
    ① 元素个数有限；
    ② 元素类型相同（属于同一数据对象）；
    ③ 元素之间是一对一（1:1） 的逻辑关系：除首元素外每个元素有唯一直接前驱，除尾元素外有唯一直接后继；
    ④ 元素有确定的位置（序号），元素之间有序；
    ⑤ 表中元素可以重复出现（值相同但位置不同）。

（二）领会

  • 1. 线性表的 ADT 定义
ADT List {
    数据对象: D = { aᵢ | aᵢ ∈ ElemSet, i = 1, 2, …, n, n ≥ 0 }
    数据关系: R = { <aᵢ₋₁, aᵢ> | aᵢ₋₁, aᵢ ∈ D, i = 2, …, n }
    基本操作:
        InitList(&L)             初始化，构造空表
        DestroyList(&L)          销毁表
        ListEmpty(L)             判空（空返回真）
        ListLength(L)            求表长（返回元素个数）
        GetElem(L, i, &e)        取第 i 个元素（i 合法：1 ≤ i ≤ n）
        LocateElem(L, e)         按值查找，返回第一个 e 的位置，无则返回 0
        PriorElem(L, cur, &pre)  求 cur 的直接前驱
        NextElem(L, cur, &next)  求 cur 的直接后继
        ListInsert(&L, i, e)     在第 i 个位置插入 e（1 ≤ i ≤ n+1）
        ListDelete(&L, i, &e)    删除第 i 个元素并用 e 返回（1 ≤ i ≤ n）
        ListTraverse(L, visit)   遍历（对每个元素调用 visit）
} ADT List

  • 2. 线性表中元素之间的逻辑关系
    相邻元素之间是前驱—后继关系；只相邻者构成"直接"关系；表中不允许有"分支"或"环"（否则不是线性结构）。

  • 3. 位置（序号）的含义

  • 位置 i 表示元素在表中的逻辑次序，第 i 个元素就是 aᵢ；
  • 教材通常从 1 开始编号（1 ≤ i ≤ n）【注意】 部分教材从 0 开始，答题按教材；
  • "在第 i 个位置插入"＝插入后新元素成为第 i 个元素（即插在 aᵢ 之前）；

  • 操作位置：插入允许 1 ≤ i ≤ n+1（可插到表尾之后）；删除允许 1 ≤ i ≤ n。

  • 4. 各基本操作的含义与前提

操作 含义 前提条件
InitList / DestroyList 建立空表 / 释放整表 —
ListEmpty / ListLength 判空 / 求表长 —
GetElem(L, i, &e) 按位置取值 1 ≤ i ≤ n
LocateElem(L, e) 按值查找（返回位置或"空"） 表非空
PriorElem / NextElem 求直接前驱 / 后继 元素存在且非首/尾元素
ListInsert(&L, i, e) 插入，表长 +1 1 ≤ i ≤ n+1，且未满（顺序表）
ListDelete(&L, i, &e) 删除，表长 −1 1 ≤ i ≤ n，且非空
ListTraverse(L, visit) 遍历所有元素 —

三、线性表的顺序存储及实现

（一）识记

  • 1. 顺序表：用一组地址连续的存储单元依次存放线性表的各元素，使得逻辑上相邻的元素物理上也相邻。

  • 2. 位置与地址

  • 位置（下标）：元素在表中的逻辑序号 i；
  • 地址映射（下标地址计算，必考）：设首元素 a₁ 的地址为 LOC(a₁)，每个元素占 L 个存储单元，则
  • LOC(aᵢ) = LOC(a₁) + (i − 1) × L　（i 从 1 开始）
  • LOC(a[i]) = LOC(a[0]) + i × L　（i 从 0 开始 【注意】）
  • 例：LOC(a₁) = 100，L = 4 → LOC(a₅) = 100 + 4 × 4 = 116。

（二）领会

  • 1. 顺序存储的基本思想：把逻辑关系"隐含"在物理相邻中——不需要额外信息表示前驱后继，靠连续存放体现逻辑顺序。

  • 2. 随机访问的含义
    因地址可由公式直接算出，访问表中任一元素的时间都相同，与元素位置无关，均为 O(1)，这种存取方式称随机存取（随机访问）。

  • 3. 表空、表满、长度
    用整型量 length 记录当前元素个数，maxSize 为容量：

  • 表空：length == 0（删除前必须判空，否则下溢）；
  • 表满：length == maxSize（插入前必须判满，否则上溢）；

  • 插入使 length +1，删除使 length −1。

  • 4. 顺序表的优缺点

  • 优点：随机访问 O(1)；存储密度 = 1（无结构性开销）；实现简单、cache 友好；
  • 缺点：插入/删除平均需移动一半元素，O(n)；容量预先固定（可能上溢或浪费）；动态扩容需复制整表。

（三）简单应用：基本操作的实现与复杂度分析

  • 插入 ListInsert(L, i, e)：实现要点：前提 1 ≤ i ≤ n+1 且未满；从后往前把 aᵢ…aₙ 后移一位，再写入 e；移动/比较次数：最好 0（表尾插）／最坏 n（表头插）／平均 n/2；时间复杂度：O(n)
  • 删除 ListDelete(L, i, &e)：实现要点：前提 1 ≤ i ≤ n 且非空；取出 aᵢ，从前往后把 aᵢ₊₁…aₙ 前移一位；移动/比较次数：最好 0（删表尾）／最坏 n−1（删表头）／平均 (n−1)/2；时间复杂度：O(n)
  • 按位置取值 GetElem(L, i)：实现要点：直接由地址公式定位；移动/比较次数：0；时间复杂度：O(1)
  • 按值查找 LocateElem(L, e)：实现要点：从表头顺序比较；移动/比较次数：最好 1／最坏 n／平均 (n+1)/2；时间复杂度：O(n)
  • 求表长 / 判空：实现要点：读 length；移动/比较次数：0；时间复杂度：O(1)

  • 建表（逐个插入/尾插）：实现要点：n 次操作；移动/比较次数：—；时间复杂度：O(n)

  • 必须记住的"移动次数"结论：插入平均 n/2，删除平均 (n−1)/2。

（四）综合应用（常考算法题型）

用顺序表（数组）设计算法，注意必须原地或另开数组、下标边界与 length 维护：
- 就地逆置：首尾互换，O(n)，空间 O(1)；
- 删除所有值为 x 的元素：用 k 记录保留个数，一次扫描覆盖写回，O(n)；
- 删除有序表中重复元素：双指针一次扫描，O(n)；
- 两有序表归并成一个有序表：双指针比较，O(m+n)；
- 求交集/并集（有序表）：双指针 O(m+n)；
- 找最大值/次大值、最小值：一次扫描 O(n)；
- 元素划分（奇数在前偶数在后 / 小于 x 在前）：双指针交换，O(n)；
- 两个序列的公共前缀/最长公共子序列（顺序表视角）：一次扫描。

四、线性表的链式存储及实现

（一）识记

  • 1. 单链表：每个结点含数据域 + 一个指针域，指针指向其后继结点；结点物理位置不要求连续，通过指针体现逻辑关系；链表由头指针标识。

  • 2. 关键术语（务必分清）

术语 含义
头指针（表头指针） 指向链表第一个结点的指针；是链表的唯一标识，不可丢失。有头结点时指向头结点，无头结点时指向首结点
头结点（表头结点） 附设在首结点之前的哑结点，数据域通常不存数据（或存表长等），指针域指向首结点；空表时仍存在，判空为 head->next == NULL
首结点 链表中第一个存放数据的结点（即 a₁ 所在结点）
表尾结点（终端结点） 最后一个数据结点，其指针域为 NULL（循环链表则指回头结点）
单向循环链表 表尾结点的指针域指向头结点（或首结点），全表成环，可从任一结点出发遍历全表
双向链表 结点含两个指针域 prior、next，分别指向直接前驱与直接后继
双向循环链表 双向链表首尾相连（首结点 prior 指向尾结点，尾结点 next 指向头结点）
静态链表 用数组存储结点，以游标（下标） 代替指针表示后继位置
  • 3. 空表与表尾的判定（带头结点单链表）
  • 空表：head->next == NULL；
  • 表尾结点：p->next == NULL；
  • 单向循环链表空表：head->next == head；表尾：p->next == head。

（二）领会

  • 1. 链式存储的基本思想
    用指针显式表示元素之间的逻辑关系（后继），结点不必连续存放，存储分配动态进行。

  • 2. 头结点的作用（高频简答）
    ① 统一空表与非空表的处理：空表也含一个头结点，插入/删除无需区分"表是否为空"；
    ② 使首位置的插入/删除与中间位置一致：不用修改头指针、不用特殊处理首结点；
    ③ 便于实现循环链表与统一操作接口，简化判空、遍历、求长等操作；
    ④ 头结点的数据域可存放表长等辅助信息（可选）。

  • 3. 操作位置与顺序访问

  • 链表中的"第 i 个结点"必须从头指针出发沿 next 逐个走 i 次，时间 O(i)；

  • 这种"只能按顺序逐个访问"的方式称顺序访问（顺序存取），与顺序表的随机访问相对。

  • 4. 结构性开销（会算）
    结点 = 数据域（d 字节） + k 个指针域（每个 p 字节）：

  • 结构性开销 = k·p /（d + k·p）× 100%
  • 例：数据 4B + 1 个指针 4B → 4/8 = 50%；
  • 双向链表（2 个指针）：8/(4+8) ≈ 66.7%；
  • 对比：顺序表无结构性开销（存储密度 = 1），但必须预留连续空间。

（三）简单应用：基本操作实现与复杂度

以带头结点的单链表为例：

  • 建立（头插法）：关键步骤：每次把新结点插在头结点之后；时间复杂度：O(n)，但结果逆序
  • 建立（尾插法）：关键步骤：用尾指针 r 保持链尾，新结点接在 r 之后；时间复杂度：O(n)，保持原序
  • 按位置查找 GetElem(i)：关键步骤：从头结点起走 i 步；时间复杂度：O(n)（走 i 步为 O(i)）
  • 按值查找 LocateElem(e)：关键步骤：逐个比较；时间复杂度：O(n)
  • 插入（已知前驱结点 p）：关键步骤：新结点 s：s->next = p->next; p->next = s;；时间复杂度：O(1)
  • 插入（只给位置 i）：关键步骤：先找第 i−1 个结点（O(n)），再插；时间复杂度：O(n)
  • 删除（已知前驱 p）：关键步骤：q = p->next; p->next = q->next; free(q);；时间复杂度：O(1)
  • 删除（只给位置 i）：关键步骤：先找第 i−1 个结点；时间复杂度：O(n)
  • 删除给定结点自身：关键步骤：非尾结点可用"把后继数据复制到自身，再删后继"技巧；时间复杂度：O(1) 【注意】
  • 求表长：关键步骤：遍历计数（若不设长度域）；时间复杂度：O(n)
  • 就地逆置 / 合并 / 去重：关键步骤：改指针，边扫边接；时间复杂度：O(n)

关键结论：链表的"插入删除 O(1)"必须以已知前驱结点（或已知位置已定位）为前提；按位置操作整体仍是 O(n)。

  • 会算结构性开销、会比较"顺序表 vs 链表"的时空代价（见第六部分对比表）。

  • 根据问题选择链表类型

  • 频繁在表头插删、无尾部需求 → 带头结点单链表；
  • 需要双向遍历、删除给定结点、逆序访问 → 双向（循环）链表；
  • 需要循环往复处理（约瑟夫环、轮转调度） → 单向循环链表；
  • 需要频繁尾部插入 → 带尾指针的（循环）链表；
  • 语言不支持指针/需限定空间 → 静态链表（见第五部分）。

（四）综合应用（常考算法题型）

  • 单链表就地逆置（头插法重置链，O(n)、O(1)）；
  • 删除所有值为 x 的结点（双指针遍历，O(n)）；
  • 删除有序链表中重复结点（一次扫描，O(n)）；
  • 求倒数第 k 个结点（快慢指针一次遍历）；
  • 找中间结点 / 判断是否有环 / 求环入口（快慢指针）；
  • 合并两个有序链表（双指针尾插，O(m+n)，O(1) 空间）；
  • 求两个链表的交集/并集/差集；
  • 两个多项式相加（按指数归并，用链表表示多项式）；
  • 按值域划分链表（小于 x 的在前）；
  • 找公共后缀/相交结点（先求长度差，再同步走）。

五、进一步讨论两种基本实现方式

（一）识记

  • 1. 空闲单元链表（备用链表、free list / avail list）
    把当前未被使用的结点通过其指针域链接成的链表，用 avail（空闲链表头指针）标识；申请结点时从空闲链表头部取出，释放结点时归还到空闲链表头部。

  • 2. 静态链表
    用数组存储结点，结点由数据域 + 游标（next，存放下一个结点的数组下标） 组成，用游标代替指针表示逻辑关系；数组的某个单元（通常下标 0）作为头结点，S[0].next 存放首结点的下标。

（二）领会

  • 1. 空闲单元链表的作用
    ① 用有限的数组空间模拟动态分配与回收（支撑静态链表的插入/删除）；
    ② 使被删除的结点能被重新利用，避免空间浪费；
    ③ 在链式栈/链式队列中实现结点的回收再利用（第三章的"带空闲单元链表的链式队列"）。

  • 2. 静态链表的实现机制

  • 结构定义：struct { ElemType data; int next; } S[maxSize];
  • 初始化：S[0].next = 0（空表）；把下标 1…maxSize−1 串成空闲单元链表，avail = 1，S[maxSize-1].next = 0（0 表示空/结束 【注意】 视教材约定）；
  • 申请结点：p = avail; avail = S[avail].next;
  • 释放结点：S[p].next = avail; avail = p;
  • 插入：定位到第 i−1 个结点（游标遍历）→ 从空闲链表取结点 → 挂链；
  • 删除：定位到第 i−1 个结点 → 摘链 → 结点归还空闲链表；

  • 定位第 i 个元素：仍需沿游标从头走 i 步 → O(n)（与动态链表相同）。

  • 3. 顺序访问与随机访问方式的对比

  • 随机访问：由地址公式直接定位，时间与位置无关；典型结构：顺序表（数组）；访问第 i 个元素：O(1)

  • 顺序访问：必须从表头沿链逐个访问；典型结构：单/双向链表、静态链表；访问第 i 个元素：O(n)

  • 4. 顺序表、链表和静态链表的使用条件

  • 顺序表：适用条件：表长可预估且变化小；频繁按位置访问（读多写少）；要求存储密度高、访问快；主要限制：插删 O(n)；容量固定，可能上溢/浪费

  • 动态链表（单/双/循环）：适用条件：表长变化大、频繁插删；不需随机访问；要求动态灵活分配；主要限制：有结构性开销；顺序访问 O(n)；指针操作易错
  • 静态链表：适用条件：表长有上限；语言不支持/禁用指针；需在数组内模拟链表且要结点回收；主要限制：容量固定；需维护空闲单元链表；插删仍需定位 O(n)

（三）简单应用

  • 静态链表基本操作实现及复杂度：取用/归还结点 O(1)；按位置/按值定位 O(n)；已知前驱时插删 O(1)；
  • 根据问题选择顺序表、链表或静态链表并实现操作（判据见上表：长度是否可预估、操作以"访问"还是"插删"为主、语言是否支持指针）。

（四）综合应用

例：① 用静态链表实现集合的插入、删除、合并（并/交）；② 同一问题分别用顺序表与链表实现并比较时间/空间复杂度（常考"选型说明题"）。

二、栈

（一）识记

  • 1. 栈的定义：只允许在表的一端进行插入和删除的线性表；允许操作的一端称栈顶（top），另一端称栈底（bottom），不含元素的栈为空栈。

  • 2. 术语

术语 含义
栈顶 / 栈底 允许插入删除的一端 / 固定不动的一端
栈顶元素 当前位于栈顶的元素（下一个出栈的就是它）
入栈（push） 在栈顶插入一个元素
出栈（pop） 删除栈顶元素并返回
栈的容量 栈所能容纳元素的最大个数（顺序栈为 maxSize）
顺序栈 用连续的数组存储栈元素，附设栈顶指针 top
链式栈 用单链表存储栈元素，栈顶设在表头（头结点之后）
出栈序列 按出栈次序排列成的元素序列
栈空 / 栈满 无元素 / 已达容量（顺序栈才有"满"）

（二）领会

  • 1. 栈的先进后出（LIFO）特性
    进栈与出栈都在同一端进行 → 后进先出（Last In First Out）；栈顶元素永远最先被取出；栈底元素最后出栈。

  • 2. 合理出栈序列（合法出栈序列）

  • 判定方法（模拟法，必考）：按入栈序列依次入栈，每当栈顶元素等于待判定序列当前元素就弹出；若最后能按给定序列全部弹出，则合法，否则非法。
  • 合法序列个数：n 个元素依次入栈，可能的合法出栈序列数为 Catalan 数
  • Cₙ = (2n)! / [ n!(n+1)! ]；n=3 → 5 个；n=4 → 14 个；n=5 → 42 个。

  • 规律提示：若某元素先出栈，则在它之后入栈的元素不可能比它先出；"先出栈的较大元素之后不能再出现比它小、且比当前栈顶更深的元素"。（本质：合法出栈序列不出现 312 型模式。）

  • 例：入栈序列 1, 2, 3, 4 时

出栈序列 判定
1 2 3 4 合法（每个元素入栈后立即出栈）
4 3 2 1 合法（全部入栈后依次出栈）
3 2 4 1 合法（push1,2,3→pop3,pop2；push4→pop4；pop1）
3 1 2 4 非法（pop3 后栈顶是 2，不可能先出 1）
2 4 1 3 非法（pop2、push3,4、pop4 后栈顶是 3，不可能先出 1）
  • 3. 顺序栈的空、满判定与操作定义（设 top 为栈顶下标）
  • 常见约定：top = −1 表示空栈（也有教材用 top = 0 表示空栈 【注意】）；top = maxSize − 1 表示栈满；
  • 判空：top == -1　判满：top == maxSize - 1；
  • 入栈：先判满 → S[++top] = x;
  • 出栈：先判空 → x = S[top--];
  • 取栈顶：x = S[top];（不出栈）

  • 全部为 O(1)。

  • 4. 链式栈的空、满判定与操作定义

  • 通常采用带头结点的单链表，栈顶设在表头（头结点之后）；
  • 判空：top->next == NULL；
  • 栈满：链式栈理论上没有固定"栈满"，只有内存耗尽（若用静态链表+空闲单元链表，则以"空闲链表空"为满）；
  • 入栈：头插（新结点插在头结点之后），O(1)；

  • 出栈：删除头结点之后的第一个结点并释放，O(1)。

  • 5. 双底栈（两栈共享空间） 【注意】（有的教材称"共享栈"）

  • 用一个数组 S[0..maxSize-1] 存放两个栈：栈 1 的栈底在下标 0，栈 2 的栈底在下标 maxSize−1，两栈顶 top1、top2 相向生长；
  • 栈空：top1 == −1 且 top2 == maxSize 分别表示两栈为空；
  • 栈满（共享空间用尽）：top1 + 1 == top2（即两栈顶相邻，中间再无空位）；
  • 优点：提高空间利用率（两个栈的空间需求此消彼长时互补），减少上溢。

（三）简单应用

  • 1. 判定序列是否为合理出栈序列：用上面的"模拟法"逐个比对（考试可手算或写伪代码）。

  • 2. 顺序栈实现（类 C）

#define maxSize 100
typedef struct { ElemType data[maxSize]; int top; } SqStack;

void InitStack(SqStack *S) { S->top = -1; }
int  StackEmpty(SqStack S) { return S.top == -1; }
int  StackFull(SqStack S)  { return S.top == maxSize - 1; }

int Push(SqStack *S, ElemType x) {
    if (StackFull(*S)) return 0;          // 上溢
    S->data[++S->top] = x; return 1;
}
int Pop(SqStack *S, ElemType *x) {
    if (StackEmpty(*S)) return 0;         // 下溢
    *x = S->data[S->top--]; return 1;
}
int GetTop(SqStack S, ElemType *x) {
    if (StackEmpty(S)) return 0;
    *x = S.data[S.top]; return 1;
}
  • 3. 链式栈实现（带头结点，栈顶在表头）
typedef struct node { ElemType data; struct node *next; } LinkNode, *LinkStack;

int Push(LinkStack top, ElemType x) {       // 头插，O(1)
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    if (!s) return 0;                        // 空间不足
    s->data = x; s->next = top->next; top->next = s; return 1;
}
int Pop(LinkStack top, ElemType *x) {       // 删首结点，O(1)
    if (top->next == NULL) return 0;         // 栈空
    LinkNode *q = top->next; *x = q->data;
    top->next = q->next; free(q); return 1;
}

（四）综合应用（必考算法）

  • 1. 括号匹配
    思路：遇左括号((、[、{) → 入栈；遇右括号 → 若栈空则不匹配，否则弹出栈顶并检查是否与之配对；扫描结束时栈空才匹配。
int Match(char *s) {
    SqStack S; InitStack(&S);
    for (int i = 0; s[i]; i++) {
        if (s[i]=='(' || s[i]=='[' || s[i]=='{') Push(&S, s[i]);
        else if (s[i]==')' || s[i]==']' || s[i]=='}') {
            if (StackEmpty(S)) return 0;
            char t; Pop(&S, &t);
            if ((s[i]==')' && t!='(') || (s[i]==']' && t!='[') || (s[i]=='}' && t!='{')) return 0;
        }
    }
    return StackEmpty(S);
}

时间 O(n)，空间 O(n)。扩展：判断表达式括号是否配对、多层嵌套、可延伸到"括号深度/最长有效括号"。

  • 2. 中缀表达式转后缀表达式（中缀转后缀）
    思路（运算符栈）：
  • 遇操作数 → 直接输出；
  • 遇运算符 op：若栈空、或栈顶为 (、或 op 优先级高于栈顶运算符 → op 入栈；否则弹出栈顶运算符并输出，再与新的栈顶比较，直到可入栈为止；
  • 遇 ( → 入栈；遇 ) → 弹出并输出运算符直到遇到 (，弹出 ( 并丢弃；
  • 扫描结束 → 弹出栈中所有运算符输出。
    优先级：*、/ 高于 +、-；( 在栈内优先级最低（除遇 ) 外不弹出）。

  • 例：A + B * C - D / E → A B C * + D E / -

  • 3. 计算后缀表达式（后缀表达式求值）
    思路（操作数栈）：从左向右扫描：

  • 遇操作数 → 入栈；
  • 遇运算符 → 弹出两个操作数（先弹出的是右操作数），做运算 左 op 右，结果再入栈；
  • 扫描完毕，栈顶元素即为结果。

  • 例：3 4 + 5 * → (3+4)5 = 35；A B C * + D E / - 即 A+BC−D/E。

  • 4. 栈的其他应用：递归的实现与消除递归、表达式/语法检查、进制转换（除基取余逆序）、迷宫/DFS 非递归、函数调用栈、编辑器的撤销操作、深度优先遍历。

三、队列

（一）识记

  • 1. 队列的定义：只允许在表的一端插入、另一端删除的线性表；先进先出（FIFO）。
  • 2. 术语
术语 含义
队头（front） 允许删除（出队）的一端
队尾（rear） 允许插入（入队）的一端
队头元素 / 队尾元素 当前最前面的元素（最先出队）/ 最后面的元素（最后出队）
入队 / 出队 在队尾插入 / 删除队头
队列长度 当前元素个数
队列空 / 队列满 无元素 / 顺序队列已达容量
队头指针 / 队尾指针 指示队头 / 队尾位置的指针（或下标）
循环队列 把顺序队列的数组首尾相连（用取模运算回绕），解决"假溢出"
链式队列 用单链表表示队列，队头在表头、队尾在表尾

（二）领会

  • 1. 顺序队列的"假溢出"问题（引出循环队列）
    顺序队列用 front、rear 指示队头队尾，每次入队 rear++、出队 front++；当 rear == maxSize 时可能数组中仍有空位（前面已出队的位置空着却无法使用），这种现象称假溢出。

  • 解决办法：把数组看成环——循环队列，用取模实现回绕：
    rear = (rear + 1) % maxSize;　front = (front + 1) % maxSize;

  • 2. 循环队列的特点、存储结构及实现机制

  • 存储结构：一维数组 + front、rear 两个整型下标；
  • 实现机制：入队/出队时下标模 maxSize 回绕，使空间循环使用；

  • 优点：避免假溢出，空间利用率高；缺点：空与满的判别需要额外处理（因为 front == rear 既可能是空也可能是满）。

  • 3. 循环队列中空、满的含义及判定（必考）

  • ① 牺牲一个单元（最常用）：队空判定：front == rear；队满判定：(rear + 1) % maxSize == front；元素个数：(rear − front + maxSize) % maxSize

  • ② 增设计数变量 size：队空判定：size == 0；队满判定：size == maxSize；元素个数：size
  • ③ 增设标志位 tag（入队置 1、出队置 0）：队空判定：front == rear && tag == 0；队满判定：front == rear && tag == 1；元素个数：由 tag 与下标推算

方案①的"满"实际牺牲一个存储单元（容量为 maxSize−1 个元素）。

  • 4. 队头和队尾的不同设定方式 【注意】（不同教材约定不同，判断公式随之变化）
  • 方式 A：front 指向队头元素，rear 指向队尾元素的下一个位置（常见）；
  • 方式 B：front 指向队头元素的前一个位置，rear 指向队尾元素；

  • 常见变体公式（方式 A、牺牲单元法）：
    队空 front == rear；队满 (rear+1)%maxSize == front；长度 (rear−front+maxSize)%maxSize；
    入队 Q[rear] = x; rear = (rear+1)%maxSize;　出队 x = Q[front]; front = (front+1)%maxSize;

    答题时先声明约定，再写公式，避免因约定不同被判错。

  • 5. 链式队列的特点与实现机制

  • 结构：带头结点的单链表 + front（指向头结点）、rear（指向队尾结点）；
  • 判空：front == rear（都指向头结点）；
  • 入队：在队尾插入（尾插），rear->next = s; rear = s;　O(1)；
  • 出队：删除头结点之后的第一个结点；若出队后队列变空，必须令 rear = front（关键细节）；
  • 队满：链式队列无固定队满，只有内存耗尽；

  • 特点：不需要预估容量、无假溢出；但每个结点有结构性开销。

  • 6. 在链式队列中实现空闲单元链表的机制（重点）
    用静态链表（数组 + 游标）实现链式队列时：

  • 数组 Q[maxSize] 存结点 {data, next}，next 为游标（下标）；
  • 队头、队尾用游标表示：front、rear 为整型下标（或"结点指针"即下标）；
  • 空闲单元链表（备用链表）用 avail 串起所有未用单元：入队时从 avail 取结点，出队时把结点归还 avail；
  • 取结点：p = avail; avail = Q[avail].next;
  • 归还结点：Q[p].next = avail; avail = p;
  • 队满：avail == 0（无空闲单元，即数组空间用尽）；
  • 作用：在固定数组空间内实现队列结点的动态分配与回收，避免空间浪费。

（三）简单应用

  • 1. 循环队列基本操作实现
#define maxSize 100
typedef struct { ElemType data[maxSize]; int front, rear; } SqQueue;

void InitQueue(SqQueue *Q) { Q->front = Q->rear = 0; }
int  QueueEmpty(SqQueue Q) { return Q.front == Q.rear; }
int  QueueFull(SqQueue Q)  { return (Q.rear + 1) % maxSize == Q.front; }
int  QueueLength(SqQueue Q){ return (Q.rear - Q.front + maxSize) % maxSize; }

int EnQueue(SqQueue *Q, ElemType x) {           // 入队 O(1)
    if (QueueFull(*Q)) return 0;
    Q->data[Q->rear] = x; Q->rear = (Q->rear + 1) % maxSize; return 1;
}
int DeQueue(SqQueue *Q, ElemType *x) {          // 出队 O(1)
    if (QueueEmpty(*Q)) return 0;
    *x = Q->data[Q->front]; Q->front = (Q->front + 1) % maxSize; return 1;
}
  • 2. 链式队列基本操作实现
typedef struct node { ElemType data; struct node *next; } LinkNode;
typedef struct { LinkNode *front, *rear; } LinkQueue;   // front 指向头结点

void InitQueue(LinkQueue *Q) {
    Q->front = Q->rear = (LinkNode *)malloc(sizeof(LinkNode));
    Q->front->next = NULL;
}
int EnQueue(LinkQueue *Q, ElemType x) {       // 尾插 O(1)
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    if (!s) return 0;
    s->data = x; s->next = NULL;
    Q->rear->next = s; Q->rear = s; return 1;
}
int DeQueue(LinkQueue *Q, ElemType *x) {      // 删首结点 O(1)
    if (Q->front == Q->rear) return 0;         // 队空
    LinkNode *q = Q->front->next; *x = q->data;
    Q->front->next = q->next;
    if (Q->rear == q) Q->rear = Q->front;      // ★ 出队后变空，恢复 rear
    free(q); return 1;
}

四、进一步讨论：栈与队列（双端队列、双底栈）

（一）识记

术语 含义
双端队列（deque） 两端都允许插入和删除的线性表
输入受限的双端队列 只允许在一端插入，两端都可删除
输出受限的双端队列 两端都可插入，只允许在一端删除
双底栈 两个栈共享同一个数组空间，两栈底固定在数组两端、栈顶相向生长（见前文），提高空间利用率

（二）领会

  • 1. 双端队列的操作机制：设前端 front、后端 rear（用数组循环实现），可执行四类操作：
  • 前端插入 / 前端删除；后端插入 / 后端删除（各自用取模回绕）。
  • 2. 空、满的含义及判定（数组循环实现，牺牲单元法）
  • 初始 front = rear = 0；
  • 空：front == rear；
  • 满：(rear + 1) % maxSize == front（与循环队列同）；
  • 元素个数：(rear − front + maxSize) % maxSize；
  • 双底栈：空为 top1 == −1（栈1空）、top2 == maxSize（栈2空）；满为 top1 + 1 == top2。

（三）简单应用

// 循环双端队列（牺牲一个单元）
int PushFront(SqDeque *D, ElemType x) {
    if (QueueFull(*D)) return 0;                 // 满
    D->front = (D->front - 1 + maxSize) % maxSize;
    D->data[D->front] = x; return 1;
}
int PushRear(SqDeque *D, ElemType x) {
    if (QueueFull(*D)) return 0;
    D->data[D->rear] = x; D->rear = (D->rear + 1) % maxSize; return 1;
}
int PopFront(SqDeque *D, ElemType *x) {
    if (QueueEmpty(*D)) return 0;
    *x = D->data[D->front]; D->front = (D->front + 1) % maxSize; return 1;
}
int PopRear(SqDeque *D, ElemType *x) {
    if (QueueEmpty(*D)) return 0;
    D->rear = (D->rear - 1 + maxSize) % maxSize;
    *x = D->data[D->rear]; return 1;
}

术语 含义

（二）领会：多维数组地址计算（必考）

  • 1. 二维数组（行主序、下标从 0 开始）
    设 A[m][n]，每元素占 L 个字节，首地址 LOC(a₀₀)：

  • LOC(aᵢⱼ) = LOC(a₀₀) + ( i × n + j ) × L

  • 2. 二维数组（列主序、下标从 0 开始）

  • LOC(aᵢⱼ) = LOC(a₀₀) + ( j × m + i ) × L

  • 3. 下标从 1 开始的写法 【注意】（A[1..m][1..n]，首地址 LOC(a₁₁)）
    行主序：LOC(aᵢⱼ) = LOC(a₁₁) + ( (i−1) × n + (j−1) ) × L
    列主序：LOC(aᵢⱼ) = LOC(a₁₁) + ( (j−1) × m + (i−1) ) × L

  • 4. 三维数组（行主序、0 基） A[d₁][d₂][d₃]：

  • LOC(a[i][j][k]) = LOC(a₀₀₀) + ( i×d₂×d₃ + j×d₃ + k ) × L

  • 5. n 维数组（行主序、0 基）

  • LOC = LOC(a₀…₀) + ( i₁×d₂×…×d_n + i₂×d₃×…×d_n + … + i_n ) × L

    记忆：每跨一行（第一维加 1）要跳过"后面所有维度的元素总数"个元素。

  • 6. 计算示例

  • 例 1：A[4][5]，L = 4，LOC(a₀₀) = 2000。
    行主序：LOC(a₂₃) = 2000 + (2×5 + 3)×4 = 2000 + 52 = 2052
    列主序：LOC(a₂₃) = 2000 + (3×4 + 2)×4 = 2000 + 56 = 2056
  • 例 2：A[3][4][5]，L = 2，LOC(a₀₀₀) = 100。
    LOC(a[1][2][3]) = 100 + (1×4×5 + 2×5 + 3)×2 = 100 + 66 = 166

（二·续）特殊矩阵的压缩存储（领会 + 简单应用，必考）

  • 1. 对称矩阵：满足 aᵢⱼ = aⱼᵢ（n×n，关于主对角线对称）。
  • 压缩方法：只存下三角（含对角线） 元素，共 n(n+1)/2 个，按行优先存入一维数组 SA[0..n(n+1)/2−1]（下标从 0 开始）：
  • 当 i ≥ j（下三角）：k = i(i+1)/2 + j

  • 当 i < j（上三角）：利用对称性存 aⱼᵢ → k = j(j+1)/2 + i

    若教材下标从 1 开始：i ≥ j 时 k = i(i−1)/2 + j − 1（0 基）或 k = i(i−1)/2 + j（1 基）【注意】 按教材约定。

  • 2. 三角矩阵

  • 下三角矩阵：上三角（不含对角线）元素全为常数 c → 存下三角 n(n+1)/2 个元素 + 1 个常数 c，共 n(n+1)/2 + 1；
  • 上三角矩阵：下三角（不含对角线）元素全为常数 c → 同理存 n(n+1)/2 + 1。

  • 地址映射与对称矩阵相同，但"访问上三角"时不取对称元素，而是取常数 c。

  • 3. 对角矩阵（带状矩阵）

  • 非零元素集中在主对角线及其上下若干条对角线上；
  • 三对角矩阵（|i − j| ≤ 1，非零元共 3n − 2 个）：按行优先压缩存储，
    0 基：k = 2i + j（|i − j| ≤ 1）；1 基：k = 2i + j − 2

  • 例：三对角矩阵 n = 4 时，非零元个数 = 3×4 − 2 = 10。

  • 4. 稀疏矩阵

  • 定义：非零元素个数远小于矩阵元素总数（一般非零元占比 < 5%）的矩阵；
  • 三元组表（顺序存储）：用一维数组存 (行, 列, 值)，并按行序（行优先） 排列；优点=省空间；缺点=不能随机存取、矩阵运算（转置/加法）效率低；
  • （链式存储，扩展）：十字链表 / 行链表（大纲未要求，了解即可）。

（三）简单应用

  • 1. 构造地址映射函数：由题意写出"下标 → 一维存储下标（或地址）"的公式（注意：行主序/列主序、下标起点、每元素字节数）。

  • 2. 访问压缩存储的数组元素

  • 由 (i, j) 求 k：直接代入公式（如对称矩阵 i ≥ j 时 k = i(i+1)/2 + j）；
  • 由 k 反求 (i, j)（对称矩阵下三角）：
    先求满足 i(i+1)/2 ≤ k 的最大 i，则 j = k − i(i+1)/2；

  • 三对角矩阵由 k 反求：i = (k+1)/3 附近取整后代入 j = k − 2i 【注意】（按教材约定与下标起点）。

  • 3. 计算示例：n = 4 的对称矩阵，元素 a₃₁（i=3, j=1，0 基）→ k = 3×4/2 + 1 = 7（存放在 SA[7]）；元素 a₁₃ → 存 a₃₁ → k = 7。

（一）识记

术语 含义
串（字符串） 由零个或多个字符组成的有限序列；元素是字符，通常整体处理
空串 长度为 0 的串，记作 ""（注意：空格串 " " 长度为 1，二者不同）

模式匹配（串匹配） 在主串 S 中查找模式串 T，找到则返回其首次出现的位置

串与线性表的区别：串的元素必须是字符，且通常以整体（子串）为单位进行操作（连接、取子串、比较、定位、替换）。

（二）领会

  • 1. 比较次数：模式匹配过程中字符比较的总次数，是衡量匹配算法效率的指标。
  • BF 算法：最好 m（首字符即匹配成功，m 为模式长度）；最坏 (n − m + 1) × m（每趟都比较到最后一位才发现不等）；

  • KMP 算法：O(n + m)。

  • 2. 串模式匹配的含义：在主串中寻找与模式串相同的子串，返回其起始位置；找不到称匹配失败（返回 0/ −1 【注意】）。

  • 3. 特征向量（next 数组 / 失效函数）
    KMP 的核心：利用模式串自身的结构信息，当某位失配时，主串指针不回退，只把模式串向右"滑动"，滑动的位数由特征向量决定。

  • 定义（0 基常见约定）：next[j] = 模式串前 j 个字符 P[0..j−1] 中最长相等前后缀（真前缀与真后缀）的长度；next[0] = 0（或 −1，视教材 【注意】）。

    直观理解：失配时，模式串前面已经匹配好的部分中，"前缀 = 后缀"的那一截可以直接复用，于是模式串只需滑到 next[j] 的位置继续比较。

（三）简单应用（必考：BF、特征向量、KMP）

  • 1. 串的基本操作：赋值 StrAssign、求长 StrLength、连接 StrConcat、求子串 SubString、比较 StrCompare、定位 StrIndex、插入、删除、替换。

  • 2. BF 算法（朴素/暴力匹配）
    思路：从主串的每个位置 i（0 ≤ i ≤ n−m）开始，逐字符与模式串比较；一旦失配，主串指针回到 i+1，模式串指针回到 0 重新比较。

int BF(char S[], char T[], int n, int m) {
    int i = 0, j = 0;
    while (i < n && j < m) {
        if (S[i] == T[j]) { i++; j++; }
        else { i = i - j + 1; j = 0; }      // 主串回退到本趟起点的下一位
    }
    return (j >= m) ? i - m : -1;            // 返回起始位置或失败
}

  • 复杂度：最好 O(m)，最坏 O((n−m+1)×m) ≈ O(n×m)。

  • 3. 特征向量（next 数组）计算（0 基约定）

void GetNext(char P[], int m, int next[]) {
    next[0] = 0;
    int j = 0;                     // j：当前最长相等前后缀长度
    for (int i = 1; i < m; i++) {
        while (j > 0 && P[i] != P[j]) j = next[j - 1];   // 回退
        if (P[i] == P[j]) j++;
        next[i] = j;
    }
}

  • 手工计算示例：模式串 T = a b a a b c a c（下标 0..7）

  • T[j]：0：a；1：b；2：a；3：a；4：b；5：c；6：a；7：c

  • 前 j+1 个字符：0：a；1：ab；2：aba；3：abaa；4：abaab；5：abaabc；6：abaabca；7：abaabcac
  • next[j]（0 基，最长相等前后缀长度）：0：0；1：0；2：1；3：1；4：2；5：0；6：1；7：0

【注意】 若教材采用"从 1 开始、next[1] = 0"的经典约定（严蔚敏式），上例对应 next = 0, 1, 1, 2, 2, 3, 1, 2（即 0 基的 next[j−1] + 1）。答题必须按教材约定，并声明起点。

  • 4. KMP 算法（利用特征向量加速匹配）
int KMP(char S[], char T[], int n, int m, int next[]) {
    GetNext(T, m, next);
    int i = 0, j = 0;
    while (i < n && j < m) {
        if (S[i] == T[j]) { i++; j++; }            // 继续比较下一字符
        else if (j == 0) i++;                      // 模式首字符失配：主串后移
        else j = next[j - 1];                      // 主串不回退，模式串滑动
    }
    return (j >= m) ? i - m : -1;
}
  • 要点：主串指针 i 永不回退，只让模式串指针 j 按 next 回退；时间 O(n + m)，空间 O(m)（存 next）。
  • 示例：主串 ababcabcacbab（n=13），模式 abcac（m=5） → BF 需约 3 趟 13 次比较，KMP 只需 1 趟不回退。

另可提及 KMP 改进（nextval）：当 P[j] == P[next[j]] 时令 nextval[j] = nextval[next[j]]，避免无效比较（大纲未要求，了解即可）。

（二）领会

  • 1. 层次结构的含义：树是一种一对多（1:n） 的层次结构——每个结点（除根）有唯一前驱（父结点），但可以有多个后继（子结点）；与线性结构的"1:1"不同，树适合表示分类、目录、组织结构、家族关系。

  • 2. 层次结构中的前驱和后继：根结点无前驱；叶结点无后继；其他结点有且仅有一个前驱，可有0 个或多个后继。

  • 3. 树的递归定义：树是 n（n ≥ 0）个结点的有限集合；n = 0 时为空树；n > 0 时有唯一的根，其余结点分成若干互不相交的子集，每个子集本身又是一棵树（子树）。

  • 4. 树的表示形式（4 种，简单应用）
    ① 树形（图形）表示法：用连线直观表示父子关系；
    ② 括号表示法：如 A(B(D,E), C(F))；
    ③ 嵌套集合（文氏图）表示法：用包含关系表示；
    ④ 凹入（缩进）表示法：用缩进层次表示。

  • 5. 树中结点个数与边数的关系（必考）

  • 树中 边数 = 结点数 − 1（即 n 个结点的树有 n − 1 条边）；
  • 所有结点的度之和 = 边数 = n − 1；

  • 森林若有 m 棵树、n 个结点，则边数 = n − m。

  • 6. 计算示例（度与叶子数）
    一棵树中度为 1、2、3、4 的结点数分别是 4、2、1、1，求叶结点数。

  • 边数 = Σ(i·nᵢ) = 1×4 + 2×2 + 3×1 + 4×1 = 15
  • 结点总数 n = 15 + 1 = 16 → n₀ = 16 − (4+2+1+1) = 8（叶结点 8 个）

    通用公式：n₀ = 1 + Σ_{i≥2}(i − 1)·nᵢ

三、二叉树

（一）识记

  • 1. 二叉树：n（n ≥ 0）个结点的有限集合，或为空，或由一个根结点及两棵互不相交的、分别称为左子树和右子树的二叉树组成；左右子树有次序，不能互换。
术语 含义
左子树 / 右子树 根结点的左、右两棵子树
左子结点 / 右子结点 根的左、右孩子
左指针 / 右指针 二叉链表中指向左孩子 / 右孩子的指针域
满二叉树 每一层都达到最大结点数的二叉树（深度 k 时有 2ᵏ − 1 个结点）
完全二叉树 结点按层序编号与满二叉树一一对应（只有最下面两层结点的度可小于 2，且最下层结点集中在左侧）
二叉链表 结点 = data + lchild + rchild（两个指针域）
二叉树的遍历 按某条搜索路线访问每个结点且每个结点只访问一次的线性序列过程

二叉树 vs 树：① 二叉树可为空（树一般不为空）；② 二叉树每个结点度 ≤ 2 且左右有序；③ 度为 2 的有序树 ≠ 二叉树（如只有一条单支的"度为 2 的有序树"与二叉树的某一形态不同）。

（二）领会

  • 1. 二叉树的递归定义：见上（空 / 根 + 左子树 + 右子树），这决定了几乎所有二叉树算法都可以用递归实现。

  • 2. 二叉树的性质及证明（必考）

  • 性质 1：性质：第 i 层上至多 2^(i−1) 个结点（i ≥ 1）；说明/证明要点：每一层最多是上一层两倍

  • 性质 2：性质：深度为 k 的二叉树至多 2ᵏ − 1 个结点（k ≥ 1）；说明/证明要点：1+2+…+2^(k−1)
  • 性质 3：性质：叶结点数 n₀ = n₂ + 1（n₂ 为度为 2 的结点数）；说明/证明要点：n = n₀+n₁+n₂；边数 = n−1 = n₁+2n₂ → 得证
  • 性质 4：性质：n 个结点的完全二叉树深度 k = ⌊log₂n⌋ + 1；说明/证明要点：2^(k−1) ≤ n < 2ᵏ
  • 性质 5：性质：完全二叉树按层序编号（1 基）：i>1 时父结点为 ⌊i/2⌋；左孩子 2i、右孩子 2i+1（存在时）；i > ⌊n/2⌋ 时 i 为叶结点；说明/证明要点：顺序存储下标关系

  • 推论：性质：n 个结点的二叉链表有 n + 1 个空指针域；说明/证明要点：2n 个指针域中 n−1 个用于指孩子

  • 3. 二叉树的顺序存储方式与下标位置

  • 用一维数组按层序存放结点；空结点留空位；
  • 1 基：根存于 A[1]；结点 i 的父为 ⌊i/2⌋，左孩子 2i，右孩子 2i+1；
  • 0 基：根存于 A[0]；结点 i 的父为 ⌊(i−1)/2⌋，左孩子 2i+1，右孩子 2i+2；最后一个非叶结点下标 = ⌊n/2⌋ − 1；

  • 适合完全二叉树（空间 O(n)）；对一般二叉树（尤其单支树）浪费严重（最坏需 2ᵏ − 1 个单元）。

  • 4. 二叉树的链式存储方式

  • 二叉链表：typedef struct BTNode { ElemType data; struct BTNode *lchild, *rchild; } BTNode, *BTree;
  • 三叉链表：再加 parent 指针，便于向上查找；

  • 二叉链表找父结点不方便，但结构简单、应用最广。

  • 5. 二叉树的遍历过程与使用的辅助数据结构

  • 先序（前序）：顺序：根 → 左 → 右；递归：先访问根再递归左右；非递归辅助结构：栈

  • 中序：顺序：左 → 根 → 右；递归：先递归左再访问根；非递归辅助结构：栈
  • 后序：顺序：左 → 右 → 根；递归：先递归左右再访问根；非递归辅助结构：栈（常用双栈/标记法）

  • 层次：顺序：按层从左到右；递归：无递归；非递归辅助结构：队列

  • 6. 表达式树与表达式的关系

  • 以叶结点存操作数、分支结点存运算符的二叉树；
  • 中序遍历 → 中缀表达式（需按优先级加括号）；
  • 先序遍历 → 前缀表达式（波兰式）；
  • 后序遍历 → 后缀表达式（逆波兰式）。

    例：表达式 (a+b)*c − d/e 对应表达式树的后序遍历即其后缀式。

（三）简单应用

  • 1. 二叉树基本操作的实现（二叉链表，递归为主）
// 先序遍历（递归）
void PreOrder(BTree T) {
    if (T) { visit(T->data); PreOrder(T->lchild); PreOrder(T->rchild); }
}
// 中序、后序只需调换 visit 位置
// 求结点个数
int Count(BTree T) { return T ? Count(T->lchild) + Count(T->rchild) + 1 : 0; }
// 求叶子个数
int LeafCount(BTree T) {
    if (!T) return 0;
    if (!T->lchild && !T->rchild) return 1;
    return LeafCount(T->lchild) + LeafCount(T->rchild);
}
// 求深度
int Depth(BTree T) {
    if (!T) return 0;
    int l = Depth(T->lchild), r = Depth(T->rchild);
    return (l > r ? l : r) + 1;
}
  • 2. 遍历的非递归实现（用栈）与层次遍历（用队列）
// 先序非递归
void PreOrderNR(BTree T) {
    BTree st[100]; int top = -1;
    if (T) st[++top] = T;
    while (top >= 0) {
        BTree p = st[top--]; visit(p->data);
        if (p->rchild) st[++top] = p->rchild;   // 先压右孩子
        if (p->lchild) st[++top] = p->lchild;   // 后压左孩子（先出）
    }
}
// 中序非递归：一路向左入栈，弹栈访问后转向右子树
void InOrderNR(BTree T) {
    BTree st[100]; int top = -1; BTree p = T;
    while (p || top >= 0) {
        while (p) { st[++top] = p; p = p->lchild; }   // 一路向左
        p = st[top--]; visit(p->data);                // 弹栈访问
        p = p->rchild;                                // 转右
    }
}
// 层次遍历（队列）
void LevelOrder(BTree T) {
    BTree q[100]; int front = 0, rear = 0;
    if (T) q[rear++] = T;
    while (front < rear) {
        BTree p = q[front++]; visit(p->data);
        if (p->lchild) q[rear++] = p->lchild;
        if (p->rchild) q[rear++] = p->rchild;
    }
}
  • 3. 根据遍历序列还原二叉树（必考）
  • 先序 + 中序 → 可唯一确定；后序 + 中序 → 可唯一确定；层次 + 中序 → 可唯一确定；
  • 先序 + 后序 → 不能唯一确定（无法区分左右单支）；

  • 方法：先序的第一个（或后序的最后一个）是根；在中序中找到该根，左边是左子树、右边是右子树的元素集合；据此递归划分。

  • 例：已知先序 ABDECF、中序 DBEACF，求后序与树形。

  • 先序首元 A 为根；中序中 A 左边 {D,B,E}、右边 {C,F}；
  • 左子树的先序 {B,D,E}，其根 B，中序 {D,B,E} → D 在左、E 在右；
  • 右子树的先序 {C,F}，其根 C，中序 {C,F} → C 无左孩子、F 为右孩子；

  • 树形：A( B(D, E), C(∅, F) )；后序 = D E B F C A。

  • 4. 表达式树：由中缀/后缀表达式构造表达式树；中序、先序、后序分别得到中缀、前缀、后缀表达式。

（四）综合应用（常考算法）

  • 求结点数 / 叶子数 / 度为 1、2 的结点数；
  • 求深度（高度）、某层结点数、最大宽度；
  • 判断两棵二叉树是否相同/相似；
  • 交换所有结点的左右子树（镜像）；
  • 复制二叉树、销毁二叉树；
  • 查找值为 x 的结点、求结点所在层次、求某结点的所有祖先；
  • 由遍历序列建立二叉链表（还原二叉树）；
  • 判断是否为完全二叉树（层次遍历，遇到空结点后不能再有非空结点）；
  • 求两个结点的最近公共祖先；
  • 先序/中序/后序的非递归实现（用栈）；
  • 用遍历思想求路径、求第 k 个结点、输出所有叶子到根的路径。

四、堆及优先队列

（一）识记

术语 含义
堆 满足"任一分支结点的值都不大于（不小于）其左右孩子"的完全二叉树
最大堆（大顶堆） 任一结点的值 ≥ 其孩子的值 → 堆顶是最大值
最小堆（小顶堆） 任一结点的值 ≤ 其孩子的值 → 堆顶是最小值
堆顶 堆的根结点（最大堆为最大元素 / 最小堆为最小元素）
子堆 以某结点的孩子为根的子树本身也是一个堆
优先队列 出队顺序由优先级决定的队列（每次取出优先级最高/最低者），通常用堆实现

（二）领会

  • 1. 堆的存储方式：堆是完全二叉树，因此可直接用一维数组顺序存储（不需指针）：
  • 0 基：结点 i 的左孩子 2i+1、右孩子 2i+2、父结点 ⌊(i−1)/2⌋；最后一个非叶结点下标 = ⌊n/2⌋ − 1；

  • 1 基：左 2i、右 2i+1、父 ⌊i/2⌋。

  • 2. 堆与完全二叉树的关系：堆一定是一棵完全二叉树（保证数组存储无空洞）；完全二叉树不一定是堆（还要满足有序性）。

  • 3. 堆的有序性（重要）

  • 只保证父结点与孩子之间的大小关系，兄弟结点之间、左右子树之间没有大小要求；

  • 因此堆顶一定是极值，但堆并不是有序的，不能像二叉查找树那样查找任意元素（查找任意元素需 O(n)）。

  • 4. 堆的建立过程：从最后一个非叶结点开始，自底向上、逐个"筛选（下沉）"，直至根；时间 O(n)（不是 O(n log n)）。

（三）简单应用（建堆、插入、删堆顶、调整）

  • 1. 建堆（自底向上筛选）
for (i = ⌊n/2⌋ - 1; i >= 0; i--)   SiftDown(i);
  • 2. 堆的插入（上浮）：把新元素放到数组末尾，然后与父结点比较并向上交换，直到满足堆序；O(log n)。
  • 3. 删除堆顶（下沉）：把最后一个元素移到堆顶、堆长度减 1，然后从根向下筛选；O(log n)。
  • 4. 堆的整理（SiftDown / SiftUp）：下沉=与较大（较小）的孩子交换；上浮=与父结点交换。
void SiftDown(int a[], int n, int i) {        // 最小堆下沉
    int x = a[i];
    for (int c = 2*i + 1; c < n; c = 2*i + 1) {
        if (c + 1 < n && a[c+1] < a[c]) c++;   // 取较小的孩子
        if (a[c] >= x) break;
        a[i] = a[c]; i = c;
    }
    a[i] = x;
}
void SiftUp(int a[], int i) {                  // 最小堆上浮
    int x = a[i];
    while (i > 0 && a[(i-1)/2] > x) { a[i] = a[(i-1)/2]; i = (i-1)/2; }
    a[i] = x;
}
  • 5. 计算示例：数组 [5, 8, 3, 9, 1] 建最小堆
  • 最后一个非叶结点下标 = ⌊5/2⌋ − 1 = 1；
  • 处理下标 1（值 8）：孩子 9、1 → 较小者 1，8 > 1 → 交换 → [5, 1, 3, 9, 8]
  • 处理下标 0（值 5）：孩子 1、3 → 较小者 1，5 > 1 → 交换 → [1, 5, 3, 9, 8]；继续下沉：下标 1 的孩子 9、8 → 较小者 8，5 < 8 → 停止；
  • 结果 最小堆 = [1, 5, 3, 9, 8]。
  • 插入 0：放末尾 → [1,5,3,9,8,0]；与父 3 交换 → [1,5,0,9,8,3]；再与父 1 交换 → [0,5,1,9,8,3]。
  • 删除堆顶：用末尾元素 3 顶替 → [3,5,1,9,8] → 下沉（与较小孩子 1 交换）→ [1,5,3,9,8]。

（四）综合应用

① 优先队列（任务调度、事件驱动模拟、Dijkstra/Prim 的顶点选择）；② 堆排序（建大顶堆 → 反复交换堆顶与末尾并调整，O(n log n)，见第七章）；③ 求 Top-K 大/小元素；④ 求中位数（双堆）；⑤ 多路归并。

五、树和森林

（一）识记

术语 含义
父结点表示法（双亲表示法） 用数组存 {data, parent}，parent 为父结点下标；找父容易、找孩子难
孩子结点表示法（多重链表） 每个结点带一个孩子链表（把所有孩子串起来）；找孩子容易、找父难
父结点-孩子结点表示法 上述两者结合：数组存 {data, parent, 孩子链}，双向都方便
孩子-兄弟表示法 结点含 firstchild（第一个孩子）与 nextsibling（下一个兄弟）两个指针 → 把树表示成二叉树
森林 m（m ≥ 0）棵互不相交的树的集合
树、森林的遍历 树的先根遍历（根→各子树）、后根遍历（各子树→根）；森林的先序遍历、中序（后根）遍历

（二）领会

  • 1. 树、森林之间的关系：树去掉根结点即得森林；森林加上一个根结点（各树根作为其孩子）即得树；森林是"树的集合"，m = 1 时退化为树。

  • 2. 树、森林与二叉树之间的相互转换（难点，必考）
    统一采用孩子-兄弟表示法：

  • 左指针（lchild）指向第一个孩子，右指针（rchild）指向下一个兄弟；
  • 树的转换：每个结点左指针连第一个孩子、右指针连下一个兄弟 → 得到一棵二叉树；
  • 森林的转换：先各自转换为二叉树，再把各棵树根用右链连成一串（视为兄弟）；森林中第一棵树的根就是所得二叉树的根；

  • 逆转换：二叉树中"沿左走是孩子、沿右走是兄弟"→ 还原为树/森林。

  • 3. 树、森林的遍历与二叉树遍历的关系（必背对应表）

树 / 森林的遍历 对应二叉树的遍历
树的先根遍历 先序遍历
树的后根遍历 中序遍历
森林的先序遍历 先序遍历
森林的中序（后根）遍历 中序遍历

结论：树的先根 = 二叉树的先序；树的后根 = 二叉树的中序；因此树/森林的遍历可直接借用二叉树的遍历算法。

（三）简单应用

① 实现树/森林的遍历（先根、后根、层次）；② 求树的深度、结点数、叶子数；③ 求树中某结点的层次/路径；④ 由孩子-兄弟表示法实现"找第 i 个孩子、找兄弟、求度数"等操作；⑤ 统计森林中树的棵数（沿右链计数）。

（四）综合应用

森林的层次遍历、树的括号表示法与树形表示法的相互转换、由广义表建立树/森林（与前章广义表衔接）、统计树叶/度为 k 的结点数等。

六、哈夫曼树及哈夫曼编码

（一）识记

术语 含义
定长编码 每个字符用相同长度的编码（需 ⌈log₂n⌉ 位），简单但总码长长
变长编码 不同字符用不同长度编码，让高频字符用短码，节省空间
编码长度 某个字符编码的位数
前缀特性（前缀码） 任一编码都不是另一个编码的前缀 → 译码唯一、无需分隔符
编码 / 译码 字符 → 编码串 / 编码串 → 字符
字符的权 字符出现的次数或频率（体现重要性）
编码树 叶结点为字符、左/右分支分别标 0/1 的二叉树
哈夫曼树（最优二叉树） WPL 最小的二叉树
哈夫曼编码 由哈夫曼树得到的变长前缀编码（最优前缀码）
叶结点的带权路径长度 该叶的权 × 从根到该叶的路径长度（边数）
WPL（树的带权路径长度） 所有叶结点带权路径长度之和：WPL = Σ wᵢ·lᵢ
带权平均码长 WPL / Σwᵢ（当权为频率/次数时即平均码长）

（二）领会

  • 1. 具有前缀特性的编码方案
  • 若把所有编码都放在一棵二叉树的叶结点上（约定"左 0 右 1"），则该方案天然具有前缀特性（因为一个叶不可能是另一个叶的祖先）；

  • 反之，若某个编码是另一个的前缀，则必然有一个编码落在非叶结点上，译码产生二义性。

  • 2. 哈夫曼树与哈夫曼编码的不唯一性

  • 左右子树可以交换（0/1 互换）→ 编码不同但码长不变；
  • 权值相同的结点合并顺序可以不同 → 树形可能不同；
  • 但所有哈夫曼树的 WPL 相同（都是最小），且每个字符的码长不变（只是 0/1 串不同）。

（三）简单应用（必考）

  • 1. 哈夫曼树的构造（贪心算法，n 个叶结点需 n−1 次合并）
    ① 把 n 个权值看作 n 棵只有一个根的二叉树，构成集合 F；
    ② 从 F 中选取两棵根权最小的树，合并成一棵新树（新根权 = 两权之和）；
    ③ 从 F 中删除这两棵树，把新树加入 F；
    ④ 重复 ②③ 直到 F 中只剩一棵树，即哈夫曼树。

    特性：哈夫曼树中没有度为 1 的结点，共 2n − 1 个结点（n 个叶 + n−1 个分支）。

  • 2. 构造示例（经典题）
    字符权值：a=5, b=29, c=7, d=8, e=14, f=23, g=3, h=11（Σw = 100）

合并过程（每次取最小的两个根权）：

步骤 合并 新权
1 g(3) + a(5) 8
2 c(7) + 8 15
3 d(8) + h(11) 19
4 e(14) + 15 29
5 19 + f(23) 42
6 29 + b(29) 58
7 42 + 58 100（根）

  • WPL = 8+15+19+29+42+58+100 = 271
    （也可按码长验证：d=3, h=3, f=2, e=3, c=4, g=5, a=5, b=2 → WPL = 8×3+11×3+23×2+14×3+7×4+3×5+5×5+29×2 = 271 ✓）

  • 一串可能编码（左 0 右 1，不唯一）：d=000, h=001, f=01, e=100, c=1010, g=10110, a=10111, b=11

  • 带权平均码长 = WPL / Σw = 271 / 100 = 2.71 位/字符（定长编码需 ⌈log₂8⌉ = 3 位 → 哈夫曼更优）

  • 3. 哈夫曼编码的生成：从根到每个叶结点的路径上，左分支记 0、右分支记 1，路径上的 0/1 串即该字符的编码。

  • 4. 译码：从根出发，按编码串的每一位走（0 走左、1 走右），走到叶结点就输出该字符并回到根，继续读下一位；若中途走到空则编码非法。

  • 5. 验证前缀特性：检查任一编码是否都不是其他编码的前缀（或等价地：所有字符都在叶结点上）。

  • 6. WPL 的计算：WPL = Σ(叶权 × 叶的路径长度)；也可用"所有合并过程产生的权值之和"快速计算（上例 = 8+15+19+29+42+58+100 = 271）。

（四）综合应用

① 设计文件压缩/传输的最优编码；② 给定字符频率求平均码长最短的编码；③ 判断题给编码是否满足前缀特性、是否最优；④ 由编码串译码或由字符集求编码；⑤ 与堆结合实现"每次取最小的两个"（用最小堆 O(n log n)）。

二、图的基本概念与基本操作

（一）识记（术语）

术语 含义
图 G = (V, E) 顶点集 V + 边集 E；
子图 顶点集、边集分别是原图的子集（E' ⊆ E 且边的端点都在 V' 中）
无向边 (v, w) 无方向的边；有向边/弧 ：v 为弧尾（始点），w 为弧头（终点）
无向图 / 有向图 边无方向 / 边有方向
带权图（网） 每条边（弧）附带权值（表示距离、代价、时间等）
邻接点 无向图：(v,w) 存在则 v、w 互为邻接点；有向图： 存在则 v 邻接到 w
关联 边与其两端顶点相关联（一条边关联两个顶点）
顶点的度 TD(v) 无向图：与该顶点关联的边数；有向图：入度 ID(v) + 出度 OD(v)
入度 / 出度 以该顶点为弧头的弧数 / 以该顶点为弧尾的弧数
稀疏图 / 密集图 e 远小于 n²（一般 e < n·log n）/ e 接近 n²
完全图 无向完全图：n(n−1)/2 条边；有向完全图：n(n−1) 条弧
路径 / 有向路径 顶点序列 v₀v₁…vₖ（相邻顶点间有边）/ 沿弧方向的路径
简单路径 / 简单回路 顶点不重复出现 / 除首尾外顶点不重复的回路
回路（环） 首尾顶点相同的路径
路径长度 路径上的边数；带权图中为各边权之和
连通图 无向图中任意两顶点间都有路径
连通分量 无向图中的极大连通子图
强连通图 / 强连通分量 有向图中任意两顶点互相可达 / 极大强连通子图
弱连通图 有向图忽略方向后连通
有向无环图（DAG） 不含回路的有向图

（二）领会

  • 1. 顶点与边的关联性：每条边关联两个顶点（无向边）或一个弧尾、一个弧头（有向边）；顶点的度正是由"关联的边数"定义的。

  • 2. 邻接的含义：邻接描述顶点与顶点之间的关系（有边相连）；关联描述顶点与边之间的关系——两者不是一回事。

  • 3. 边与顶点的度的关系（必考）

  • 无向图：ΣTD(v) = 2e（每条边给两端各贡献 1 度）；

  • 有向图：ΣID(v) = ΣOD(v) = e；ΣTD(v) = 2e。

  • 4. 有向路径：必须沿着弧的方向前进；有向图中"(v,w) 有路径"与"(w,v) 有路径"是两回事（这正是强连通与弱连通的区别）。

（三）简单应用（特性小计算）

  • n 个顶点的无向完全图边数 = n(n−1)/2（n=5 → 10）；有向完全图弧数 = n(n−1)（n=5 → 20）；
  • 由度求边数：e = ΣTD / 2；
  • 例：无向图中有 3 个度为 4 的顶点、4 个度为 3 的顶点，其余顶点度均小于 3，求顶点数最少是多少？
    已知度和 = 3×4 + 4×3 = 24 → 2e ≥ 24 需为偶数（成立）；余下度和 = 2e − 24，且每个小于 3 的顶点度 ≤ 2 → 余下顶点数 ≥ (2e−24)/2；取 e = 12（度和 24）时余下度为 0，最少顶点 = 3+4 = 7；
  • 判断图是否连通、是否为完全图、是否含环、某序列是否为路径等。

三、图的存储结构及基本操作的实现

（一）识记

存储结构 结构描述
邻接矩阵 一维数组 vexs[n] 存顶点 + 二维数组 arcs[n][n] 存边（0/1 或权值；无边用 0 或 ∞ 【注意】）
邻接表 顶点表（表头结点） 数组：data + firstarc；每个顶点挂一条边表，表结点为 adjvex（邻接点在顶点表中的下标）+ nextarc（+ info 权值）
逆邻接表 与邻接表结构相同，但边表中存放的是指向该顶点的弧（入边），便于求入度
表结点 邻接表中表示一条边的结点（adjvex + nextarc）
（扩展）十字链表 / 邻接多重表 便于同时求有向图出入度 / 处理无向图每条边存储两次的问题

（二）领会：三种结构与图的对应关系

  • 空间：邻接矩阵：O(n²)（与边数无关）；邻接表：O(n + e)；逆邻接表：O(n + e)
  • 适合：邻接矩阵：密集图；邻接表：稀疏图；逆邻接表：稀疏图（侧重入度）
  • 判断 (i,j) 是否相邻：邻接矩阵：O(1)；邻接表：O(度)；逆邻接表：O(度)
  • 求某顶点的所有邻接点：邻接矩阵：O(n)；邻接表：O(度)；逆邻接表：O(入度)
  • 无向图：邻接矩阵：矩阵对称；第 i 行（列）非零个数 = 顶点 i 的度；邻接表：边表结点总数 = 2e；逆邻接表：同邻接表
  • 有向图：邻接矩阵：第 i 行非零个数 = 出度；第 i 列非零个数 = 入度；邻接表：边表结点总数 = e，求出度易、求入度难；逆邻接表：便于求入度，求出度难

（三）简单应用（实现与信息获取）

typedef struct { ElemType vexs[MAXV]; int arcs[MAXV][MAXV]; int n, e; } MGraph;

} VNode, AdjList[MAXV];

  • 邻接矩阵：求顶点度（数行/列非零个数）、判断两点是否相邻、求所有邻接点；
  • 邻接表：遍历某顶点的边表可得其所有邻接点与出度；统计全表可得入度（或改用逆邻接表直接求入度）；
  • 无向图邻接表的边表结点数 = 2e；有向图 = e（由此可校验建表是否正确）。

四、图的搜索

（一）识记

术语 含义
图的搜索（遍历） 从某顶点出发，沿边访问图中所有顶点且每个顶点仅访问一次的过程
深度优先搜索（DFS） 类似树的先序遍历：访问顶点 → 递归访问其未访问的邻接点 → 回溯
广度优先搜索（BFS） 类似树的层次遍历：访问顶点 → 依次访问其所有未访问邻接点 → 再按访问顺序处理下一层

（二）领会

  • 1. 图搜索的特性：图可能有回路且可能不连通，因此必须设 visited[] 访问标志数组防止重复访问；对非连通图需对每个未访问顶点重新发起一次搜索（每次得到一个连通分量）。

  • 2. 图的搜索序列：与起始顶点和邻接点的访问次序（存储结构中的顺序） 有关——同一图不同起点或不同存储顺序，搜索序列不同。

  • 3. 图搜索时使用的辅助数据结构

  • DFS：栈（递归时用系统栈；非递归时显式栈）+ visited[]；
  • BFS：队列 + visited[]。
  • 都需要 visited[n]。

（三）简单应用（实现与搜索序列）

int visited[MAXV];
void DFS(ALGraph G, int v) {                 // 邻接表 DFS（递归）
    visit(v); visited[v] = 1;
    for (ArcNode *p = G.vertices[v].firstarc; p; p = p->nextarc)
        if (!visited[p->adjvex]) DFS(G, p->adjvex);
}
void BFS(ALGraph G, int v) {                 // 邻接表 BFS（队列）
    int q[MAXV], front = 0, rear = 0;
    visit(v); visited[v] = 1; q[rear++] = v;
    while (front < rear) {
        int u = q[front++];
        for (ArcNode *p = G.vertices[u].firstarc; p; p = p->nextarc)
            if (!visited[p->adjvex]) { visit(p->adjvex); visited[p->adjvex] = 1; q[rear++] = p->adjvex; }
    }
}
  • 示例：V = {1,2,3,4,5}，边 1-2, 1-3, 2-4, 3-4, 4-5（邻接点按序号升序）
  • DFS 序列：1, 2, 4, 3, 5（1→2→4→3（4 的邻接点按序）→回退→5）

  • BFS 序列：1, 2, 3, 4, 5

  • 复杂度：邻接矩阵 O(n²)；邻接表 O(n + e)（DFS、BFS 相同）。

（四）综合应用（基于搜索思想）

① 求连通分量个数；② 判断两顶点间是否有路径、求一条简单路径；③ 判断图中是否有环（DFS 中出现回边）；④ 判断二分图（BFS/DFS 染色）；⑤ 迷宫求解、连通块统计（岛屿问题）；⑥ 无向图求割点/桥（扩展）；⑦ 拓扑排序的 DFS 实现。

五、图的生成树

（一）识记

术语 含义
生成树 连通图的极小连通子图：含全部 n 个顶点和 n − 1 条边（再加一条边必成环，少一条边必不连通）
深度优先生成树 由 DFS 得到的生成树（非连通图得到生成森林）
广度优先生成树 由 BFS 得到的生成树
最小生成树（MST） 带权连通图中边权之和最小的生成树

（二）领会

  • 1. 生成树的特性：n 个顶点、恰好 n−1 条边、连通且无环；生成树可能不唯一（DFS/BFS 生成树通常不同，最小生成树也可能不唯一——当存在等权边时）。

  • 2. 最小生成树的特性：权值之和最小；包含 n 个顶点、n−1 条边；MST 不唯一但最小代价唯一。

  • 3. 普里姆（Prim）算法的求解策略："加点法"

  • 从任一顶点出发，把顶点逐步加入集合 U（已入选）；
  • 每次在"U 中顶点 ↔ V−U 中顶点"的所有边中选权最小的一条，把对应顶点加入 U；
  • 重复 n−1 次；

  • 适合密集图，时间复杂度 O(n²)（邻接矩阵；用堆可优化到 O(e log n)）。

  • 4. 克鲁斯卡尔（Kruskal）算法的求解策略："加边法"

  • 把所有边按权值从小到大排序；
  • 依次考察每条边，若它的两个端点不在同一连通分量（加入后不形成回路）则选入；
  • 直到选够 n−1 条边；

  • 适合稀疏图，时间复杂度 O(e log e)（排序 + 并查集）。

  • 5. 最小生成树代价的计算：把选中的 n−1 条边权值相加。

（三）简单应用（必考过程题）

  • 示例：顶点 A、B、C、D、E、F，边权 A-B 6、A-C 1、A-D 5、B-C 5、B-E 3、C-D 5、C-E 6、C-F 4、D-F 2、E-F 6

  • 用 Prim 求 MST（从 A 出发）

  • 1：入选顶点集：{A}；可选的最小边：A-C(1)；选入边（权）：A-C (1)

  • 2：入选顶点集：{A,C}；可选的最小边：C-F(4)；选入边（权）：C-F (4)
  • 3：入选顶点集：{A,C,F}；可选的最小边：F-D(2)；选入边（权）：F-D (2)
  • 4：入选顶点集：{A,C,D,F}；可选的最小边：C-B(5)；选入边（权）：C-B (5)

  • 5：入选顶点集：{A,B,C,D,F}；可选的最小边：B-E(3)；选入边（权）：B-E (3)

  • MST 代价 = 1 + 4 + 2 + 5 + 3 = 15

  • 用 Kruskal 求 MST
    边按权排序：AC(1), DF(2), BE(3), CF(4), AD(5), BC(5), CD(5), AB(6), CE(6), EF(6)

  • AC(1) 选入（{A,C}）；DF(2) 选入（{D,F}）；BE(3) 选入（{B,E}）；
  • CF(4)：C∈{A,C}、F∈{D,F} 不同 → 选入（合并为 {A,C,D,F}）；
  • AD(5)：同在 {A,C,D,F} → 舍去（成环）；
  • BC(5)：C∈{A,C,D,F}、B∈{B,E} 不同 → 选入（全图连通）；
  • 已有 5 = n−1 条边 → 结束。
  • MST 代价 = 1 + 2 + 3 + 4 + 5 = 15（与 Prim 结果一致，MST 边集相同）

（四）综合应用

① 网络布线/管道铺设的最小成本设计；② 判断图是否连通（生成树能否覆盖全部顶点）；③ 求"次小生成树"（扩展）；④ 基于 Prim/Kruskal 策略的贪心算法设计。

六、有向无环图及其应用

（一）识记

术语 含义

（二）领会 + （三）简单应用

  • 1. 拓扑排序的过程（必考）
    ① 在 AOV 网中选一个入度为 0 的顶点并输出；
    ② 删除该顶点及其所有出边（相关顶点入度减 1）；
    ③ 重复 ①②，直到全部顶点输出（成功）或找不到入度为 0 的顶点而仍有顶点未输出（说明有环）。
  • 用栈/队列保存入度为 0 的顶点；复杂度 O(n + e)；

  • 拓扑序列可能不唯一；判断有向图是否存在环：拓扑排序能否输出全部顶点。

  • 2. 关键路径的求解过程（必考，AOE 网）
    ① 正向递推求事件最早开始时间：ve(j) = max{ ve(i) + w(<i,j>) }（源点 ve = 0）；
    ② 逆向递推求事件最迟开始时间：从汇点开始 vl(j) = min{ vl(k) − w(<j,k>) }，vl(汇点) = ve(汇点)；
    ③ 求活动的最早开始时间：e(a) = ve(弧尾)；
    ④ 求活动的最迟开始时间：l(a) = vl(弧头) − 活动持续时间；
    ⑤ 时间余量 = l(a) − e(a)；余量为 0 的活动即关键活动；
    ⑥ 关键活动构成的从源点到汇点的路径即关键路径（可能不唯一），其长度即最短工期。

七、最短路径

（一）识记

术语 含义
源点 / 终点 路径的起点 / 终点
带权图中的路径长度 路径上各边权值之和
单源最短路径 从一个源点到其余各顶点的最短路径（Dijkstra 算法）
所有点对间的最短路径 图中每一对顶点之间的最短路径（Floyd 算法）

（二）领会 + （三）简单应用

  • 1. 迪杰斯特拉（Dijkstra）算法的求解过程（单源，贪心）
  • 设集合 S（已确定最短路径的顶点，初始只含源点 v₀），数组 dist[i] 记录 v₀ 到 i 的当前最短距离（初始为直接边的权，无直接边为 ∞）；
  • ① 选：从 V−S 中选 dist 最小的顶点 u 加入 S；
  • ② 更新：对 u 的每个邻接点 w，若 dist[u] + w(u,w) < dist[w] 则更新 dist[w]（并记录前驱 p[w] = u）；
  • ③ 重复 ①② 共 n−1 次，直到所有顶点加入 S；

  • 要求所有边权非负；邻接矩阵实现 O(n²)（堆优化 O(e log n)）；dist 数组给出最短距离，p 数组可还原路径。

  • Dijkstra 计算示例（有向图，源点 1）
    边：1→2 (2)、1→3 (5)、2→3 (1)、2→4 (7)、3→4 (3)

  • 初始：S：{1}；dist[2]：2；dist[3]：5；dist[4]：∞；选入：—

  • ①：S：{1,2}；dist[2]：2；dist[3]：min(5, 2+1)=3；dist[4]：min(∞, 2+7)=9；选入：2
  • ②：S：{1,2,3}；dist[2]：2；dist[3]：3；dist[4]：min(9, 3+3)=6；选入：3

  • ③：S：{1,2,3,4}；dist[2]：2；dist[3]：3；dist[4]：6；选入：4

  • 结果：1→2 = 2；1→2→3 = 3；1→2→3→4 = 6

  • 2. 弗洛伊德（Floyd）算法的求解过程（所有点对，动态规划）

  • 用邻接矩阵 D（D[i][j] 为 i→j 的当前最短距离，无边为 ∞）；
  • 递推公式：D⁽ᵏ⁾[i][j] = min( D⁽ᵏ⁻¹⁾[i][j], D⁽ᵏ⁻¹⁾[i][k] + D⁽ᵏ⁻¹⁾[k][j] )
    即"允许经过顶点 k 中转"时是否更短；k 从 1 到 n 逐轮更新；
  • 时间复杂度 O(n³)；允许负权边（但不能有负权回路）；

  • 可同时用 path[i][j] 记录路径经过的中间顶点。

  • Floyd 计算示例（3 个顶点：1→2 权 4、2→3 权 1、1→3 权 10）

  • D⁽⁰⁾ = [[0,4,10],[∞,0,1],[∞,∞,0]]
  • k=2 时：D[1][3] = min(10, 4+1=5) = 5 → D = [[0,4,5],[∞,0,1],[∞,∞,0]]

  • k=1、k=3 无改进 → 1→3 最短距离 = 5（路径 1→2→3）

  • 3. 三种算法对照

  • Dijkstra：解决的问题：单源最短路径；思想：贪心（逐步扩充 S）；时间复杂度：O(n²) / O(e log n)；权值限制：非负权

  • Floyd：解决的问题：所有点对最短路径；思想：动态规划（逐轮加中转点）；时间复杂度：O(n³)；权值限制：可含负权（无负环）
  • （对比）Prim：解决的问题：最小生成树；思想：贪心加点；时间复杂度：O(n²)；权值限制：无向连通带权图

（四）综合应用

① 交通/网络路由的最短代价路径；② 地图导航、物流配送；③ 城市间最短里程/最少费用/最快时间；④ 结合路径数组输出具体路径；⑤ 判断负权回路（Bellman-Ford，扩展）。

八、本章对比与易混点

易混点 正确理解
邻接 vs 关联 邻接＝顶点与顶点；关联＝顶点与边
无向图度 vs 有向图入/出度 无向：关联边数；有向：入度 + 出度
完全图边数 无向 n(n−1)/2；有向 n(n−1)
连通 vs 强连通 vs 弱连通 无向图连通 / 有向图互相可达 / 有向图忽略方向后连通
连通分量 vs 强连通分量 无向图的极大连通子图 / 有向图的极大强连通子图
邻接矩阵 vs 邻接表 矩阵 O(n²) 适合密集图、判断相邻 O(1)；邻接表 O(n+e) 适合稀疏图、求邻接点快

无向图邻接表边结点数 2e（每条边存两次）；有向图为 e

生成树 vs 最小生成树 生成树只要极小连通（n−1 条边）；MST 要求权和最小

拓扑排序 vs DFS 拓扑排序用"入度为 0"逐步删除；也可用 DFS 按完成时间逆序
ve / vl 方向 ve 正向递推取 max；vl 逆向递推取 min
关键活动判据 时间余量 l(a) − e(a) = 0
Dijkstra vs Prim 都是"选最小、更新"，但 Dijkstra 更新的是到源点的距离和（dist[u]+w），Prim 更新的是到树的距离（只看 w）
Dijkstra vs Floyd 单源 O(n²)（非负权）vs 全点对 O(n³)（可负权、无负环）
最短路径 vs 最小生成树 前者是两点间路径和最小；后者是整棵树边权和最小
  • 复杂度速查：DFS/BFS 矩阵 O(n²)、邻接表 O(n+e)；Prim O(n²)；Kruskal O(e log e)；拓扑排序 O(n+e)；关键路径 O(n+e)；Dijkstra O(n²)；Floyd O(n³)

二、排序的基本概念

（一）识记

术语 含义
排序 把一组（无序）记录按关键字递增（升序）或递减（降序）排列成有序序列的过程
关键字 记录中用于比较、排序的数据项
主关键字 能唯一标识一个记录的关键字（排序结果唯一）
次关键字 不能唯一标识记录的关键字（可能重复）
升序 / 降序 由小到大 / 由大到小
逆序对（反序） 满足 i < j 但 kᵢ > kⱼ 的数据对；逆序对越多，序列越无序
内部排序 待排记录全部存放在内存中进行的排序
外排序 记录太多、内存装不下，排序过程需在内存与外存之间多次交换
稳定排序 关键字相等的记录，排序前后相对次序不变
比较次数 / 交换（移动）次数 排序过程中关键字比较的次数 / 记录移动或交换的次数（衡量代价）

（二）领会

  • 1. 稳定的含义：对任意两个关键字相等的记录 Rᵢ、Rⱼ（排序前 Rᵢ 在 Rⱼ 之前），排序后 Rᵢ 仍应在 Rⱼ 之前。稳定的算法：直接插入、起泡、归并、基数（＋箱子）；不稳定的算法：希尔、快速、直接选择、堆排序。

    口诀："快（快速）些（希尔）选（选择）堆（堆排序）不稳定"。

  • 2. 评价排序算法的标准
    ① 时间复杂度（比较次数 + 移动次数，关注最好/平均/最坏）；
    ② 空间复杂度（辅助空间，是否"就地"）；
    ③ 稳定性；
    ④ 算法的复杂性与可实现性（代码是否简单）；
    ⑤ 对数据规模与初始排列的适应性；
    ⑥ 是否基于比较（比较类排序下界为 O(n log n)）。

  • 3. 数据的初始排列（对性能影响很大）

  • 正序（基本有序）：直接插入：O(n) 最好；起泡：O(n) 最好；快速（取首元素为枢轴）：O(n²) 最坏；归并/堆/选择：不受影响

  • 逆序：直接插入：O(n²) 最坏；起泡：O(n²) 最坏；快速（取首元素为枢轴）：O(n²) 最坏；归并/堆/选择：不受影响

  • 随机：直接插入：O(n²)；起泡：O(n²)；快速（取首元素为枢轴）：O(n log n) 平均；归并/堆/选择：O(n log n)

  • 4. 排序中的主要操作：关键字比较与记录移动（交换）——所有算法的时间复杂度都由这两类操作的次数决定（基数排序不比较关键字）。

三、插入排序

（一）识记

  • 直接插入排序：依次把每个待排序元素插入到前面已排好序的有序子段中的适当位置，使有序子段不断加长，直至全部有序。
  • 希尔排序（缩小增量排序）：取一个增量 d，把相隔 d 的元素分为一组（组内排序），增量逐步缩小，最后一趟 d = 1（此时即直接插入排序）。
  • 增量序列：各趟所用的增量取值序列，如 d = ⌊n/2⌋, ⌊n/4⌋, …, 1（折半增量）。

（二）领会

  • 1. 直接插入排序
  • 基本思想：把第 i 个元素暂存，与前面有序区从后向前比较，找到位置后后移元素并插入；
  • 稳定；最好 O(n)（正序，每个元素只比较 1 次）、最坏 O(n²)（逆序）、平均 O(n²)；空间 O(1)；
  • 移动次数 ≈ 逆序对个数；

  • 适合 n 较小或基本有序的序列。

  • 2. 希尔排序

  • 基本思想：先按较大增量分组做直接插入排序，使序列快速趋于基本有序，再逐步缩小增量，最后 d = 1 时（序列已基本有序）做一趟直接插入排序，效率很高；
  • 组内排序：同一组内用直接插入排序；各组交替进行；
  • 与直接插入排序的相关性：d = 1 时的希尔排序就是直接插入排序；前面的各趟是为最后一趟"减少逆序对、降低移动次数"做准备；
  • 不稳定（相同关键字的元素可能因分组而改变相对次序）；
  • 时间复杂度与增量序列有关，一般约 O(n^1.3)（优于 O(n²)，未达 O(n log n)）；空间 O(1)。

（三）简单应用（一趟/逐趟结果）

  • 示例：对 49, 38, 65, 97, 76, 13, 27, 49 排序

  • 直接插入排序（逐趟状态，| 右侧为有序区）

初始   49 | 38  65  97  76  13  27  49
i=2    38  49 | 65  97  76  13  27  49
i=3    38  49  65 | 97  76  13  27  49
i=4    38  49  65  97 | 76  13  27  49
i=5    38  49  65  76  97 | 13  27  49
i=6    13  38  49  65  76  97 | 27  49
i=7    13  27  38  49  65  76  97 | 49
i=8    13  27  38  49  49  65  76  97      ← 相等的 49 保持原次序（稳定）
  • 希尔排序（增量 4 → 2 → 1）
d=4  分组：(49,76) (38,13) (65,27) (97,49) → 组内插入排序
     结果：49  13  27  49  76  38  65  97
d=2  分组：(49,27,76,65) (13,49,38,97) → 组内排序
     结果：27  13  49  38  65  49  76  97
d=1  整体直接插入排序 → 13  27  38  49  49  65  76  97
  • 综合应用：运用插入思想解决"把新元素插入有序表""在线（边输入边排序）""几乎有序的序列排序"等问题；链表上的直接插入排序（避免大量移动）。

四、交换排序

（一）识记

  • 起泡（冒泡）排序：反复比较相邻两个元素，逆序则交换；每趟把当前最大（或最小）元素"冒"到它应在的一端，整体有序范围逐步扩大。
  • 快速排序：选一个枢轴（pivot），通过一趟划分把序列分为"左区全部 ≤ 枢轴、枢轴、右区全部 ≥ 枢轴"，再对左右两区递归处理。
  • 划分（partition）：一趟扫描把比枢轴小的移到左边、大的移到右边，并把枢轴放到最终位置。
  • 枢轴的选择方法：① 取第一个元素；② 取最后一个元素；③ 取中间位置元素；④ 随机选取；⑤ 三元取中（取首、中、尾三个元素的中值作枢轴，避免有序序列退化）。

（二）领会

  • 1. 起泡排序
  • 稳定；最好 O(n)（正序，配合"本趟无交换即已有序"的标志优化）、最坏 O(n²)（逆序）、平均 O(n²)；空间 O(1)；
  • n 个元素最多 n−1 趟；第 k 趟比较 n−k 次；

  • 每趟至少能使一个元素就位（整体有序区扩大一个）。

  • 2. 快速排序

  • 基于分治思想：划分（分）→ 递归处理左右（治）；
  • 不稳定；平均/最好 O(n log n)、最坏 O(n²)；空间 O(log n)（递归工作栈）；
  • 枢轴对效率的影响：若每次划分都极不均匀（如序列已正序/逆序且固定取首元素为枢轴），递归深度达 n，退化为 O(n²)；划分越接近等分效率越高（O(n log n)）；
  • 平均性能最好的内部排序算法（常数因子小），是"目前被认为最好"的通用内部排序方法 【注意】（教材常如此表述）。

（三）简单应用（一趟结果）

  • 示例：对 49, 38, 65, 97, 76, 13, 27, 49 排序

  • 起泡排序（逐趟，升序、大者上浮）

趟1  38  49  65  76  13  27  49 [97]
趟2  38  49  65  13  27  49 [76  97]
趟3  38  49  13  27  49 [65  76  97]
趟4  38  13  27  49 [49  65  76  97]
趟5  13  27  38 [49  49  65  76  97]  → 完成
  • 快速排序（取首元素 49 为枢轴，一趟划分后）
27  38  13 [49] 76  97  65  49
            ↑ 枢轴 49 已到达最终位置，左区 {27,38,13} < 49，右区 {76,97,65,49} ≥ 49

判据：一趟划分后枢轴到位、左右分区满足大小关系 ⇒ 快速排序。

  • 综合应用：运用交换思想解决"一趟找第 k 小（快速选择）""划分成大小两类（如奇偶/小于 x 在前）""求前 k 个最小元素"等问题。

五、选择排序

（一）识记

  • 直接选择排序：每趟从无序区选出最小（或最大）元素，与无序区的第一个（或最后一个）元素交换，使有序区扩大一个。
  • 堆排序：把序列看成完全二叉树，先建立初始堆（升序用大顶堆），再反复"堆顶与末尾元素交换 + 调整剩余元素为堆"，逐步得到有序序列。
  • 初始堆：由无序序列自底向上调整而成的第一个堆。

（二）领会

  • 1. 直接选择排序
  • 不稳定（交换可能跨越相等元素）；
  • 时间复杂度恒为 O(n²)（比较次数固定为 n(n−1)/2，不受初始排列影响）；
  • 交换（移动）次数少（最多 n−1 次交换）→ 适合记录较大、移动代价高的场合（配合索引/链表更佳）；

  • 空间 O(1)。

  • 2. 堆排序

  • 基本思想：① 建初始堆（从最后一个非叶结点 ⌊n/2⌋−1 起自底向上筛选，O(n)）；② 反复把堆顶（最大）与当前末尾交换，堆长度减 1，再向下调整恢复堆；③ n−1 次后即升序；
  • 不稳定；
  • 时间复杂度 O(n log n)（最好/平均/最坏都是 O(n log n)）；
  • 空间 O(1)（就地排序）；
  • 适合 n 较大且要求最坏情况也不能退化 的场合（相比快速排序的优势）。

（三）简单应用

  • 示例（堆排序思路）：对 49, 38, 65, 97, 76, 13, 27, 49

  • 建大顶堆后堆顶为 97 → 与末尾 49 交换 → 调整 → 次大为 76 → …… 依次就位，最终升序 13 27 38 49 49 65 76 97。

  • 综合应用：用堆求 Top-K 大/小元素、求中位数（双堆）、优先队列调度；直接选择思想用于"每趟定位最小值"类问题。

六、归并排序

（一）识记

  • 合并（merge）：把两个有序段合并成一个有序段（双指针比较，O(长度和)）。
  • 有序段 / 归并段：已经有序的子序列 / 参与归并的有序段。
  • 归并排序：反复"两两合并"，使有序段长度由 1 → 2 → 4 → … → n。

（二）领会

  • 1. 递归实现（自顶向下）：把序列一分为二，分别递归排序，再合并；递归深度 ⌈log₂n⌉。

  • 2. 非递归实现（自底向上）：先相邻两两合并（长度 1 → 2），再长度 2 → 4，逐趟扩大，直到长度 ≥ n。

  • 3. 特性

  • 稳定（合并时相等元素先取左段）；
  • 时间复杂度 O(n log n)（最好/平均/最坏均为 O(n log n)，不受初始排列影响）；
  • 空间复杂度 O(n)（需要辅助数组）；
  • 是外排序的基础方法（多路归并常用于外排序）。

（三）简单应用（逐趟结果）

  • 示例：对 49, 38, 65, 97, 76, 13, 27, 49
初始        49 | 38 | 65 | 97 | 76 | 13 | 27 | 49
趟1 (1→2)   38  49 | 65  97 | 13  76 | 27  49
趟2 (2→4)   38  49  65  97 | 13  27  49  76
趟3 (4→8)   13  27  38  49  49  65  76  97

判据：若某趟结果的序列呈现"若干长度为 2ᵏ 的有序段"，即为归并排序的中间状态。

  • 综合应用：合并两个（多个）有序表（第 2 章已考）、求逆序对（归并统计）、外排序的多路归并、链表归并排序（空间 O(1)）。

七、分配排序

（一）识记

术语 含义
箱子排序（桶排序） 按关键字范围划分若干箱子，把记录分配到相应箱子，再按箱子顺序收集
基数排序 按关键字的各位数字逐位进行"分配—收集"（LSD 从最低位开始）
分配 按当前位（个位/十位/百位…）把记录放入对应的 r 个队伍（箱子）中
收集 按箱子编号 0…r−1 依次把记录取出串接，形成新的序列

（二）领会

  • 1. 基数排序的基本思想
    设关键字为 d 位、基数为 r（十进制 r = 10）：从最低位开始，逐位执行"分配 → 收集"，重复 d 趟后序列即有序。
    （LSD 最低位优先：适合数值型；MSD 最高位优先：适合字符串型，需递归分箱。）

  • 2. 特性

  • 稳定（LSD 逐位分配收集保持相对次序）；
  • 时间复杂度 O(d(n + r))（d 为位数、r 为基数，与 d、n、r 有关，与初始排列无关）；
  • 空间复杂度 O(n + r)（需要箱子/队列）；
  • 不基于关键字比较，因此不受"比较类排序下界 O(n log n)"的限制；
  • 适合关键字位数少、取值范围有限、记录数很大（如整数、字符串、成绩）的场合。

（三）简单应用

  • 示例：对 278, 109, 63, 930, 589, 184, 505, 269, 8, 83 做一趟（按个位）分配—收集
个位 0: 930          → 收集顺序：930
     3: 63, 83                    63, 83
     4: 184                       184
     5: 505                       505
     8: 278, 8                    278, 8
     9: 109, 589, 269             109, 589, 269
一趟结果：930, 63, 83, 184, 505, 278, 8, 109, 589, 269
再按十位、百位各做一趟 → 最终有序：8, 63, 83, 109, 184, 269, 278, 505, 589, 930
  • 综合应用：多关键字排序（先按次关键字、再按主关键字，LSD 天然支持）、大整数/字符串排序、成绩单按班级+分数排序。

八、八大排序算法总对比（必背表）

  • 直接插入：平均：O(n²)；最好：O(n)（正序）；最坏：O(n²)；辅助空间：O(1)；稳定性：稳定；主要特点：n 小或基本有序时最好；移动≈逆序对数
  • 希尔：平均：约 O(n^1.3)；最好：与增量有关；最坏：与增量有关；辅助空间：O(1)；稳定性：不稳定；主要特点：缩小增量、组内插入；优于 O(n²)
  • 起泡：平均：O(n²)；最好：O(n)（正序+标志）；最坏：O(n²)；辅助空间：O(1)；稳定性：稳定；主要特点：相邻交换；最多 n−1 趟
  • 快速：平均：O(n log n)；最好：O(n log n)；最坏：O(n²)；辅助空间：O(log n)；稳定性：不稳定；主要特点：平均最快；枢轴影响巨大；分治
  • 直接选择：平均：O(n²)；最好：O(n²)；最坏：O(n²)；辅助空间：O(1)；稳定性：不稳定；主要特点：比较次数固定；交换次数最少
  • 堆排序：平均：O(n log n)；最好：O(n log n)；最坏：O(n log n)；辅助空间：O(1)；稳定性：不稳定；主要特点：最坏也不退化；就地排序
  • 归并：平均：O(n log n)；最好：O(n log n)；最坏：O(n log n)；辅助空间：O(n)；稳定性：稳定；主要特点：需辅助数组；外排序基础

  • 基数：平均：O(d(n+r))；最好：O(d(n+r))；最坏：O(d(n+r))；辅助空间：O(n+r)；稳定性：稳定；主要特点：非比较排序；与初始排列无关

  • 常见考法结论

  • 时间复杂度与初始排列无关：直接选择、堆排序、归并排序、基数排序；
  • 正序时最好 O(n)：直接插入、起泡（其它都比较/移动 O(n log n) 以上）；
  • 最坏 O(n²) 的"高效算法"：快速排序（可通过三元取中/随机化改善）；
  • 稳定性：稳定 = 直接插入、起泡、归并、基数（+箱子插入类）；不稳定 = 希尔、快速、直接选择、堆排序；
  • 空间：O(1) = 直接插入、希尔、起泡、直接选择、堆排序；O(log n) = 快速；O(n) = 归并；O(n+r) = 基数；
  • 交换次数最少：直接选择排序；移动次数最少且稳定：归并排序（但费空间）；
  • 比较类排序的下界是 O(n log n)；基数排序不受此限。

观察到的现象 推测算法

九、本章易混点与关键结论

易混点 正确理解
稳定的含义 关键字相等的记录排序前后相对次序不变（不是"值不变"）
主关键字 vs 次关键字 能唯一标识记录 / 不能唯一标识（可重复）
内部 vs 外排序 全部在内存 / 需要内外存交换
希尔排序 vs 直接插入 希尔按增量分组做插入排序；d=1 时即直接插入排序；希尔不稳定
快速排序的枢轴 枢轴位置确定后不再移动；取固定端点为枢轴 + 序列已有序 → 退化 O(n²)
三元取中 取首、中、尾三元素的中值作枢轴，改善有序/逆序输入的性能
堆排序的"堆" 升序排序建大顶堆（每次把堆顶最大值换到末尾）
直接选择 vs 堆排序 都是"选最值"；直接选择 O(n²)，堆排序 O(n log n)
归并 vs 快速 都分治、O(n log n) 平均；归并稳定但需 O(n) 空间，快速就地但不稳定、最坏 O(n²)

二、查找的基本概念

（一）识记

术语 含义
查找（检索） 在查找表中确定是否存在关键字等于给定值的记录，并给出其位置/信息
单值查找 / 范围查找 查找某一个关键字值的记录 / 查找关键字在某个范围内的所有记录
查找表 由同一类型（记录）构成的集合；分静态查找表（只查不改）与动态查找表（可插入删除）
成功查找 / 不成功查找 找到 / 未找到满足条件的记录
内部查找 / 外部查找 查找表全部在内存 / 需访问外存
平均查找长度（ASL） 查找过程中关键字比较次数的期望值：ASL = Σ pᵢ·cᵢ（pᵢ 为查找第 i 个记录的概率，cᵢ 为找到它所需的比较次数）

（二）领会

  • 1. 查找算法的适用条件
方法 对存储的要求 对有序性的要求
顺序查找 顺序存储或链式存储皆可 不需要有序
折半查找 必须顺序存储（需随机访问） 必须有序
分块（索引顺序）查找 顺序存储 + 索引表 块间有序、块内可无序
二叉查找树 / AVL / B 树 链式（或顺序模拟） 按 BST 性质组织
哈希查找 顺序存储（散列表） 不需要有序，但依赖哈希函数
  • 2. 查找长度的含义：ASL 是比较次数的平均值（期望值），用于衡量查找算法的时间性能；分成功查找的 ASL 与不成功查找的 ASL（后者常用于哈希表评价）。ASL 越小越好；通常假设等概率查找 pᵢ = 1/n。

三、顺序表的查找

（一）识记

术语 含义
顺序表 用连续单元存储记录的表（可随机访问）
顺序查找（线性查找） 从表的一端开始逐个比较关键字
折半查找（二分查找） 每次与查找区间的中间位置元素比较，逐步把区间缩小一半
折半查找判定树 描述折半查找过程的二叉判定树（每个结点对应一次比较）
索引 由"分块最大（小）关键字 + 起始地址"构成的表
索引顺序查找（分块查找） 先查索引确定所在块，再在块内顺序查找

（二）领会

  • 1. 顺序查找的适用条件：表无序或有序皆可；顺序存储或链式存储皆可；实现简单，适合表小或查找不频繁的场合；可用哨兵（监视哨） 免去越界判断。
  • 成功 ASL = (n+1)/2（等概率：Σi/n = (1+2+…+n)/n）；
  • 不成功 ASL = n + 1（带哨兵时比较 n+1 次；不带哨兵为 n 次 【注意】 视教材）；

  • 时间复杂度 O(n)。

  • 2. 折半查找的适用条件（必考）：必须是有序表，且必须采用顺序存储（能随机访问）；链式存储无法直接折半（可改用跳表/树结构）。复杂度 O(log₂n)。

（三）简单应用（ASL 计算，必考）

  • 1. 顺序查找 ASL
  • 成功：ASL = (n+1)/2（n=10 → 5.5）；

  • 不成功：n + 1。

  • 2. 折半查找：判定树与 ASL

  • 判定树高度（查找成功时的最大比较次数）h = ⌊log₂n⌋ + 1（等价于 ⌈log₂(n+1)⌉）；
  • 等概率成功 ASL：设判定树第 i 层有 2^(i−1) 个结点（满树 n = 2ʰ−1 时）
  • ASL = (1/n)·Σ_{i=1}^{h} i·2^(i−1) = ((n+1)/n)·log₂(n+1) − 1 ≈ log₂(n+1) − 1
  • 计算示例（n = 11）：判定树各层结点数为 1、2、4、4
    ASL = (1×1 + 2×2 + 3×4 + 4×4)/11 = (1 + 4 + 12 + 16)/11 = 33/11 = 3
    即平均约 3 次比较，最大比较次数 = 树高 = 4（⌊log₂11⌋+1 = 4）。
                6                ← 第1层（mid = ⌊(1+11)/2⌋ = 6）
             /     \
            3       9            ← 第2层
          /  \    /  \
         1    4  7   10          ← 第3层
          \    \  \    \
           2    5  8   11        ← 第4层
  • 3. 分块查找（索引顺序查找）ASL 与最优配置
  • 表分 b 块、每块 s 个记录（块内无序、块间有序），索引表存每块最大关键字与起始地址；
  • 索引查找用顺序查找时：ASL = (b+1)/2 + (s+1)/2；
  • 最优配置：由 b = n/s 代入，当 s = √n（即块数 b = √n）时 ASL 最小，ASL ≈ √n + 1；
  • 例：n = 100，s = b = 10 → ASL = (10+1)/2 + (10+1)/2 = 11（≈√100 + 1）。

    若索引表用折半查找，则 ASL ≈ ⌈log₂(b+1)⌉ + (s+1)/2。

四、树形结构的查找

（一）识记

术语 含义
二叉查找树（BST） 或为空，或满足：左子树所有结点关键字 < 根 < 右子树所有结点关键字，左右子树也都是 BST
BST 的特性 中序遍历得到递增有序序列；查找路径唯一；不含相同关键字（可约定）
查找过程中关键字比较序列 从根开始的比较关键字序列（如查找 37：45 → 24 → 37）
AVL 树（平衡二叉树） 任一结点的左右子树高度差的绝对值 ≤ 1 的二叉查找树
平衡因子（BF） 结点左子树高度 − 右子树高度，取值 −1、0、1
B 树 一种多路平衡查找树：m 阶 B 树的每个结点最多 m 棵子树、m−1 个关键字，所有叶结点在同一层（绝对平衡）

（二）领会

  • 1. 二叉查找树基本操作的过程
  • 查找：与根比较 → 小于走左、大于走右、相等成功；走到空即查找失败。比较次数 ≤ 树高；
  • 插入：先按查找走到空位置，把新结点作为叶结点插入（BST 的插入总是插在叶子处）；

  • 生成树形：由初始序列依次插入决定；插入顺序不同 → 树形不同。

  • 2. 树形与查找效率的关系

  • 最好情况：树接近平衡（完全二叉树形态），树高 = ⌊log₂n⌋+1，查找 O(log₂n)；
  • 最坏情况：插入序列有序 → 退化为单支树（相当于链表），树高 = n，查找 O(n)；

  • 结论：BST 的查找效率取决于树高（形态）；为保持高效需动态平衡（AVL 树、红黑树、B 树）。

  • 3. 二叉查找树的插入、查找与删除（删除是难点）
    删除结点 p 分三种情况：
    ① p 是叶子 → 直接删除（把父结点的相应指针置空）；
    ② p 只有左子树或只有右子树 → 用其唯一的子树顶替 p（"子承父业"）；
    ③ p 左右子树都有 → 用它的中序前驱（左子树中最大者） 或 中序后继（右子树中最小者） 的值替换 p 的值，然后按 ① 或 ② 删除那个前驱/后继结点。

  • 删除示例：依次插入 45, 24, 53, 12, 37, 93 建成 BST（中序：12, 24, 37, 45, 53, 93）

        45
       /  \
     24    53
    /  \     \
   12   37    93
  • 删除 24（左右子树都有）→ 用中序前驱 12 或中序后继 37 顶替：
    用 37 顶替后：
        45
       /  \
     37    53
    /        \
   12         93

（中序：12, 37, 45, 53, 93）

  • 4. B 树的查找、插入与结点分裂过程
  • B 树的查找：在结点内用顺序查找或折半查找关键字；若命中则成功；否则沿相应指针下移到孩子结点继续（直到叶结点为空 → 失败）；
  • B 树的插入：总是插入到最底层的叶结点；若插入后该结点关键字个数 > m−1（溢出） → 分裂：
    取中间关键字（第 ⌈m/2⌉ 个）上移到父结点，其余左右两半分别构成两个新结点；
    若父结点也溢出，则继续向上分裂（可能直到根分裂 → 树高 +1）；

  • 绝对平衡：B 树所有叶结点在同一层，因此查找路径长度相同，效率稳定。

  • B 树插入分裂示例（3 阶 B 树，每个结点最多 2 个关键字）

插入 1     →  [1]
插入 2     →  [1 2]
插入 3     →  [1 2 3] 溢出 → 中间 2 上移 → 根[2]，左[1]，右[3]
插入 4     →  最右叶 [3 4]
插入 5     →  [3 4 5] 溢出 → 中间 4 上移 → 根[2 4]，三叶 [1] [3] [5]

（三）简单应用

  • 1. 二叉查找树基本操作实现（类 C）
typedef struct BSTNode { int key; struct BSTNode *lchild, *rchild; } BSTNode, *BSTree;

BSTNode *Search(BSTree T, int k) {                 // 查找
    while (T && T->key != k) T = (k < T->key) ? T->lchild : T->rchild;
    return T;                                       // NULL 即查找失败
}
int Insert(BSTree *T, int k) {                      // 插入（递归）
    if (!*T) { *T = (BSTNode*)malloc(sizeof(BSTNode));
               (*T)->key = k; (*T)->lchild = (*T)->rchild = NULL; return 1; }
    if (k == (*T)->key) return 0;                   // 已存在，不插
    return (k < (*T)->key) ? Insert(&(*T)->lchild, k) : Insert(&(*T)->rchild, k);
}
int Delete(BSTree *T, int k) {                      // 删除（难点，三种情况）
    if (!*T) return 0;
    if (k < (*T)->key) return Delete(&(*T)->lchild, k);
    if (k > (*T)->key) return Delete(&(*T)->rchild, k);
    BSTNode *p = *T;
    if (!p->lchild)       *T = p->rchild;           // ② 只有右子树（含叶子）
    else if (!p->rchild)  *T = p->lchild;           // ② 只有左子树
    else {                                          // ③ 左右都有：用中序前驱顶替
        BSTNode *s = p->lchild;
        while (s->rchild) s = s->rchild;            // 找左子树最大者
        p->key = s->key; Delete(&p->lchild, s->key);// 递归删除前驱
    }
    free(p); return 1;
}

类型 触发情形 调整方法

RR 新结点插在右子树的右侧 左单旋
LR 新结点插在左子树的右侧 先左旋（对左孩子）再右旋（对根）（双旋）

  • 插入 16、3（3 为 16 的左孩子）；插入 7：7 > 3 → 作为 3 的右孩子 → 结点 16 的 BF = 2（左高 2、右高 0）→ LR 型；

     3     16

（其余：插入 3,2,1 → LL → 右单旋 → 根 2；插入 1,2,3 → RR → 左单旋 → 根 2；插入 3,5,4 → RL → 双旋 → 根 4）

  • 3. 树形查找效率分析：BST 查找长度 = 树高（最好 ⌊log₂n⌋+1、最坏 n）；AVL 树/B 树查找长度 = O(log₂n)（AVL 树高 ≤ 约 1.44log₂n；m 阶 B 树高 ≈ log_m n）；AVL 树插入/删除需 O(log n) 次旋转以内。

（四）综合应用

① 由无序序列构造 BST 并写出树形/中序序列；② 判断给定树是否为 BST/AVL；③ 求查找某关键字的比较序列；④ 计算 BST 的 ASL（等概率：(1/n)Σ(结点所在层数)）；⑤ 用 AVL 树维持动态有序表；⑥ B 树/B+ 树用于文件索引与数据库（减少外存访问次数）。

五、哈希表及其查找

（一）识记

术语 含义
哈希表（散列表） 由哈希函数与冲突处理方法把关键字映射到存储位置的查找表
哈希函数 H(k) 由关键字直接计算存储地址的函数
哈希地址 H(k) 计算出的存储位置
冲突（碰撞） 不同关键字计算出相同哈希地址的现象
同义词 具有相同哈希地址的不同关键字（彼此互为同义词）
完美哈希函数 不产生任何冲突的哈希函数（理想情况）
基本聚集（一次聚集） 线性探测法中，连续被占用的单元形成"堆积"，使后续冲突概率与探测长度增大
二级聚集 二次探测法中，同义词按相同探测序列探测所形成的聚集
装填因子 α α = 表中记录数 n / 表长 m（衡量表的"满"程度；α 越大冲突越多）
查找成功的 ASL / 不成功的 ASL 成功查找的比较次数平均值 / 查找不存在的关键字时的比较次数平均值（按 m 个地址平均）

（二）领会

  • 1. 哈希函数的构造方法（6 种）
方法 说明
直接定址法 H(k) = a·k + b（线性函数），不产生冲突，适合关键字连续、分布已知
数字分析法 选取关键字中分布均匀的若干位作哈希地址（如学号后 4 位）
平方取中法 取 k² 的中间若干位作哈希地址（中间位受各位影响大）
折叠法 把关键字分割成若干段相加（可移位叠加/间界叠加）
除留余数法 H(k) = k mod p，p 通常取不大于表长 m 的质数（最常用）
基数转换法 把关键字按另一基数转换后取位（如按 13 进制转换）
（随机数法） H(k) = random(k)，适合关键字长度不等
  • 2. 冲突解决方法（4 类）
方法 做法 特点
开放地址法 H_i = (H(k) + d_i) mod m，在表内寻找空闲单元 无需额外空间；但会产生聚集
线性探测法 d_i = 1, 2, 3, …（顺序后移） 简单；产生基本聚集，探测长度增长快
二次探测法 d_i = 1², −1², 2², −2², … 减轻基本聚集，但有二级聚集
伪随机探测/再散列 d_i 由伪随机序列或另一哈希函数给出 聚集更少
链地址法（拉链法） 把所有同义词链成一条单链表，表头存各哈希地址 不产生聚集；适合表长不确定；可插入删除
公共溢出区法 冲突的记录一律放入公共溢出区 简单，适合冲突很少的情况
再哈希法（双散列） 冲突时用另一个哈希函数再算地址 不易聚集，计算量增加
  • 3. 影响哈希方法效率的因素
    ① 哈希函数是否均匀（分布越均匀冲突越少）；
    ② 冲突处理方法（链地址法一般优于线性探测）；
    ③ 装填因子 α（最主要因素：α 越大冲突越多、ASL 越大）；
    ④ 关键字集合的特点；
    ⑤ 表长 m 与 p 的选取（p 取质数）。

六、本章对比与易混点

1. 各查找方法对比（必背）

  • 顺序查找：存储要求：顺序或链式；有序要求：不需有序；平均查找长度 ASL：成功 (n+1)/2；时间复杂度：O(n)；适合：表小/无序/链式
  • 折半查找：存储要求：必须顺序存储；有序要求：必须有序；平均查找长度 ASL：≈ log₂(n+1) − 1；时间复杂度：O(log₂n)；适合：有序表、查询频繁、表可随机访问
  • 分块（索引顺序）查找：存储要求：顺序存储 + 索引表；有序要求：块间有序、块内无序；平均查找长度 ASL：(b+1)/2 + (s+1)/2，最优 ≈ √n + 1；时间复杂度：O(√n)；适合：表大且分块组织、动态插入较多
  • 二叉查找树：存储要求：链式；有序要求：按 BST 性质；平均查找长度 ASL：与树高有关（≈log₂n ~ n）；时间复杂度：最好 O(log₂n)、最坏 O(n)；适合：动态查找表
  • AVL 树：存储要求：链式；有序要求：BST + 平衡；平均查找长度 ASL：O(log₂n)；时间复杂度：稳定 O(log₂n)；适合：频繁查找+插入删除、要求最坏也快
  • B 树 / B+ 树：存储要求：外存块结构；有序要求：多路平衡；平均查找长度 ASL：O(log_m n)；时间复杂度：稳定；适合：外存索引（数据库/文件系统）
  • 哈希（散列）查找：存储要求：顺序存储（散列表）；有序要求：不需有序；平均查找长度 ASL：与 α 有关（如 1+α/2）；时间复杂度：平均 O(1)；适合：只做精确查找、不需要范围/顺序访问

2. 易混点

易混点 正确理解
折半查找的条件 必须有序 + 必须顺序存储（随机访问）；链式不能直接折半
折半判定树的高度 vs ASL 高度 = 最大比较次数 = ⌊log₂n⌋+1；ASL 是平均比较次数 ≈ log₂(n+1) − 1
顺序查找「不成功」 需比较到表尾（n 或 n+1 次），远大于成功时的 (n+1)/2
分块查找的最优块长 s = √n（块数与块长相等时 ASL 最小 ≈ √n + 1）
BST 的插入位置 新结点总是插到叶子处（查找失败的位置）
BST 删除的两种情况 单子树 → 子树顶替；双子树 → 中序前驱/后继顶替后删除该结点
BST 的效率 取决于树高（形态）；有序插入 → 退化为单支树 O(n)
AVL 平衡因子 BF = 左子树高 − 右子树高，只能取 −1、0、1
LL/RR/LR/RL LL→右单旋；RR→左单旋；LR→先左后右；RL→先右后左
B 树阶数 m 每个结点最多 m 棵子树、m−1 个关键字；根至少 2 棵子树；非根非叶至少 ⌈m/2⌉ 棵子树
B 树分裂 中间关键字上移父结点，左右两半成两个结点；可能向上传播甚至增加树高
B 树 vs 二叉查找树 B 树多路、绝对平衡（所有叶同层）；适合外存（减少 I/O 次数）
哈希冲突 不同关键字算出同一地址（≠ 同义词本身，同义词是"哈希地址相同"的关键字）
基本聚集 vs 二级聚集 基本聚集来自线性探测（连续占用成片）；二级聚集来自二次探测（同义词探测序列相同）
哈希查找效率 主要取决于装填因子 α 与冲突处理方法，而不是表长 n；理想 O(1)
链地址法优势 不产生聚集、可动态插入删除、适合 α 接近或超过 1
哈希表能否范围查找 不能（不支持有序遍历）；范围查找需用有序表/B 树/B+ 树

（三）计算题模板

  • 顺序查找：成功 ASL = (n+1)/2；不成功 = n+1。
  • 折半查找：画判定树（每次取 mid）→ 统计各层结点数 → ASL = Σ(层数×该层结点数)/n；最大比较次数 = 树高 = ⌊log₂n⌋+1。
  • 分块查找：ASL = (b+1)/2 + (s+1)/2；由 n = b·s 与均值不等式求最优 s = b = √n。
  • BST：按序列依次插入画树 → 中序验证 → 删除按三种情况处理 → ASL = Σ(结点层数)/n。
  • AVL：插入后从插入点向上找最小不平衡子树 → 判断 LL/RR/LR/RL → 旋转 → 验证 BF。
  • B 树：逐次插入 → 溢出（关键字数 > m−1）→ 中间关键字上移、左右分裂，必要时向上传播。
  • 哈希表：按 H(k) 计算地址 → 冲突时按探测序列（线性：+1,+2,…；二次：±1²,±2²…）逐个试放 → 列表记录比较次数 → 成功 ASL = Σcᵢ/n；不成功 ASL = Σ(各地址探测到空的次数)/m；α = n/m。

第二章 线性表 · 考前简记（关键词版）

一、定义与术语

  • 线性表：n（≥0）个数据元素的有限序列 (a₁,…,aₙ)；n=0 空表，n 为表长
  • 表头元素 a₁；表尾元素 aₙ
  • 直接前驱/直接后继＝唯一且相邻；前驱/后继＝其前（后）的所有元素
  • 位置（序号）i：元素逻辑次序（教材多从 1 开始 【注意】）
  • 有序表＝按关键字有序（可折半查找）；无序表＝未排序（只能顺序查找）

  • 特点：有限 · 同类型 · 1:1（首无前驱、尾无后继）· 位置有序 · 元素可重复

  • ADT 操作：Init · Destroy · Empty · Length · GetElem(按位置取) · LocateElem(按值找) · PriorElem/NextElem · Insert(1≤i≤n+1，表长+1) · Delete(1≤i≤n，表长−1) · Traverse

二、顺序表（顺序存储）

  • 思想：地址连续的单元依次存元素，逻辑相邻=物理相邻（逻辑关系隐含在物理连续性中）
  • 地址公式：LOC(aᵢ) = LOC(a₁) + (i−1) × L（0 起：LOC(a[i]) = LOC(a[0]) + i×L）
  • 随机访问：任一元素 O(1)，与位置无关
  • 表空：length==0（删除判空，否则下溢）；表满：length==maxSize（插入判满，否则上溢）
操作 移动比较次数 复杂度
插入 最好 0 / 最坏 n / 平均 n/2 O(n)
删除 最好 0 / 最坏 n−1 / 平均 (n−1)/2 O(n)
按位置取值 — O(1)
按值查找 最好 1 / 最坏 n / 平均 (n+1)/2 O(n)
求长 / 判空 — O(1)
  • 插入要点：判满 + 判位置 → 从后往前后移 → 写入 → length+1
  • 删除要点：判空 + 判位置 → 取出 → 从前往后前移 → length−1
  • 优缺点：优点＝随机访问 O(1)、存储密度 1、简单；缺点＝插删 O(n)、容量固定（上溢/浪费）
  • 常用算法：就地逆置 · 删所有 x · 有序表去重 · 两有序表归并 · 交并集 · 划分奇偶（均 O(n)）

三、链表（链式存储）

  • 思想：结点＝数据域+指针域，用指针表示后继，物理可不连续，动态分配
  • 术语：
  • 头指针（指向第一个结点，链表唯一标识）
  • 头结点/表头结点（哑结点，在首结点前，空表也在）
  • 首结点（第一个数据结点）
  • 表尾结点/终端结点（next = NULL）
  • 单向循环链表（尾 next 指回头结点）
  • 双向链表（prior+next）
  • 双向循环链表（首尾相连）
  • 静态链表（数组+游标）
  • 空表判定：带头结点 head->next == NULL；循环链表 head->next == head

  • 头结点作用：统一空表/非空表 · 首位置插删与中间一致 · 简化循环链表与操作接口 · 可存表长

  • 顺序访问：访问第 i 个需从头走 i 步 → O(i)，不能随机定位

  • 结构性开销＝指针域字节 / 结点总字节（4B 数据+4B 指针 → 50%；双指针 → ≈66.7%）
操作 复杂度
建表（头插） O(n)，逆序
建表（尾插，带尾指针） O(n)，保持原序
按位置 / 按值查找 O(n)

  • 选型：表头频繁插删→带头结点单链表；需双向/删指定结点→双向链表；循环往复（约瑟夫）→循环链表；频繁尾部操作→带尾指针；不支持指针→静态链表

  • 单链表常用算法：就地逆置 · 删 x · 去重 · 倒数第 k 个（快慢指针）· 中间结点/判环 · 合并有序链表 · 交集并集 · 多项式相加 · 相交结点

四、空闲单元链表与静态链表

  • 空闲单元链表（备用链表）：把未使用结点用指针域串成链表，avail 指向表头；取结点：p=avail; avail=S[avail].next;　归还：S[p].next=avail; avail=p;

  • 作用：数组内模拟动态分配回收 · 复用被删结点 · 支撑链式栈/队列的结点回收

  • 静态链表：数组 S[maxSize]，元素 {data, next(游标下标)}；S[0] 为头结点，S[0].next 为首结点下标；0 表示空/结束 【注意】

  • 机制：初始化建空闲链（avail=1）→ 插入时取结点挂链 → 删除时摘链归还 → 定位第 i 个仍需沿游标走 O(n)
  • 特点：不用指针（适合无指针语言）· 容量固定 · 插删不移动元素

五、对比与选型（一句话版）

  • 随机访问（O(1)）＝顺序表；顺序访问（O(n)）＝链表/静态链表
结构 适用
顺序表 表长可预估且稳、频繁按位置访问、读多写少
动态链表 表长变化大、频繁插删、不需随机访问
静态链表 表长有上限、无指针语言、需结点回收
  • 顺序表 vs 链表：存取 O(1)↔O(n)；插删 O(n)（平均移动一半）↔已知前驱 O(1)；存储密度 1 ↔ 有结构性开销；预分配可能上溢 ↔ 动态分配无上溢

六、易混点一句

  • 头指针（变量·唯一标识）≠ 头结点（哑结点·可无）≠ 首结点（第一个数据结点）：
  • 直接前驱唯一 ↔ 前驱可有多个
  • 顺序存储（物理连续）≠ 顺序访问（逐个走）
  • 表长 length ≠ 容量 maxSize
  • 满表插入=上溢，空表删除=下溢
  • 静态链表插删不移动元素（用游标+空闲链）
  • "链表插删 O(1)"前提是已知前驱

七、算法步骤链（背诵用）

  • 顺序表插入：判满→判位置→从后往前后移→写 e→length+1
  • 顺序表删除：判空→判位置→取出 e→从前往后前移→length−1
  • 单链表插入（p 后插 s）：s->next=p->next; p->next=s;
  • 单链表删除（p 为前驱）：q=p->next; p->next=q->next; free(q);

  • 尾插法建表：r->next=s; r=s（结果保持原序）

第三章 栈和队列 · 考前简记（关键词版）

二、栈

第五章 树与二叉树 · 考前简记（关键词版）

一、树的基本概念

  • 树：n≥0 结点的有限集合，唯一根 + m 棵互不相交子树（1:n 层次结构，除根外前驱唯一、后继可多个）
  • 术语：结点的度（孩子数）· 树的度（最大度）· 叶结点（度0）· 分支结点 · 层（根为第1层）· 深度/高度 【注意】 · 路径长度（边数）· 有序树 · 森林（m 棵不相交树）
  • 关系：边数 = 结点数 − 1；Σ所有结点度 = 边数；森林边数 = n − m
  • 叶结点公式：n₀ = 1 + Σ_{i≥2}(i−1)nᵢ
  • 表示形式 4：树形 · 括号（如 A(B(D,E),C(F))）· 嵌套集合 · 凹入缩进

二、二叉树核心性质（必背）

性质 内容
1 第 i 层至多 2^(i−1) 个结点
2 深度 k 至多 2ᵏ − 1 个结点
3 n₀ = n₂ + 1（证：n=n₀+n₁+n₂，边=n−1=n₁+2n₂）
4 完全二叉树 n 个结点 → 深度 k = ⌊log₂n⌋ + 1
5 层序编号（1 基）：父 ⌊i/2⌋、左 2i、右 2i+1；i > ⌊n/2⌋ 为叶
推论 二叉链表 n 个结点有 n+1 个空指针域
  • 0 基下标：父 ⌊(i−1)/2⌋、左 2i+1、右 2i+2、最后一个非叶 = ⌊n/2⌋−1
  • 满二叉树：每层都满，深度 k → 2ᵏ−1 个结点；完全二叉树：编号与满二叉树一一对应，最下层集中左侧
  • 顺序存储：适合完全二叉树；一般二叉树浪费（最坏 2ᵏ−1）；链式存储：二叉链表(lchild,rchild)／三叉链表(+parent)
  • 二叉树 vs 树：二叉树可空 · 左右有序 · 度为2的有序树 ≠ 二叉树

三、遍历（必考）

遍历 顺序 辅助结构
先序 根→左→右 栈（非递归）
中序 左→根→右 栈
后序 左→右→根 栈（双栈/标记）
层次 按层从左到右 队列
  • 还原：先序+中序、后序+中序、层次+中序 → 唯一确定；先序+后序 → 不能
  • 方法：先序首元（后序末元）＝根 → 中序划分左右 → 递归
  • 例：先序 ABDECF、中序 DBEACF → 树 A(B(D,E), C(∅,F))，后序 = D E B F C A
  • 表达式树：叶=操作数、分支=运算符；中序→中缀、先序→前缀（波兰）、后序→后缀（逆波兰）
  • 常用递归算法：Count（结点数）· LeafCount（叶子）· Depth（深度＝max(左,右)+1）· 复制/交换左右↔镜像 · 判断相同/相似 · 判断完全二叉树（层次遍历遇空后不得再有非空）

四、堆与优先队列

  • 堆＝满足"父 ≥ 子（最大堆）/ 父 ≤ 子（最小堆）"的完全二叉树；堆顶＝极值；子堆仍是堆
  • 存储：一维数组（0 基：左 2i+1、右 2i+2、父 ⌊(i−1)/2⌋；最后非叶 ⌊n/2⌋−1）
  • 有序性：只保证父与子，兄弟无序；堆不能查找任意元素（≠二叉查找树）
  • 建堆：从最后一个非叶 ⌊n/2⌋−1 起自底向上筛选 → O(n)
  • 插入：放末尾 → 上浮 O(log n)；删除堆顶：末尾顶替 + 下沉 O(log n)
  • 例 [5,8,3,9,1] 建最小堆：处理 i=1(8) 交换 1 → [5,1,3,9,8]；处理 i=0(5) 交换 1 → [1,5,3,9,8]；插 0 → [0,5,1,9,8,3]；删堆顶 → [1,5,3,9,8]
  • 优先队列：出队按优先级（极值优先），用堆实现；应用＝任务调度、Dijkstra/Prim、Top-K、双堆求中位数、堆排序 O(n log n)

六、哈夫曼树与哈夫曼编码

  • 术语：定长编码（等长，⌈log₂n⌉ 位）· 变长编码（高频短码）· 前缀特性（任一编码都不是另一个的前缀 → 译码唯一、无需分隔符）· 编码树 · 哈夫曼树（WPL 最小的二叉树） · WPL = Σwᵢlᵢ · 带权平均码长 = WPL / Σwᵢ
  • 构造：每次取两个根权最小的树合并（新权=和），重复 n−1 次；无度为1的结点，共 2n−1 个结点
  • WPL 快速算法：WPL = 所有合并产生的新权值之和
  • 经典例（a5,b29,c7,d8,e14,f23,g3,h11，Σw=100）
  • 合并：3+5=8 → 7+8=15 → 8+11=19 → 14+15=29 → 19+23=42 → 29+29=58 → 42+58=100
  • WPL = 8+15+19+29+42+58+100 = 271；平均码长 = 271/100 = 2.71（定长需 3 位）
  • 编码：左 0 右 1；例 d=000, h=001, f=01, e=100, c=1010, g=10110, a=10111, b=11（不唯一）
  • 译码：从根按位走，到叶输出并回根
  • 不唯一性：左右可交换、同权合并顺序可变 → 编码不同；但 WPL 与各字符码长唯一

  • 哈夫曼树无度为 1 的结点、共 2n−1 个结点
  • 哈夫曼编码不唯一但 WPL/码长唯一

第六章 图结构 · 考前简记（关键词版）

一、基本概念

  • 图 G=(V,E)：顶点集 + 边集；子图；无向边 (v,w)；有向边/弧 ：v=弧尾、w=弧头；带权图（网）
  • 邻接点（顶点—顶点）↔ 关联（顶点—边）；度 TD：无向＝关联边数；有向＝入度 ID + 出度 OD
  • 关键关系：ΣTD = 2e（无向）；有向 ΣID = ΣOD = e；无向完全图 n(n−1)/2；有向完全图 n(n−1)；稀疏图 e ≪ n²（e < n·log n）
  • 路径（顶点序列）· 有向路径（沿弧）· 简单路径（顶点不重复）· 回路· 简单回路 · 路径长度（边数 / 带权为权和）· DAG（有向无环）
  • 连通图（无向任意两点有路）· 连通分量（极大连通子图）· 强连通图（有向互相可达）· 弱连通图（忽略方向连通）

二、存储结构

  • 结构：邻接矩阵：vexs[n] + arcs[n][n]；邻接表：顶点表 data+firstarc + 边表表结点 adjvex+nextarc(+info)；逆邻接表：同邻接表，但存入边
  • 空间：邻接矩阵：O(n²)；邻接表：O(n+e)；逆邻接表：O(n+e)
  • 适合：邻接矩阵：密集图；邻接表：稀疏图；逆邻接表：稀疏图（求入度）
  • 判相邻：邻接矩阵：O(1)；邻接表：O(度)；逆邻接表：O(度)
  • 求邻接点：邻接矩阵：O(n)；邻接表：O(度)；逆邻接表：O(入度)
  • 无向图：邻接矩阵：对称，行/列非零数＝度；邻接表：边结点数＝2e；逆邻接表：同
  • 有向图：邻接矩阵：行＝出度、列＝入度；邻接表：边结点数＝e；求入度难；逆邻接表：求入度易

三、图的搜索

  • 特性：需 visited[] 防重复；非连通图对每个未访问顶点重新发起（每次得一个连通分量）；搜索序列随起点与存储次序变化
  • DFS（似先序）：栈（递归）；BFS（似层次）：队列
  • 复杂度：邻接矩阵 O(n²)；邻接表 O(n+e)
  • 示例 边 1-2,1-3,2-4,3-4,4-5（升序）→ DFS: 1,2,4,3,5；BFS: 1,2,3,4,5
  • 应用：连通分量计数 · 路径查找 · 判环（回边）· 二分图染色 · 迷宫/岛屿 · 拓扑排序

四、生成树与最小生成树

  • 生成树：连通图的极小连通子图，n 个顶点 + n−1 条边，可能不唯一；DFS/BFS 生成树（非连通图→生成森林）
  • 最小生成树 MST：边权之和最小；MST 可能不唯一但最小代价唯一
  • Prim（加点法）：从任一顶点开始，每次在"已选集 ↔ 未选集"的边中取权最小者加入；O(n²)，适合密集图
  • Kruskal（加边法）：边按权升序，只要两端不在同一连通分量就选入；直到 n−1 条；O(e log e)，适合稀疏图
  • 经典例（A-B6, A-C1, A-D5, B-C5, B-E3, C-D5, C-E6, C-F4, D-F2, E-F6）
  • Prim(A)：AC1 → CF4 → FD2 → CB5 → BE3 → 代价 15
  • Kruskal：AC1, DF2, BE3, CF4,（AD5 舍）, BC5 → 代价 15

五、有向无环图及其应用

  • AOV 网：顶点=活动、弧=先后关系 → 拓扑排序
  • 拓扑排序步骤：① 选入度为 0 顶点输出 → ② 删除该顶点及其出边（相关入度−1）→ ③ 重复；无法输出全部顶点即有环；复杂度 O(n+e)；序列可能不唯一
  • AOE 网：弧=活动（权=持续时间）、顶点=事件；源点（唯一入度 0）、汇点（唯一出度 0）
  • 关键路径求解（必背）
  • ve（正向）：ve(j)=max{ve(i)+w(<i,j>)}，源点 ve=0
  • vl（逆向）：vl(j)=min{vl(k)−w(<j,k>)}，vl(汇点)=ve(汇点)
  • 活动 e(a)=ve(弧尾)；l(a)=vl(弧头) − w；余量 = l − e，余量为 0 → 关键活动

  • 关键路径＝源点到汇点最长路径，长度＝最短工期，可能不唯一

  • 经典例（a1 V1→V2 6, a2 V1→V3 4, a3 V1→V4 5, a4 V2→V5 1, a5 V3→V5 1, a6 V4→V6 2, a7 V5→V7 9, a8 V5→V8 7, a9 V6→V8 4, a10 V7→V9 2, a11 V8→V9 4）

  • ve：0, 6, 4, 5, 7, 7, 16, 14, 18
  • vl：0, 6, 6, 8, 7, 10, 16, 14, 18
  • 关键活动：a1, a4, a7, a8, a10, a11 → 关键路径 V1→V2→V5→V7→V9 与 V1→V2→V5→V8→V9，工期 18

六、最短路径

  • Dijkstra（单源，贪心，非负权）：S 初始含源点 → 每次选 V−S 中 dist 最小者加入 → 以其更新邻接点 dist[u]+w < dist[w]；O(n²)（堆优化 O(e log n)）
  • 例（1→2:2, 1→3:5, 2→3:1, 2→4:7, 3→4:3）→ dist：1→2=2、1→3=3、1→4=6
  • Floyd（所有点对，动态规划）：D⁽ᵏ⁾[i][j]=min(D⁽ᵏ⁻¹⁾[i][j], D⁽ᵏ⁻¹⁾[i][k]+D⁽ᵏ⁻¹⁾[k][j])，k 逐轮；O(n³)；允许负权（无负环）
  • 例（1→2:4, 2→3:1, 1→3:10）→ k=2 时 1→3 = min(10, 5) = 5
  • 对比：Dijkstra 单源 O(n²)、非负权 ↔ Floyd 全点对 O(n³)、可负权；Dijkstra vs Prim：前者更新"到源点距离和"，后者更新"到树的边权"

七、复杂度速查

  • DFS/BFS：矩阵 O(n²)、邻接表 O(n+e)：
  • Prim O(n²)
  • Kruskal O(e log e)
  • 拓扑排序 O(n+e)
  • 关键路径 O(n+e)
  • Dijkstra O(n²)
  • Floyd O(n³)

八、易混点一句

  • 邻接（顶点间）≠ 关联（顶点与边）：
  • 无向完全图 n(n−1)/2 ↔ 有向完全图 n(n−1)
  • 连通（无向）↔ 强连通（有向互相可达）↔ 弱连通（忽略方向）
  • 邻接矩阵行=出度、列=入度
  • 邻接表求入度难→用逆邻接表
  • 无向图邻接表边结点 2e
  • DFS 用栈、BFS 用队列
  • 生成树（n−1 条边）≠ 最小生成树（权最小）
  • Prim 加点 O(n²) ↔ Kruskal 加边 O(e log e)
  • AOV 顶点=活动（拓扑）↔ AOE 弧=活动（关键路径）
  • ve 正推取 max、vl 逆推取 min
  • 关键活动判据：余量 = 0
  • Dijkstra 非负权 ↔ Floyd 可负权

九、计算模板

  • 度与边：2e = ΣTD；有向 e = ΣID = ΣOD
  • 邻接表结点数：无向 2e、有向 e
  • 搜索序列：按邻接点升序模拟（DFS 栈／BFS 队列）
  • MST：Prim 列候选边表逐次取最小；Kruskal 边排序 + 判环（不同分量才选），凑满 n−1 条；代价=权和
  • 拓扑排序：列各顶点入度 → 反复"输出入度 0 并删出边"
  • 关键路径：正推 ve(max) → 逆推 vl(min) → 活动 e/l/余量 → 余量 0 为关键 → 工期
  • 最短路径：Dijkstra 填 dist 表；Floyd 逐轮更新矩阵

第七章 内部排序 · 考前简记（关键词版）

一、基本概念

  • 排序＝按关键字把记录排成升/降序；主关键字（唯一标识）／次关键字；逆序对＝ikⱼ（≈直接插入的移动次数）；内部排序（全在内存）／外排序（需内外存交换）
  • 稳定＝关键字相等的记录相对次序不变
  • 稳定：直接插入 · 起泡 · 归并 · 基数（+箱子）；不稳定：希尔 · 快速 · 直接选择 · 堆（口诀"快些选堆不稳定"）
  • 评价标准：时间复杂度（比较+移动）· 空间 · 稳定性 · 实现难易 · 数据规模与初始排列 · 是否基于比较
  • 初始排列影响：直接插入/起泡正序最好 O(n)；快速正序或逆序取端点为枢轴最坏 O(n²)；直接选择、堆、归并、基数不受影响

二、八大排序总表（必背）

  • 直接插入：平均：O(n²)；最好：O(n)；最坏：O(n²)；空间：O(1)；稳定：稳定；特点：n 小/基本有序最好；移动≈逆序对
  • 希尔：平均：≈O(n^1.3)；最好：与增量有关；最坏：与增量有关；空间：O(1)；稳定：不稳定；特点：增量分组做插入；d=1 即直接插入
  • 起泡：平均：O(n²)；最好：O(n)；最坏：O(n²)；空间：O(1)；稳定：稳定；特点：相邻交换；最多 n−1 趟
  • 快速：平均：O(n log n)；最好：O(n log n)；最坏：O(n²)；空间：O(log n)；稳定：不稳定；特点：平均最快；枢轴影响大；分治
  • 直接选择：平均：O(n²)；最好：O(n²)；最坏：O(n²)；空间：O(1)；稳定：不稳定；特点：比较固定；交换次数最少
  • 堆排序：平均：O(n log n)；最好：O(n log n)；最坏：O(n log n)；空间：O(1)；稳定：不稳定；特点：最坏不退化；就地
  • 归并：平均：O(n log n)；最好：O(n log n)；最坏：O(n log n)；空间：O(n)；稳定：稳定；特点：需辅助数组；外排序基础
  • 基数：平均：O(d(n+r))；最好：同；最坏：同；空间：O(n+r)；稳定：稳定；特点：非比较；与初始排列无关

三、各算法要点

  • 直接插入：把待排序元素插入前面有序子段（从后往前比较、后移插入）；稳定；最好 O(n)/平均最坏 O(n²)；O(1)
  • 希尔：增量 d 分组 → 组内排序（插入）→ 缩小增量（如 n/2, n/4, …, 1）；不稳定；≈O(n^1.3)；与直接插入关系＝d=1 时就是直接插入
  • 起泡：相邻比较逆序交换，每趟最值到位（整体有序区扩大）；稳定；加"本趟无交换"标志可正序 O(n)
  • 快速：选枢轴 → 一趟划分（枢轴到位，左小右大）→ 递归左右；枢轴选取：首/尾/中间/随机/三元取中；枢轴偏斜 → 退化 O(n²)；不稳定；平均 O(n log n)、空间 O(log n)
  • 直接选择：每趟选最值与无序区首位交换；不稳定；恒 O(n²)、交换最少（≤n−1 次）
  • 堆排序：建初始堆（升序用大顶堆；最后非叶 ⌊n/2⌋−1 起自底向上筛选，建堆 O(n)）→ 堆顶与末尾交换 → 调整剩余堆 → 重复；不稳定；恒 O(n log n)、O(1)
  • 归并：合并两个有序段；递归（自顶向下）/非递归（自底向上，长度 1→2→4→…）；稳定；恒 O(n log n)、空间 O(n)；外排序基础
  • 基数：按位"分配—收集"（LSD 从个位起，十位、百位…），d 趟；稳定；O(d(n+r))、空间 O(n+r)；不比较关键字，不受 O(n log n) 下界限制

四、经典示例（49 38 65 97 76 13 27 49）

  • 直接插入逐趟：49|38… → 38 49|65… → … → 13 27 38 49 49 65 76 97
  • 希尔(4,2,1)：d=4 → 49 13 27 49 76 38 65 97；d=2 → 27 13 49 38 65 49 76 97；d=1 → 有序
  • 起泡：趟1 38 49 65 76 13 27 49 [97] → 趟5 完成
  • 快速（首元素 49 为枢轴）一趟：27 38 13 [49] 76 97 65 49（枢轴到位）
  • 归并：趟1 38 49 | 65 97 | 13 76 | 27 49 → 趟2 38 49 65 97 | 13 27 49 76 → 趟3 有序
  • 基数（278 109 63 930 589 184 505 269 8 83）按个位一趟 → 930, 63, 83, 184, 505, 278, 8, 109, 589, 269；再做十位、百位 → 有序

六、由结果推测算法

  • 枢轴到位、左小右大 → 快速：
  • 最大/最小元素到位 → 起泡／直接选择
  • 前段局部有序 → 直接插入
  • 按增量 d 分组组内有序 → 希尔

七、关键结论

  • 与初始排列无关：直接选择、堆、归并、基数
  • 正序最好 O(n)：直接插入、起泡
  • 最坏 O(n²) 的高效算法：快速（用三元取中/随机化改善）
  • 空间：O(1)＝插入/希尔/起泡/选择/堆；O(log n)＝快速；O(n)＝归并；O(n+r)＝基数
  • 交换最少：直接选择；比较类排序下界 O(n log n)，基数排序不受限

  • 枢轴取固定端点 + 序列已有序 → 快速退化 O(n²)
  • 升序堆排序用大顶堆
  • 直接选择 O(n²) ↔ 堆排序 O(n log n)
  • 归并稳定但 O(n) 空间 ↔ 快速就地但不稳定、最坏 O(n²)
  • 基数排序不比较关键字

第八章 查找 · 考前简记（关键词版）

一、基本概念

  • 查找＝在查找表中找关键字等于给定值的记录；单值查找／范围查找；查找表（静态/动态）；成功/不成功查找；内部/外部查找
  • ASL = Σ pᵢ·cᵢ（平均查找长度；等概率 pᵢ=1/n）——分成功 ASL 与不成功 ASL
  • 适用条件速记：无序+链式→顺序查找；有序+顺序存储→折半查找；块间有序块内无序→分块查找；动态→BST/AVL/B 树；精确查找→哈希

二、顺序表查找（必背 ASL）

  • 顺序查找：条件：顺序/链式、不需有序；ASL：成功 (n+1)/2、不成功 n+1；复杂度：O(n)
  • 折半查找：条件：必须有序 + 顺序存储；ASL：≈ log₂(n+1) − 1；最大比较次数 = ⌊log₂n⌋+1；复杂度：O(log₂n)

  • 分块（索引顺序）查找：条件：顺序存储 + 索引表；块间有序、块内无序；ASL：(b+1)/2 + (s+1)/2；最优 s = b = √n → ≈ √n + 1；复杂度：O(√n)

  • 折半判定树（n=11）：各层结点数 1、2、4、4 → ASL = (1×1+2×2+3×4+4×4)/11 = 33/11 = 3；树高 = 4

三、树形结构的查找

  • BST 性质：左子树 < 根 < 右子树；中序遍历得递增序列
  • 查找：小走左、大走右；比较次数 ≤ 树高；插入：总是插在叶子（查找失败处）；效率取决于树形：接近平衡 O(log₂n)、有序插入退化为单支树 O(n)
  • 删除三情况：① 叶子→直接删 ② 只有一个子树→子树顶替 ③ 左右都有→中序前驱/后继顶替其值，再删该结点

  • 示例：插入 45,24,53,12,37,93 → 删 24（双子树）用中序后继 37 顶替

  • AVL 树：任一结点左右子树高差 ≤1；平衡因子 BF ∈ {−1,0,1}

类型 情形 旋转
LL 插在左子树的左侧 右单旋
RR 插在右子树的右侧 左单旋
LR 插在左子树的右侧 先左后右（双旋）
RL 插在右子树的左侧 先右后左（双旋）
  • 例：插入 16,3,7 → 16 处 BF=2、LR 型 → 结果根 7（左 3、右 16）

  • AVL 树高 ≈ 1.44log₂n → 查找/插入/删除 O(log₂n)

  • B 树：m 阶——每结点最多 m 棵子树 / m−1 个关键字；根≥2 棵子树；非根非叶结点≥⌈m/2⌉ 棵子树；所有叶在同一层（绝对平衡）

  • 查找：结点内顺序/折半 → 沿指针下移；插入：插入最底层叶结点 → 溢出（关键字数 > m−1）则分裂：中间关键字上移父结点，左右两半成两个结点；可能向上传播（根分裂则树高 +1）
  • 示例（3 阶）：插 1,2 → [1 2]；插 3 → 溢出 → 根 [2]，叶 [1] [3]；插 4,5 → 根 [2 4]，叶 [1] [3] [5]

四、哈希表

  • 术语：哈希表 · 哈希函数 H(k) · 哈希地址 · 冲突（不同关键字同地址）· 同义词 · 完美哈希函数 · 装填因子 α = n/m · 基本聚集（线性探测的连续占用）· 二级聚集（二次探测同义词同序列）
  • 哈希函数构造 6 法：直接定址法 H=a·k+b；数字分析法（取分布均匀位）；平方取中法（取 k² 中间位）；折叠法（分段相加）；除留余数法 H=k mod p（p 取 ≤m 的质数，最常用）；基数转换法
  • 冲突解决 4 类
方法 做法 特点
开放地址法 H_i=(H(k)+d_i) mod m 表内寻空位
├ 线性探测 d = 1,2,3,… 简单但基本聚集
├ 二次探测 d = ±1²,±2²,… 减轻基本聚集，有二级聚集
└ 伪随机/再散列 d 取伪随机或另一函数 聚集更少

五、各查找方法对比（必背）

  • 顺序查找：存储：顺序/链式；有序：不需；ASL：成功 (n+1)/2；复杂度：O(n)；适合：表小、无序
  • 折半查找：存储：必须顺序；有序：必须有序；ASL：≈ log₂(n+1)−1；复杂度：O(log₂n)；适合：有序表频繁查询
  • 分块查找：存储：顺序+索引；有序：块间有序；ASL：(b+1)/2+(s+1)/2 → ≈√n+1；复杂度：O(√n)；适合：大表、分块组织
  • BST：存储：链式；有序：BST 性质；ASL：与树高有关；复杂度：最好 O(log₂n)、最坏 O(n)；适合：动态查找表
  • AVL：存储：链式；有序：BST+平衡；ASL：O(log₂n)；复杂度：稳定 O(log₂n)；适合：查/插/删都要求快
  • B 树/B+ 树：存储：外存块；有序：多路平衡；ASL：O(log_m n)；复杂度：稳定；适合：外存索引/数据库
  • 哈希：存储：散列表；有序：不需；ASL：与 α 有关（1+α/2）；复杂度：平均 O(1)；适合：只做精确查找

六、易混点一句

  • 折半必须"有序 + 顺序存储"（链式不行）：
  • 判定树高度=最大比较次数、ASL=平均比较次数
  • 顺序查找不成功需 n（或 n+1）次
  • 分块最优 s=b=√n
  • BST 插入总在叶子
  • BST 删除双子树用中序前驱/后继顶替
  • BST 有序插入→单支树 O(n)
  • LL→右单旋、RR→左单旋、LR→先左后右、RL→先右后左
  • m 阶 B 树：≤m 子树、≤m−1 关键字、非根非叶≥⌈m/2⌉ 子树、叶同层
  • B 树分裂＝中间关键字上移
  • 哈希效率看 α（不是 n）
  • 线性探测→基本聚集；二次探测→二级聚集
  • 链地址法不聚集
  • 哈希表不能范围查找

七、计算模板

  • 顺序查找：成功 (n+1)/2、不成功 n+1
  • 折半：画判定树（每次 mid）→ 各层结点数 → ASL=Σ(层×结点数)/n；max 比较 = ⌊log₂n⌋+1
  • 分块：ASL=(b+1)/2+(s+1)/2，最优 s=b=√n
  • BST：按序插入画树 → 中序验证 → 删除按三情况 → ASL=Σ(结点层数)/n
  • AVL：找最小不平衡子树 → 判 LL/RR/LR/RL → 旋转并验证 BF
  • B 树：逐个插入 → 溢出则中间关键字上移 + 左右分裂，可能向上传播
  • 哈希：按 H(k) 定地址 → 冲突按探测序列试放（记录比较次数）→ 成功 ASL=Σcᵢ/n；不成功 ASL=Σ(各地址探测到空的次数)/m；α=n/m

四、算法步骤链（背诵用）

  • 顺序表插入：判满 → 判位置 → 从后往前移 → 写 e → 长+1

  • 中缀转后缀：操作数输出 → 运算符按"栈空/栈顶( / 优先级高"入栈，否则弹栈输出 → ) 弹至 ( → 结束全弹
  • 后缀求值：操作数入栈；运算符弹两个（先弹的是右操作数）算 左 op 右 再入栈
  • 先序遍历非递归：弹栈访问 → 先压右、后压左；中序：一路向左入栈 → 弹栈访问 → 转右
  • 层次遍历 / BFS：用队列，出队访问后孩子（邻接点）入队
  • 建堆：自最后一个非叶 ⌊n/2⌋−1 起自底向上筛选
  • 哈夫曼构造：每次取两个最小权合并，共 n−1 次
  • 树/森林 → 二叉树：左指针 = 第一个孩子，右指针 = 下一个兄弟
  • DFS / BFS：DFS 用栈、BFS 用队列，均需 visited[]
  • Prim：每次选"已选集 ↔ 未选集"的最小边；Kruskal：边升序 + 判环，凑满 n−1 条
  • 拓扑排序：选入度 0 → 输出 → 删其出边 → 重复（不能全输出即有环）
  • 关键路径：正推 ve(max) → 逆推 vl(min) → 算 e、l、余量 → 余量 0 为关键活动
  • Dijkstra：选 dist 最小者入 S → 用 dist[u]+w 更新；Floyd：D[i][j]=min(D[i][j], D[i][k]+D[k][j])
  • 折半查找：mid=⌊(low+high)/2⌋ 比较后缩区间
  • BST 插入：查找到空位置插入（总在叶子）；删除双子树结点：中序前驱/后继顶替再删
  • AVL 旋转：LL→右单旋 · RR→左单旋 · LR→先左后右 · RL→先右后左
  • B 树插入分裂：中间关键字上移父结点，左右分裂，可向上传播
  • 哈希建表：H(k) 定地址 → 冲突按探测序列（线性 +1,+2,…；二次 ±1²,±2²…）试放 → 统计比较次数算 ASL
