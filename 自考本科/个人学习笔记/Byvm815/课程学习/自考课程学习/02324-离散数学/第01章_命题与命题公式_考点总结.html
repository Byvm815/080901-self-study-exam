二、1.1 命题与命题联结词（领会）

（一）命题

  • 1. 命题：能够判断真假的陈述句。
  • 命题的真值只有两个：真（T / 1） 与 假（F / 0），且唯一确定；

  • 命题标识符（命题变元）：p、q、r、…（取值 T 或 F）；命题常元：T（真）、F（假）。

  • 2. 不是命题的常见情形（易考判断）

情形 例子 原因
疑问句 "今天下雨吗？" 不陈述
祈使句 / 命令句 "请关门！" 无真假
感叹句 "多么美的风景！" 无真假
悖论 "本语句是假的" 真假如 "假" 则真、如 "真" 则假，自相矛盾
含未确定变元的句子 "x > 3"（x 未定） 真值随 x 而定，本身无确定真值（命题函数）
真值未知但客观确定的陈述 "地球外存在生命" 仍是命题（真假客观确定，只是目前不知道）

结论：判断是否为命题看两点——① 是陈述句；② 有唯一确定的真假（与是否"知道"真假无关）。

  • 3. 复合命题：由原子命题经联结词连接而成的命题。

（二）五个基本联结词（必考，真值表必须背熟）

  • 否定：记号：¬p；读法：非 p；真值规则：p 真则 ¬p 假；p 假则 ¬p 真
  • 合取：记号：p∧q；读法：p 且 q；真值规则：同真才真
  • 析取：记号：p∨q；读法：p 或 q（可兼或）；真值规则：至少一个为真即真
  • 蕴涵（条件）：记号：p→q；读法：如果 p 则 q；真值规则：仅当 p 真 q 假时为假，其余为真
  • 等价（双条件）：记号：p↔q；读法：p 当且仅当 q；真值规则：p 与 q 同真同假时为真

  • （异或/排斥或）【注意】：记号：p⊕q；读法：p 与 q 不同时为真；真值规则：视教材是否列为基本联结词

  • 真值表

  • 0：q：0；¬p：1；p∧q：0；p∨q：0；p→q：1；p↔q：1；p⊕q：0

  • 0：q：1；¬p：1；p∧q：0；p∨q：1；p→q：1；p↔q：0；p⊕q：1
  • 1：q：0；¬p：0；p∧q：0；p∨q：1；p→q：0；p↔q：0；p⊕q：1

  • 1：q：1；¬p：0；p∧q：1；p∨q：1；p→q：1；p↔q：1；p⊕q：0

  • 蕴涵 p→q 的要点

  • p 稱前件（条件、假设），q 稱后件（结论）;
  • p 为假时，p→q 一律为真（"善意推定"）；
  • p→q 为假只有一个情形：p 真而 q 假；

  • 自然语言中"如果…那么…"的因果含义在数理逻辑中不予考虑（只按真值表判定）。

  • 运算次序（优先级，【注意】 以教材为准）

  • ¬ > ∧ > ∨ > → > ↔（即：否定最优先，→ 低于 ∨ 而高于 ↔）；同级从左到右；括号优先。

（三）自然语言的符号化（领会，必考）

自然语言表述 符号化
p 且 q / 既 p 又 q / p 与 q p∧q
p 或 q（可兼或） p∨q
要么 p 要么 q（排斥或） (p∧¬q)∨(¬p∧q) 或 p⊕q
如果 p 则 q / p 是 q 的充分条件 / 只要 p 就 q / p 推出 q p→q
只有 p 才 q / p 是 q 的必要条件 / q 仅当 p q→p
p 当且仅当 q / p 与 q 等价 p↔q
除非 p，否则 q ¬p→q（即 p∨q）
并非 p / p 不成立 ¬p
不 p 不 q（"既不…也不…"） ¬p∧¬q

  • 符号化步骤：① 找出所有原子命题并令其为一个命题变元；② 确定联结词及其层次（括号）；③ 按优先级写成公式。

  • 例：将"如果明天不下雨，我们就去郊游；否则我们就在家看书"符号化。
    设 p：明天下雨；q：我们去郊游；r：我们在家看书。
    → ¬p→q 与 p→r，合起来写作 (¬p→q)∧(p→r)。

三、1.2 命题公式的等值演算（简单应用，本章核心）

（一）命题公式

  • 1. 合式公式（命题公式，WFF）的递归定义
    ① 单个命题变元或命题常元是合式公式；
    ② 若 A 是合式公式，则 ¬A 是合式公式；
    ③ 若 A、B 是合式公式，则 (A∧B)、(A∨B)、(A→B)、(A↔B) 是合式公式；
    ④ 只有有限次应用 ①②③ 得到的符号串才是合式公式。

  • 2. 赋值（解释）：给公式中每个命题变元指定一个真值（0/1）：

  • 使公式为真的赋值稱成真赋值；使公式为假的赋值稱成假赋值；

  • n 个命题变元共有 2ⁿ 个赋值（真值表有 2ⁿ 行）。

  • 3. 真值表：列出所有赋值与对应公式真值的表，用于判断公式类型。

  • 例：A = p→(q∨¬r)，3 个变元 → 8 行真值表；当 p=1、q=0、r=1 时 q∨¬r = 0∨0 = 0，故 A = 0（唯一的成假赋值之一 【注意】 逐个算清）。

（二）公式的分类（必考）

类型 定义 例
重言式（永真式） 在所有赋值下都为真 p∨¬p
矛盾式（永假式） 在所有赋值下都为假（不可满足式） p∧¬p
可满足式 至少有一个成真赋值 p∧q、p→q
  • 关系：重言式的否定是矛盾式，矛盾式的否定是重言式；重言式都是可满足式，矛盾式一定不是可满足式；既非重言式也非矛盾式的公式是可满足式（且也是可非满足式，即都有成真与成假赋值）。

（三）等值（等价）与基本等值式

  • 1. 等值的定义：设 A、B 为两个命题公式，若 A↔B 是重言式，则稱 A 与 B 等值（等价），记作 A⇔B（或 A = B）。
  • 等值关系满足自反性、对称性、传递性；

  • 判断两公式是否等值：可用 真值表法（对比两列真值）或 等值演算法。

  • 2. 常用等值式（命题定律，必背，考试中大量使用）

名称 等值式
双重否定律 ¬¬A ⇔ A
幂等律 A∨A ⇔ A；A∧A ⇔ A
交换律 A∨B ⇔ B∨A；A∧B ⇔ B∧A
结合律 (A∨B)∨C ⇔ A∨(B∨C)；(A∧B)∧C ⇔ A∧(B∧C)
分配律 A∨(B∧C) ⇔ (A∨B)∧(A∨C)；A∧(B∨C) ⇔ (A∧B)∨(A∧C)
德摩根律 ¬(A∨B) ⇔ ¬A∧¬B；¬(A∧B) ⇔ ¬A∨¬B
吸收律 A∨(A∧B) ⇔ A；A∧(A∨B) ⇔ A
零律 A∨1 ⇔ 1；A∧0 ⇔ 0
同一律 A∨0 ⇔ A；A∧1 ⇔ A
排中律 A∨¬A ⇔ 1
矛盾律 A∧¬A ⇔ 0
蕴涵等值式 A→B ⇔ ¬A∨B
等价等值式 A↔B ⇔ (A→B)∧(B→A)；A↔B ⇔ (A∧B)∨(¬A∧¬B)
假言易位（逆否） A→B ⇔ ¬B→¬A
等价否定等值式 A↔B ⇔ ¬A↔¬B
归谬论 (A→B)∧(A→¬B) ⇔ ¬A

  • 3. 等值演算的方法与套路
    ① 消去 →、↔（用蕴涵等值式、等价等值式）；
    ② 用德摩根律把 ¬ 内移（内移到变元前）；
    ③ 用分配律、吸收律化简；
    ④ 目标形式：析取范式 / 合取范式 / 主范式（第 2 章）或最简形式。

  • 例 1（化简）：化简 (p→q)∧(p→¬q)
    = (¬p∨q)∧(¬p∨¬q) 　（蕴涵等值式）
    = ¬p∨(q∧¬q) 　（分配律）
    = ¬p∨0 　（矛盾律）
    = ¬p 　（同一律）　→ 说明该式等值于 ¬p。

  • 例 2（判断类型）：判断 p→(q→p) 的类型
    = ¬p∨(¬q∨p)
    = (¬p∨p)∨¬q = 1∨¬q = 1 → 是重言式。

  • 例 3（证明等值）：证明 (p∧q)→r ⇔ p→(q→r)
    右边 = p→(¬q∨r) = ¬p∨¬q∨r；
    左边 = ¬(p∧q)∨r = ¬p∨¬q∨r　→ 左右相等 ✓（稱输出律：p∧q→r ⇔ p→(q→r)）

（四）蕴涵（蕴含）与常用蕴涵式

  • 1. 蕴涵的定义：若 A→B 是重言式，则稱 A 蕴涵 B，记作 A⇒B（A 推出 B）。
  • 等值与蕴涵的区别：A⇔B 要求 A↔B 是重言式（双向）；A⇒B 只要求 A→B 是重言式（单向）；
  • A⇔B 的充要条件是 A⇒B 且 B⇒A；

  • 注意：公式 p→q 为真并不代表 p⇒q（必须在所有赋值下为真）。

  • 2. 常用蕴涵式（必背）

名称 蕴涵式
附加 A ⇒ A∨B
化简 A∧B ⇒ A（也 ⇒ B）
假言推理 A∧(A→B) ⇒ B
拒取式 (A→B)∧¬B ⇒ ¬A
析取三段论 (A∨B)∧¬A ⇒ B
假言三段论 (A→B)∧(B→C) ⇒ A→C
等价三段论 (A↔B)∧(B↔C) ⇒ A↔C
构造性二难 (A→B)∧(C→D)∧(A∨C) ⇒ B∨D
破坏性二难 (A→B)∧(C→D)∧(¬B∨¬D) ⇒ ¬A∨¬C
合取引入 A，B ⇒ A∧B
  • 3. 等值演算的应用：化简逻辑表达式（数字电路化简）、判断公式类型（是否重言式）、证明两公式等值、为推理证明作准备。

四、1.3 联结词完备集（领会）

  • 1. 联结词完备集（全功能集）：若任何一个命题公式都能用某个联结词集合中的联结词等值地表示，则稱该集合为联结词完备集。

  • 2. 常见完备集（都会写等值转换）

完备集 说明
{¬, ∧, ∨} 最基本的完备集
{¬, ∧} ∨ 可消去：A∨B ⇔ ¬(¬A∧¬B)
{¬, ∨} ∧ 可消去：A∧B ⇔ ¬(¬A∨¬B)
{¬, →} A∨B ⇔ ¬A→B
{↑}（与非，谢费尔竖） 单个联结词即可构成完备集
{↓}（或非，皮尔斯箭头） 单个联结词即可构成完备集
  • 3. 与非、或非的定义（必记）
  • 与非：p↑q ⇔ ¬(p∧q)；可表示：¬p ⇔ p↑p；p∧q ⇔ ¬(p↑q) ⇔ (p↑q)↑(p↑q)；p∨q ⇔ (p↑p)↑(q↑q)；

  • 或非：p↓q ⇔ ¬(p∨q)；可表示：¬p ⇔ p↓p；p∨q ⇔ (p↓q)↓(p↓q)；p∧q ⇔ (p↓p)↓(q↓q)。

  • 4. 最小完备集：若某完备集去掉任何一个联结词后就不再完备，则稱为最小完备集（如 {¬,∧}、{¬,∨}、{¬,→}、{↑}、{↓}）。

五、本章对比与易混点

易混点 正确理解
命题 vs 命题变元 命题有确定真值；命题变元是可取真假值的符号
"含变量 x 的句子" "x > 3" 本身不是命题（是真值随 x 变的命题函数），但 "∀x(x>3)" 或给定 x 值后才是命题
p→q 的假值条件 只有 p 真、q 假时为假；p 假时 p→q 为真
充分 vs 必要条件 "p 是 q 的充分条件" → p→q；"p 是 q 的必要条件" → q→p
"只有 p 才 q" 翻译为 q→p（p 是 q 的必要条件）
"除非 p，否则 q" 翻译为 ¬p→q（等价于 p∨q）
可兼或 vs 排斥或 可兼或 → p∨q；排斥或 → (p∧¬q)∨(¬p∧q)
重言式 / 矛盾式 / 可满足式 全真 / 全假 / 至少一个成真赋值；矛盾式不可满足
等值 vs 蕴涵 A⇔B 需 A↔B 为重言式（双向）；A⇒B 只需 A→B 为重言式（单向）
⇔ / ⇒ 与 ↔ / → 前两者是关系符号（元语言，表示"等值/蕴涵"）；后两者是联结词（对象语言，构成公式）

运算次序 ¬ > ∧ > ∨ > → > ↔（【注意】 以教材为准），不确定时加括号

（三）计算 / 证明题模板

  • 符号化：设变元 → 找联结词与层次 → 写公式（注意必要条件要"倒过来"）。
  • 构造真值表：列 2ⁿ 个赋值 → 逐层计算子公式 → 得主联结词列 → 判断类型。
  • 判断公式类型：真值表法（看列）或等值演算法（化到 1 或 0）。
  • 等值演算证明：① 消去 →、↔；② 德摩根内移；③ 分配/吸收化简；④ 两边化到同一形式；每步注明所用定律名称（阅卷按步给分）。
  • 判断蕴涵是否成立：只需检查 A→B 是否重言式；可用真值表或等值演算（化为 1），或找一个成假赋值来举反例否定。
