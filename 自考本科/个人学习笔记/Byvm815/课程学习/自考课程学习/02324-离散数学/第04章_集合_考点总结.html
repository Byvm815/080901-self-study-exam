二、4.1 集合的基本概念（领会）

（一）集合与元素

  • 1. 集合：把一些确定的、彼此不同的对象作为一个整体来考虑，这个整体就是集合；其中的对象称集合的元素。
  • 元素与集合的关系：属于 ∈ 或 不属于 ∉（二者必居其一）；

  • 集合的三大特征：确定性（任一对象是否属于该集合是确定的）、互异性（元素彼此不同，重复书写不增加元素）、无序性（元素的排列顺序无关）。

  • 2. 常用数集记号

记号 含义
N 自然数集（有的教材含 0 【注意】）
Z 整数集
Q 有理数集
R 实数集
C 复数集
Z⁺（N⁺） 正整数集
  • 3. 集合的三种表示法
表示法 形式 例
列举法（枚举法） 把元素一一列出 A = {a, b, c}；B = {1, 2, 3, …}
描述法（谓词法） A = {x P(x)}
图示法（文氏图） 用封闭曲线表示集合与元素的关系 用于直观说明（一般不作严格证明）

（二）集合间的关系

概念 定义 备注
子集 A ⊆ B ⟺ 对任意 x，x∈A → x∈B 空集是任何集合的子集：∅ ⊆ A
真子集 A ⊂ B ⟺ A ⊆ B 且 A ≠ B 任何集合是自身的子集（A ⊆ A）
相等 A = B ⟺ A ⊆ B 且 B ⊆ A 证明集合相等的标准方法
空集 ∅ 不含任何元素的集合 ∅ ⊆ A 恒成立；∅ ∈ A 一般不成立；空集唯一
全集 E（U） 所讨论对象的全体（相对概念） 与讨论范围有关
  • 区分"属于"与"包含"（高频易错）
  • ∈ / ∉：元素与集合之间的关系；
  • ⊆ / ⊂：集合与集合之间的关系；
  • 例：∅ ∈ {∅} 成立（{∅} 有一个元素 ∅）；∅ ⊆ {∅} 也成立。

（三）幂集

  • 幂集 P(A)：A 的所有子集构成的集合（也记作 2^A）。

  • 基数公式：若 A 是有限集，|P(A)| = 2^|A|。

  • 例：A = {a, b} → P(A) = {∅, {a}, {b}, {a, b}}，|P(A)| = 2² = 4。

  • 例：A = {a, {b}} → P(A) = {∅, {a}, {{b}}, {a, {b}}}，|P(A)| = 4。

  • 例（易错）：P(∅) = {∅}（|P(∅)| = 1）；P({∅}) = {∅, {∅}}（|P({∅})| = 2）。

  • 幂集的性质：P(A) ∩ P(B) = P(A∩B)；P(A) ∪ P(B) ⊆ P(A∪B)（不一定相等）。

（四）有限集、无限集、可数集与不可数集（领会）

概念 含义
有限集 / 无限集 元素个数有限 / 无限；有限集合 A 的**基数
可数集（可列集） 能与自然数集 N 建立一一对应的集合
不可数集 不能与 N 建立一一对应的无限集
  • 基数比较（了解）
  • |N| = |Z| = |Q| = ℵ₀（可数无限；整数集、有理数集都是可数集）；
  • |R| = ℵ > ℵ₀（实数集是不可数集）；
  • 康托尔定理：对任何集合 A，|P(A)| = 2^|A| > |A|（幂集的基数严格大于原集合）；
  • 有限集的基数就是元素个数：|∅| = 0；|{a,b,c}| = 3。

三、4.2 集合的运算（简单应用，本章核心）

（一）五种基本运算

运算 定义 说明
并 A∪B {x x∈A ∨ x∈B}
交 A∩B {x x∈A ∧ x∈B}
差（相对补） A−B {x x∈A ∧ x∉B}
补（绝对补） ~A（Ā） E − A = {x x∈E ∧ x∉A}
对称差 A⊕B 【注意】 (A−B)∪(B−A) = (A∪B)−(A∩B) 属于且仅属于其中一个
  • 关键转化：A − B = A∩~B（把差化为交与补，是证明恒等式的常用手段）。
  • 互斥（不相交）：A∩B = ∅。
  • 有限集基数（容斥原理，了解）：|A∪B| = |A| + |B| − |A∩B|；|A∪B∪C| = |A|+|B|+|C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|。

（二）运算律（与第 1 章命题定律一一对应，必背）

  • 幂等律：集合恒等式：A∪A = A；A∩A = A；对应命题定律：A∨A ⇔ A
  • 交换律：集合恒等式：A∪B = B∪A；A∩B = B∩A；对应命题定律：A∨B ⇔ B∨A
  • 结合律：集合恒等式：(A∪B)∪C = A∪(B∪C)；(A∩B)∩C = A∩(B∩C)；对应命题定律：结合律
  • 分配律：集合恒等式：A∪(B∩C) = (A∪B)∩(A∪C)；A∩(B∪C) = (A∩B)∪(A∩C)；对应命题定律：分配律
  • 德摩根律：集合恒等式：~(A∪B) = ~A∩~B；~(A∩B) = ~A∪~B；对应命题定律：¬(A∨B) ⇔ ¬A∧¬B
  • 吸收律：集合恒等式：A∪(A∩B) = A；A∩(A∪B) = A；对应命题定律：吸收律
  • 零律：集合恒等式：A∪E = E；A∩∅ = ∅；对应命题定律：A∨1 ⇔ 1；A∧0 ⇔ 0
  • 同一律：集合恒等式：A∪∅ = A；A∩E = A；对应命题定律：A∨0 ⇔ A；A∧1 ⇔ A
  • 排中律：集合恒等式：A∪~A = E；对应命题定律：A∨¬A ⇔ 1
  • 矛盾律：集合恒等式：A∩~A = ∅；对应命题定律：A∧¬A ⇔ 0

  • 双重否定律：集合恒等式：~~A = A；对应命题定律：¬¬A ⇔ A

  • 差与补的常用恒等式（高频）

  • A − B = A∩~B
  • A − B = A − (A∩B)
  • (A − B) − C = A − (B∪C)
  • A − (B∪C) = (A − B)∩(A − C)
  • A − (B∩C) = (A − B)∪(A − C)（"差对并交的德摩根式"）
  • (A∪B) − C = (A − C)∪(B − C)

  • A ⊆ B ⟺ A∩B = A ⟺ A∪B = B ⟺ A − B = ∅ ⟺ ~B ⊆ ~A（包含的五种等价刻画，常考）

  • 对称差的性质（了解）：A⊕B = B⊕A；A⊕A = ∅；A⊕∅ = A；(A⊕B)⊕C = A⊕(B⊕C)。

（三）集合恒等式的三种证明方法（必考题型）

方法 思路 说明
① 命题演算法（元素法） 用"x∈左边 ⟺ … ⟺ x∈右边"逐步等值变形 最常用、最严格；也可分证 A⊆B 与 B⊆A
② 恒等式代入法（等值演算法） 用已知恒等式（分配律、德摩根、吸收律…）逐步变形 类似第 1 章的等值演算，每步要写依据
③ 文氏图法 画图比较 仅用于直观验证/说明，不能作为严格证明

  • 【例 1；元素法】证明 A − (B∪C) = (A − B)∩(A − C)
    对任意 x：
    x ∈ A − (B∪C)
    ⟺ x∈A ∧ x∉(B∪C)
    ⟺ x∈A ∧ ¬(x∈B ∨ x∈C)　（属于并集的定义）
    ⟺ x∈A ∧ (x∉B ∧ x∉C)　（德摩根）
    ⟺ (x∈A ∧ x∉B) ∧ (x∈A ∧ x∉C)　（交换、结合、幂等）
    ⟺ x ∈ (A − B) ∧ x ∈ (A − C)
    ⟺ x ∈ (A−B)∩(A−C)　⇒ 两边相等 ✓

  • 【例 2；元素法】证明 (A − B) − C = A − (B∪C)
    x ∈ (A−B) − C ⟺ (x∈A ∧ x∉B) ∧ x∉C ⟺ x∈A ∧ (x∉B ∧ x∉C) ⟺ x∈A ∧ x∉(B∪C) ⟺ x ∈ A − (B∪C) ✓

  • 【例 3；恒等式代入法】证明 A∪(A∩B) = A（吸收律）
    A∪(A∩B) = (A∩E)∪(A∩B)（同一律）= A∩(E∪B)（分配律）= A∩E（零律）= A（同一律）✓

  • 【例 4；分证互含】证明 (A−B)∪B = A∪B
    ① 证左 ⊆ 右：若 x ∈ (A−B)∪B，则 x∈A−B 或 x∈B；前者给出 x∈A（⇒ x∈A∪B），后者给出 x∈A∪B → 左 ⊆ 右；
    ② 证右 ⊆ 左：若 x ∈ A∪B，则 x∈A 或 x∈B。若 x∈B，则 x∈左；若 x∉B，则 x∈A 且 x∉B ⇒ x∈A−B ⊆ 左 → 右 ⊆ 左；
    ∴ 两边相等 ✓

  • 【例 5；用包含等价刻画】证明 A ⊆ B ⟺ A∩B = A
    若 A ⊆ B：对 x∈A∩B 有 x∈A（⇒ A∩B ⊆ A）；对 x∈A，由 A ⊆ B 得 x∈B，故 x∈A∩B（⇒ A ⊆ A∩B）→ 相等；
    反之若 A∩B = A，则对 x∈A 有 x∈A∩B ⇒ x∈B，故 A ⊆ B ✓

四、4.3 有序对与笛卡儿积（简单应用）

（一）有序对与有序 n 元组

  • 1. 有序对（序偶）：由两个对象按确定的顺序构成的二元组。

  • 要点： ≠ （当 x ≠ y 时）——这与集合 {x, y} = {y, x} 完全不同。

  • 2. 有序对的集合性定义（Kuratowski 定义）

  • = {{x}, {x, y}}

  • 定理（唯一性）： = ⟺ x = u 且 y = v。

  • 3. 有序 n 元组 ：同理， = ⟺ xᵢ = yᵢ（i = 1,…,n）。

（二）笛卡儿积（直积）

  • 定义：A × B = { | x∈A ∧ y∈B}

  • 特例：A × A 记作 A²（如 R² = R×R 表示平面上的点集）。

  • 例：A = {1, 2}，B = {a, b} → A×B = {<1,a>, <1,b>, <2,a>, <2,b>}，|A×B| = 2×2 = 4；
    B×A = {, , , }，A×B ≠ B×A ✓

（三）计算 / 证明题模板

  • 求幂集：列出全部子集（注意 ∅ 与自身必在），个数核对 2^n；含嵌套元素时逐层区分。
  • 判断关系：先判断是"元素∈集合"还是"集合⊆集合"，再逐项验证。
  • 集合恒等式证明（元素法）：写"对任意 x，x∈左 ⟺ … ⟺ x∈右"，每步注明依据（定义、德摩根、分配律等）。
  • 集合恒等式证明（代入法）：从复杂一侧出发，用恒等式逐步化简到另一侧，每步写依据。
  • 证明包含：证 A ⊆ B 即证"x∈A ⇒ x∈B"；证明相等即双向包含。
  • 笛卡儿积计算：逐个构造有序对 → 核对 |A×B| = |A|·|B|；讨论交换/结合/分配性质时举反例即可否定，用定义证明才能肯定。
  • 由 |P(A)| 求 |A|：|A| = log₂|P(A)|。
