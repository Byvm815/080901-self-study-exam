## 二、9.1 欧拉图与哈密顿图（简单应用）

### （一）欧拉图（关注"边"）

| 术语 | 定义 |
|---|---|
| **欧拉通路（欧拉迹）** | 经过图中**每条边一次且仅一次**的通路 |
| **欧拉回路** | 经过每条边一次且仅一次的**回路** |
| **欧拉图** | **存在欧拉回路**的图 |
| **半欧拉图（一笔画图）** | 存在欧拉通路但**不存在**欧拉回路的图 |

**⭐ 欧拉定理（判别，必背）**

| 图 | 存在欧拉通路/回路的充要条件 |
|---|---|
| **无向图** | **有欧拉回路 ⟺ G 连通且所有顶点的度都是偶数**（此时是欧拉图） |
| **无向图** | **有欧拉通路（无欧拉回路）⟺ G 连通且恰有 2 个奇度顶点**（这两个奇度顶点必为通路的两个端点，即半欧拉图） |
| **有向图** | **有欧拉回路 ⟺ D 强连通且每个顶点的入度 = 出度** |
| **有向图** | **有欧拉通路 ⟺ D 单向连通，且除两个顶点外各顶点入度 = 出度**（一个顶点出度比入度大 1 = 起点，另一个入度比出度大 1 = 终点） |

**判别与应用示例**
| 图 | 判别 | 结论 |
|---|---|---|
| **K₅**（5 阶完全图） | 连通，每个顶点度 = 4（**都是偶数**） | **欧拉图**（存在欧拉回路） |
| **两个三角形共用一个顶点的图** | 连通，公共顶点度为 4、其余 4 个顶点度均为 2（**全偶**） | **欧拉图** |
| **K₄** | 连通，但 4 个顶点度都是 3（**4 个奇度顶点**） | **既无欧拉回路又无欧拉通路**（不能一笔画） |
| **恰有 2 个奇度顶点的连通图** | 满足半欧拉条件 | **可一笔画**（从一奇度点出发、另一奇度点结束），但**不能回到起点** |
| **有向图：每点入度 = 出度且强连通** | 满足条件 | **有向欧拉图** |

**应用**：**一笔画问题**（判断能否不重复地走遍所有边）、邮递员（中国邮路）问题（了解）。

### （二）哈密顿图（关注"顶点"）

| 术语 | 定义 |
|---|---|
| **哈密顿通路** | 经过图中**每个顶点一次且仅一次**的通路（即含全部顶点的初级通路） |
| **哈密顿回路** | 经过每个顶点一次且仅一次的回路（含全部顶点的初级回路） |
| **哈密顿图** | **存在哈密顿回路**的图 |

**⭐ 判别（至今没有充要条件，只有必要/充分条件）**

| 类型 | 内容 | 用途 |
|---|---|---|
| **必要条件** | 若 G 是哈密顿图，则对**任意非空真子集 S ⊊ V**，都有 **p(G − S) ≤ \|S\|**（p 为 G − S 的连通分支数） | **主要用于否定**（找到一个 S 使不等式不成立 ⇒ 非哈密顿图） |
| **充分条件：狄拉克定理** | n（≥3）阶**简单图**，若**每个顶点的度 ≥ n/2**，则 G 是哈密顿图 | 判定是（**不满足时不能否定**） |
| **充分条件：奥尔定理** | n（≥3）阶**简单图**，若对**任意两个不相邻的顶点 u、v** 都有 **deg(u) + deg(v) ≥ n**，则 G 是哈密顿图 | 同上 |

**示例**
- **Kₙ（n ≥ 3）是哈密顿图** ✓（且每个顶点度 = n−1 ≥ n/2，符合狄拉克定理）；
- **星形图 K₁,ₙ（n ≥ 3）不是哈密顿图**：取 **S = {中心顶点}**，则 **G − S** 是 n 个孤立顶点，**p(G − S) = n > 1 = |S|** ⇒ 违反必要条件 ⇒ **不是哈密顿图** ✓（**必要条件典型的用法**）；
- 例：6 阶简单图，每个顶点度 ≥ 3 ⇒ 由狄拉克定理是**哈密顿图**；
- 例：6 阶简单图，任意两个不相邻顶点的度之和 ≥ 6 ⇒ 由奥尔定理是**哈密顿图**。

**应用**：旅行商问题（TSP，了解）。

### （三）欧拉图 vs 哈密顿图（对比，必记）

| 比较项 | 欧拉图 | 哈密顿图 |
|---|---|---|
| 遍历对象 | **边**（每条边恰一次） | **顶点**（每个顶点恰一次） |
| 判别难度 | **有充要条件**（欧拉定理，容易判别） | **无充要条件**，只有必要/充分条件（较难） |
| 典型例子 | K₅、Cₙ（n 阶圈） | Kₙ（n ≥ 3）、Cₙ |
| 应用 | 一笔画 | 旅行商 |

## 三、9.2 平面图（简单应用）

### （一）定义与面

**平面图**：若图 G 能**画在平面上**使得**任何两条边除端点外都不相交**（无边交叉），则称 G 为**平面图**（可平面图），这种画法称**平面嵌入**；否则称**非平面图**。
> 注意：**平面图不唯一地看画法**——只要**存在**一种无边交叉的画法即为平面图。

**面与面的次数**
- 平面图把平面分成若干**区域**，每个区域称一个**面**（面数记 **r**，也记 Φ）；
- 面积无限的面称**外部面（无限面）**，其余称内部面；
- **面的次数 deg(f)** = 该面**边界上的边数**（一条边若是两个面的公共边界，则在两个面中各计一次）。

**重要关系**：**Σ_{f} deg(f) = 2m**（各面次数之和 = 边数的 2 倍，与握手定理同源）。

### （二）⭐ 欧拉公式（必背）

**对连通平面图**：**n − m + r = 2**（顶点数 − 边数 + 面数 = 2），即 **r = m − n + 2**。
**对具有 k 个连通分支的平面图**：**n − m + r = k + 1**（即 r = m − n + k + 1）。

**例**：某连通平面图有 n = 6 个顶点、m = 10 条边 ⇒ **r = 2 − n + m = 2 − 6 + 10 = 6** 个面。
**例**：一棵树（连通无圈）m = n − 1 ⇒ r = 2 − n + (n−1) = **1**（只有外部面一个面）✓

### （三）平面图的判别（不等式法，必考）

**由欧拉公式推出的必要条件（用于判"非平面"）**
1. 连通**简单**平面图（**n ≥ 3**）：**m ≤ 3n − 6**；
2. 若连通简单平面图**没有三角形**（每个面次数 ≥ 4，如二部图）：**m ≤ 2n − 4**；
3. 一般地，由 Σdeg(f) = 2m 与每个面次数 ≥ 3（或 ≥ 4）可推出上述不等式。

**两个经典非平面图（必须记住）**
| 图 | 数据 | 判定 |
|---|---|---|
| **K₅** | n = 5，m = 10 | **10 > 3×5 − 6 = 9** ⇒ **非平面图** ✓ |
| **K₃,₃**（完全二部图） | n = 6，m = 9，且**无三角形** | **9 > 2×6 − 4 = 8** ⇒ **非平面图** ✓ |

**库拉托夫斯基定理（了解）**：图 G 是平面图 **⟺** G **不含与 K₅ 或 K₃,₃ 同胚的子图**（同胚＝通过若干次"边细分/收缩"可相互得到）。

### （四）判别方法与步骤

1. **尝试平面嵌入**：能画出无边交叉的图形 ⇒ 平面图；
2. **用不等式否定**：连通简单平面图必须 m ≤ 3n−6（无三角形时 m ≤ 2n−4）；**违反即非平面**（K₅、K₃,₃ 即此法）；
3. **找 K₅/K₃,₃ 的同胚子图**（库拉托夫斯基定理，了解）；
4. **用欧拉公式求面数**或**由面数与次数关系反推边数**。

## 四、9.3 树及其遍历（综合应用，本章计算重点）

### （一）树的基本概念

| 术语 | 定义 |
|---|---|
| **树（无向树）** | **连通且无回路**的无向图 |
| **森林** | **无回路**的图（每个连通分支都是一棵树） |
| **树叶（叶结点）** | **度为 1** 的顶点 |
| **分支点（内部结点）** | **度 ≥ 2** 的顶点 |
| **生成树** | 连通图的**极小连通生成子图**（含全部顶点、n−1 条边，不唯一；了解） |

### （二）⭐ 树的等价定义（六个等价命题，必背）

对 n 阶无向图 T，**下列命题两两等价**：
① **T 是树**（连通无回路）；
② T **无回路**且 **m = n − 1**；
③ T **连通**且 **m = n − 1**；
④ T 中**任意两个顶点之间有唯一一条通路**；
⑤ T **连通**，且**删去任何一条边后就不连通**（极小连通图）；
⑥ T **无回路**，且**添加任意一条新边（连接已有顶点）就产生唯一一条回路**（极大无回路图）。

### （三）⭐ 树的性质与计算（必考）

1. **边数**：**n 阶树有 n − 1 条边**（m = n − 1）；
2. **树叶**：任一棵 n ≥ 2 的树**至少有两片树叶**；
3. **握手定理**：Σdeg(v) = 2m = **2(n − 1)**；
4. **森林**：若森林有 **n 个顶点、k 棵树（k 个连通分支）**，则 **m = n − k**；
5. **叶数计算公式（重点）**：设 nᵢ 为度为 i 的顶点数，则
   **n₁ = 2 + Σ_{i≥3} (i − 2)·nᵢ**（即 **n₁ = 2 + n₃ + 2n₄ + 3n₅ + …**）

**计算示例**
- **例 1**：一棵树有 2 个度为 4 的顶点、3 个度为 3 的顶点，其余均为树叶，求树叶数。
  **n₁ = 2 + (4−2)×2 + (3−2)×3 = 2 + 4 + 3 = 9**（9 片树叶）
  **验算**：n = 9 + 2 + 3 = 14，m = n − 1 = 13；Σdeg = 9×1 + 2×4 + 3×3 = 9 + 8 + 9 = 26 = 2×13 ✓
- **例 2**：n = 10 的树有 **9** 条边；有 10 个顶点、3 棵树的森林有 10 − 3 = **7** 条边。
- **例 3**：一棵树若有 5 片树叶、3 个度为 3 的顶点，其余为度为 2 的顶点，则
  由 n₁ = 2 + Σ(i−2)nᵢ：5 = 2 + (3−2)×3 = 5 ✓ 说明其余顶点**只能都是度为 2 的顶点**（度为 2 的顶点数不影响叶数）。

### （四）根树与二叉树

**根树（有向树）**（了解）：若有向树中**恰有一个顶点入度为 0**（称**根**）、其余顶点入度均为 1，则称该有向树为**根树**；出度为 0 的顶点称**叶**；顶点的**层数**（从根到该顶点的路径长度）、**树的高度**（最大层数）。

**二叉树**：每个顶点的**度数不超过 2** 的根树（左右有序：左孩子、右孩子）。

**⭐ 二叉树的性质（必背）**
1. 二叉树**第 i 层**上至多有 **2^(i−1)** 个顶点（i ≥ 1）；
2. **深度为 h** 的二叉树至多有 **2^h − 1** 个顶点（满二叉树达到）；
3. 对任何二叉树：**n₀ = n₂ + 1**（树叶数 = 度为 2 的顶点数 + 1）；
4. **完全二叉树**（n 个顶点）的深度为 **⌊log₂n⌋ + 1**；
5. （了解）n 个顶点的完全二叉树中，结点按层序编号 i 的左孩子为 2i、右孩子为 2i+1（1 基约定 ⚠️）。

**⭐ 三种遍历（必考）**
| 遍历 | 顺序 | 口诀 |
|---|---|---|
| **先序遍历（前序）** | **根 → 左子树 → 右子树** | 根在**最前** |
| **中序遍历** | **左子树 → 根 → 右子树** | 根在**中间** |
| **后序遍历** | **左子树 → 右子树 → 根** | 根在**最后** |

**遍历示例**：设二叉树为 **A(B(D, E), C(∅, F))**（A 为根；B 有左右孩子 D、E；C 只有右孩子 F）
- **先序**：**A B D E C F**（根 先访问）
- **中序**：**D B E A C F**（左 根 右）
- **后序**：**D E B F C A**（根 最后访问）

**应用**
1. **表达式树**：叶为操作数、分支为运算符；**中序 → 中缀表达式**、**先序 → 前缀表达式（波兰式）**、**后序 → 后缀表达式（逆波兰式）**；
2. **由遍历序列还原二叉树**：**先序 + 中序** 或 **后序 + 中序** 可唯一确定（先序首元/后序末元为根 → 在中序中划分左右子树 → 递归）；**先序 + 后序不能唯一确定**；
3. 树的层次遍历（用队列，了解）。

## 五、本章对比与易混点

| 易混点 | 正确理解 |
|---|---|
| **欧拉图 vs 哈密顿图** | 欧拉图关注**边**（每边一次）；哈密顿图关注**顶点**（每点一次） |
| **欧拉图的判别** | 有**充要条件**（欧拉定理）：无向图**所有顶点度为偶数**（回路）或**恰有 2 个奇度顶点**（通路） |
| 半欧拉图 | 有欧拉通路但**无欧拉回路**（恰 2 个奇度顶点） |
| 有向欧拉图条件 | **强连通**且**每点入度 = 出度**（若只有通路：两点例外） |
| **哈密顿图判别** | **没有充要条件**！只有**必要条件 p(G−S) ≤ \|S\|**（用于否定）与**充分条件**（狄拉克、奥尔） |
| 充分条件的作用 | 满足 ⇒ 是哈密顿图；**不满足不能断定不是** |
| 必要条件的作用 | 不满足 ⇒ **不是**哈密顿图（如星形图取 S = {中心}） |
| **平面图 vs 非平面图** | 只要**存在**一种无边交叉的画法就是平面图；**K₅、K₃,₃ 是非平面图** |
| **欧拉公式** | 连通平面图 **n − m + r = 2**；k 个分支时为 **n − m + r = k + 1** |
| 面的次数 | **Σdeg(f) = 2m**；外部面也要计入 |
| 平面图不等式 | 连通简单平面图（n≥3）**m ≤ 3n−6**；无三角形时 **m ≤ 2n−4** |
| **树 vs 森林** | 树＝**连通**无圈；森林＝无圈（可不连通） |
| 树的边数 | **m = n − 1**；森林 m = n − k（k 棵树） |
| **树的六个等价命题** | 连通/无圈/边数 n−1/唯一通路/极小连通/极大无圈，互相等价 |
| 二叉树性质 | **n₀ = n₂ + 1**；第 i 层 ≤ 2^(i−1)；深度 h ≤ 2^h − 1 |
| **遍历顺序** | 先序＝根左右；中序＝左根右；后序＝左右根（**先序+后序不能还原**） |

### （三）计算 / 判别题模板
1. **判欧拉图**：① 检查**连通性**（无向图连通 / 有向图强连通）→ ② 统计**各顶点度数**（有向图为入度=出度）→ ③ 全部为偶数（或恰 2 个奇数）= 有欧拉回路（通路）。
2. **判哈密顿图**：先试充分条件（度数是否都 ≥ n/2；不相邻顶点度之和是否 ≥ n）→ 若不满足，再用**必要条件**找一个子集 S 使 **p(G−S) > |S|** 来否定。
3. **判平面图**：数 n 与 m → ① 若 m > 3n−6（或图无三角形且 m > 2n−4）⇒ **非平面**；② 否则尝试画出平面嵌入。
4. **欧拉公式应用**：由 n、m 求面数 **r = m − n + 2**；或由面数/次数关系反求 m。
5. **树的叶数计算**：列出各度顶点数 → 代 **n₁ = 2 + Σ_{i≥3}(i−2)nᵢ** → 用 Σdeg = 2(n−1) 验算。
6. **二叉树遍历**：按"先序＝根左右、中序＝左根右、后序＝左右根"递归写出；**由序列还原**：先序首元（后序末元）为根 → 在中序中切开左右子树 → 递归。
