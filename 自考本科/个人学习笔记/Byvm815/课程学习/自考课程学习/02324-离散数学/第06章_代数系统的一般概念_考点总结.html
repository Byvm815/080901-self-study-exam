二、6.1 代数系统（领会）

（一）代数系统与二元运算

  • 1. 二元运算：设 S 是非空集合，映射 f: S×S → S 称为 S 上的二元运算（常记作 * 或 ·）。
  • 二元运算的定义本身就要求结果属于 S（即封闭性是二元运算的固有要求）；

  • n 元运算：f: Sⁿ → S；若某运算的结果可能超出 S，则称该运算在 S 上不封闭，不能作为 S 上的运算。

  • 2. 代数系统：非空集合 S 连同 S 上的若干运算，记作 。

  • 例：、、、、。

（二）运算的六条性质（必背，判别时逐条核对）

性质 定义（设 * 为 S 上二元运算）
封闭性 ∀x, y∈S，x*y ∈ S
交换律 ∀x, y∈S，xy = yx
结合律 ∀x, y, z∈S，(xy)z = x(yz)
幂等律 ∀x∈S，x*x = x（元素 x 满足 xx = x 时称 x 是幂等元*）
分配律 对两个运算 * 与 ∘：x(y∘z) = (xy)∘(x*z)（ 对 ∘ 左分配）；右分配*同理，左右都成立才说满足分配律
吸收律 对两个运算 * 与 ∘：x*(x∘y) = x 且 x∘(x*y) = x

补充（【注意】 视教材）：消去律——若 xy = xz 则 y = z（左消去）；若 yx = zx 则 y = z（右消去）。

  • 典型实例

  • ：交换律：✔；结合律：✔；幂等律：✘；分配律：—；吸收律：—

  • ：交换律：✔；结合律：✔；幂等律：部分（0、1 幂等）；分配律：· 对 + 分配 ✔；吸收律：—
  • ：交换律：✔；结合律：✔；幂等律：✔；分配律：∪、∩ 互相分配 ✔；吸收律：✔
  • （减法）：交换律：✘；结合律：✘；幂等律：✘；分配律：—；吸收律：—

（三）特殊元素（必考，务必会算）

  • 幺元（单位元）e：∀x∈S，e*x = x*e = x；存在性与唯一性：若存在必唯一
  • 零元 θ：∀x∈S，θ*x = x*θ = θ；存在性与唯一性：若存在必唯一
  • 幂等元：满足 x*x = x 的元素 x；存在性与唯一性：可多个（幺元、零元通常都是幂等元）
  • 逆元：设 e 为幺元，对 a∈S，若存在 b 使 a*b = b*a = e，则称 b 为 a 的逆元，记 a⁻¹；存在性与唯一性：在结合律下若存在必唯一

  • 左（右）幺元 / 左（右）逆元：只满足一侧（了解）；存在性与唯一性：—

  • 唯一性证明（常考简答）

  • 幺元唯一：设 e₁、e₂ 都是幺元，则 e₁ = e₁*e₂ = e₂ ✓
  • 逆元唯一（结合律下）：设 b、c 都是 a 的逆元，则

  • b = b*e = b*(a*c) = (b*a)*c = e*c = c ✓

  • 常见实例一览

  • ：幺元：0；零元：无；幂等元：0；可逆元：所有元素（a⁻¹ = −a）

  • ：幺元：1；零元：0；幂等元：0、1；可逆元：±1
  • ：幺元：0；零元：无；幂等元：0；可逆元：所有元素
  • ：幺元：1；零元：无；幂等元：1；可逆元：所有元素
  • ：幺元：∅；零元：A；幂等元：全部元素；可逆元：仅 ∅（自身为逆元）
  • ：幺元：A；零元：∅；幂等元：全部元素；可逆元：仅 A

  • （对称差）：幺元：∅；零元：无；幂等元：仅 ∅；可逆元：所有元素（逆元为自身）

  • 逆元的性质：(a⁻¹)⁻¹ = a；若 a、b 有逆元，则 (a*b)⁻¹ = b⁻¹*a⁻¹（顺序颠倒）。

  • 由运算表判断特殊元素（常考题型）

  • 交换律：运算表关于主对角线对称；
  • 幺元：某元素的行与列都与表头相同（该行/列原样照抄表头）；
  • 零元：该元素的行与列全部等于它自己；
  • 逆元：先找幺元 e，再对 a 找出满足 a*b = b*a = e 的 b；
  • 幂等元：主对角线上元素 = 该元素本身者。

（二）群的阶与基本性质

  • 群的阶：群 G 的元素个数 |G|；有限群（|G| 有限）/ 无限群。

  • 元素的阶（周期，了解）：使 aⁿ = e 的最小正整数 n；例： 中 1 的阶为 4，2 的阶为 2。

  • 群的性质（必背）

  • 幺元唯一、每个元素的逆元唯一；
  • 群中成立消去律：a*b = a*c ⇒ b = c（左消去）；b*a = c*a ⇒ b = c（右消去）；
  • 方程有唯一解：a*x = b 的解 x = a⁻¹*b；y*a = b 的解 y = b*a⁻¹；
  • (a⁻¹)⁻¹ = a；(a*b)⁻¹ = b⁻¹*a⁻¹；
  • 群中除幺元外不存在其他幂等元（即若 a*a = a，则 a = e）；
  • 群中不存在零元（除非 |G| = 1 的平凡群）；
  • 有限半群若满足消去律，则它必是群（了解）。

（三）子群及其判别条件（必考）

  • 定义：设 是群，∅ ≠ H ⊆ G，若 本身也是群，则称 H 是 G 的子群，记 H ≤ G。
  • 平凡子群：{e} 与 G 本身；

  • 例： 的子群 = {0, ±n, ±2n, …}（n 为非负整数）； 的子群 {0,3}、{0,2,4}。

  • 子群的判别条件（三个常用定理，必背）

  • 判别法一（两步法）：条件：H 非空；① ∀a, b∈H，a*b ∈ H（封闭）；② ∀a∈H，a⁻¹ ∈ H（逆元封闭）；用法：分别验证封闭与逆元

  • 判别法二（一步法，最常用）：条件：H 非空，且 ∀a, b∈H，a*b⁻¹ ∈ H（或 a⁻¹*b ∈ H）；用法：一步同时验证封闭与逆元

  • 判别法三（有限子群）：条件：H 是 G 的非空有限子集，且 H 对 * 封闭；用法：有限集只需验封闭（结合律与逆元自动满足）

  • 例（用一步法）：证明 2Z = {2k | k∈Z} 是 的子群

  • 2Z ≠ ∅（0 = 2×0 ∈ 2Z）；
  • 任取 a = 2m, b = 2n ∈ 2Z，则 a * b⁻¹ = a + (−b) = 2m − 2n = 2(m−n) ∈ 2Z ✓

  • 故 2Z ≤ Z ✓

  • 例（有限子集只验封闭）： 中 H = {0, 2, 4}：非空且封闭（2+2=4、2+4=0、4+4=2 均在 H 中）⇒ H ≤ Z₆ ✓

（四）运算表判别群（经典例题）

设 S = {e, a, b, c}，运算 * 的运算表如下（e 为幺元）：

  • e：e：e；a：a；b：b；c：c
  • a：e：a；a：e；b：c；c：b
  • b：e：b；a：c；b：e；c：a

  • c：e：c；a：b；b：a；c：e

  • 判别：

  • 封闭：表中所有结果都在 S 中 ✓；
  • 幺元：e 所在行、列与表头完全一致 ⇒ e 是幺元 ✓；
  • 逆元：a*a = e、b*b = e、c*c = e ⇒ 每个元素都以自身为逆元 ✓；
  • 交换：表关于主对角线对称 ✓；
  • 结合律：该表正是 Klein 四元群（Z₂×Z₂）的运算表，满足结合律 ✓
    ⇒ 是交换群（Abel 群），且每个非幺元元素的阶都是 2。

四、6.3 环与域（识记）

（一）环

  • 定义：代数系统 （带两个二元运算），若满足：
    ① 是交换群（Abel 群）；
    ② 是半群（封闭 + 结合）；
    ③ · 对 + 满足分配律（左、右分配），
    则称 为环。

  • 记号与术语：+ 称加法、· 称乘法；加法幺元记 0；a 的加法逆元记 −a；若乘法有幺元记 1。

  • 例子：、、、、、多项式环 R[x]、矩阵环 。

  • 基本性质（了解）：0·a = a·0 = 0；(−a)·b = a·(−b) = −(ab)；(a−b)·c = a·c − b·c。

  • 环的分类

类型 条件
交换环 乘法满足交换律
含幺环 乘法有幺元 1
无零因子环 若 ab = 0 则 a = 0 或 b = 0
整环 **交换环 + 含幺环 + 无零因子 +

（二）域

  • 定义：代数系统 （至少含两个元素），若满足：
    ① 是交换群；
    ② 是交换群（即所有非零元素对乘法构成交换群）；
    ③ · 对 + 满足分配律，
    则称 为域。

  • 例子：、、、（p 为素数）。

  • 反例： 不是域——因为 2∈Z 且 2 ≠ 0，但 2 的乘法逆元 1/2 ∉ Z（非零元对乘法不构成群）。

  • 层级关系（必记）：

  • 域 ⇒ 整环 ⇒ 交换含幺环 ⇒ 环
    （域一定是整环：域中若无零因子条件不满足，则 ab = 0 且 a ≠ 0 会导致 b = a⁻¹·0 = 0，矛盾；整环不一定是域，如 是整环但非域。）
  • 有限整环必是域（了解）。

（三）判别题模板（最常考）

  • 判群（五步）：① 封闭（运算结果是否仍在集合内）→ ② 结合律 → ③ 找幺元（逐一验证候选元素）→ ④ 每个元素是否都有逆元 →（⑤ 是否交换 ⇒ 是否 Abel 群）。
  • 判半群/独异点：只需验 ① 封闭 + ② 结合；（独异点再加）③ 是否有幺元。
  • 由运算表判别：交换＝表对称；幺元＝该行该列照抄表头；零元＝该行该列全是它；逆元＝对每元素找 b 使 a*b = e；幂等元＝主对角线上等于自身者。
  • 判子群：先找幺元与逆元，再用"非空 + a*b⁻¹ ∈ H"一步法；有限子集只验封闭。
  • 判环/域：先验 是交换群（含幺元、每元素有负元、可交换）；再验乘法是半群（域则要"非零元成群"）；最后验分配律。
