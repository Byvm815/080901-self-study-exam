第 7 章 格与布尔代数 · 考点总结

课程：02324 离散数学（080901 自考）
课程内容：7.1 格的基本概念 ； 7.2 分配格与有补格 ； 7.3 布尔代数
考核层次：7.1 领会 ； 7.2 领会 ； 7.3 识记
重点/难点：格、分配格、有补格的概念及性质

一、本章知识地图

  • 7.1 格的基本概念：核心内容：最大下界（下确界 inf）与最小上界（上确界 sup）、格的两种定义及其联系、格的判别（哈斯图法）、格的性质；层次：领会
  • 7.2 分配格与有补格：核心内容：分配格（分配律 / 不含 M₃、N₅ 子格）、有界格、补元、有补格；层次：领会

  • 7.3 布尔代数：核心内容：布尔代数的定义（有补分配格）、例子（幂集、二值布尔代数）、基本性质；层次：识记

  • 本章主线：偏序集 →（任意两元素都有 inf/sup）格 →（满足分配律）分配格 →（有 0、1 且每元素有补元）有补格 →（有补 + 分配）布尔代数。

二、7.1 格的基本概念（领会）

（一）复习：上下界与确界

设 是偏序集，B ⊆ A，a∈A（回顾第 5 章）：
- 上界：∀x∈B，x ≤ a；下界：∀x∈B，a ≤ x；
- 上确界（最小上界，sup B）：上界中最小者（存在则唯一）；
- 下确界（最大下界，inf B）：下界中最大者（存在则唯一）。

【注意】 上下界未必存在；即使存在，也可能不在 B 中。

（二）格的定义（两种定义方法，必背）

  • 定义一（偏序定义）：设 是偏序集，若 L 中任意两个元素都存在最大下界与最小上界，则称 为格。
  • 记 inf{a, b} = a ∧ b（称交、下确界）；sup{a, b} = a ∨ b（称并、上确界）；

  • 【注意】 这里的 ∧、∨ 是格运算符号（不是命题联结词，也不要与集合的交并混淆，但性质惊人相似）。

  • 定义二（代数定义）：设 是带两个二元运算的代数系统，若运算满足
    ① 交换律：a∧b = b∧a，a∨b = b∨a；
    ② 结合律：(a∧b)∧c = a∧(b∧c)，(a∨b)∨c = a∨(b∨c)；
    ③ 吸收律：a∧(a∨b) = a，a∨(a∧b) = a，
    则称 为格。

  • 两种定义的联系（重要，常考简答）

  • 由偏序定义的格：定义 a∧b = inf{a,b}、a∨b = sup{a,b} 后，可验证 ∧、∨ 满足交换律、结合律与吸收律 ⇒ 得到代数定义下的格；
  • 由代数定义的格：在 L 上定义关系 a ≤ b ⟺ a∧b = a（⟺ a∨b = b），则可验证 ≤ 是偏序，且 a∧b、a∨b 恰为 {a,b} 的下确界与上确界 ⇒ 得到偏序定义下的格；
  • 两种定义等价；代数定义的好处是能用等式推演（如证明幂等律、分配律），偏序定义的好处是能借助哈斯图判别。

（三）格的判别（必考）

  • 方法一：哈斯图法（直观）
    对哈斯图中每一对元素检验：向上的公共上界中取最小者是否存在；向下的公共下界中取最大者是否存在。只要有一对元素缺 inf 或 sup，就不是格。

  • 方法二：运算验证法（代数）：检验 ∧、∨ 是否满足交换律、结合律、吸收律。

  • 典型例子（必记）

偏序集 是否格 说明
是格 a∧b = A∩B，a∨b = A∪B
**<Z⁺, >**（整除） 是格
全序集（链） 是格 a∧b = min(a,b)，a∨b = max(a,b)
**<{1,2,4,8}, >** 是格（链）
**<{1,2,3,6,12}, >** 是格
A = {a,b,c}，a ≤ b，a ≤ c（b、c 不可比） 不是格 {b,c} 无上界 ⇒ sup 不存在
**<{2,3,6,12}, >** 不是格

（四）格的性质（领会）

  • 幂等律可由吸收律推出（经典推导，常考）：
    ① a∨a = a∨(a∧(a∨a)) = a（用吸收律 a∨(a∧b) = a，取 b = a∨a）；
    ② a∧a = a∧(a∨a) = a（用吸收律 a∧(a∨b) = a，取 b = a，并代入①）。
  • 保序性（单调性）：若 a ≤ b，则a∧c ≤ b∧c 且 a∨c ≤ b∨c；
  • 分配不等式（一般格中只有不等式）：
  • a∨(b∧c) ≤ (a∨b)∧(a∨c)；a∧(b∨c) ≥ (a∧b)∨(a∧c)
    （分配格中两式均取等号，见 7.2）；
  • 由运算导出序：a ≤ b ⟺ a∧b = a ⟺ a∨b = b；
  • 对偶原理（了解）：把格中公式的 ∧ 与 ∨ 互换、≤ 与 ≥ 互换，所得命题仍成立；
  • 格的子格（了解）：L 的子集 S 在同样的 ∧、∨ 下仍构成格（注意运算结果必须仍落在 S 中）。

三、7.2 分配格与有补格（领会，本章核心判别）

（一）分配格

  • 定义：格 若满足分配律

  • a∧(b∨c) = (a∧b)∨(a∧c) 与 a∨(b∧c) = (a∨b)∧(a∨c)
    则称 L 为分配格。

    在格中，两条分配律只要一条成立，另一条自动成立（对偶）。

  • 判别方法

  • 直接验证分配律是否成立（对任意元素）；
  • 看是否有 M₃ 或 N₅ 型子格（定理，超好用）：

  • 格是分配格 ⟺ 它不含与钻石格 M₃ 或五角格 N₅ 同构的子格。

  • 两个著名的非分配格（必记）

  • 钻石格 M₃：结构：{0, 1, a, b, c}：0 ≤ a, b, c ≤ 1，a、b、c 两两不可比；非分配的验证：a∧(b∨c) = a∧1 = a；而 (a∧b)∨(a∧c) = 0∨0 = 0 ⇒ a ≠ 0（分配律不成立）

  • 五角格 N₅：结构：{0, a, b, c, 1}：0 ≤ a ≤ b ≤ 1，且 0 ≤ c ≤ 1（c 与 a、b 不可比）；非分配的验证：b∧(a∨c) = b∧1 = b；而 (b∧a)∨(b∧c) = a∨0 = a ⇒ a ≠ b

  • 分配格的例子：（分配格）、任何链（全序集）都是分配格、（整除格）。

（二）有界格、补元、有补格

  • 有界格：若格 L 存在最大元（全上界）1 与最小元（全下界）0，则称 为有界格。
  • 有界格中：a∧0 = 0，a∨0 = a，a∧1 = a，a∨1 = 1；

  • 有限格必是有界格（有限个元素的 sup 与 inf 都存在）；无限格可以有界（如 [0,1] 上的实数区间）或无界（如 无最大元）。

  • 补元：设 是有界格，a∈L，若存在 b∈L 使

  • a∧b = 0 且 a∨b = 1，
    则称 b 是 a 的补元（记 a′ 或 ¬a）。
  • 有界格中元素的补元不一定存在；即使存在也不一定唯一（如 M₃ 中 a 的补元可以是 b 或 c）；

  • 重要定理：在分配格中，若元素有补元则补元唯一（因此可有记号 a′）。

  • 有补格：有界格 L 若每个元素都至少有一个补元，则称 L 为有补格。

  • 例： 是有补格（A 的子集 S 的补元是 ~S）；
  • 例：M₃ 与 N₅ 都是有补格但都不是分配格（说明"有补"与"分配"是两回事）；
  • 反例：链 <{1,2,4,8}, |> 是有界分配格，但 2 没有补元（2∧x = 1 只可能 x = 1，而 2∨1 = 2 ≠ 8）⇒ 不是有补格。

（三）判别速查表（必背）

概念 判别条件
格 任意两元素都有 inf 与 sup（或 ∧∨ 满足交换、结合、吸收）
分配格 满足分配律（等价：不含 M₃ 或 N₅ 同构子格）
有界格 有最大元 1 与最小元 0
补元 存在 b 使 a∧b = 0 且 a∨b = 1
有补格 有界 且每个元素都有补元
布尔代数 有补的分配格（有界 + 分配 + 每元素有补元）

四、7.3 布尔代数（识记）

（一）定义

  • 布尔代数：有补的分配格称为布尔代数，记 ——即同时满足：
    ① 是分配格；② 有界（存在 0 与 1）；③ 每个元素都有补元（补元唯一，记 a′）。

  • 等价代数定义（了解）： 若满足交换律、分配律、同一律（a∧1 = a，a∨0 = a）、补元律（a∧a′ = 0，a∨a′ = 1），则称为布尔代数。

（三）布尔代数的基本性质（了解，考试多以选择/填空出现）

性质 内容
幂等律 a∧a = a；a∨a = a
交换律 / 结合律 同格
吸收律 a∧(a∨b) = a；a∨(a∧b) = a
分配律 a∧(b∨c) = (a∧b)∨(a∧c)；a∨(b∧c) = (a∨b)∧(a∨c)
同一律 a∧1 = a；a∨0 = a
零律 a∧0 = 0；a∨1 = 1
补元律（排中/矛盾） a∧a′ = 0；a∨a′ = 1
双重否定律 (a′)′ = a
德摩根律 (a∧b)′ = a′∨b′；(a∨b)′ = a′∧b′
常数 0′ = 1；1′ = 0

关键点：双重否定律与德摩根律只在分配格（布尔代数）中成立（在一般的有界格或有补格中不保证成立）。

五、本章对比与易混点

易混点 正确理解
格的 ∧、∨ 是格的交与并（inf/sup），不是命题联结词；但在分配格/布尔代数中与集合的 ∩、∪ 性质一致
格 vs 偏序集 偏序集只要求"可比或不可比"；格要求任意两元素都有 inf 与 sup（并非所有偏序集都是格）
格 vs 链 链（全序集）一定是格（∧ = min、∨ = max）；格不一定是链（允许不可比元素）
上界 vs 上确界 上界可多个；上确界是上界中最小的那个（唯一）
inf 存在但不属于集合 下确界可以不在子集 B 中（但必须在 L 中）
幂等律的来源 格中幂等律由吸收律推出（不是独立公理）
分配不等式 vs 分配律 一般格只有不等式 a∨(b∧c) ≤ (a∨b)∧(a∨c)；分配格才取等号
分配格判别 满足分配律 ⟺ 不含 M₃ 或 N₅ 子格
M₃、N₅ 的性质 都是格、都是有补格，但都不是分配格
补元唯一性 一般有界格中补元不一定存在、存在也不一定唯一；分配格中若存在必唯一
有界 vs 有补 有界＝有 0 和 1；有补＝有界 且每元素都有补元（有界不一定有补，如链 {1,2,4,8}）
布尔代数 ＝有补的分配格（三个条件同时满足）；有限布尔代数元素个数必为 2ⁿ
德摩根律的适用 只在分配格/布尔代数中成立

（三）判别题模板

  • 判格：画出哈斯图 → 对每一对元素找 sup（公共上界中最小）与 inf（公共下界中最大） → 全部存在才是格；举出一对不存在即可否定。
  • 判分配格：① 直接验证分配律（任取元素算 a∧(b∨c) 与 (a∧b)∨(a∧c) 是否相等）；② 或检查是否存在 M₃/N₅ 型子格。
  • 判有界格：找是否有最大元（被所有元素 ≤ 的元素）与最小元。
  • 求补元：对 a 逐一试 b，使 gcd 型/∩型运算 = 0 且 lcm 型/∪型运算 = 1；在分配格中补元唯一，可记为 a′。
  • 判有补格：有界 + 每个元素都能找到补元；只要有一个元素无补元即否定（如链 {1,2,4,8} 中的 2）。
  • 判布尔代数：三条件全满足 —— 分配格 + 有界（0、1）+ 每元素有补元。
  • 求 inf/sup 具体值：在整除格中 inf = gcd、sup = lcm；在幂集格中 inf = ∩、sup = ∪；在链中 inf = min、sup = max。
