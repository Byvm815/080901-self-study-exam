二、5.1 关系及关系的性质（领会）

（一）关系的定义

  • 二元关系：从 A 到 B 的二元关系 R 是笛卡儿积 A×B 的任一子集，即 R ⊆ A×B；若 A = B，则称 A 上的关系。
  • 若 ∈ R，记作 xRy；
  • 定义域 dom R = {x | ∃y(∈R)}；值域 ran R = {y | ∃x(∈R)}；域 fld R = dom R ∪ ran R；
  • 特殊关系：空关系 ∅、全域关系 E_A = A×A、恒等关系 I_A = { | x∈A}。

（二）关系的三种表示方法（必考）

③ 关系图 以 A 的元素为结点；若 ∈R 则画从 x 指向 y 的有向边（ 画自环）

（三）关系的五条性质（必考，必须会判别）

  • 自反性：∀x∈A，∈R；关系矩阵判别：主对角线全 1；关系图判别：每个结点都有自环
  • 反自反性：∀x∈A，∉R；关系矩阵判别：主对角线全 0；关系图判别：每个结点都无自环
  • 对称性：若 ∈R，则 ∈R；关系矩阵判别：矩阵对称（rᵢⱼ = rⱼᵢ）；关系图判别：有向边成对出现（互为反向）
  • 反对称性：若 ∈R 且 ∈R，则 x = y；关系矩阵判别：i≠j 时 rᵢⱼ 与 rⱼᵢ 不同时为 1；关系图判别：任意两点间至多一条有向边（不成对）

  • 传递性：若 ∈R 且 ∈R，则 ∈R；关系矩阵判别：M_R 的布尔平方 ⊆ M_R（即 M_R⊙M_R ≤ M_R）；关系图判别：有链必有"短路"边

  • 重要提示（易错）

  • 自反与反自反不是互补关系：既有关系既不自反也不反自反（如 A={1,2}，R={<1,1>}）；但同一非空集合上的关系不能同时自反又反自反；
  • 对称与反对称也不互补：可同时成立（如 恒等关系 I_A 既对称又反对称）；也可都不成立（如 R={<1,2>,<2,1>,<2,3>} 在 A={1,2,3} 上）；
  • 空关系：反自反、对称、反对称、传递，但不自反（除非 A=∅）；

  • 全域关系 E_A：自反、对称、传递，但不反自反；一般不反对称（|A|≥2 时）。

  • 判别步骤：先写出 A 的所有元素，再逐条性质按定义核对（自反看对角线；对称/反对称看反向对是否同时存在及其后果；传递看所有"两步链"）。

三、5.2 关系的运算（领会）

（一）常规运算

设 R、S 都是从 A 到 B 的关系：
- 并 R∪S = { | ∈R ∨ ∈S}；
- 交 R∩S；差 R−S；补 ~R = (A×B) − R（注意补是相对于 A×B）；
- 逆关系：R⁻¹ = { | ∈R}（矩阵转置、关系图反向）。

  • 逆关系的性质
性质 内容
双重逆 (R⁻¹)⁻¹ = R
并/交/差的逆 (R∪S)⁻¹ = R⁻¹∪S⁻¹；(R∩S)⁻¹ = R⁻¹∩S⁻¹；(R−S)⁻¹ = R⁻¹−S⁻¹
复合的逆（顺序颠倒） (R∘S)⁻¹ = S⁻¹∘R⁻¹
逆与性质 R 自反 ⟺ R⁻¹ 自反；R 对称 ⟺ R⁻¹ = R；R 传递 ⟺ R⁻¹ 传递

（二）复合运算（重点）

  • 定义：设 R 是从 A 到 B 的关系、S 是从 B 到 C 的关系，则 R 与 S 的复合（记 R∘S，【注意】 不同教材记号方向相反）

  • R∘S = { | ∃y∈B（∈R ∧ ∈S）}（即"先 R 后 S"，是从 A 到 C 的关系）。

  • 关系矩阵的布尔乘法：M_{R∘S} = M_R ⊙ M_S
    其中布尔乘法：先按位相乘（∧）再布尔加（∨）：cᵢⱼ = ∨ₖ(rᵢₖ ∧ sₖⱼ)（只要有一项 1 即得 1）。

  • 例：A = {1,2,3}，R = {<1,2>, <2,3>}，S = {<2,2>, <3,1>}

  • R∘S：<1,2>∈R 与 <2,2>∈S ⇒ <1,2>；<2,3>∈R 与 <3,1>∈S ⇒ <2,1> ⇒ R∘S = {<1,2>, <2,1>}
  • S∘R：<2,2>∈S 与 <2,3>∈R ⇒ <2,3>；<3,1>∈S 与 <1,2>∈R ⇒ <3,2> ⇒ S∘R = {<2,3>, <3,2>}

  • ⇒ R∘S ≠ S∘R（复合不满足交换律）

交换律 一般不成立

四、5.3 等价关系与序关系（简单应用，本章得分重点）

（一）等价关系

  • 定义：A 上的关系 R 若同时满足 自反、对称、传递，则称 R 为 A 上的等价关系。

  • 典型例子：数的相等 =；三角形的相似/全等；模 n 同余关系；集合的等势；人群中"同姓/同龄"；矩阵的相似。

  • 等价类：[x]_R = {y | y∈A ∧ ∈R}（与 x 有关系的所有元素构成的集合）。

  • 等价类的三大性质（必考）

  • 每个等价类非空（因自反性 x∈[x]）；
  • xRy ⟺ [x] = [y]（同类元素等价）；

  • 若 ∉R，则 [x]∩[y] = ∅（不同类不相交）。

    结论：等价类要么完全相同、要么完全不相交。

  • 商集：A/R = {[x]_R | x∈A}（所有等价类构成的集合）——它正是 A 的一个划分。

  • 划分：A 的子集族 π = {A₁, A₂, …, Aₘ} 若满足
    ① 每个 Aᵢ ≠ ∅；② Aᵢ∩Aⱼ = ∅（i≠j）；③ A₁∪A₂∪…∪Aₘ = A，则称 π 是 A 的一个划分，每个 Aᵢ 称划分块（类）。

  • 重要定理：A 上的等价关系与 A 的划分一一对应（由等价关系可得商集（划分）；由划分可定义等价关系"同块即相关"）。

  • 例：A = {1,2,…,8}，R 为模 3 同余关系（aRb ⟺ a ≡ b (mod 3)）

  • 等价类：[1] = {1,4,7}，[2] = {2,5,8}，[3] = {3,6}；
  • 商集 A/R = {{1,4,7}, {2,5,8}, {3,6}}（3 个划分块）。

（二）相容关系（了解，大纲提到"相容关系"的判定）

  • 相容关系：A 上同时满足自反、对称的关系（不要求传递）。
  • 相容类：非空子集 B，其中任意两元素都相容；
  • 最大相容类：不能被其他相容类真包含的相容类；
  • 覆盖：A 中所有最大相容类构成的集合（块可相交，区别于划分）。

（三）序关系

关系 满足性质 记号与例
偏序关系（半序） 自反、反对称、传递 ≤；数的"≤"、集合的"⊆"、整除"
拟序关系（严格偏序） 反自反、传递（必反对称） <（严格小于）；"真包含" ⊂
全序关系（线序） 偏序 且任意两元素可比（∀x,y，x≤y 或 y≤x） 数集上的 ≤； 称全序集或链

  • 可比与不可比：若 x≤y 或 y≤x，则 x、y 可比；否则不可比（偏序集允许不可比元素，如图的哈斯图中无连线者）。

  • 哈斯图（Hasse 图）的画法（必考）
    ① 去掉所有自环（自反性使 无意义）；
    ② 去掉由传递性可推出的边（即若 x<y 且 y<z，则删去 x 到 z 的边，只保留覆盖关系）；
    ③ 把较小的元素画在下方、较大的元素画在上方，用直线段连接（不画箭头）；
    ④ 得到的简图即为哈斯图。

  • 例：A = {1,2,3,6,12} 上的整除关系 ≤（a ≤ b ⟺ a | b）

  • 覆盖关系：1|2、1|3、2|6、3|6、6|12；哈斯图：

五、5.4 函数（领会）

（一）函数的定义

设 f 是从 A 到 B 的二元关系，若满足：
① dom f = A（A 中每个元素都有像）；② 每个 x∈A 只有一个像（唯一性），
则称 f 为从 A 到 B 的函数（映射），记 f: A → B，x 的像记 f(x)。
- 判别关系是否为函数："每个 x 都有像"且"像唯一"（缺一不可）；
- dom f = A；ran f = {f(x) | x∈A} ⊆ B（称值域/像集）；当 ran f = B 时 f 是满射；
- 函数相等：f = g ⟺ 定义域相同且对每个 x 有 f(x) = g(x)（与 B 无关，只要求像相同）；
- 特殊函数：恒等函数 I_A: A→A，I_A(x) = x；常函数（所有 x 的像相同）。

（二）单射、满射、双射（必考判别）

类型 定义 判别要点
单射（内射） 若 f(x₁) = f(x₂) 则 x₁ = x₂（不同元素像不同） 水平线与图象至多一个交点
满射（映上） ran f = B（B 中每个元素都是某个 x 的像） 每个 y∈B 都要找到原像
双射（一一映射） 既单射又满射 存在反函数；
  • 例
  • f: R → R，f(x) = x²：非单射（f(1)=f(−1)）、非满射（负数无原像）；
  • f: R → [0,+∞)，f(x) = x²：满射但仍非单射；
  • f: Z → Z，f(x) = 2x：单射但非满射；

  • f: R → R，f(x) = 2x + 1：双射（既有唯一原像又可取遍 R）。

  • 计数结论（有限集，常考）：|A| = m、|B| = n

  • 从 A 到 B 的函数共 n^m 个；
  • 单射个数 = P(n, m) = n(n−1)…(n−m+1)（要求 m ≤ n，否则无单射）；
  • 双射存在 ⟺ m = n，此时双射个数 = m!。

（三）复合函数与反函数

  • 复合函数：f: A→B，g: B→C，则 g∘f: A→C，(g∘f)(x) = g(f(x))。
  • 满足结合律：(h∘g)∘f = h∘(g∘f)；一般不满足交换律；
  • 恒等函数是幺元：f∘I_A = I_B∘f = f；
  • 单射/满射的复合（单向结论，易考）：
已知 结论
f 单射且 g 单射 g∘f 单射
f 满射且 g 满射 g∘f 满射
f、g 都是双射 g∘f 双射
g∘f 单射 ⇒ f 单射（g 未必）
g∘f 满射 ⇒ g 满射（f 未必）
  • 反函数：f: A→B 存在反函数 ⟺ f 是双射；此时 f⁻¹: B→A 也是双射，且
  • f⁻¹∘f = I_A，f∘f⁻¹ = I_B；
  • (f⁻¹)⁻¹ = f；(g∘f)⁻¹ = f⁻¹∘g⁻¹。

（三）计算 / 证明题模板

  • 求关系矩阵/关系图：按 A、B 元素排列，逐对检查 是否属于 R。
  • 判别五条性质：写定义 → 逐条核对（对角线、反向对、两步链）；矩阵法最快捷。
  • 求复合 R∘S：对每个 ∈R，找所有 ∈S，得 ；矩阵用布尔乘法。
  • 求闭包：r(R) = R∪I_A；s(R) = R∪R⁻¹；t(R) = R∪R²∪…∪Rⁿ（n=|A|）或用 Warshall 逐轮更新矩阵。
  • 判等价关系：先证自反、再证对称、最后证传递（三步缺一不可）；求等价类 → 求商集（即划分）。
  • 判偏序/画哈斯图：证自反+反对称+传递 → 只保留覆盖关系 → 下小上大、不画箭头。
  • 求极值元/上下确界：把 B 中元素按偏序关系逐一比较；上界要能"覆盖"B 中所有元素，上确界取上界中的最小者。
  • 判函数/单射/满射：先看"每个 x 是否有唯一像"→ 再证单射（f(x₁)=f(x₂) ⇒ x₁=x₂）→ 再证满射（任给 y∈B 求原像）。
  • 复合函数：先算 f(x)、再算 g(f(x))；注意定义域与值域要衔接（g 的定义域需包含 f 的值域）。
