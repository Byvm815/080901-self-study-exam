二、2.1 范式（领会）

（一）基本概念

概念 定义 例（变元 p, q, r）
文字 命题变元或其否定 p、¬p、q、¬q
简单合取式（基本积） 有限个文字的合取 p∧¬q∧r、¬p
简单析取式（基本和） 有限个文字的析取 p∨¬q∨r、¬p
析取范式（DNF） 有限个简单合取式的析取：A₁∨A₂∨…∨Aₙ (p∧¬q)∨(¬p∧r)
合取范式（CNF） 有限个简单析取式的合取：A₁∧A₂∧…∧Aₙ (p∨q)∧(¬p∨r)

注意：单个文字既可看作简单合取式，也可看作简单析取式；因此单个文字本身既是析取范式也是合取范式。

（二）范式的性质（必考）

  • 一个简单合取式是矛盾式 ⟺ 它同时含某个命题变元及其否定（如 p∧¬q∧¬p）；
  • 一个简单析取式是重言式 ⟺ 它同时含某个命题变元及其否定（如 p∨¬q∨¬p）；
  • 一个析取范式是矛盾式 ⟺ 它的每个简单合取式都是矛盾式；
  • 一个合取范式是重言式 ⟺ 它的每个简单析取式都是重言式；
  • 范式的用途：① 判断公式类型；② 化简公式；③ 作为求主范式的中间步骤；
  • 一个公式的析取范式（合取范式）不唯一（这正是需要"主范式"的原因）。

（三）求范式的步骤（三步法，必考）

  • ① 消去 → 与 ↔
  • A→B ⇔ ¬A∨B；

  • A↔B ⇔ (A→B)∧(B→A)（或 (A∧B)∨(¬A∧¬B)，按其结果形式选择）。

  • ② 把 ¬ 内移（德摩根律 + 双重否定律）

  • ¬(A∨B) ⇔ ¬A∧¬B；¬(A∧B) ⇔ ¬A∨¬B；¬¬A ⇔ A；

  • 目标：使 ¬ 只出现在命题变元之前（得到"文字"）。

  • ③ 用分配律化为目标形式

  • 求析取范式（积之和）：用 ∧ 对 ∨ 的分配律：A∧(B∨C) ⇔ (A∧B)∨(A∧C)；
  • 求合取范式（和之积）：用 ∨ 对 ∧ 的分配律：A∨(B∧C) ⇔ (A∨B)∧(A∨C)；

  • 最后合并相同项、消去重复。

  • 例 1（求析取范式）：A = (p→q)→r
    = ¬(¬p∨q)∨r 　（消去 →）
    = (p∧¬q)∨r 　（德摩根 + 双重否定）
    → 已经是析取范式：(p∧¬q)∨r（其中 r 是单文字的简单合取式）。

  • 例 2（求合取范式）：B = (p∧q)→r
    = ¬(p∧q)∨r = (¬p∨¬q)∨r = ¬p∨¬q∨r（既是合取范式，也是析取范式——单个简单析取式）。

  • 例 3（求合取范式）：C = p∨(q∧r) 已是合取范式：(p∨q)∧(p∨r)？注意：p∨(q∧r) 本身也是析取范式（"简单合取式 q∧r" 与 "p" 的析取）；若要写成合取范式，用分配律：p∨(q∧r) ⇔ (p∨q)∧(p∨r) ✓

三、2.1（续）小项与大项（领会，主范式的基础）

（一）定义

概念 定义 个数
小项（极小项） n 个命题变元的简单合取式，其中每个变元及其否定恰好出现一次 2ⁿ 个
大项（极大项） n 个命题变元的简单析取式，其中每个变元及其否定恰好出现一次 2ⁿ 个

（二）编码规则（关键，易错！）

  • 统一步骤：把变元按字母顺序（或教材约定顺序） 排列，然后
  • 小项 mᵢ：用 1 表示变元本身、0 表示其否定；得到的二进制串转成十进制即为下标 i；

  • 大项 Mᵢ：用 0 表示变元本身、1 表示其否定（与小项相反！）。

  • 两变元的小项与大项（必背）

  • 00：成真/成假赋值：p=0, q=0；小项 mᵢ：m₀ = ¬p∧¬q；大项 Mᵢ：M₀ = p∨q

  • 01：成真/成假赋值：p=0, q=1；小项 mᵢ：m₁ = ¬p∧q；大项 Mᵢ：M₁ = p∨¬q
  • 10：成真/成假赋值：p=1, q=0；小项 mᵢ：m₂ = p∧¬q；大项 Mᵢ：M₂ = ¬p∨q
  • 11：成真/成假赋值：p=1, q=1；小项 mᵢ：m₃ = p∧q；大项 Mᵢ：M₃ = ¬p∨¬q

记忆：小项"1 是变元本身"（m₃ = p∧q 对应 11）；大项"1 是否定"（M₃ = ¬p∨¬q 对应 11）。

（三）性质（必考）

  • 小项的性质
  • 每个小项只有一个成真赋值（即其编码对应的赋值），其余 2ⁿ−1 个赋值下为假；
  • 任意两个不同小项的合取是矛盾式；
  • 全体小项的析取是重言式；

  • 小项 mᵢ 的否定是大项 Mᵢ：¬mᵢ ⇔ Mᵢ（如 ¬m₂ = ¬(p∧¬q) = ¬p∨q = M₂ ✓）。

  • 大项的性质

  • 每个大项只有一个成假赋值（其编码对应的赋值），其余赋值下为真；
  • 任意两个不同大项的析取是重言式；
  • 全体大项的合取是矛盾式；

  • 大项 Mᵢ 的否定是小项 mᵢ：¬Mᵢ ⇔ mᵢ。

  • 由此得到重要结论：

  • 公式 A 的成真赋值 ⟷ 使对应小项为真的赋值 ⇒ 可用成真赋值写出主析取范式；
  • 公式 A 的成假赋值 ⟷ 使对应大项为假的赋值 ⇒ 可用成假赋值写出主合取范式。

四、2.2 主范式（简单应用，本章第一个得分重点）

（一）定义

概念 定义
主析取范式 由小项的析取构成的析取范式（每个小项对应公式的一个成真赋值）
主合取范式 由大项的合取构成的合取范式（每个大项对应公式的一个成假赋值）
  • 唯一性定理：
  • 任何非矛盾式都有唯一的主析取范式；
  • 任何非重言式都有唯一的主合取范式；
  • 矛盾式：主析取范式不存在（也可说"不含任何小项"），其主合取范式含全部 2ⁿ 个大项；
  • 重言式：主合取范式不存在，其主析取范式含全部 2ⁿ 个小项。

（二）求主范式的两种方法

  • 方法 1：真值表法（最稳妥）
    ① 列出公式的真值表（2ⁿ 行）；
    ② 取所有成真赋值对应的小项，用 ∨ 连接 ⇒ 主析取范式；
    ③ 取所有成假赋值对应的大项，用 ∧ 连接 ⇒ 主合取范式；
    ④ 可写成简写形式：∑m(…) 与 ∏M(…)。

  • 例：A = p→q（两个变元，赋值 00、01、10、11）

p q A=p→q
0 0 1 ← 成真 → m₀
0 1 1 ← 成真 → m₁
1 0 0 ← 成假 → M₂
1 1 1 ← 成真 → m₃
  • 主析取范式 = m₀∨m₁∨m₃ = (¬p∧¬q)∨(¬p∧q)∨(p∧q) = ∑m(0,1,3)

  • 主合取范式 = M₂ = ¬p∨q = ∏M(2)　（与 A ⇔ ¬p∨q 一致 ✓ 便于验算）

  • 方法 2：等值演算法（先求范式再补全）
    ① 先求析取范式或合取范式；
    ② 对缺变元的简单式补全变元：A ⇔ A∧(B∨¬B)（求主析取时）或 A ⇔ A∨(B∧¬B)（求主合取时）；
    ③ 用分配律展开，合并相同小项、删除重复小项；
    ④ 按编码写成 ∑m(…) 或 ∏M(…)。

  • 例：求 A = (p∧q)∨(¬p∧r) 的主范式
    真值表（p,q,r）：

  • 000：p∧q：0；¬p∧r：0；A：0

  • 001：p∧q：0；¬p∧r：1；A：1 (m₁)
  • 010：p∧q：0；¬p∧r：0；A：0
  • 011：p∧q：0；¬p∧r：1；A：1 (m₃)
  • 100：p∧q：0；¬p∧r：0；A：0
  • 101：p∧q：0；¬p∧r：0；A：0
  • 110：p∧q：1；¬p∧r：0；A：1 (m₆)

  • 111：p∧q：1；¬p∧r：0；A：1 (m₇)

  • 主析取范式 = m₁∨m₃∨m₆∨m₇ = ∑m(1,3,6,7)
    = (¬p∧¬q∧r)∨(¬p∧q∧r)∨(p∧q∧¬r)∨(p∧q∧r)

  • 主合取范式 = M₀∧M₂∧M₄∧M₅ = ∏M(0,2,4,5)
    = (p∨q∨r)∧(p∨¬q∨r)∧(¬p∨q∨r)∧(¬p∨q∨¬r)

（三）两种主范式的相互转换（必考，最省时）

  • 核心规律：小项与大项的下标互补——
    若 2ⁿ 个小项下标全集的某公式主析取范式为 ∑m(S)（S 为成真赋值下标集合），则

  • 主合取范式为 ∏M(补集)，即 ∏M(S̄)（S̄ 为 {0,1,…,2ⁿ−1} 中不属于 S 的下标）。
    反之亦然。

  • 例 1：A = p→q 的主析取为 ∑m(0,1,3) → 补集为 {2} → 主合取 = ∏M(2) = M₂ ✓

  • 例 2：上例 A = (p∧q)∨(¬p∧r) 主析取 ∑m(1,3,6,7) → 补集 {0,2,4,5} → 主合取 ∏M(0,2,4,5) ✓

  • 由主范式看公式类型（快速判断）

主范式情况 公式类型
主析取含全部 2ⁿ 个小项 重言式
主合取含全部 2ⁿ 个大项 矛盾式
小项/大项均不完整 可满足式（非重言、非矛盾）

五、2.3 自然推理系统（简单应用，本章第二个得分重点）

（一）推理与有效推理

  • 1. 推理的形式：由前提 A₁, A₂, …, Aₙ 推出结论 B，其逻辑形式为

  • A₁∧A₂∧…∧Aₙ → B（记作 A₁, A₂, …, Aₙ ⇒ B）。

  • 2. 有效推理（推理正确）的定义：若 A₁∧A₂∧…∧Aₙ → B 是重言式，则称该推理有效（正确），此时记 A₁, A₂, …, Aₙ ⇒ B。

  • 直观含义：只要前提全为真，结论必为真；

  • 特别注意：推理有效 ≠ 结论真实（前提可能本身为假）；推理无效时，即使结论为真，推理也不正确。

  • 3. 三种判定方法（考纲明确要求）

  • 真值表法：列出所有赋值，检查"前提全真的行中结论是否都为真"；或直接检查蕴涵式 A₁∧…∧Aₙ→B 是否恒真；适用：变元少（≤3 个）时直观

  • 主范式法：求前提合取 A = A₁∧…∧Aₙ 的成真赋值集合 S_A 与结论 B 的成真赋值集合 S_B；推理有效 ⟺ S_A ⊆ S_B（等价地：B 的主合取范式的大项集合 ⊆ A 的主合取范式的大项集合）；适用：变元较多、需要精确说明理由时
  • 推理法（形式证明）：用 P/T/CP 规则从前提逐步推出结论；适用：考试主流，答案规范、按步给分

（二）推理规则（必背）

  • P 规则：名称：前提引入规则；含义/用法：推理过程中随时可以引入一个前提
  • T 规则：名称：结论引用（重言蕴涵）规则；含义/用法：由已推出的公式（或前提），按重言蕴涵式/等值式推出新公式；可引用前面已证的结论；置换规则（用等值式替换子公式）属 T 规则

  • CP 规则：名称：附加前提（条件证明）规则；含义/用法：若要证明 A→B：把 A 作为附加前提引入，推出 B 后即得 A→B（可使证明大幅简化）

  • T 规则常用的蕴涵式/等值式（第 1 章已背，这里作为推理规则使用）

  • 假言推理：A∧(A→B) ⇒ B；
  • 拒取式：(A→B)∧¬B ⇒ ¬A；
  • 析取三段论：(A∨B)∧¬A ⇒ B；
  • 假言三段论：(A→B)∧(B→C) ⇒ A→C；
  • 化简：A∧B ⇒ A；附加：A ⇒ A∨B；合取引入：A, B ⇒ A∧B；
  • 构造性二难、破坏性二难；
  • 置换（等值替换）：A→B ⇔ ¬A∨B、德摩根律、分配律、双重否定、假言易位等。

补充（【注意】 视教材）：归谬法（反证法）——为证 A₁,…,Aₙ ⇒ B，把 ¬B 作为附加前提，若能推出矛盾（如 r∧¬r），则推理有效；亦可写为"由附加前提 ¬B 推出矛盾 ⇒ B"。

（三）形式证明的书写格式（阅卷按步给分）

序号    公式        依据
①      A→B        P
②      A           P
③      B          T①② 假言推理
……

写法要点：每行都要写"依据"（P 表示前提，T 表示由前面某几行 + 规则名推出，CP 表示附加前提/结论）；习惯上用真值表或主范式法验证结果。

（四）典型证明题（必考题型）

  • 【例 1】前提 p→q, q→r, p；结论 r
① p→q        P
② q→r        P
③ p          P
④ q          T①③ 假言推理
⑤ r          T②④ 假言推理

  • 说明：也可用假言三段论由 ①② 得 p→r，再由 ③ 得 r。推理有效（这就是"假言三段论 + 假言推理"）。

  • 【例 2】前提 (p∨q)→(r∧s), p；结论 r

① p              P
② p∨q            T① 附加律
③ (p∨q)→(r∧s)    P
④ r∧s            T②③ 假言推理
⑤ r              T④ 化简律
  • 【例 3】前提 ¬p∨q, ¬q∨r, p；结论 r
① ¬p∨q      P
② p          P
③ q          T①② 析取三段论
④ ¬q∨r      P
⑤ r          T③④ 析取三段论
  • 【例 4；用 CP 规则】前提 p→q, q→r；结论 p→r
① p→q        P
② q→r        P
③ p          CP（附加前提）
④ q          T①③ 假言推理
⑤ r          T②④ 假言推理
⑥ p→r        CP（由 ③~⑤ 得条件结论）
  • 【例 5；构造性二难】前提 p→q, r→s, p∨r；结论 q∨s
① p→q            P
② r→s            P
③ p∨r            P
④ q∨s            T①②③ 构造性二难
  • 【例 6；先验证再证明（含等值替换）】前提 p→(q→r), p, q；结论 r
① p→(q→r)       P
② p              P
③ q→r            T①② 假言推理
④ q              P
⑤ r              T③④ 假言推理

也可先用输出律 p→(q→r) ⇔ (p∧q)→r 替换后推理。

（五）真值表法 / 主范式法判定例题

  • 【例 7；真值表法判断有效性】 前提 p→q, q；结论 p（"肯定后件"的谬误）

  • 0：q：0；p→q：1；前提全真？：q=0，不符

  • 0：q：1；p→q：1；前提全真？：前提全真，而 p = 0
  • 1：q：0；p→q：0；前提全真？：p→q=0，不符
  • 1：q：1；p→q：1；前提全真？：前提全真，p = 1 ✓

→ 存在前提全真而结论假的赋值（p=0,q=1）⇒ 推理无效。

  • 【例 8；主范式法】 判定：前提 p∨q, ¬p∨r；结论 q∨r（归结形式）
  • 前提合取 A = (p∨q)∧(¬p∨r)，其成真赋值：010、011、101、111 ⇒ S_A = {2,3,5,7}；
  • 结论 B = q∨r，成真赋值：001、010、011、101、110、111 ⇒ S_B = {1,2,3,5,6,7}；

  • 因 S_A ⊆ S_B ⇒ 推理有效。
    （另：前提的主合取范式 ∏M(0,1,4,6)，结论的主合取范式 ∏M(0,4)，后者是前者的子集，也说明有效。）

  • 两种常见谬误（务必区分）

谬误 形式 反例
肯定后件 p→q, q ⇒ p p=0, q=1
否定前件 p→q, ¬p ⇒ ¬q p=0, q=1
  • 正确的推理形式（对照记忆）
正确 形式
假言推理 p→q, p ⇒ q
拒取式 p→q, ¬q ⇒ ¬p
析取三段论 p∨q, ¬p ⇒ q
假言三段论 p→q, q→r ⇒ p→r

六、本章对比与易混点

易混点 正确理解
析取范式 vs 合取范式 析取范式＝积之和（简单合取式的析取）；合取范式＝和之积（简单析取式的合取）
范式是否唯一 范式不唯一；主范式唯一（非矛盾式有唯一主析取，非重言式有唯一主合取）
小项 vs 大项编码 小项：1＝变元本身；大项：1＝变元的否定（两者相反，最易错！）
小项与大项的关系 ¬mᵢ ⇔ Mᵢ，¬Mᵢ ⇔ mᵢ（互为否定）
小项的作用 vs 大项的作用 小项对应成真赋值（写主析取）；大项对应成假赋值（写主合取）
主析取/主合取的下标关系 互补：∑m(S) ↔ ∏M(S̄)
矛盾式 / 重言式的主范式 矛盾式无主析取（主合取含全部 2ⁿ 个大项）；重言式无主合取（主析取含全部小项）
简单合取式 vs 简单析取式的"永假/永真" 简单合取式永假 ⟺ 同时含 p 与 ¬p；简单析取式永真 ⟺ 同时含 p 与 ¬p
推理有效 vs 结论真 推理有效指前提真则结论必真；结论真不代表推理有效；前提假时推理可能"有效"
⇒ 与 → ⇒ 是推理关系（元语言）；→ 是联结词（公式内部）
CP 规则 为证 A→B，把 A（前件）作为附加前提引入，推出 B
肯定后件 / 否定前件 都是无效推理；正确形式是假言推理与拒取式
