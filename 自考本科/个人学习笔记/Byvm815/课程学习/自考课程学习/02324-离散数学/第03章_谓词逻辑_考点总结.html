二、3.1 谓词的概念与表示（领会）

（一）基本概念

  • 个体词（个体）：所研究对象中可独立存在的对象（具体或抽象的实体）；表示：个体常元 a, b, c（具体对象）；个体变元 x, y, z（取值于个体域 D，又称论域）
  • 谓词：刻画个体性质或个体之间关系的词；表示：一元谓词 P(x)（性质）；n 元谓词 P(x₁,…,xₙ)（关系）；谓词常元/谓词变元
  • 命题函数：含个体变元的谓词表达式 P(x)；表示：本身不是命题（赋值后才成为命题）
  • 0 元谓词：不含个体词的谓词；表示：即命题（如 P）

（二）用谓词表示命题（领会，必练）

  • 方法：① 确定个体域 D；② 设个体常元表示具体对象；③ 设谓词表示性质/关系；④ 写成谓词表达式。
命题 符号化
张三是大学生 设 S(x)：x 是大学生，a：张三 → S(a)
3 > 2 设 G(x, y)：x > y → G(3, 2)
李四与王五同岁 设 E(x, y)：x 与 y 同岁 → E(l, w)
北京是中国的首都 设 C(x, y)：x 是 y 的首都 → C(b, c)
  • 要点：
  • 个体域不同，符号化写法不同（如"所有人都会死"在个体域"人类"下写 ∀xD(x)，在个体域"全体事物"下写 ∀x(M(x)→D(x))）；
  • 谓词本身不含真假，只有赋值（指定个体域、个体、谓词）后才成为有真假的命题。

三、3.2 量词与合式公式（识记，本章得分重点之一）

（一）量词

  • 全称量词：记号：∀x；读法："对所有 x""任意的 x"；个体域中所有个体都具有该性质

  • 存在量词：记号：∃x；读法："存在 x""至少有一个 x"；个体域中至少有一个个体具有该性质

  • 量词与有限个体域的关系（理解的关键）：若个体域有限 D = {a₁, a₂, …, aₙ}，则

  • ∀xP(x) ⇔ P(a₁)∧P(a₂)∧…∧P(aₙ)（全称量词是合取的推广）
  • ∃xP(x) ⇔ P(a₁)∨P(a₂)∨…∨P(aₙ)（存在量词是析取的推广）

    这一对应关系解释了符号化中"全称配蕴涵、存在配合取"的口诀。

（二）合式公式（谓词公式）的递归定义

① 原子公式：n 元谓词 P(x₁,…,xₙ)（含 0 元谓词即命题）是合式公式；
② 若 A 是合式公式，则 ¬A 是；
③ 若 A、B 是，则 (A∧B)、(A∨B)、(A→B)、(A↔B) 是；
④ 若 A 是合式公式，x 是个体变元，则 ∀xA、∃xA 是；
⑤ 只有有限次应用上述规则得到的符号串才是合式公式。

（三）指导变元与辖域

  • 指导变元（作用变元）：量词后面紧跟的那个个体变元（∀x、∃y 中的 x、y）；

  • 辖域（作用域）：量词所约束的范围——若量词后紧跟括号则括号内为其辖域，否则为紧跟其后的最小子公式。

  • 例：

公式 指导变元 辖域
∀x(P(x)→Q(x)) x (P(x)→Q(x))
∃x(P(x)∧Q(y)) x (P(x)∧Q(y))
∀xP(x)∧Q(x) x 只有 P(x)（最后一个 Q(x) 中的 x 不受约束）
∀x(P(x)→∃yQ(x,y)) x；y (P(x)→∃yQ(x,y))；(Q(x,y))

（四）自由出现与约束出现

  • 约束出现（约束变元）：变元出现在相应量词的辖域内且该量词的指导变元正是它；
  • 自由出现（自由变元）：变元不在任何以它为指导变元的量词辖域内。
  • 闭式（封闭公式）：不含自由变元的公式（一定是命题）；含自由变元的称开式。
公式 约束出现 自由出现
∀x(P(x)∧Q(x)) x 无（闭式）
∀xP(x)→Q(x) 前面的 x 后面的 x
∀x(P(x)→Q(y)) x y
  • 记忆技巧："看量词的指导变元是否罩住它"——被罩住是约束，没被罩住是自由。

（五）两个改写规则（必考）

  • 1. 约束变元改名规则（换名规则）
    改变量词的指导变元及其辖域中相应的变元名称（只改约束出现，不改自由出现）。

  • 限制：新名称不能与该量词辖域内已有的变元重名（否则改变公式含义）。
    例：∀x(P(x)→Q(x,y)) 可改名为 ∀z(P(z)→Q(z,y))（y 是自由的，不改）。

  • 2. 自由变元代入规则（代入规则）
    对公式中自由出现的个体变元，可用某个个体词（个体常元 or 自由个体变元）同时代入其所有自由出现。

  • 限制：代入后的变元不能被公式中的量词约束（否则要改名）。
    例：A(x) = P(x)∨Q(y) 中把自由变元 y 代入常元 a → P(x)∨Q(a)。

（六）命题的符号化（最常考，务必熟练）

自然语言 符号化（个体域为全域）
所有的 A 都是 B ∀x(A(x)→B(x))
有的 A 是 B ∃x(A(x)∧B(x))
所有的 A 都不是 B ∀x(A(x)→¬B(x)) 或 ¬∃x(A(x)∧B(x))
有的 A 不是 B ∃x(A(x)∧¬B(x))
并非所有的 A 都是 B ¬∀x(A(x)→B(x)) ⇔ ∃x(A(x)∧¬B(x))
有的 x 使 P 成立 ∃xP(x)
不存在使 P 成立的 x ¬∃xP(x) ⇔ ∀x¬P(x)
每个人都有父母 ∀x∃y(父母(x,y))
有一个数小于所有正数 ∃y∀x(正数(x)→小于(y,x))
  • 两个致命易错（必记）：
  • 全称量词配蕴涵：∀x(A(x)→B(x))（不能写成 ∀x(A(x)∧B(x))，那样成了"所有个体都是 A 且都是 B"）

  • 存在量词配合取：∃x(A(x)∧B(x))（不能写成 ∃x(A(x)→B(x))，那样"不是 A 的个体"也使之成立，语义过弱）

  • 多重量词的顺序不能随意交换（以 L(x,y)：x 爱 y 为例）

  • ∀x∃yL(x,y)：每个人都爱某个人（可以是不同的人）；
  • ∃y∀xL(x,y)：存在一个人，被所有人爱（同一个人）；
  • 二者不等值，但 ∃y∀xL(x,y) ⇒ ∀x∃yL(x,y)（单向）。
    （同种量词可交换：∀x∀y ⇔ ∀y∀x，∃x∃y ⇔ ∃y∃x）

四、3.3 谓词演算的等价式与蕴涵式（领会）

（一）赋值（解释）

  • 谓词公式的赋值（解释）包括四部分：
    ① 指定个体域 D；② 对个体常元指派 D 中的元素；③ 对自由个体变元指派 D 中的元素；④ 对谓词（及命题变元） 作出解释。

    赋值后公式成为命题，可判真假；若公式闭式，其真假只取决于个体域与谓词的解释。

  • 谓词公式的分类（相对命题公式的推广）

  • 永真式（有效公式）：在任何解释下都为真；
  • 矛盾式（不可满足式）：在任何解释下都为假；
  • 可满足式：存在一个解释使其为真。

（二）常用等值式（必背）

  • 1. 量词否定等值式（最常考）
公式 说明
¬∀xP(x) ⇔ ∃x¬P(x) "并非所有"＝"存在不"
¬∃xP(x) ⇔ ∀x¬P(x) "不存在"＝"所有都不"
¬∀x¬P(x) ⇔ ∃xP(x) 常用变形
¬∃x¬P(x) ⇔ ∀xP(x) 常用变形
  • 2. 量词辖域的扩张与收缩等值式（B 中不含变元 x）
等值式 备注
∀x(A(x)∧B) ⇔ ∀xA(x)∧B 合取可直接扩缩
∀x(A(x)∨B) ⇔ ∀xA(x)∨B 析取可直接扩缩
∃x(A(x)∧B) ⇔ ∃xA(x)∧B 合取可直接扩缩
∃x(A(x)∨B) ⇔ ∃xA(x)∨B 析取可直接扩缩
∀x(A→B(x)) ⇔ A→∀xB(x) 蕴涵前件不含 x
∃x(A→B(x)) ⇔ A→∃xB(x) 蕴涵前件不含 x
∀x(B(x)→A) ⇔ ∃xB(x)→A 蕴涵后件不含 x（注意变成 ∃）
∃x(B(x)→A) ⇔ ∀xB(x)→A 蕴涵后件不含 x（注意变成 ∀）
  • 3. 量词分配等值式（只有两条！）
成立 不成立（只有单向蕴涵）
∀x(A(x)∧B(x)) ⇔ ∀xA(x)∧∀xB(x) ∀x(A(x)∨B(x)) ⇐ ∀xA(x)∨∀xB(x)（反向不成立）
∃x(A(x)∨B(x)) ⇔ ∃xA(x)∨∃xB(x) ∃x(A(x)∧B(x)) ⇒ ∃xA(x)∧∃xB(x)（反向不成立）

  • 4. 同种量词可交换：∀x∀yP(x,y) ⇔ ∀y∀xP(x,y)；∃x∃y ⇔ ∃y∃x（异种量词不可交换）

  • 5. 命题逻辑等值式的推广：第 1 章的等值式（德摩根、分配律、吸收律、蕴涵等值式等）对谓词公式的子公式同样适用（作为整体替换）。

（三）常用蕴涵式（单向，必背）

蕴涵式 含义
∀xP(x) ⇒ ∃xP(x) 个体域非空时，"所有"推出"存在"
∀xP(x)∨∀xQ(x) ⇒ ∀x(P(x)∨Q(x)) 全称对析取只有单向
∃x(P(x)∧Q(x)) ⇒ ∃xP(x)∧∃xQ(x) 存在对合取只有单向
∀x(A(x)→B(x)) ⇒ ∀xA(x)→∀xB(x) 全称蕴涵推出蕴涵的全称
∀x(A(x)→B(x)) ⇒ ∃xA(x)→∃xB(x) 全称蕴涵推出存在的蕴涵
∃y∀xP(x,y) ⇒ ∀x∃yP(x,y) 量词顺序（强的推弱的）

五、3.4 前束范式（简单应用）

（一）定义

  • 前束范式：形如 Q₁x₁Q₂x₂…QₖxₖM 的公式，其中 Qᵢ ∈ {∀, ∃}，所有量词都在公式最前面（辖域延伸到整个公式），M 称为母式（矩阵），不含任何量词。

    例：∀x∃y(P(x)∧Q(y)) 是前束范式；¬∃xP(x)∨Q(x) 不是（¬ 与 ∃ 混在一起、量词未前置）。

（二）求前束范式的步骤（必考，五步法）

  • ① 消去 → 与 ↔：用 A→B ⇔ ¬A∨B、A↔B ⇔ (A→B)∧(B→A)；
  • ② 把 ¬ 内移：用德摩根律 + 量词否定等值式（¬∀x ↔ ∃x¬、¬∃x ↔ ∀x¬），使 ¬ 只作用于原子公式；
  • ③ 换名（改约束变元名称）：使各量词的指导变元互不相同、且与自由变元不重名（避免前置后变元冲突）；
  • ④ 量词前移：用辖域扩张等值式把量词逐个移到公式最前面（注意后件不含 x 的情形会改变量词种类）；

  • ⑤ 整理母式：得到 Q₁x₁…QₖxₖM。

  • 要点：前束范式不唯一（换名方式、量词前移顺序不同会得到不同形式，但彼此等值）。

（三）典型例题

  • 【例 1】求 ∀x(P(x)→Q(x)) 的前束范式
    = ∀x(¬P(x)∨Q(x))　→ 已是前束范式（量词在最前，母式 ¬P(x)∨Q(x)）。

  • 【例 2】求 ∀xP(x)→∃xQ(x) 的前束范式
    = ¬∀xP(x)∨∃xQ(x)　（消去 →）
    = ∃x¬P(x)∨∃xQ(x)　（量词否定）
    = ∃x¬P(x)∨∃yQ(y)　（换名，避免同名冲突）
    = ∃x∃y(¬P(x)∨Q(y))　（量词前移）

  • 【例 3】求 ¬(∀xP(x)→∃yQ(y)) 的前束范式
    = ¬(¬∀xP(x)∨∃yQ(y))　（消去 →）
    = ∀xP(x)∧¬∃yQ(y)　（德摩根）
    = ∀xP(x)∧∀y¬Q(y)　（量词否定）
    = ∀x∀y(P(x)∧¬Q(y))　（量词前移）

  • 【例 4】求 ∃xP(x)→∀yQ(y) 的前束范式
    = ¬∃xP(x)∨∀yQ(y)
    = ∀x¬P(x)∨∀yQ(y)
    = ∀x∀y(¬P(x)∨Q(y))

  • 【例 5】求 ∃x(P(x)∧∀y(Q(y)→R(x,y))) 的前束范式
    = ∃x∀y(P(x)∧(Q(y)→R(x,y)))　（用 ∀x(A∧B(x)) ⇔ A∧∀xB(x) 把 ∀y 前移）
    = ∃x∀y(P(x)∧(¬Q(y)∨R(x,y)))　（母式中消去 →）

  • 【例 6】求 ∀xP(x)∨∃yQ(y) 的前束范式（注意 ¬ 不涉及，直接前移）
    先将 ∃y 换名（若与 x 同名）→ ∀x∃y(P(x)∨Q(y))

六、3.5 谓词演算的推理理论（简单应用）

（一）量词推理的四条基本规则（必背）

  • US：名称：全称指定（例示）规则；形式：∀xA(x) ⇒ A(c)（或 A(y)）；限制条件（易考）：用个体常元 c 或不在公式中出现的变元 y 代入；代入后的变元不能落入新量词的辖域
  • ES：名称：存在指定（例示）规则；形式：∃xA(x) ⇒ A(c)；限制条件（易考）：c 必须是前面未出现过的特定个体常元（"新名字"），且只能先例示、后使用
  • UG：名称：全称推广规则；形式：A(x) ⇒ ∀xA(x)；限制条件（易考）：x 必须是任意的：不能是由 ES 引入的特定常元，且未被其他量词约束
  • EG：名称：存在推广规则；形式：A(c) ⇒ ∃xA(x)；限制条件（易考）：用 c 或 x 代入均成立（由"有一个"推广得 ∃）

记忆：US/ES 是"消去量词"（往下用），UG/EG 是"引入量词"（往上用）；
US 与 ES 的区别：US 可对任意个体（常元或变元）进行，ES 只能指定一个新的特定常元；
UG 与 EG 的区别：EG 对具体个体可推广，UG 必须保证该变元具有任意性（尤其不能是 ES 指定的常元）。

（二）书写格式：在命题逻辑 P/T/CP 规则基础上增加量词规则

序号    公式                依据
①      ∀x(M(x)→D(x))      P
②      M(s)→D(s)          US①            （s：苏格拉底）
③      M(s)               P
④      D(s)               T②③ 假言推理

（三）典型例题（必考题型）

  • 【例 1】所有人都会死；苏格拉底是人 ⇒ 苏格拉底会死
① ∀x(M(x)→D(x))     P
② M(s)→D(s)         US①
③ M(s)              P
④ D(s)              T②③ 假言推理

推理有效（形式化后即命题逻辑的假言推理）。

  • 【例 2】∀x(P(x)→Q(x)), ∃xP(x) ⇒ ∃xQ(x)
① ∃xP(x)            P
② P(c)              ES①            （c 为新的特定常元）
③ ∀x(P(x)→Q(x))     P
④ P(c)→Q(c)         US③
⑤ Q(c)              T②④ 假言推理
⑥ ∃xQ(x)            EG⑤
  • 【例 3】∃x(P(x)∧Q(x)) ⇒ ∃xP(x)
① ∃x(P(x)∧Q(x))     P
② P(c)∧Q(c)         ES①
③ P(c)              T② 化简
④ ∃xP(x)            EG③
  • 【例 4】∀x(P(x)→Q(x)) ⇒ ∃xP(x)→∃xQ(x)（结论是条件式 → 用 CP 规则）
① ∃xP(x)            CP（附加前提）
② P(c)              ES①
③ ∀x(P(x)→Q(x))     P
④ P(c)→Q(c)         US③
⑤ Q(c)              T②④ 假言推理
⑥ ∃xQ(x)            EG⑤
⑦ ∃xP(x)→∃xQ(x)     CP
  • 【例 5】∀x(P(x)→Q(x)) ⇒ ∀xP(x)→∀xQ(x)
① ∀xP(x)            CP
② ∀x(P(x)→Q(x))     P
③ P(y)              US①            （用变元 y，便于后面 UG）
④ P(y)→Q(y)         US②
⑤ Q(y)              T③④ 假言推理
⑥ ∀xQ(x)            UG⑤
⑦ ∀xP(x)→∀xQ(x)     CP
  • 【例 6】∀x(P(x)→Q(x)), ∀x(Q(x)→R(x)) ⇒ ∀x(P(x)→R(x))
① ∀x(P(x)→Q(x))     P
② ∀x(Q(x)→R(x))     P
③ P(y)→Q(y)         US①
④ Q(y)→R(y)         US②
⑤ P(y)→R(y)         T③④ 假言三段论
⑥ ∀x(P(x)→R(x))     UG⑤
  • 【例 7】"每个大学生都要学数学，小李是大学生 ⇒ 小李要学数学"
    形式化：∀x(S(x)→M(x)), S(l) ⇒ M(l)（同例 1 的证明结构）

（四）常见错误提示

  • ES 指定的常元必须是新的：若前面已用 c 作 ES，后面再 ES 必须换新名（如 d）；
  • 不能对 ES 指定的常元作 UG（否则由"某个特定个体"错误地推出"所有个体"）；
  • US 代入的变元不能被新的量词辖域捕获（必要时先换名）；
  • 引用前提（P）顺序不受限制，但 ES 的"新常元"约束与步骤顺序有关，一般先 ES 后 US（避免冲突）。

七、本章对比与易混点

易混点 正确理解
个体词 vs 谓词 个体词＝对象；谓词＝对象的性质或关系
谓词 vs 命题 谓词（含变元）不是命题（命题函数）；赋值/加量词后才是命题
∀ 配 ∧ 还是 → 符号化"所有 A 都是 B"用 ∀x(A(x)→B(x))；存在 A 是 B 用 ∃x(A(x)∧B(x))
指导变元 vs 辖域 指导变元＝量词后紧跟的变元；辖域＝量词约束的范围（只看紧跟的最小公式）
约束出现 vs 自由出现 被量词"罩住"的是约束；否则自由；闭式无自由变元
改名 vs 代入 改名改约束出现（只改某量词辖域内）；代入改自由出现（全部同时代入）
量词否定 ¬∀xP(x) ⇔ ∃x¬P(x)；¬∃xP(x) ⇔ ∀x¬P(x)（"否定了量词要翻牌"）
分配等值式 只有 ∀(A∧B) ⇔ ∀A∧∀B 与 ∃(A∨B) ⇔ ∃A∨∃B 成立；另外两条只有单向蕴涵
辖域扩张的蕴涵式 ∀x(B(x)→A) ⇔ ∃xB(x)→A（后件不含 x 时量词由 ∀ 变 ∃），反之亦然
量词顺序 ∃y∀xP ⇒ ∀x∃yP（不可反推）；同种量词可交换
前束范式 所有量词都在最前面且母式不含量词；不唯一
US / ES US 可代任意个体；ES 只能用新常元
UG / EG EG 由具体个体得 ∃；UG 要求变元任意（ES 的常元不能 UG）
