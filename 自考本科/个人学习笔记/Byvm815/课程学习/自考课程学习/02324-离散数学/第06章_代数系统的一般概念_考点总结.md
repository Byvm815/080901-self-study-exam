## 二、6.1 代数系统（领会）

### （一）代数系统与二元运算

- **1. 二元运算**：设 S 是**非空集合**，映射 **f: S×S → S** 称为 **S 上的二元运算**（常记作 * 或 ·）。
- 二元运算的定义本身就要求**结果属于 S**（即**封闭性**是二元运算的固有要求）；
- **n 元运算**：f: Sⁿ → S；若某运算的结果可能超出 S，则称该运算在 S 上**不封闭**，不能作为 S 上的运算。

- **2. 代数系统**：**非空集合 S 连同 S 上的若干运算**，记作 **<S, *, ∘, …>**。
- 例：<Z, +>、<R, ·>、<P(A), ∪, ∩>、<Z, +, ·>、<M_n(R), +, ·>。

### （二）运算的六条性质（必背，判别时逐条核对）

| 性质 | 定义（设 * 为 S 上二元运算） |
|---|---|
| **封闭性** | **∀x, y∈S，x*y ∈ S** |
| **交换律** | **∀x, y∈S，x*y = y*x** |
| **结合律** | **∀x, y, z∈S，(x*y)*z = x*(y*z)** |
| **幂等律** | **∀x∈S，x*x = x**（元素 x 满足 x*x = x 时称 **x 是幂等元**） |
| **分配律** | 对两个运算 * 与 ∘：**x*(y∘z) = (x*y)∘(x*z)**（* 对 ∘ 左分配）；**右分配**同理，左右都成立才说满足分配律 |
| **吸收律** | 对两个运算 * 与 ∘：**x*(x∘y) = x** 且 **x∘(x*y) = x** |

> 补充（【注意】 视教材）：**消去律**——若 x*y = x*z 则 y = z（**左消去**）；若 y*x = z*x 则 y = z（**右消去**）。

- **典型实例**

- **<Z, +>**：交换律：✔；结合律：✔；幂等律：✘；分配律：—；吸收律：—
- **<Z, ·>**：交换律：✔；结合律：✔；幂等律：部分（0、1 幂等）；分配律：· 对 + 分配 ✔；吸收律：—
- **<P(A), ∪, ∩>**：交换律：✔；结合律：✔；幂等律：✔；分配律：∪、∩ 互相分配 ✔；吸收律：✔
- **<Z, −>（减法）**：交换律：✘；结合律：✘；幂等律：✘；分配律：—；吸收律：—

### （三）特殊元素（必考，务必会算）

- **幺元（单位元）e**：**∀x∈S，e\*x = x\*e = x**；存在性与唯一性：**若存在必唯一**
- **零元 θ**：**∀x∈S，θ\*x = x\*θ = θ**；存在性与唯一性：**若存在必唯一**
- **幂等元**：满足 **x\*x = x** 的元素 x；存在性与唯一性：可多个（幺元、零元通常都是幂等元）
- **逆元**：设 e 为幺元，对 a∈S，若存在 **b 使 a\*b = b\*a = e**，则称 **b 为 a 的逆元**，记 a⁻¹；存在性与唯一性：在**结合律**下**若存在必唯一**
- **左（右）幺元 / 左（右）逆元**：只满足一侧（了解）；存在性与唯一性：—

- **唯一性证明（常考简答）**
- **幺元唯一**：设 e₁、e₂ 都是幺元，则 **e₁ = e₁\*e₂ = e₂** ✓
- **逆元唯一**（结合律下）：设 b、c 都是 a 的逆元，则
- **b = b\*e = b\*(a\*c) = (b\*a)\*c = e\*c = c** ✓

- **常见实例一览**

- **<Z, +>**：幺元：**0**；零元：无；幂等元：0；可逆元：所有元素（a⁻¹ = −a）
- **<Z, ·>**：幺元：**1**；零元：**0**；幂等元：0、1；可逆元：±1
- **<Q, +>**：幺元：0；零元：无；幂等元：0；可逆元：所有元素
- **<R−{0}, ·>**：幺元：1；零元：无；幂等元：1；可逆元：所有元素
- **<P(A), ∪>**：幺元：**∅**；零元：**A**；幂等元：全部元素；可逆元：仅 ∅（自身为逆元）
- **<P(A), ∩>**：幺元：**A**；零元：**∅**；幂等元：全部元素；可逆元：仅 A
- **<P(A), ⊕>（对称差）**：幺元：**∅**；零元：无；幂等元：仅 ∅；可逆元：**所有元素（逆元为自身）**

- **逆元的性质**：**(a⁻¹)⁻¹ = a**；若 a、b 有逆元，则 **(a\*b)⁻¹ = b⁻¹\*a⁻¹**（**顺序颠倒**）。

- **由运算表判断特殊元素（常考题型）**
- **交换律**：运算表关于**主对角线对称**；
- **幺元**：某元素的**行与列都与表头相同**（该行/列原样照抄表头）；
- **零元**：该元素的**行与列全部等于它自己**；
- **逆元**：先找幺元 e，再对 a 找出满足 a\*b = b\*a = e 的 b；
- **幂等元**：**主对角线上**元素 = 该元素本身者。

## 三、6.2 群与半群（领会，本章核心判别题）

### （一）半群、独异点、群（三级定义，必背）

- **半群**：定义（逐步加强）：代数系统 <S, *>，其中 * **封闭**且**满足结合律**；例子：<Z⁺, +>、<R, ·>、<P(A), ∪>
- **独异点（含幺半群）**：定义（逐步加强）：**半群**且**含幺元**；例子：<N, +>（幺元 0）、<Z, ·>（幺元 1）、<P(A), ∪>（幺元 ∅）、<M_n(R), ·>
- **群**：定义（逐步加强）：**独异点**且**每个元素都有逆元**（即：封闭 + 结合 + 幺元 + 逆元）；例子：<Z, +>、<Q, +>、<R−{0}, ·>、<P(A), ⊕>、<Zₙ, +ₙ>
- **交换群（Abel 群）**：定义（逐步加强）：**群**且运算满足**交换律**；例子：<Z, +>、<R−{0}, ·>、<P(A), ⊕>

- **判别流程（务必按顺序核对）**：**① 是否封闭 → ② 是否结合 → ③ 有无幺元 → ④ 每个元素是否可逆 → ⑤（若问是否交换群）运算是否可交换**。

- **判别示例**

| 系统 | 判别结论 | 原因 |
|---|---|---|
| <Z, +> | **Abel 群** | 封闭、结合、幺元 0、逆元 −a、可交换 |
| <Z, ·> | **独异点（不是群）** | 幺元 1，但 2 无乘法逆元 |
| <N, +>（含 0） | **独异点（不是群）** | 幺元 0，但正整数无负元 |
| <Z⁺, +> | **半群（不是独异点）** | 无幺元（0∉Z⁺） |
| <R, ·> | **独异点（不是群）** | 0 无逆元 |
| <R−{0}, ·> | **Abel 群** | 每非零数有倒数 |
| <P(A), ∪> | **独异点（不是群）** | 幺元 ∅，但非空子集无逆元 |
| **<P(A), ⊕>（对称差）** | **Abel 群** | 幺元 ∅，每元素逆元为自身 |

### （二）群的阶与基本性质

- **群的阶**：群 G 的元素个数 **|G|**；有限群（|G| 有限）/ 无限群。
- **元素的阶（周期，了解）**：使 **aⁿ = e** 的最小正整数 n；例：<Z₄, +₄> 中 1 的阶为 4，2 的阶为 2。

- **群的性质（必背）**
- **幺元唯一、每个元素的逆元唯一**；
- **群中成立消去律**：a\*b = a\*c ⇒ **b = c**（左消去）；b\*a = c\*a ⇒ **b = c**（右消去）；
- **方程有唯一解**：a\*x = b 的解 **x = a⁻¹\*b**；y\*a = b 的解 **y = b\*a⁻¹**；
- **(a⁻¹)⁻¹ = a**；**(a\*b)⁻¹ = b⁻¹\*a⁻¹**；
- 群中**除幺元外不存在其他幂等元**（即若 a\*a = a，则 a = e）；
- **群中不存在零元**（除非 |G| = 1 的平凡群）；
- 有限半群若满足消去律，则它必是群（了解）。

### （三）子群及其判别条件（必考）

- **定义**：设 <G, *> 是群，∅ ≠ H ⊆ G，若 **<H, \*> 本身也是群**，则称 H 是 G 的**子群**，记 **H ≤ G**。
- **平凡子群**：**{e}** 与 **G 本身**；
- 例：<Z, +> 的子群 **<nZ, +> = {0, ±n, ±2n, …}**（n 为非负整数）；<Z₆, +₆> 的子群 {0,3}、{0,2,4}。

- **子群的判别条件（三个常用定理，必背）**

- **判别法一（两步法）**：条件：H **非空**；① **∀a, b∈H，a\*b ∈ H**（封闭）；② **∀a∈H，a⁻¹ ∈ H**（逆元封闭）；用法：分别验证封闭与逆元
- **判别法二（一步法，最常用）**：条件：H **非空**，且 **∀a, b∈H，a\*b⁻¹ ∈ H**（或 a⁻¹\*b ∈ H）；用法：一步同时验证封闭与逆元
- **判别法三（有限子群）**：条件：H 是 G 的**非空有限子集**，且 **H 对 * 封闭**；用法：有限集只需验封闭（结合律与逆元自动满足）

- **例（用一步法）**：证明 **2Z = {2k | k∈Z}** 是 <Z, +> 的子群
- 2Z ≠ ∅（0 = 2×0 ∈ 2Z）；
- 任取 a = 2m, b = 2n ∈ 2Z，则 **a * b⁻¹ = a + (−b) = 2m − 2n = 2(m−n) ∈ 2Z** ✓
- 故 **2Z ≤ Z** ✓

- **例（有限子集只验封闭）**：<Z₆, +₆> 中 H = {0, 2, 4}：非空且封闭（2+2=4、2+4=0、4+4=2 均在 H 中）⇒ H ≤ Z₆ ✓

### （四）运算表判别群（经典例题）

设 S = {e, a, b, c}，运算 * 的运算表如下（e 为幺元）：

- **e**：e：e；a：a；b：b；c：c
- **a**：e：a；a：e；b：c；c：b
- **b**：e：b；a：c；b：e；c：a
- **c**：e：c；a：b；b：a；c：e

- **判别**：
- **封闭**：表中所有结果都在 S 中 ✓；
- **幺元**：e 所在行、列与表头完全一致 ⇒ **e 是幺元** ✓；
- **逆元**：a\*a = e、b\*b = e、c\*c = e ⇒ **每个元素都以自身为逆元** ✓；
- **交换**：表关于主对角线对称 ✓；
- **结合律**：该表正是 **Klein 四元群**（Z₂×Z₂）的运算表，满足结合律 ✓
⇒ **<S, *> 是交换群（Abel 群）**，且每个非幺元元素的阶都是 2。

## 四、6.3 环与域（识记）

### （一）环

- **定义**：代数系统 **<R, +, ·>**（带两个二元运算），若满足：
① **<R, +> 是交换群（Abel 群）**；  
② **<R, ·> 是半群**（封闭 + 结合）；  
③ **· 对 + 满足分配律**（左、右分配），  
则称 **<R, +, ·>** 为**环**。

- **记号与术语**：+ 称**加法**、· 称**乘法**；加法幺元记 **0**；a 的加法逆元记 **−a**；若乘法有幺元记 **1**。
- **例子**：<Z, +, ·>、<Q, +, ·>、<R, +, ·>、<C, +, ·>、<Zₙ, +ₙ, ×ₙ>、多项式环 R[x]、矩阵环 <M_n(R), +, ·>。
- **基本性质（了解）**：**0·a = a·0 = 0**；**(−a)·b = a·(−b) = −(ab)**；**(a−b)·c = a·c − b·c**。

- **环的分类**

| 类型 | 条件 |
|---|---|
| **交换环** | 乘法满足**交换律** |
| **含幺环** | 乘法**有幺元 1** |
| **无零因子环** | 若 ab = 0 则 a = 0 或 b = 0 |
| **整环** | **交换环 + 含幺环 + 无零因子 + | R | ≥ 2** 【注意】 |

### （二）域

- **定义**：代数系统 **<F, +, ·>**（**至少含两个元素**），若满足：
① **<F, +> 是交换群**；  
② **<F − {0}, ·> 是交换群**（即**所有非零元素对乘法构成交换群**）；  
③ **· 对 + 满足分配律**，  
则称 **<F, +, ·>** 为**域**。

- **例子**：**<Q, +, ·>**、**<R, +, ·>**、**<C, +, ·>**、**<Z_p, +_p, ×_p>（p 为素数）**。
- **反例**：**<Z, +, ·> 不是域**——因为 2∈Z 且 2 ≠ 0，但 2 的乘法逆元 1/2 ∉ Z（非零元对乘法不构成群）。

- **层级关系（必记）**：
- **域 ⇒ 整环 ⇒ 交换含幺环 ⇒ 环**
（**域一定是整环**：域中若无零因子条件不满足，则 ab = 0 且 a ≠ 0 会导致 b = a⁻¹·0 = 0，矛盾；**整环不一定是域**，如 <Z, +, ·> 是整环但非域。）
- **有限整环必是域**（了解）。

## 五、本章对比与易混点

| 易混点 | 正确理解 |
|---|---|
| **封闭性 vs 二元运算** | 二元运算的定义已要求结果属于 S；若运算结果可能超出 S，则该运算**不是** S 上的运算 |
| **半群 / 独异点 / 群** | 半群＝封闭+结合；独异点＝半群+**幺元**；群＝独异点+**每元素可逆** |
| **幺元 vs 零元** | e\*x = x（不变）；θ\*x = θ（"吃掉"一切） |
| 幂等元 vs 幂等律 | 某元素 x\*x = x 称**幂等元**；所有元素都如此才称运算满足**幂等律** |
| 幺元/零元/逆元的唯一性 | **幺元、零元若存在必唯一**；**逆元在结合律下唯一**（非结合时可能不唯一） |
| **群的判别** | 必须**四条全满足**：封闭、结合、有幺元、每元素可逆（**缺一不可**） |
| <Z, ·> 是群吗 | **不是**（独异点），因 2 无乘法逆元 |
| 群中能否有零元 | **不能**（除平凡群），且群中除幺元外**无幂等元** |
| **子群判别** | 非空 + 封闭 + 逆元封闭（或一步法 a\*b⁻¹∈H）；**有限子集只需封闭** |
| **环 vs 域** | 环只要求 <R,+> 交换群、<R,·> **半群**；域要求 <F−{0},·> 是**交换群** |
| 域与整环 | **域 ⇒ 整环**；整环**不一定**是域（如 Z） |
| (a\*b)⁻¹ | = **b⁻¹\*a⁻¹**（顺序颠倒） |

### （三）判别题模板（最常考）

- **判群（五步）**：① 封闭（运算结果是否仍在集合内）→ ② 结合律 → ③ 找幺元（逐一验证候选元素）→ ④ 每个元素是否都有逆元 →（⑤ 是否交换 ⇒ 是否 Abel 群）。
- **判半群/独异点**：只需验 ① 封闭 + ② 结合；（独异点再加）③ 是否有幺元。
- **由运算表判别**：交换＝表对称；幺元＝该行该列照抄表头；零元＝该行该列全是它；逆元＝对每元素找 b 使 a\*b = e；幂等元＝主对角线上等于自身者。
- **判子群**：先找幺元与逆元，再用"非空 + a\*b⁻¹ ∈ H"一步法；有限子集只验封闭。
- **判环/域**：先验 <R, +> 是交换群（含幺元、每元素有负元、可交换）；再验乘法是半群（域则要"非零元成群"）；最后验分配律。
