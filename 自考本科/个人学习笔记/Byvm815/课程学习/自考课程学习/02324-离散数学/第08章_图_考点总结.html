二、8.1 图的基本概念（识记）

（一）图的定义

  • 无向图 G = ：V 是非空有穷的顶点集（元素称顶点），E 是 V 中元素的无序对构成的集合（元素称边）。
  • 有向图 D = ：E 是 V 中元素的有序对（称有向边/弧）， 中 u 为始点（弧尾）、v 为终点（弧头）。
  • 图的阶：顶点数 |V| = n（称 n 阶图）；

  • 无向边记 (u, v)（= (v, u)）；有向边记 （≠ ）。

  • 关联与邻接（两个易混术语）

  • 关联：边 e = (u, v) 与它的端点 u、v 相关联（边与顶点的关系）；
  • 邻接：若 u、v 之间有边，则称 u 与 v 相邻（邻接）（顶点与顶点的关系）。

（二）几类特殊的图（必记）

名称 定义 说明
零图 E = ∅ 的图（n 阶零图记 Nₙ） 只有顶点没有边
平凡图 1 阶零图（ V
无向完全图 Kₙ 任意两顶点之间都有边 边数 = n(n−1)/2
有向完全图 任意两顶点之间都有两条方向相反的弧 弧数 = n(n−1)
简单图 无平行边、无环的图 反之称多重图 【注意】（教材约定）
稀疏图 / 密集图 边数相对较少 / 接近完全图 相对概念

（三）子图与补图

概念 定义
子图 G' = ，V' ⊆ V，E' ⊆ E（且 E' 中边的端点都在 V' 中）
真子图 G' ⊆ G 且 G' ≠ G
生成子图（支撑子图） 子图且 V' = V（含全部顶点）
导出子图 由 V' 导出的子图（顶点集为 V'，边集取 G 中两端点都在 V' 中的全部边）
补图 ~G 与 G 有相同顶点集，且 u、v 在 ~G 中相邻 ⟺ u、v 在 G 中不相邻（【注意】 通常对简单图定义）
自补图 与自己的补图同构的图（G ≅ ~G）
  • 自补图的必要条件（常考）
  • 若 n 阶图是自补图，则其边数须为完全图边数的一半：|E| = n(n−1)/4，故 n(n−1) 能被 4 整除，即 n ≡ 0 或 1 (mod 4)；
  • 例：n = 4 时 |E| = 3（4 阶路径 P₄ 是自补图）；n = 5 时 |E| = 5（5 阶圈 C₅ 是自补图）。

（四）顶点的度与握手定理（本章最常考）

  • 无向图：顶点 v 的度 deg(v) = 与 v 关联的边数（【注意】 环对度贡献 2）；
  • 有向图：出度 deg⁺(v)（以 v 为始点的弧数）、入度 deg⁻(v)（以 v 为终点的弧数），deg(v) = deg⁺(v) + deg⁻(v)；

  • 最大度 Δ(G)、最小度 δ(G)。

  • 【重点】 握手定理（欧拉定理，必背）

  • 无向图：Σ_{v∈V} deg(v) = 2|E|（所有顶点度数之和 = 边数的两倍）；

  • 有向图：Σ deg⁺(v) = Σ deg⁻(v) = |E|。

  • 重要推论

  • 任何图中，奇度顶点的个数必为偶数；
  • 一个非负整数序列能成为某图的度序列的必要条件：和为偶数（且最大值不超过 n−1）；
  • 简单无向图 n 个顶点最多 n(n−1)/2 条边；

  • 若每个顶点的度都等于 r，则称 r 度正则图，此时 |E| = nr/2，故 n·r 必为偶数（如"每个顶点度数都是 3" ⇒ n 必为偶数）。

  • 典型计算题

  • 例 1：无向图 6 个顶点的度依次为 1, 1, 2, 2, 3, 3 ⇒ Σ = 12 ⇒ |E| = 6；
  • 例 2：G 中有 4 个度为 3 的顶点、6 个度为 2 的顶点，其余顶点度为 1 且共有 2 个 ⇒ Σ = 12+12+2 = 26 ⇒ |E| = 13；
  • 例 3：判断"是否存在 3 个顶点、度分别为 2, 3, 3 的简单无向图"——3 阶简单图最大度为 2 ⇒ 不存在；
  • 例 4：已知图有 10 条边、每个顶点度数相同，n = 5 ⇒ 每个顶点度为 2×10/5 = 4（4 度正则图，即 K₅ 的 10 条边 ✓）。

三、8.2 图的连通性（领会）

（一）通路与回路（术语辨析，必考）

  • 通路（路径）：顶点与边交替出现的序列 v₀e₁v₁e₂…eₖvₖ（每条边两端正是相邻的两个顶点）；通路的长度 = 边数 k
  • 回路（圈）：起点与终点相同的通路（v₀ = vₖ）；长度 ≥ 1（简单图中 ≥ 3）
  • 简单通路：边不重复的通路（迹）；看边
  • 简单回路：边不重复的回路；看边
  • 初级通路（路径）：顶点不重复的通路；看顶点

  • 初级回路（圈）：除起点=终点外，顶点不重复的回路；看顶点

  • 关系与结论

  • 初级通路一定是简单通路；简单通路不一定是初级通路（例如 A→B→C→A→D 中顶点 A 重复但边不重复）；
  • 在简单图中，通路可直接用顶点序列表示（边由顶点对唯一确定）；
  • 重要定理：在 n 阶图中，若 u 与 v 之间存在通路，则必存在长度不超过 n−1 的初级通路；若存在经过某顶点的回路，则必存在长度不超过 n 的初级回路。

（二）无向图的连通性

概念 定义
连通（u ~ v） u 与 v 之间存在通路
连通图 图中任意两个顶点都连通
连通分支（连通分量）p(G) 极大连通子图的个数（n 阶连通图 p = 1）
  • 常用结论
  • 若无向图有 n 个顶点、p 个连通分支，则边数 |E| ≥ n − p（取等号时每个分支都是树，等价于"生成森林"）；
  • 若 |E| > (n−1)(n−2)/2，则图必连通（了解）；
  • 顶点数 n ≥ 2 的连通图至少有 n−1 条边（树）。

（三）有向图的连通性（三类，必记层次关系）

类型 定义
强连通 任意两顶点之间互相可达（u 到 v、v 到 u 都有通路）
单向连通 任意两顶点之间至少有一个方向可达
弱连通 忽略弧的方向后（作为无向图）是连通的
  • 层次关系：强连通 ⟹ 单向连通 ⟹ 弱连通（反之不成立）。
  • 可达：有向图中 u 到 v 存在有向通路，称 u 可达 v；
  • 有向图中"两个顶点互相可达"是等价关系（对应强连通分支，了解）。

四、8.3 图的表示（简单应用）

（一）邻接矩阵

  • 定义：对 n 阶图（顶点依次编号 v₁, v₂, …, vₙ），邻接矩阵 A = (aᵢⱼ)ₙₓₙ：
  • 无向图：aᵢⱼ = 1 ⟺ vᵢ 与 vⱼ 之间有边；aᵢⱼ = 0 否则（顶点到自身无环时对角线为 0）；

  • 有向图：aᵢⱼ = 1 ⟺ 是弧（即 vᵢ 到 vⱼ 有弧）；aᵢⱼ = 0 否则。

  • 由邻接矩阵读图的信息（必考）

想知道什么 如何从 A 读出

边数（无向） 所有元素之和 ÷ 2（即 Σᵢ 行和 ÷ 2）

（二）邻接矩阵的幂 Aᵏ 的含义（难点·路径矩阵，必考）

  • 【重点】 定理：设 A 为图 G 的邻接矩阵，则 Aᵏ 的第 i 行第 j 列元素 (Aᵏ)ᵢⱼ = 从 vᵢ 到 vⱼ 长度为 k 的通路的数目。

    对有向图与无向图同样成立（无向图中"通路"不计方向）。

  • 由 Aᵏ 判断连通性

  • 若在 A + A² + A³ + … + A^(n−1) 中 (i, j) 元素非 0，则 vᵢ 与 vⱼ 连通（u 可达 v）；
  • 由此可定义可达矩阵（路径矩阵）P：Pᵢⱼ = 1 ⟺ vᵢ 到 vⱼ 存在长度 ≤ n−1 的通路；无向图的可达矩阵对称，有向图一般不称；

  • 无向图的连通分支个数可由 P 判断（P 中互相可达的顶点构成一个分支）。

  • 例（承上）：A 如上，计算 A² 的若干元素

  • (A²)₁₁ = 0·0 + 1·1 + 1·1 + 0·0 = 2 ⇒ v₁ 到 v₁ 长度为 2 的通路有 2 条：v₁v₂v₁、v₁v₃v₁；
  • (A²)₁₃ = 0·1 + 1·1 + 1·0 + 0·1 = 1 ⇒ v₁ 到 v₃ 长度为 2 的通路 1 条：v₁v₂v₃；

  • (A²)₁₄ = 0·0 + 1·0 + 1·1 + 0·0 = 1 ⇒ v₁ 到 v₄ 长度为 2 的通路 1 条：v₁v₃v₄。

  • 计算要点：矩阵乘法（普通整数乘法）下，(Aᵏ)ᵢⱼ = Σ_{t₁,…,t_{k−1}} aᵢt₁·a_t₁t₂·…·a_{t_{k−1}j}，每一项对应一条长度为 k 的通路；若只关心"是否存在"，则可用布尔矩阵乘法（∨ 与 ∧）。

（三）计算 / 应用模板

  • 求度与边数：写出全部顶点的度 → Σdeg = 2|E| 求边数；反之由边数求度。
  • 判存在性：① 度序列和为偶数；② 最大值 ≤ n−1（简单图）；③ 奇度顶点个数为偶数；不满足即不存在。
  • 完全图/正则图：Kₙ 边数 n(n−1)/2；r 正则图 |E| = nr/2（须为整数）。
  • 自补图：先算应有边数 n(n−1)/4（必须为整数 ⇒ n ≡ 0 或 1 mod 4），再构造/验证与补图同构。
  • 邻接矩阵读图：列矩阵 → 数边（无向图元素和 ÷ 2）→ 求各顶点度（行和；有向图行和=出度、列和=入度）→ 判断完全图/零图/是否有环。
  • 求 Aᵏ / 判连通：按矩阵乘法算 A²、A³…；Aᵏ 单元格 = 长度为 k 的通路数；把 A + A² + … + A^(n−1) 中非零处标 1，即得可达矩阵，从而判断连通/连通分支。
  • 通路的计数：用 Aᵏ 元素直接回答"从 vᵢ 到 vⱼ 长度为 k 的通路有几条"；若要问"是否存在"则只用布尔运算。
