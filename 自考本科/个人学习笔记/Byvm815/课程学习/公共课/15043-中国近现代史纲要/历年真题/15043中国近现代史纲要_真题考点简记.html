〇、一页知识地图（先看这一页）

0.1 四大历史阶段（全课程一棵树）

  • 第一阶段 旧民主主义革命（1840—1919）—— "列强怎么打进来，中国人怎么找路"
  • 列强侵略线：鸦片战争（1840）→《南京条约》→ 第二次鸦片战争 → 甲午战争 →《马关条约》→ 八国联军 →《辛丑条约》（完全沦为半殖民地半封建社会）
  • 抗争与探索线：太平天国（1851）→ 洋务运动（1861）→ 戊戌维新（1898）→ 辛亥革命（1911）
  • 思想启蒙线：魏源《海国图志》（师夷长技以制夷）→ 严复《救亡决论》→ 邹容《革命军》→ 三民主义 → 新文化运动（1915，民主与科学）
  • 转折点：五四运动（1919）＝ 新民主主义革命的开端
  • 第二阶段 新民主主义革命（1919—1949）—— "三次国内革命战争 + 一次民族战争"
  • 大革命（1924—1927）：中共一大／二大／三大 → 国民党一大 → 北伐 → 大革命失败
  • 土地革命战争（1927—1937）：南昌起义 → 八七会议 → 井冈山 → 长征 → 遵义会议（生死攸关的转折点）
  • 抗日战争（1937—1945）：七七事变 → 洛川会议 → 《论持久战》→ 中共七大（毛泽东思想写入党章）→ 抗战胜利
  • 解放战争（1945—1949）：重庆谈判 → 三大战役 → 渡江战役 → 七届二中全会 → 中华人民共和国成立
  • 第三阶段 社会主义革命和建设（1949—1978）—— "从新民主主义到社会主义"
  • 巩固政权（抗美援朝、土改、三反五反）→ 过渡时期总路线（一化三改） → 三大改造（1956 社会主义基本制度确立） → 《论十大关系》、中共八大 → 曲折（大跃进、"文革"）
  • 第四阶段 改革开放和社会主义现代化建设新时期（1978— ）—— "两个一百年"
  • 十一届三中全会（1978.12）＝ 开启改革开放新时期 → 十三大"三步走" → 十四大社会主义市场经济体制 → 十八届三中全会全面深化改革 → 十八大以来进入新时代 → 二十大中国式现代化

一、时间轴主线（【必背】单选就是沿着这条线出的）

  • 1840—1842 鸦片战争 → 1842《南京条约》（中国近代史上第一个不平等条约）
  • 1843 魏源《海国图志》，提出 "师夷长技以制夷"
  • 1851 金田起义（太平天国爆发）→ 1853 定都天京 → 1856 天京事变（太平天国由盛转衰的转折点）
  • 1856—1860 第二次鸦片战争 → 1860 英法联军火烧圆明园
  • 1861 洋务运动兴起（冯桂芬最先完整表述洋务派指导思想）
  • 1888 北洋水师（洋务派新式海军主力）
  • 1894—1895 甲午战争 → 1895《马关条约》（割让台湾）→ 1895 严复《救亡决论》喊出"救亡"口号
  • 1898 戊戌维新运动（百日维新）
  • 1900 八国联军侵华 → 1901《辛丑条约》（中国完全沦为半殖民地半封建社会）
  • 1903 邹容《革命军》（提出建立"中华共和国"）
  • 1905 中国同盟会成立（机关报 《民报》），孙中山提出三民主义
  • 1911 武昌起义 → 1912 中华民国成立、颁布《中华民国临时约法》→ 清帝退位（结束两千多年君主专制制度）
  • 1913 二次革命 → 1914 中华革命党反袁 → 1915 护国运动（蔡锷）→ 1917 护法运动
  • 1915 新文化运动兴起（陈独秀在上海创办 《青年杂志》，后改名《新青年》，提倡民主与科学）
  • 1919 五四运动（新民主主义革命的开端；直接导火线＝巴黎和会上中国外交的失败）→ 马克思主义广泛传播（李大钊、杨匏安、李达、蔡和森）
  • 1921 中共一大（中国共产党成立）→ 1922 中共二大（第一次提出反帝反封建的民主革命纲领）→ 1923 中共三大（决定共产党员以个人身份加入国民党，实现国共合作）
  • 1924 国民党一大（国共合作正式形成）→ 1925 广州国民政府成立、国民革命军建立 → 1926 北伐
  • 1927 大革命失败 → 8 月 1 日南昌起义 → 8 月 7 日八七会议（确定土地革命和武装斗争的方针）→ 9 月秋收起义 → 10 月井冈山革命根据地创建
  • 1928 张学良东北易帜（国民党在全国统治的建立）
  • 1930《星星之火，可以燎原》（毛泽东提出以乡村为中心）
  • 1931 九一八事变（日本发动侵略战争）
  • 1933 福建事变（蔡廷锴、蒋光鼐在福州抗日反蒋）
  • 1934—1936 红军长征 → 1935.1 遵义会议（党的历史上生死攸关的转折点）
  • 1937.7 七七事变（全民族抗战开始）→ 1937.8 洛川会议（通过 《抗日救国十大纲领》）→ 1937.12 南京大屠杀
  • 1938 台儿庄战役（抗战以来正面战场重大胜利）
  • 1940 枣宜会战（张自忠以身殉国）
  • 1945 抗日战争胜利；1945 中共七大（毛泽东思想确立为指导思想）；1945 董必武出席联合国制宪会议（解放区代表）
  • 1945.8—10 重庆谈判（《双十协定》）→ 1946 国民党发动全面内战 → 1948—1949 三大战役 → 1949.4 渡江战役、南京解放
  • 1949.3 中共七届二中全会（毛泽东提出"两个务必"）→ 1949.9 人民政协通过《共同纲领》 → 1949.10.1 中华人民共和国成立
  • 1950—1953 抗美援朝；1950—1952 土地改革；1951—1952 "三反""五反"运动
  • 1953 党提出过渡时期总路线（"一化三改"）→ 1953—1957"一五"计划（集中主要力量发展重工业）
  • 1953—1956 三大改造：个体农业（互助组→初级社→高级社）、手工业、资本主义工商业（和平赎买）→ 1956 社会主义基本制度确立
  • 1956《论十大关系》（处理党派关系方针＝长期共存、互相监督）；中共八大
  • 1957 反右派运动 → 1958 大跃进、人民公社化 → 1961—1965 国民经济调整 → 1964 提出"四个现代化"
  • 1966—1976"文化大革命"（导火线＝1966 年"五一六通知"的发表）
  • 1978.12 中共十一届三中全会（开启改革开放和社会主义现代化建设新时期）
  • 1979.1.1《告台湾同胞书》；1979.3 邓小平提出四项基本原则
  • 1981 中共十一届六中全会（通过《关于建国以来党的若干历史问题的决议》）
  • 1984 中共十二届三中全会（通过《中共中央关于经济体制改革的决定》）
  • 1987 中共十三大（"三步走"发展战略）
  • 1988 海南经济特区设立
  • 1992 邓小平南方谈话 → 中共十四大（确立社会主义市场经济体制改革目标）
  • 1997 香港回归；1999 澳门回归
  • 2001 中国正式加入世界贸易组织
  • 2002 中共十六大（21 世纪头二十年全面建设小康社会）
  • 2005.3 十届全国人大三次会议通过 《反分裂国家法》
  • 2012 中共十八大（中国特色社会主义进入新时代的标志）
  • 2013.11 中共十八届三中全会（通过《中共中央关于全面深化改革若干重大问题的决定》）
  • 2017 中共十九大（习近平新时代中国特色社会主义思想确立为指导思想）
  • 2018 庆祝改革开放 40 周年大会
  • 2021 建党百年、全面建成小康社会（第一个百年奋斗目标实现）
  • 2022 中共二十大（以中国式现代化全面推进中华民族伟大复兴）

六、【必背】原因 / 经验 / 内容类

1. 原因类

  • 旧民主主义时期反侵略斗争失败的主要原因：社会制度的腐败（更根本的原因）；经济技术的落后。
  • 太平天国失败的根本原因：缺乏先进阶级的领导（农民阶级的局限性）。
  • 抗日战争胜利的主要原因：以爱国主义为核心的伟大民族精神是决定因素；中国共产党的中流砥柱作用是关键；全民族抗战是重要法宝；同世界反法西斯力量的同情和支持分不开。
  • 资产阶级维新派自身的弱点和局限：不敢否定封建主义；对帝国主义抱有幻想；惧怕人民群众。
  • 洋务运动失败的原因：封建性（"中体西用"）；对外国依赖性强；管理腐朽。
  • 过渡时期总路线反映历史必然的原因：社会主义工业化是国家独立富强的首要条件；资本主义经济力量弱小，不可能成为中国工业起飞的基础；对个体农业进行社会主义改造是保证工业化的必要条件。

2. 经验 / 结论类

  • 新民主主义革命胜利的基本经验：坚持无产阶级及其政党中国共产党的坚强领导；坚持马克思主义基本原理同中国具体实际相结合、推进马克思主义中国化；统一战线、武装斗争、党的建设是战胜敌人的三个法宝。
  • 中国共产党百年奋斗的历史经验：十个坚持——坚持党的领导、坚持人民至上、坚持理论创新、坚持独立自主、坚持中国道路、坚持胸怀天下、坚持开拓创新、坚持敢于斗争、坚持统一战线、坚持自我革命。
  • 鸦片战争后近代中国社会性质：半殖民地半封建社会。
  • 中国特色社会主义最本质的特征：中国共产党的领导。

3. 内容 / 措施类

  • "五反"运动的内容（1952）：反对行贿、偷税漏税、盗窃国家财产、偷工减料、盗窃经济情报。
  • "三反"运动：反贪污、反浪费、反官僚主义（与"五反"不要混）。
  • 中国共产党早期组织所开展的主要工作：研究和宣传马克思主义；到工人中宣传和组织；进行建党问题的讨论和实际组织工作。
  • 中国各民主党派形成时期的社会基础和性质：社会基础＝民族资产阶级、城市小资产阶级及其相联系的知识分子和其他爱国分子；性质＝阶级联盟性质的政党。
  • 四项基本原则（1979，邓小平）：坚持人民民主专政、共产党的领导、马克思列宁主义毛泽东思想；是实现四个现代化的根本前提。
  • 中共二大的最低纲领和最高纲领：见第二节。
  • 国民党政权独裁统治的主要表现（1927 年后）：建立庞大的军队和全国性特务系统；推行保甲制度；厉行文化专制主义。
  • 新中国成立初期中共面临的主要问题和考验：能否保卫革命胜利成果、巩固新生人民政权；能否战胜严重经济困难、迅速恢复发展国民经济；能否巩固民族独立、维护国家主权安全；能否经受全国执政新考验、保持优良传统作风。

4. 评价 / 史实类

  • 中华民国临时政府的性质与局限：性质＝资产阶级共和国性质的革命政权，革命派占领导主体；局限＝未废除不平等条约、未满足农民的土地要求。
  • 《天朝田亩制度》的意义和局限性：见第三节。
  • 辛亥革命失败后革命派进行的武装斗争：1913 二次革命；1914 组织中华革命党坚持反袁；1915 蔡锷发动护国运动；1917 成立护法军政府、护法运动；1919 改组为中国国民党。
  • 抗日战争胜利后中国国内的三种建国方案：大地主大资产阶级专政（国民党）；资产阶级共和国（中间派别）；工人阶级领导的人民共和国（中国共产党）。
  • 新中国成立初期巩固政权的措施：抗美援朝、土地改革、镇压反革命、"三反""五反"。
