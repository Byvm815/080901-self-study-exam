0.2 四条贯穿全课的主线

主线 1：三种存储结构 ＋ 一种特殊存储（第 1、2 章）

存储方式 逻辑相邻是否物理相邻 存取方式 插入删除代价 典型考点
顺序存储 一定相邻 随机存取 需移动元素（插入 n−i+1、删除 n−i） 地址公式、移动次数、二分查找前提
链式存储 不一定相邻 顺序存取 只改指针（先连后断） 判空、指针操作、静态链表
索引存储 — 先查索引再查数据 需维护索引表 分块查找：块间有序、块内无序
散列（哈希）存储 — 按关键字直接算地址 需处理冲突 散列函数、ASL 与装填因子

主线 2：顺序表 vs 链表，怎么选（第 2 章，大题第 ⑧ 类模板的原题）

判据 选顺序表 选链表
主要操作 查找多（随机存取、O(1)） 插入删除多（改指针即可）
表长变化 长度基本固定 长度变化大、难以预估
存储开销 无指针域，但需预分配 有指针域开销，可动态增长

主线 3：排序算法总表（第 7 章最重要的一张表）

排序方法 平均时间 最坏时间 辅助空间 稳定性 一句话特征
直接插入排序 O(n²) O(n²) O(1) 稳定 基本有序时最快；可用哨兵 r[0]
起泡（冒泡）排序 O(n²) O(n²) O(1) 稳定 相邻比较交换；趟数固定
简单选择排序 O(n²) O(n²)（与初始无关） O(1) 不稳定 每趟选最小放到前面；比较次数恒为 n(n−1)/2
希尔排序 O(n^1.3) O(n²) O(1) 不稳定 缩小增量的插入排序（增量可 ×1/3）
快速排序 O(n log n) O(n²) O(log n) 不稳定 平均最快；以基准划分
堆排序 O(n log n) O(n log n) O(1) 不稳定 空间最省；升序建大根堆
归并排序 O(n log n) O(n log n) O(n) 稳定 效率高又稳定；适合链式存储；分治
基数排序 O(d(n+r)) O(d(n+r)) O(r) 稳定 不比较关键字
  • 口诀：稳定只有「插、泡、归、基」；O(n log n) 是「快、堆、归」；空间最省是堆、最费是归。
  • 三个固定搭配：基本有序 → 直接插入或冒泡；高效且稳定 → 归并；高效且省空间 → 堆排序。

主线 4：查找三结构 ＋ 哈希（第 8 章）

查找方法 前提条件 ASL（等概率） 最大比较次数 存储
顺序查找 无要求（元素能比较即可） (n+1)/2 n 顺序／链式皆可
二分（折半）查找 有序 ＋ 顺序存储 log₂(n+1) − 1 ⌊log₂n⌋ + 1 必须顺序表
分块（索引顺序）查找 块间有序、块内无序 索引表 ＋ 块内 — 索引方法存储
BST 查找 建二叉排序树 Σ(深度×概率) 树高（最坏 n） 二叉链表
哈希查找 选好散列函数 与装填因子有关，与 n 无关（最好 O(1)） 由冲突处理定 数组

第 1 章 绪论（8 空）

本章知识地图：数据结构三要素（逻辑结构 ＋ 存储结构 ＋ 运算）→ 线性/非线性 → 术语 → 算法 5 特性 → 复杂度。一句话：本章只考「定义 ＋ 特性 ＋ 复杂度」三件事。

线性结构与非线性结构的判定（2 空）

关系说明：同一个判定的两种问法——正面问「叫什么」，反面问「特征是什么」。记忆钩子：线性＝一对一；树＝一对多；图＝多对多；集合＝无逻辑关系。

  • 数据元素之间存在先后次序关系的结构　→　线性结构（A#25）
  • 非线性结构结点间一对多或多对多的关系　→　一对多（C#11）

算法的时间复杂度与空间复杂度（1 空）

  • 执行时间与问题规模n无关时常数的时间复杂度　→　O(1)（B#11）

数据类型与抽象数据类型（1 空）

关系说明：数据类型分 原子类型 与 结构类型；再往上就是 ADT（定义＋实现分离）。

  • 数据类型分为原子类型和____　→　结构类型（B#12）

数据的逻辑结构与存储结构（2 空）

关系说明：同一件事的两问：运算定义在哪个结构上 ＋ 数据结构包含哪三方面。一句话：「运算定义在逻辑结构上，实现落在存储结构上」。

  • 数据的运算定义在数据的何种结构上　→　逻辑结构（C#12）
  • 数据结构一般包括＿＿、存储结构和数据运算三个方面的内容。　→　逻辑结构（D#20）

算法的五个特性（1 空）

  • 算法的每一个步骤都必须有确切的含义，这个特性是算法的＿＿。　→　确定性（E#16）

数据结构基本术语（数据/数据元素）（1 空）

关系说明：术语层：数据 → 数据元素 → 数据项。数据＝所有能输入计算机并被处理的符号的集合。

  • 在计算机科学中，＿＿是指所有能输入计算机并被计算机处理的符号的集合。　→　数据（E#17）

第 2 章 线性表（9 空）

本章知识地图：线性表的术语 → 顺序表（地址公式、移动次数） → 链表（判空、指针、静态链表） → 选型。一句话：本章＝「一个公式（地址）＋ 一个计数（移动次数）＋ 两条指针语句」。

顺序表/一维数组的地址计算（3 空）

关系说明：本课程第一大填空桶（3 空）。同一个公式反复考：Loc(a_i) ＝ SA ＋ (i−1)×d（下标 1 起）或 SA+ i×d（下标 0 起）。核对问的是「首地址」还是「末地址」。

  • 每元素占8单元、首地址100时第6元素末地址　→　147（A#26）
  • 将100个数据元素保存在顺序表中，第一个元素地址是1000、第二个是1004，则最后一个元素的存储地址是＿＿。　→　1396（D#24）
  • 一维数组a顺序存储、下标从0开始，每个元素占4个存储单元，a[8]的起始地址为100，则a[11]的起始地址为＿＿。　→　112（E#19）

线性表的存储结构（顺序/链式/静态链表）（1 空）

关系说明：顺序（随机存取）／链式（顺序存取）／静态链表（用数组实现链表）——后两种是「用数组装链式」的对比。

  • 在数组中保存的链表称为　→　静态链表（A#27）

单链表的结构与判空（1 空）

关系说明：带头结点 head->next==NULL；不带头结点 head==NULL；带头结点循环链表 head->next==head。三句话一起记。

  • 带头结点单链表为空的判断条件　→　head->next==NULL（B#13）

顺序表插入删除的移动次数（1 空）

关系说明：插入 n−i＋1、删除 n−i；平均移动 n/2 与 (n−1)/2。

  • 长度n顺序表第i个位置插入元素的移动次数　→　n-i+1（B#14）

线性表的基本术语与元素（2 空）

关系说明：表头（无前趋）· 表尾/终端元素（无后继）· 前趋 · 后继 · 数据元素。

  • 线性表中没有后继的终端元素　→　终端元素（B#15）
  • 线性表是一个有限序列，组成线性表的是n(n≥0)个＿＿。　→　元素（E#18）

单链表的指针操作（1 空）

关系说明：插入：s->next = p->next; p->next = s;（顺序不能颠倒）；删除：q = p->next; p->next = q->next; free(q);

  • 单链表结点存储地址存放在哪个结点的指针域　→　直接前趋（C#13）

第 3 章 栈和队列（1 空）

本章知识地图：栈（LIFO）→ 出栈序列合法性 → 应用（括号匹配、中缀转后缀、后缀求值）；队列（FIFO）→ 循环队列判空判满判长 → 链式队列。一句话：本章填空很少，但解答题必出 1—2 道。

队列的存储与实现（1 空）

关系说明：链式队列 ＝ 带头指针 ＋ 尾指针的单链表；与循环队列的判空判满一起记。

  • 链式队列采用带头指针及尾指针的____　→　单链表（A#30）

第 4 章 数组、广义表和串（6 空）

本章知识地图：多维数组（行/列优先 ＋ 地址计算）→ 特殊矩阵与稀疏矩阵 → 广义表（head/tail/长度/深度、递归性） → 串。一句话：本章＝「数组的数位置 ＋ 广义表的剥壳」。

广义表的表头/表尾/长度/深度（1 空）

关系说明：四条铁律：① 长度＝最外层元素个数；② head 取第一个元素本身；③ tail 一定带括号；④ 深度＝括号嵌套层数（原子 0、空表 1）。

  • 广义表G=(a,b,(c,d,(e,f)),g)的长度　→　4（A#29）

多维数组的行/列优先存储（2 空）

关系说明：行优先 / 列优先两种存法：Loc(A[i][j]) ＝ SA ＋ (i×列数＋j)×d（行优先）；列优先时先数完整列。

  • 3×8数组按行优先存储的第10个元素　→　N[1][1]（B#16）
  • 数组在C语言中按何种优先顺序存储　→　行（C#14）

特殊矩阵与稀疏矩阵（1 空）

关系说明：特殊矩阵（对称/三角/对角，压缩有规律）／ 稀疏矩阵（非零元素远少于总数 → 三元组表、十字链表）。

  • 非零元素个数远小于元素总数的矩阵名称　→　稀疏矩阵（C#15）

广义表的定义与性质（2 空）

关系说明：递归性（描述中用到了自身）＋ 求 head(head(A)) 这类逐层剥壳。

  • 广义表描述中用到自身所体现的性质　→　递归（C#16）
  • 广义表A=(((a,b),(c,d,e)),(f,g),h)，函数 head(head(A)) 的结果是＿＿。　→　(a,b)（D#16）

第 5 章 树与二叉树（5 空）

本章知识地图：树的性质与术语 → 二叉树 5 条性质 ＋ n₀＝n₂＋1 → 遍历与还原 → 存储（空指针域 n＋1）→ 哈夫曼树、堆、二叉排序树 → 树/森林/二叉树转换。一句话：本章是第二大章，「性质 ＋ 遍历还原」是主力。

二叉树的性质与形态数（2 空）

关系说明：性质 ＋ 计数一起考：n₀ ＝ n₂ ＋ 1、n ＝ n₀＋n₁＋n₂；n 个结点的二叉树形态数＝卡特兰数（3 个结点 5 种）。

  • 20个结点含5个叶结点时度为1的结点数　→　11（A#31）
  • 3个结点的不同形状的二叉树有＿＿棵。　→　5（D#25）

树与森林的相互转换（1 空）

关系说明：树 → 二叉树 「左孩子右兄弟」；删去树根即得森林；树的先根遍历 ↔ 二叉树先序，树的后根遍历 ↔ 二叉树中序。

  • 删除树的根结点后得到的结构　→　森林（C#17）

堆与堆排序（1 空）

关系说明：升序建大根堆、降序建小根堆；从最后一个非叶结点 ⌊n/2⌋ 起向前「筛选」下沉。

  • 采用堆排序算法对数据序列进行升序排序时，首先应对初始数据建立＿＿根堆。　→　大（D#17）

哈夫曼树与带权路径长度（1 空）

关系说明：结点总数 2n−1（n 个叶结点）；WPL 只算叶结点；没有度为 1 的结点；每次取两个最小权值合并。

附二、易混点速查（做成表，按章排）

2.1 绪论与线性表

对照项 一句话判别
逻辑结构 vs 存储结构 逻辑结构面向问题、独立于存储；说「一一对应」＝错
顺序存储 vs 链式存储 逻辑相邻 → 顺序存储一定物理相邻，链式存储不一定
随机存取 vs 顺序存取 顺序表随机、链表顺序
插入 vs 删除移动次数 插入 n−i＋1、删除 n−i
带头结点 vs 不带头结点判空 head->next==NULL vs head==NULL
时间复杂度与什么有关 只与问题规模有关，与语言／硬件／编译程序无关

2.2 栈、队列、数组、广义表

对照项 一句话判别
栈 vs 队列 LIFO vs FIFO
循环队列 空 front==rear；牺牲一个单元时满 (rear+1)%m==front；长 (rear−front+m)%m
出栈序列合法性 出现「小、大、更小」的交叉倒置即非法
后缀表达式求值 只需一个栈（保存操作数及运算结果）
栈顶在数组高端 top 初值为 n+1 时进栈是 top--; data[top]=x;
head / tail tail(A) 一定带括号；head(tail(A)) 先剥一层再取第一个
广义表深度 嵌套层数（原子 0、空表 1、最外层括号算 1 层）
串 vs 一般线性表 串的特殊性在于数据元素是一个字符
矩阵压缩存储的目的 节省存储空间

2.3 树与二叉树

对照项 一句话判别
满二叉树 vs 完全二叉树 满＝结点最多 2^k−1；完全＝只有最下两层可不满且左集中
二叉树 vs 度为 2 的树 二叉树的子树有严格的左右之分；二叉树可以是空树，度为 2 的树不能为空树
n₀ 与 n₂ n₀ ＝ n₂ ＋ 1
二叉链表空指针域 n＋1（n 个结点）
唯一确定二叉树 必须含中序（前序＋后序不行）
树的先根 / 后根 树的先根 ↔ 二叉树先序；树的后根 ↔ 二叉树中序
森林 → 二叉树 第一棵树作左子树，其余树构成右子树（结点数＝m2+m3+…）
哈夫曼树 结点总数 2n−1；WPL 只算叶结点；无度为 1 的结点
建堆方向 升序建大根堆、降序建小根堆

2.4 图

对照项 一句话判别
度之和 Σd ＝ 2e，一定是偶数
边数极值 完全无向图 n(n−1)/2；有向完全图 n(n−1)；连通图最少 n−1；非连通简单图最多 (n−1)(n−2)/2
邻接矩阵 无向图对称；行和＝出度、列和＝入度，度＝出度＋入度
Prim vs Kruskal Prim 适合稠密图、Kruskal 适合稀疏图；MST 不唯一但权值和最小
AOV vs AOE AOV 顶点表活动（拓扑排序）；AOE 弧表活动（关键路径）；可拓扑排序 ⇒ 无环图
Dijkstra vs Floyd 单源 vs 全对；Dijkstra 不能有负权

2.5 排序与查找

对照项 一句话判别
稳定排序 只有「插、泡、归、基」
高效三兄弟 快排（平均）· 堆排 · 归并；空间最省＝堆（O(1)）、最费＝归并（O(n)）
选算法的固定搭配 基本有序 → 插入/冒泡；高效且稳定 → 归并；高效且省空间 → 堆；不比较 → 基数
比较次数与初始序列 简单选择排序恒为 n(n−1)/2（与初始无关）；起泡、插入与初始有关
一趟后元素是否就位 直接插入排序不保证；快速、堆、起泡每趟能选出一个元素到最终位置
折半查找 前提 有序 ＋ 顺序存储；最大比较次数 ⌊log₂n⌋＋1
分块查找 前提 块间有序、块内无序，且用索引方法存储
B 树 非根非叶关键字 ⌈m/2⌉−1 ～ m−1（25 阶 → 至少 12 个）；叶同层；插入只在最底层
哈希 冲突＝关键字不同而哈希函数值相同；最好 O(1)；ASL 只与装填因子有关

附三、考前 30 分钟清单（只看这一页）

  • 复杂度排序：O(1) ＜ O(log n) ＜ O(n) ＜ O(n log n) ＜ O(n²) ＜ O(2ⁿ) ＜ O(n!)
  • 地址公式：行主序 SA + (i×列数 + j)×d（下标 0 起）；对称矩阵 i≥j 时 k ＝ i(i+1)/2 ＋ j；上三角元素个数 n(n+1)/2
  • 顺序表：插入移动 n−i＋1、删除移动 n−i；平均移动 n/2 与 (n−1)/2
  • 循环队列：空 front==rear；满 (rear+1)%m==front；长 (rear−front+m)%m
  • 中缀→后缀：(8+2*5)/7 ⇒ 8 2 5 * + 7 /；后缀求值只需一个栈
  • 二叉树 5 性质：第 i 层 ≤ 2^(i−1)；深 k 至多 2^k−1；n₀＝n₂＋1；深 ⌊log₂n⌋＋1；顺序存储 i ↔ 2i、2i+1
  • 形态数：3 个结点二叉树 5 种；空指针域 ＝ n＋1；唯一确定：前序＋中序／后序＋中序
  • 哈夫曼：结点 2n−1、WPL 只算叶结点
  • 树的先根 ↔ 二叉树先序；树的后根 ↔ 二叉树中序
  • 图：Σ度＝2e；n(n−1)/2、n(n−1)、n−1、(n−1)(n−2)/2；e ∈ [n−1, n(n−1)/2]
  • Prim 稠密、Kruskal 稀疏；Dijkstra 单源、Floyd 全对；可拓扑排序 ⇒ 无环图
  • 稳定排序：直接插入、起泡、归并、基数；简单选择恒 n(n−1)/2
  • 折半查找最大比较次数 ＝ ⌊log₂n⌋＋1（100 个元素不成功最多 7 次）
  • BST 中序有序；AVL 平衡因子绝对值 ≤ 1；LL 右旋、RR 左旋、LR 先左后右、RL 先右后左
  • B 树：25 阶非根结点关键字 12 ～ 24；叶同层；插入只在最底层
  • 哈希：除留余数 H(key)=key % p（p 取不大于表长的最大质数）；ASL 与 n 无关、与装填因子有关
